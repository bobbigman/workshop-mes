# 客户独立部署 — 开通与运维清单（docs/23 P0）

> 配套配置模板：`appsettings.Trial.template.json`  
> 托管形态：IIS 站点 + 独立应用程序池（对齐 docs/05）。

## 一、开通前先锁死

- [ ] 试用服务器可用
- [ ] 子域名 / 主机名（如 a.example.com）
- [ ] HTTPS 证书来源
- [ ] SQL Server 实例位置与备份盘（建议异盘）

## 二、新客户开通清单

客户代码（Instance:Code）：____________  
显示名称：____________  
工厂代码：____________  
公网网址：____________  
内部端口 / IIS 绑定：____________  

1. [ ] 建库 `Mes_{Code}`，建运行账号仅本库权限（不用 sa）
2. [ ] 目录：`D:/MesTrials/{Code}/app|data|logs`
3. [ ] 放入标准发布包；从模板生成 `appsettings.json`（Jwt Issuer=`mes-{Code}`，Audience=`mes-{Code}-app`）
4. [ ] 首次：`BootstrapOnStartup=true` + 管理员初始密码；启动一次后改为 `false` 并重启
5. [ ] IIS：独立站点 + 独立应用池，绑定主机名；工作目录指向该客户 `app`
6. [ ] 反向代理 / HTTPS；数据库端口不对公网
7. [ ] 验证：登录页显示客户名；账号密码可登录；改 factoryCode 不能换厂
8. [ ] 与另一实例交叉：甲 token 调乙 → 401；停甲不影响乙
9. [ ] 台账登记（不含明文密码）；交付网址与初始密码，要求改密

**禁止**：从甲客户库克隆乙试用库；复制含密码的配置；多实例共用 Jwt Secret。

## 三、日常操作（单实例）

| 动作 | 方法 |
|---|---|
| 停 / 启 / 重启 | IIS 管理器 → 对应应用池 或 `appcmd` |
| 看日志 | `{实例}/logs`（`ErrorLogging:Directory`，文件 `mes-error-yyyyMMdd*.log`）；按响应/`msg` 中的追踪号搜索；另可看 IIS 日志 |
| 到期停用 | 停应用池或摘掉主机名绑定；**不删库** |
| 续期 | 启应用池 / 恢复绑定 |

## 四、升级（逐实例）

1. 备份该实例数据库 + `app` 目录 + 附件
2. 停应用池
3. 替换程序文件（保留该客户 `appsettings.json` 与 data/logs）
4. 启应用池；冒烟登录与报工
5. 失败则回滚程序与库到备份版本

脚本须显式接收实例路径；不得默认停全部实例或删库。

不写明文密码、Jwt Secret、连接串密码。

## 六、迁到客户电脑（摘要）

停写 → 停该实例 → 备份库/附件/配置 → 客户机 IIS + SQL 恢复 → 改连接串、PublicBaseUrl、**新 Jwt Secret/iss/aud** → 验 PDA → 云端保持停用、禁双写。  
详见 docs/23 §9、docs/1E §8。
