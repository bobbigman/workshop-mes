# 智能客服 · 知识发布样例目录

> 本目录是「智能客服」与「扣子 MCP `search_support_docs`」的**同一套知识发布样例**。部署时把整个目录复制到服务器上配置的
> `Ai:SupportDocs:RootPath`（示例 `D:\MES\SupportDocs`），PC 客服与扣子助手都只读这个目录，不读仓库 docs 根目录；**不要**再在扣子云端另传一份当主副本。

## 一、文件格式约定

- 只支持 **UTF-8 编码**的 `.md`、`.txt` 文件；其它扩展名一律忽略。
- 文件开头用 YAML front matter 标注元信息，约定字段如下：

```markdown
---
title: 报工与复核
role: 管理员
version: 1.0
systemVersion: 当前部署版本
updatedAt: 2026-09-20
---
```

| 字段 | 含义 | 备注 |
|---|---|---|
| title | 文档标题 | 必填 |
| role | 适用角色 | 如「管理员」「班组长」「生产人员」，可写「全员」 |
| version | 文档版本 | 必填；缺失时客服显示「未标注版本」 |
| systemVersion | 适用系统版本 | 便于判断文档是否过时 |
| updatedAt | 更新时间 | 必填，`yyyy-MM-dd` |

- 正文用 Markdown 标题（`#`、`##`、`###`）分章节，检索按标题/章节切分与加权。
- 每篇内容尽量包含：**菜单路径 → 操作步骤 → 前置条件 → 常见失败原因**。
- 不得写入部署凭据、默认密码、数据库连接串、密钥等敏感内容。
