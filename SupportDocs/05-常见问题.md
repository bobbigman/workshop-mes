# 常见问题

## 网页打不开、登录失败

网页打不开：查工厂网络和地址，问同事能否打开；都打不开就找服务器维护人员。

账号密码错误：核对账号和密码大小写，忘记密码由管理员在【系统配置 → 用户 → 编辑】重设。

登录失效：重新登录后回原页面查记录。不能因为重新登录就把刚才那批再报一遍。

## 提示无报工权限

1. 管理员到【系统配置 → 部门】，确认人员在正确部门【成员】中。
2. 再到【基础数据 → 工序 → 编辑】，确认【报工权限】选了这个部门。
3. 保存后由实际操作人员重新打开工单检查。

管理员不受部门限制，班组长受限制。不要为报一道工序把工人改成管理员。

## 超出计划数、剩余可报为零

1. 检查工序是否选对，本次良品是否误填累计数。
2. 管理员查计划和有效报工（待复核、已通过的）：待复核、已通过都占上限，退回不占。
3. 订单计划真有变更，由管理员核实后调整；原记录错了，按改数流程纠正。

不要用不良数、换工序或换工单绕过限制。不良数只记真实不合格件。

## 有不良品却选不到原因

不良品大于 0 必须选原因。管理员先在【基础数据 → 不良品项】建立原因，再到【工序 → 编辑 → 不良品项】选上保存。

现场重新打开工单选工序后查看。没有正确原因时，不要随便选别的凑数。

## PDA / 摄像头没反应、工单不存在

1. 打开底部【扫码】。手机点【打开摄像头扫码】并允许权限；PDA 切【扫码枪模式】，确认扫码头按键盘方式输入并自动回车。
2. 避反光、换角度，确认二维码没污损。
3. 用【手动输入工单号】填纸上编号并【确定】。手动能开而扫码不行，请管理员查标签内容、扫码头或 HTTPS/证书。
4. 扫出整段网址时：网页摄像头可识别本站报工链接；PDA 标签更建议【工单号（PDA）】。也可用系统相机直接打开链接。
5. 编号仍不存在，管理员核对本厂地址及工单是否建立。

摄像头打不开多半是 HTTP 访问或未信任证书；配置 HTTPS 并信任证书后，扫码页可调用手机摄像头。普通手机也可用工单列表或手动输入。

## 扫码一定要扫工单码吗？工序码（工位码）怎么用？

不是。流转卡有两种码：**工单码**（一张单一张，扫完进报工页自己选工序）和**工序码 / 工位码**（管理员打印设置里选「按工序」，每道工序各出一张标签、标着工序名，贴到工位上）。扫**工序码**会**自动预选好那道工序**，工人直接填数量提交，少点一步。

默认打印的仍是工单码 / 报工页链接，只有主动选「按工序」才出工序码；已印的旧卡照样能扫。扫到工序码不会自动提交报工，还是要核对后填数提交；码扫不出或工序找不到，自动退回手动选工序，不报错。

## 报工后生产报表为什么没增加

先到【生产管理 → 报工】按工单查询复核状态。

- 待复核：计进度但未进报表，请班组长或管理员核对通过。
- 已退回：不计有效进度和报表，核对原因修改原记录再复核。
- 已通过：再查报表是今日、本月还是上月。按原报工时间统计，今天复核昨天的记录，不算今天报工。

不要为了让报表增加重复报工。

## 完成数为什么是 80，不是 180

有任务时工单完成数取各道有效良品（待复核和已通过的报工）最少值。例如裁切 100、包装 80，工单为 80；还有一道检验没报，最少值就是 0。

看板与工单详情、列表用同一个最少值口径：这张单显示 80，不会显示 180。「工序达成进度」取各正计划工序（良品/计划）的最小值（0～100%）。生产报表只计已通过。比较数字先确认页面和统计口径。

旧工单如果没有工序任务，打开详情时会尝试按产品路线补出任务；确实没有路线和任务时，列表会按该单有效良品合计显示，不能套用“各道取最少”。先找管理员检查产品路线，不要把没有任务当成已完成。

## 工单找不到、结束后又变执行中

找不到：完整工单号查询，再切状态。【全部】不含已取消，取消单到【已取消】查；手机没有已取消页签，找管理员。

状态变动：有效报工更新进度，各道报满可自动结束；退回、改数减少有效量后可能回执行中或未开始，管理员也能手动结束、撤回。

核对原报工数量、复核状态和工单详情，不把“已结束”当成“全已复核”。

## 报错了、不确定是否提交成功

记下工单、工序、人员、时间、本次数量和提示，管理员在【报工】查原记录。

已成功不再报；记录错了先退回已通过记录，再修改并复核；确认没保存才排错重报。

待复核记录在手机【我的报工】可自己撤回改，改后仍待复核、留痕可查；已通过的先退回再改；已结算记录不能直接退回或改数。不要报负数抵消或删工单纠错。

## 产品或基础资料删不掉

资料之间有关联。产品被工单使用、路线被产品使用时，会阻止直接删除。

1. 按提示确认哪项还在引用，交管理员核查。
2. 只是名字错了优先编辑，先判断是否真需删除。
3. 确需清理，由管理员按依赖处理：工单 → 产品定义 → 工艺路线 → 工序 → 不良品项 → 单位 → 部门。

不是让你为删产品把历史工单全删掉。涉及生产历史，先由负责人确认保留方式。

## 补报与改数有什么区别

已有记录填错用【修改】；实际完成但没记录才新增或补报。

【一键补报未完工序】在电脑【报工】页，仅管理员。对列出的所有未报满工序补同一良品数，上限为剩余量最小值，不自动认定前道已完成。

要记实际工人，勾【按工序拆分到人】，每道合计等于统一数；不拆分记当前管理员名下。

## AI 不能用、页面报服务器错误

AI 关闭、未配置或连接失败时仍可看本手册，正常工单报工不依赖 AI。AI 不能执行修改、补报、删除。

业务页面服务器错误：记录时间、页面、工单号、步骤和追踪编号，交管理员或维护人员查。不要把密码、密钥发给 AI。

提交报错先查是否生成记录，再决定重试。页面错误不代表数据一定没保存。

## 提示授权已过期 / 功能用不了（授权档限制）

系统按工厂授权档开放功能：入门款（trial）含下工单、派工、报工、车间看板；工资与工价、扫码报工、报工复核、交期预警/企微推送、打印标签、建议报价（接金蝶）等属更高档能力。

1. 顶栏出现「授权已过期或无法校验，高级功能暂不可用」：是授权到期/断网超过宽限，有效档临时降为入门款，现场报工与车间看板仍可用；联系部署方续费后重新登录即可恢复。
2. 低档登录后看不到某菜单/按钮（如工资、扫码、复核、微信预警、建议报价）：属该档不开放的高级功能，不是故障。升级档位需联系部署方，改档后重新登录生效。

不要为绕过限制把工人改成管理员。授权判定按工厂档位 + 用户角色两维，互不替代。

## 登录提示体验账套已到期

体验账套默认有效期 7 天，到期自动清空该厂全部资料（含上传的附件）并禁用所有账号登录，不可恢复。历史库、正式版、私有版不会触发。

需要保留数据，请在到期前联系部署方转正式版（企业版/旗舰版/私有版）。到期后没有保留或导出通道，只能重新开通体验或转正后重建。
