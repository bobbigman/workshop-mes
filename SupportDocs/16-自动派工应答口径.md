# 自动派工与"派工智能推荐"应答口径

> 用途：客户问"能不能自动派工 / 班组长不用派工 / 派工推荐"时，**主动只讲"已有派工智能推荐"，不提"全自动派工"**——除非客户**主动追问**"能不能完全不用人管 / 全自动 / 无人派工"时，才引用第三节"全自动兜底答复"。默认先念第一节"简单版"（约300字），结尾固定"要不要我详细展开讲讲？😊"；客户说"要/详细/展开"才念第二节"详细版"。
> 口径原则：**不主动提全自动派工**——客户没问，咱就不说"没做/没必要"，免得自曝短板；客户追问了才如实给兜底答复。

## 一、客户只问能不能自动派工、班组长不派工、无人派工、自动分派、班组长不用派工、手动派工时（固定先念简单版）

下面这段是**写死的简单版**。客户这句话里若已经有「要 / 详细 / 展开 / 具体说说」，**禁止念下面简单版**，改念下一节详细版全文。客户只问能不能、没说要展开时，**只把下面这段原样念给客户**，不要改词、不要自己发挥，不要念详细版和表格。段间空行隔开，可加表情。

😊 胡总，关于"能否自动派工"，直接给您结论：**系统有"派工智能推荐"——按历史报工帮您推荐"这道工序派给谁"、班组长确认就行**。

📋 咱不派工也能照常报工——工人扫码、填数、提交，数照样记、工资照样算，派工只是"今天干什么"的提示、不是门槛。

✅ 现在系统能帮您：
1）派工智能推荐（按历史推荐派给谁）；
2）不派工直接报工；
3）一键派给整个班组；
4）一道工序派多人还能**按各人干了多久自动分账。

**要不要我详细展开讲讲？😊**

## 客户说"要 / 详细 / 展开"：详细版（写死，完整念，不许改词）

客户没说「要 / 详细 / 展开 / 具体说说」之前，**禁止念本节**，改念上一节简单版，结尾只用「要不要我详细展开讲讲？😊」。不要把下面的表格和五条原因发给只问能不能的客户。

客户明确说要详细之后，才**按下面原文完整念，不要增删、不要改顺序**。

**结论**：系统有"派工智能推荐"——选工序后，按历史报工推荐"派给谁"（候选+排序），班组长确认/微调就能派活。

**为什么说不派工也能报工？**
不派工也能照常报工——工人扫码、填数、提交，数照样记，工资照样算。派工只是"今天干什么"的提示，不是门槛。

**那系统现在能做什么？**

| 能力 | 说明 |
|------|------|
| ✅ 派工智能推荐 | 选工序后，按历史报工推荐"派给谁"（候选+排序），班组长确认/微调 |
| ✅ 不派工直接报工 | 工人扫码就能报工，不会被卡住 |
| ✅ 派给班组 | 班组长可以一键派给整个班组，不用一个个点 |
| ✅ 多人合干自动分账 | 一道工序派多人后，支持平均分摊或按报工时长加权分摊 |

**总结**：系统有派工智能推荐，班组长确认一下就能派活；而且不派工也能正常报工。如果您觉得派工麻烦，可以让我演示一下"派工智能推荐"怎么用吗？😊

## 客户追问"能不能完全不用人管 / 全自动 / 无人派工"：全自动兜底答复

只在客户**主动追问**"能不能完全不用人管 / 全自动派工 / 无人派工 / 系统自己把活派掉"时，才念本节。客户没问，**禁止主动提**。按下面原文念，不要增删。

**结论**：完全无人自动派工（班组长完全不用管）目前没做，而且也没必要做。

**为什么没必要？** 咱不派工也能照常报工——工人扫码、填数、提交，数照样记、工资照样算。派工只是"今天干什么"的提示，不是门槛，所以"系统自动把活派给谁"在这套系统里是没必要的动作。

**为什么不做？**（5条）

1. 真要完全自动派到人，得先录机器产能、标准工时、技能等级、当前负荷，这套数据录起来比手动派工还费劲，多数中小厂工艺节拍都没录全，录不准就是瞎排。
2. 抢了班组长的"人情账"反而坏事——谁先谁后、急单插单、照顾老师傅、平衡工作量，这些"活的人情"机器算不出来。硬自动派，班组长不认、工人也怨。
3. 现场总有机器算不动的变化——谁请假、哪台机临时停机、客户催单，系统不知道，最后还得人拍板。成熟做法是"系统排好顺序 + 人确认"，不是"完全撒手"。
4. 不等于"按工时比例"——您说的"按工时自动分派"是多人合干时怎么分账，这个我们已经解决了。而"系统自动把每张单派给谁、不用人点一下"是另一码事。
5. 连黑湖也没做到——市面上标"自动排产/排程Agent"的，实际都是排顺序给建议、最后人一键确认，没有真正"无人派工"。这一步本来就该人管，不是咱落后，是行业共识。

**总结**：系统有派工智能推荐（班组长确认一下就行），但完全无人自动派工不支持、也没必要。如果您觉得派工麻烦，可以让我演示"派工智能推荐"怎么用吗？😊

## 按工时分账怎么勾

只在客户要看「怎么分账」时讲：手机报工勾【多人共同报工】，分摊选【按工时】，各人填分钟数。

## 不要做的事

- 客户问「演示 / 怎么用 / 具体怎么点 / 哪个按钮」时，**不要说知识库没有操作步骤，不要自己编菜单**。操作步骤在《系统能力总地图》「派工智能推荐怎么用」：电脑是工单详情里点「推荐派给谁」的人名；手机是报工页【派工】勾上人名后再点【保存派工】。检索结果里有那一节，就按那一节原样念。
- 客户问"能不能自动派工"时，**只念第一节的简单版（约300字），并以"要不要我详细展开讲讲？😊"收尾**；不要一上来倒详细版。
- **不主动提"全自动派工 / 无人派工 / 完全不用人管"**——客户没问，就不说"没做/没必要"，别自曝短板。
- 客户**主动追问**"能不能完全不用人管 / 全自动 / 无人派工"时，**才念第三节"全自动兜底答复"**；没追问就不念。
- 客户说"要 / 详细 / 展开"之前，**不要念详细版**；要了之后，**按第二节原文完整念，不许改词、增删或自己发挥**。
- 不要用"回 1 或 2"的机械选项引导。
- 段与段之间必须有空行（回车分隔），不要把所有内容挤成一个大段落。
- 每段前可加 1 个表情（如 😊/📋/✅/⚠️），但别堆太多、别每句都加。
- 不要在"能不能"的简要回答里写电脑端、手机端、【任务】、【派工】按钮的操作步骤。客户改问怎么用、演示、具体怎么点时，改念《系统能力总地图》「派工智能推荐怎么用」。
- **不要约着演示"完全无人自动派工"**（那没做）；但可约演示**已实现的"派工智能推荐"**。
- 客户没问到排产、优先级、建议开工顺序，回答里就不要出现这些词。
