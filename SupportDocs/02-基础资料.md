# 基础资料

> 与操作手册同源生成；维护 docs/30、31 和 docs/manual 正文后运行 npm run manual:sync。

## 建账号、改密码

谁来做：管理员。入口：**系统配置 → 用户**。

1. 点【+ 创建用户】，填写账号、姓名，需要时填写手机号和微信号（微信号选填，仅作记录；用户列表可按【微信号】搜人）。
2. 选角色：配置和下单选【管理员（电脑全权限）】；现场复核选【班组长（复核 + 报工）】；只报工选【生产人员（仅手机报工）】。
3. 填初始密码，包含大写字母、小写字母和数字。点【确定】。
4. 回到列表核对姓名、账号和角色，再把系统地址及个人账号交给本人。

做完怎么看：用户出现在列表中。生产人员登录后进入手机工单页，管理员和班组长进入电脑工单页。

忘记密码：找到该用户，点【编辑】，填写【新密码】后点【确定】。新密码留空则保持原密码。当前手机端没有自助改密码入口，由管理员处理。登录填写的是【账号】，不一定是资料中的手机号。

## 建部门、把人加入部门

谁来做：管理员。入口：**系统配置 → 部门**。先建好需要加入的用户。

1. 点【+ 创建部门】，填写【部门编码】和【部门名称】，例如 CJ01、裁切组。
2. 在【成员】中选择已有用户，可多选。需要复核本组的班组长也加入本组。
3. 点【确定】，回列表核对部门及成员。
4. 后续增减人员，点部门右侧【编辑】，调整成员后保存。

做完怎么看：列表【成员】中能看到对应人员。工人能否报一道工序，还要在“工序”里允许这个部门报工。

选不到人：先去“用户”确认账号已建立，再重新打开部门页面。

## 配单位、不良品项和工序

谁来做：管理员。入口：**基础数据 → 单位 / 不良品项 / 工序**。

1. 在【单位】点【+ 创建单位】，填“件”“张”等实际计数单位，点【确定】。
2. 在【不良品项】点【+ 创建不良品项】，填“尺寸不合格”“划伤”等原因，点【确定】。
3. 在【工序】点【+ 创建工序】，填【工序编号】和【工序名称】，例如 CJ、裁切。
4. 在【报工权限】选允许报这道工序的部门；在【不良品项】选这道工序可能用到的原因。
5. 点【保存】，核对列表里的【报工权限(部门)】和【不良品项】。

做完怎么看：工序列表出现新工序，并列出允许报工的部门和不良原因。

注意：权限按部门判断。工人和班组长必须属于允许的部门；管理员不受此限制。管理员能报成功，不能证明工人的权限已经配好。

## 批量导入

谁来做：管理员。入口：**系统配置 → 用户**、**基础数据 → 工序**、**基础数据 → 产品定义** 工具栏的【导入】。

1. 点【导入】，再点【下载母版】，得到 `.xlsx`（不支持老式 `.xls`）。
2. 按表头填数据。第 2 行是格式示例，可改可删；关联列（报工部门编码、不良品项名称、单位名称、工艺路线编号、工序编码）须与本厂**已有**资料一致，留空表示不挂关联。
3. 点【上传文件】选填好的表格。结束后看「成功 N / 失败 M」；失败行会列出 Excel 行号和原因，可复制后改表再传。
4. 成功条会进列表；失败行不会留下半截数据。同一文件里好行会入库、坏行报错，不必整份重导。

做完怎么看：对应列表出现新数据；若有失败，按行号改 Excel 后只重传或再传一次即可。

注意：产品编号、用户账号不能重复。工序/产品的关联填错会整行失败并提示，不会静默跳过。空文件或全是空行会提示「没有可导入的数据行」。

## 配工艺路线和产品

工艺路线就是"这个产品按什么顺序把活做完"的工序流程（比如裁切 → 检验 → 包装）。谁来做：管理员。入口：**基础数据 → 工艺路线 / 产品定义**。先配好单位、工序。

1. 在【工艺路线】点【+ 创建工艺路线】，填路线编号、名称。
2. 第一行选第一道工序，点【+ 添加一行】继续选后面的工序，例如“裁切 → 检验 → 包装”。按行从上到下排列（当前不能拖动排序）。
3. 核对顺序后点【保存】。排错了可重新选择各行工序，或用【×】删除多余行再添加。
4. 在【产品定义】点【+ 创建产品】，填产品编号、名称，选单位和工艺路线。供应商、单价按实际情况填写。
5. 点【保存】，在列表核对产品编号、单位和工艺路线。

做完怎么看：下工单时能选到产品，创建后的工单详情能看到对应工序。

注意：**产品编号不能重复，名称可以重复。** 同名产品要核对编号。需要扫码报工的产品应配好工艺路线，避免打开工单后没有工序可选。

## 上传作业指导书、图纸和图片

谁来做：管理员。入口：**基础数据 → 产品定义** 或 **基础数据 → 工序**，打开某条记录的【编辑】。

1. 在【产品定义】或【工序】点某条记录【编辑】（新建的保存后即可）。
2. 表单下方「作业指导书 / 图纸」区，点【上传作业指导书 / 图纸】选文件。
3. 支持 pdf / docx / xlsx / jpg / png / webp，单个不超过 20MB；版本（如 V1.2）可填可不填。
4. 上传后列表显示文件名、类型、版本；可点【删除】移除（只删登记记录，磁盘文件保留）。

做完怎么看：产品页、工序页能看到已挂文件；工人手机报工界面（H5）打开对应工单，可查看这些作业指导书、图纸和图片；管理员在 PC 工单详情页【图纸 / 作业指导书】区也能按单查看并预览（pdf / docx 页面内预览，xlsx 下载查看）。

注意：jpg / png / webp 也能传，可作为产品图片或工序示意图。文件一旦挂在产品或工序上，删除该产品/工序前须先移除这些文件（删除依赖倒序：先删知识库文件，才能删产品/工序）。

说明：这是“制造知识库”——文件存服务器知识库目录，系统只记路径。PC 工单详情页已按工单聚合查看图纸/作业指导书并支持内嵌预览（预览依赖点击文档时按需加载；Word/PDF 排版以实际文件为准）。

## 按需使用的辅助功能

谁来做：管理员。这些功能不影响先跑通建单报工。

自定义字段：进【系统配置 → 自定义字段】，选对象（要加字段的资料，如工单、产品、报工），点【+ 添加字段】，填名称、类型及单选选项后【保存】。已建字段类型不能改。对象选【报工】时，工人手机报工页会出现这些字段（如设备、模具），随报工一起保存、可查回；对象选【工单】时，当前工单表单展示工单字段。其他对象的配置入口不代表所有页面都已有填写入口。

工单列表显示与筛选（可选）：对象选「工单」时，可打开「在工单列表显示」。打开后【工单】页表格会出现该列。需要按自定义内容查单时，在工单页选字段、匹配方式（文本可选精确/包含；单选和数字固定精确）和值后点【查询】。关显示只藏列，不影响按该字段筛选，也不影响打印勾选。不支持查「没填过的空值」。

排产评分（帮您给生产任务排个先后顺序）：进【报表 → 排产评分】，看现有任务和交期，按实际情况给客户等级、金额、换型、齐套性（材料配不配得齐）打分，调好权重后【重新计算】，需要时【导出 Excel】。算出的建议顺序得计划员确认，不表示系统已自动派工、也不代表真有外部库存。

微信预警：默认关闭的可选功能，开启方法见下一章《微信预警（企业微信推送，默认关闭）》。

做完怎么看：重新打开核对保存的配置，查看计算结果或实际消息接收结果；错误交维护人员处理。
