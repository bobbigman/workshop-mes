# 工资与预警

## 工价和工资报表

谁来做：负责算工资的管理员。入口：**基础数据 → 工价表**（先定"每道活给多少钱"）、**报表 → 工资报表**（按周/月算工资）。

### 先把"每道活给多少钱"定好（工价表）

工价表就是"哪个产品、哪道工序，按件 / 按小时 / 干一次给多少钱"的清单，可一次管一大片：

1. 可按【产品 / 工序 / 部门 / 人员】筛选（多条件组合），列表按【产品 + 工序】排好序，方便核对；到期的价（过了失效时间）用不同颜色标出来，不影响改价。
2. 批量定 / 加价可用【导入】上传 Excel（列：产品编号、工序编号、部门、人员、计价方式、单价、不良扣款、生效时间、失效时间、优先级），哪一行哪个字段填错，会逐行提示原因。
3. 计价方式三选一：**【计件（元/件）】**按件算、**【计时（元/小时）】**按小时算、**【固定（单笔）】**干这道给一次。填单价、不良扣款（出一件不良扣多少）、生效时间，需要可设失效时间、优先级，点【保存】。

### 到周底 / 月底，一键算工资

4. 报工都复核通过后，进【工资报表】点【生成工资单】：选按月还是按周，填周期（如 2026-09 表示 9 月、2026-W37 表示第 37 周），按需选算哪些人，点【生成】。
5. 生成后先看【明细】。系统按**已通过的报工**自动算出**计件合计 / 计时金额**；若有报工没对上任何一条工价，会标红色【未匹配】——先回去把工价补齐，别把缺价的当零工资发了。
6. 工资单**没有手工发薪列**（底薪、餐补、社保个税这类已移除）——工资单只放报工算出来的活钱，干净对账；到手工资里的底薪、补贴、社保扣款等由工厂按自己规则另行核算发放，**系统不代算社保费率、也不负责银行代发**。
7. **应发合计 = 计件合计 + 计时金额 − 不良扣款**（不良扣款按工价里的【不良扣款】× 不良数扣）。
8. 核对无误再点【确认】：只要有红色【未匹配】，系统会拦住不让确认，先把工价补齐。确认后这批复核过的报工就**锁死**了，数量不能再改。想带走数据核对，点【导出 CSV】（用 Excel 能打开）。

**算错了、工价没配对怎么办**：改对工价后，已确认的工资单也能纠——管理员点【撤回重算】把单**软撤回**（单子和明细都保留、不删除）回草稿，重算金额后再确认，全程留痕、可查可重算，错误金额不会永远定格。多张一起改，列表勾选后点【批量重算】：草稿原地重算、已确认先撤回再重算，任一张失败单独提示原因，不影响其它单。

**看明细、查账**：工资报表页可按【工序 / 时间】筛选，报表层直接列出明细（人员、工序、良品、不良、单价、不良扣款、小计，并带工单的**颜色 / 规格尺码**两列），可【导出明细 CSV】；原【明细】按钮进单子照旧。

**手机看工资**：用手机浏览器打开工资报表，汇总自动变成**卡片式**（人名 + 应发合计 + 状态 + 操作按钮，不用左右拖），明细大块默认收起；批量重算在手机上不可用（提示电脑端操作）。工人端【我的工资】不受影响。

**工人手机看工资【我的工资】**：工人（开了计件工资档）在手机点工作台 / 我的报工里的【我的工资】，按**天 / 周 / 月**看累计预估金额（默认本月）。金额三档口径：**已结算** → 工资单明细的固化金额；**未结算但已复核** → 报工快照的单价 × 金额；**待复核 / 被退回** → 只展示并标状态、**不计入累计**。本厂配了颜色 / 规格字段，明细还多出颜色、尺码两列；五金厂没有。累计是估算，以确认后的工资单为准。

**按色码看工资【工资色码汇总】**：报表 → 工资色码汇总（管理员，需开计件工资档），按「款 + 颜色 + 规格」汇总工资（数量、金额），可【导出 CSV】（带款 / 色 / 规格 / 数量 / 金额）；口径与工资报表一致（只算已确认工资单对应的已通过报工）。没配色码字段的账套页面提示去「自定义字段」配置、不显示数据。

做完怎么看：工资单从【草稿】变成【已确认】。确认就是定稿结算，相关报工就不能随便改，别当成普通保存。

注意：工资只按**已通过的报工**算（还在核对、或被打回的都不算）。计件=良品数×单价，计时=时长（小时）×单价，固定=单价一次；出了不良按【不良扣款】扣。**系统不自动算社保费率、也不负责银行代发**，具体薪酬规则由工厂自己定。草稿算错了先核对报工和工价，可删掉重生成；已确认单要改，用【撤回重算】（仅管理员），别口头答应"随便改已确认的数"。

## 微信预警（企业微信群机器人，默认关闭）

谁来做：管理员。入口：**系统配置 → 微信预警**。

这是默认关闭的可选功能，不开也能正常用系统：临期、超期在看板上已有黄/红提示。

1. 前置条件：在**企业微信**里建一个纯内部群，群设置中添加「群机器人」（名称随客户端版本可能不同），复制机器人的 **Webhook** 地址。**不需要**域名备案，也**不需要**企业微信自建应用的可信 IP；服务器需要能出站访问 `qyapi.weixin.qq.com`。
2. 打开【启用推送】开关，填 **Webhook**（完整链接或纯 key 都行，保存后显示为 `********`），填默认 @成员（企微 UserId，多人用竖线分隔，也可填 `@all`），需要时调整【每日上限】，点【保存】。
3. 交期预警规则（页上也有说明）：**一天一批一条消息**（临期+超期写在一起）；**当日批次不重推**。
4. 群规则（可选）：可分别配置【报工成功 / 工单开始 / 工单结束 / 异常上报】触发推送；异常上报按设备 / 物料 / 质量匹配对应规则（机修 / 仓库 / 质检），规则里填的成员才会被 @，留空只发群不 @人。
5. 点【发送测试消息】验证链路；需要时点【推送临期/超期工单】手动推送。
6. 若要自动推：计划任务调 `backend/scripts/wechat-alert-cron.ps1`（每日交期）和 `wechat-events-cron.ps1`（事件投递，约每分钟）；每机器人每分钟最多 20 条，超了会延后/提示。

做完怎么看：群里能收到测试消息。收不到先看【启用推送】是否打开、Webhook 是否填对，再点【发送测试消息】排查；手机是否弹锁屏通知取决于手机通知权限、免打扰和系统设置，不能保证一定弹窗。

注意：Webhook key 属敏感信息，不要发给 AI 或发到群里。不使用预警也可以正常报工和阅读手册。

## 产品优势速览（演示给老板看）

谁来做：管理员、销售伙伴。入口：**帮助 → 产品优势速览**（也可登录前打开该页）。

解决什么：出门演示不用背 PPT。页上用大白话写清三大麻烦怎么解、六步闭环、以及「本地部署 / 断外网也能用 / 数据不出厂」等差异；下面可展开「销售备忘」（话术、竞品对比），演示时请先收起备忘。

1. 打开【产品优势速览】，先看页顶横幅「本地部署・局域网运行・数据不出厂」。
2. 按页面向下讲：三个麻烦 → 六步闭环 → 三大差异 → 金蝶相关扩展（建议报价、排产评分等，已做才写）。
3. 需要对照话术或竞品表时，再展开销售备忘；讲完可点页内演示路径链到真实功能页。
4. 工单、报工、看板、工资等业务页顶部会有一行浅色价值提示（一句人话），与本页口径一致；**不是弹窗**，可忽略不影响操作。

做完怎么看：能打开页面、能讲清「数据在您自己服务器」；不要向客户承诺未闭环能力（如未接金蝶就吹齐套真取数、未认证就吹企微已推送）。

注意：「断外网也能用」限定局域网内核心功能（工单/报工/看板/工资）；推送依赖企业微信通道，不是断网也能推。工资对外只讲计件算清楚、可查可重算，不把底薪社保银行代发说成系统全包。
