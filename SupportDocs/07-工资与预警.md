# 工资与预警

> 与操作手册同源生成；维护 docs/30、31 和 docs/manual 正文后运行 npm run manual:sync。

## 工价和工资报表

谁来做：负责算工资的管理员。入口：**基础数据 → 工价表**（先定"每道活给多少钱"）、**报表 → 工资报表**（按周/月算工资）。

### 先把"每道活给多少钱"定好（工价表）

工价表就是"哪个产品、哪道工序，按件 / 按小时 / 干一次给多少钱"的清单，可一次管一大片：

1. 可按【产品 / 工序 / 部门 / 人员】筛选（多条件组合），列表按【产品 + 工序】排好序，方便核对；到期的价（过了失效时间）用不同颜色标出来，不影响改价。
2. 批量定 / 加价可用【导入】上传 Excel（列：产品编号、工序编号、部门、人员、计价方式、单价、不良扣款、生效时间、失效时间、优先级），哪一行哪个字段填错，会逐行提示原因。
3. 计价方式三选一：**【计件（元/件）】**按件算、**【计时（元/小时）】**按小时算、**【固定（单笔）】**干这道给一次。填单价、不良扣款（出一件不良扣多少）、生效时间，需要可设失效时间、优先级，点【保存】。

### 到周底 / 月底，一键算工资

4. 报工都复核通过后，进【工资报表】点【生成工资单】：选按月还是按周，填周期（如 2026-09 表示 9 月、2026-W37 表示第 37 周），按需选算哪些人，点【生成】。
5. 生成后先看【明细】。系统按**已通过的报工**自动算出**计件合计**（就是件数 × 单价）；若有报工没对上任何一条工价，会标红色【未匹配】——先回去把工价补齐，别把缺价的当零工资发了。
6. 【草稿】阶段还能补五列手工数（按人 / 周期填，不是每条报工）：**底薪、餐补、其他补贴、社保个税、其他扣款**。社保个税、其他扣款填**正数**，系统按公式自动扣。
7. **到手钱 = 计件合计 + 底薪 + 餐补 + 其他补贴 − 社保个税 − 其他扣款**。列表里的「应发合计」就是这个数。
8. 核对无误再点【确认】：只要有红色【未匹配】，系统会拦住不让确认，先把工价补齐。确认后这批复核过的报工就**锁死**了，数量不能再改、手工列也不能再动。想带走数据核对，点【导出 CSV】（用 Excel 能打开）。

做完怎么看：工资单从【草稿】变成【已确认】。确认就是定稿结算，相关报工就不能随便改，别当成普通保存。

注意：工资只按**已通过的报工**算（还在核对、或被打回的都不算）。计件=良品数×单价，计时=时长（小时）×单价，固定=单价一次；出了不良按【不良扣款】扣。手工那五列只是方便把"到手大概多少"凑齐，**系统不自动算社保费率、也不负责银行代发**，具体薪酬规则由工厂自己定。草稿算错了先核对报工和工价，可删掉重生成；已确认单怎么纠错，以现场版本的按钮为准（别口头答应"随便改已确认的数"）。

## 微信预警（企业微信推送，默认关闭）

谁来做：管理员。入口：**系统配置 → 微信预警**。

这是默认关闭的可选功能，不开也能正常用系统：临期、超期在看板上已有黄/红提示。

1. 前置条件：工厂注册企业微信并完成认证，在企业微信后台建好自建应用。
2. 打开【启用推送】开关，填 CorpID、Secret、AgentId、接收人 UserId（多人用竖线分隔），需要时调整【每日上限】，点【保存】。
3. 交期预警规则（页上也有说明）：**一天一批一条消息**（临期+超期写在一起）；**当日批次不重推**。
4. 点【发送测试消息】验证链路；需要时点【推送临期/超期工单】手动推送。
5. 若要每天自动推：服务器 `appsettings` 配置 `WechatAlert:CronToken`，用计划任务调 `backend/scripts/wechat-alert-cron.ps1`（`POST /api/WechatAlert/cron-push`）。

做完怎么看：接收人企业微信能收到测试消息。收不到多半是没打开【启用推送】或企业微信参数没配对，先点【发送测试消息】排查。

注意：Secret 与 CronToken 属敏感信息，不要发给 AI 或发到群里。不使用预警也可以正常报工和阅读手册。

## 产品优势速览（演示给老板看）

谁来做：管理员、销售伙伴。入口：**帮助 → 产品优势速览**（也可登录前打开该页）。

解决什么：出门演示不用背 PPT。页上用大白话写清三大麻烦怎么解、六步闭环、以及「本地部署 / 断外网也能用 / 数据不出厂」等差异；下面可展开「销售备忘」（话术、竞品对比），演示时请先收起备忘。

1. 打开【产品优势速览】，先看页顶横幅「本地部署・局域网运行・数据不出厂」。
2. 按页面向下讲：三个麻烦 → 六步闭环 → 三大差异 → 金蝶相关扩展（建议报价、排产评分等，已做才写）。
3. 需要对照话术或竞品表时，再展开销售备忘；讲完可点页内演示路径链到真实功能页。
4. 工单、报工、看板、工资等业务页顶部会有一行浅色价值提示（一句人话），与本页口径一致；**不是弹窗**，可忽略不影响操作。

做完怎么看：能打开页面、能讲清「数据在您自己服务器」；不要向客户承诺未闭环能力（如未接金蝶就吹齐套真取数、未认证就吹企微已推送）。

注意：「断外网也能用」限定局域网内核心功能（工单/报工/看板/工资）；推送依赖企业微信通道，不是断网也能推。工资对外只讲计件算清楚、可查可重算，不把底薪社保银行代发说成系统全包。
