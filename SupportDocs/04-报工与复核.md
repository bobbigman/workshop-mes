# 报工与复核

## 企业微信免密报工（发手机号，机器人秒回链接）

谁来做：工人已开通个人免密码（管理员在「系统配置 → 用户」点过【二维码】生成过；没生成过机器人也会自动补）。工人不用输账号密码，在企业微信里跟本厂机器人报手机号即可报工。

1. **工人发凭证**：企微里跟本厂机器人对话，发自己的**手机号**（11 位，最稳）、**登录账号**或**唯一姓名**。
2. **机器人秒回专属链接**：机器人按「手机号 → 登录账号 → 姓名」顺序在系统里找本厂在职用户，命中一人就回卡片「张三师傅，点这里报工」+ 一条专属免密报工链接。
3. **点链接免密报工**：点卡片链接 → 企微内置浏览器打开 → 免输密码直接进工作台 → 点任务或扫工单码，填良品、不良、选不良原因，提交。
4. **链接 30 天有效**：第一次点开登录后，30 天内再点同一链接直接进工作台；过期或清了缓存，再发一次手机号拿新链接。

查无此人 / 停用 / 重名怎么办：机器人回「未找到该手机号的员工…」/「该账号已停用」/「找到多人…请发手机号或登录账号」，**一律不发链接**。

说明：与账号密码登录并行，老登录原样保留；报工权限仍按「工序报工权限 = 部门」校验，无权限的工序进得去也报不了。详细流程见 `01-操作入门.md` #企业微信免密报工。

## 电脑报工

谁来做：管理员、班组长。入口：**生产管理 → 报工**；也可在工单行点【报工】。

1. 点【+ 报工】，工单号可下拉选择（显示工单号+产品名，也可手敲），选中后自动带出产品与工序。
2. 核对产品，选工序，查看【计划、良品、不良、剩余】。
3. 填本次【良品数】和【不良品数】，不是从开工至今的累计数。
4. 不良品大于 0 时选【不良原因】。需要记录时长时填小时和分钟，单次合计不超过 24 小时。
5. 一道工序几个人一起干：勾【多人共同报工】，选【平均】或【按工时】，再勾参与人（必须含自己）。人选只列出这道工序允许报工的部门里的人。下面会预览每人分到的良品、不良，加起来等于刚填的总数，分不尽的归当前报工人。这和【代报工】不是一回事，不要两个一起用。
6. 点【提交并返回】核对后保存并返回工作台；同张单继续报下一批，点【提交并继续】。

### 代报工（替工人记数）

谁来做：管理员、班组长。入口：**生产管理 → 报工 → 代报工**。

1. 点【代报工】，选工单、工序。
2. 选实际干活的工人（可一次代多人，各人数量按实际填，不搞平均）。
3. 填各人数量，核对后点【提交】。

做完怎么看：报工记录记到**被代的工人名下**、直接进他的工资；记录里能查到是谁代的。

注意：被代报的工人必须在该工序报权部门里，班组长再限本组；代报工是”替人记实际账”，不是绕过权限。报工列表可按【人员类型】筛选（全部 / 内部员工 / 临时用工 / 外部供应商），外部供应商的代报记录一眼可辨、便于月底跟委外厂对账。

做完怎么看：查询工单号，核对工序、报工人、数量和复核状态。管理员新增直接【已通过】，班组长新增为【待复核】。

注意：普通【+ 报工】记在当前登录人名下，没有”代谁报”字段。需要把漏报记到实际工人名下，管理员使用”一键补报未完工序”的拆分功能，或【代报工】，并先核实实际完成情况。顶部筛选工单编号也可下拉点选（只列未结束工单）；查已结束单可手敲编号。

### 上级工序校验（软提示 / 硬拦截，可选）

默认不校验、允许串着报工（工人先干后面工序再补前道也放行）。管理员可在【系统配置 → 报工上级校验】打开后按需配：

1. **软提示**（默认）：报工提交时若紧邻上一道复核通过量不足，弹一句「紧邻上一道复核通过量不足，是否继续报工？」，点【继续】照常入库（允许串报）。
2. **硬拦截**：可再勾一批要卡死的工序清单。清单里的工序复核通过量不足时，后端直接拒绝报工并提示，不写库；清单外的工序仍按软提示。
3. 判断口径与复核页一致：首道工序不校验；非首道看**紧邻上一道已复核通过**的良品数（待复核/未复核的不算）。校验在**后端统一执行**，H5 和 PC、补报、代报都走同一套规则，PC 也绕不开硬拦截。

做完怎么看：默认什么都不弹（不打扰）；打开后按配置弹提示或拦报工。改配置立即生效、不用重启。

## 报工数量设置（允许超报比例 / 上道不良计不计入）

> 这是**工厂级可选开关**（docs/230，对标黑湖「报工数配比 + 超报审批」），默认不开；不开则维持老规则（报工上限 = 本道计划数、上道只移交良品），现场照常使用不受影响。

谁来做：仅管理员。入口：**系统配置 → 报工数量设置**。PC 端配置，H5 报工与复核走同一套规则。

1. 打开【报工数量设置】，两个开关：
   - **每工序允许超报比例 %**（`overrun_ratio`）：填整数 0～999，5 表示 5%。默认 0（报工上限 = 本道工序计划数，超 1 个即拦）。
   - **上道不良品计不计入下道可报**（`count_defect`）：默认不计入（下道可报上限 = 上道已复核**良品**数，与黑湖一致）；可改成计入（下道可报上限 = 上道已复核**良品 + 不良**数，适用返修/不良回用）。
2. 点【保存】，立即生效、不用重启。

**这两个开关管的是两把不同的尺子，别混成一个**：

- **尺子①允许超报比例**：放宽"本道超计划数"的上限。允许件数 = `ceil(工序计划数 × (1 + 比例/100))`，向上取整、不取半件。比例内正常报工；超了提示「超出允许超报比例」，直接硬拦（软确认也跳不过）。比例只放宽本道计划这尺子，不影响上道校验。
- **尺子②上道不良计不计入**：改"后道超前道良品"的校验口径。计入 = 把上道已复核的不良也当可流转量。这条仍走原有的 soft 确认 / hard 拦截（见下节「上级工序校验」）。

**复核页验证超报**：复核时若本道累计良品（待复核+已通过）超过允许件数，或超上道上限，页面仍标【数量异常】、可【确认放行】——这与黑湖"超报需审批"对齐。报工时被硬拦拦在门口；复核页看到「数量异常」，通常是报完后把比例改小、或把工序计划改小了，属正常现象。

注意：超报的良品**照常计件**（本期只控数量、不控工资）；只按工厂整体一个比例配，暂不支持按工序/产品单独配。负数或大于 999 的比例保存时会被拒绝。

## 复核：通过或退回报工

谁来做：管理员、班组长。入口：**生产管理 → 报工复核**。班组长只能复核与自己有共同部门的人员报工。

1. 工单编号可下拉选择（只列当前有待复核报工的工单，含已结束但仍挂着待复核的；也可手敲），或按工人姓名筛选，选【待复核】，点【查询】。
2. 核对工序、工人、良品、不良、时长，正确的点【通过】。
3. 多条都已核对，可勾选后点【批量通过】，核对条数再确认。
4. 有问题点【退回】，写具体原因，例如“实际为 18 件，请核对”，点【确定退回】。
5. 纠正已通过记录，先选【已通过】查询，再退回。已结算报工不能退回。

做完怎么看：切到【已通过】或【已退回】查询确认。通过后计入生产报表；退回后不计有效进度，工单状态可能变化。

注意：退回后核对并修改原记录，不要未经确认另报一遍。原记录修改后回到待复核。

## 班组长/管理员：手机端报工复核

入口：底部【复核】（仅班组长、管理员可见；普通工人没有此 tab）。企业档以下账套不显示。

1. 点【复核】，默认只看待复核列表：工单号、产品、工序、工人、良品/不良、报工时间。
2. 单条：点【通过】直接通过；点【退回】必须填写原因（1～256 字）。
3. 多条：勾选待复核卡片，点【批量通过】，按实际通过条数提示。
4. 可用顶部筛选切换「已通过 / 已退回」，或按工单号、工人姓名查询。

做完怎么看：通过后该条进生产报表入账；退回后进度回落、报表仍不含。班组长只审本组，管理员审全厂。

注意：工人拿链接直达复核页会跳回任务页。电脑端【报工复核】仍可用，口径与手机一致。

## 报错数量怎么改

谁来做：管理员、班组长；**报工本人（待复核记录）也可在手机端自己撤回改**，改动留痕可查。

1. 待复核（还没审核）的报工：报工本人在手机【我的报工】可撤回/修改自己这条记录的良品、不良、原因、时长，改后仍为【待复核】；每次修改都会记一条修改记录（原值 → 新值、谁改的、什么时间），可追溯。
2. 管理员/班组长在【生产管理 → 报工】查询工单，按工序、人员和时间找到原记录。
3. 已通过且【修改】不可点时，先到【报工复核】退回这条记录并写原因。
4. 回【报工】重新查询，点原记录【修改】，填正确的良品、不良、原因、时长，点【保存】。
5. 到【报工复核】重新核对通过；管理员改数后同样需要复核。

做完怎么看：原记录数量变更，保存后为【待复核】，通过后再查报表。误报 20、实际 18，就改为 18，不是填 -2。

注意：**已通过**的记录要走退回再改；**已结算**的记录不能改或退回，交结算负责人核查。生产人员只能改自己的待复核报工，不能改别人的。

## 一键补报未完工序

这个功能就是：工人干过的活漏报了，管理员一次把漏掉的工序补报上，要的话还能按人头拆开记到具体工人名下。谁来做：仅管理员、电脑端。入口：**生产管理 → 报工 → 一键补报未完工序**。

1. 先核实哪些工序确实做过、谁做的，确认是漏报。
2. 在工单号下拉选择或手敲编号，选中后自动加载；检查【待报工序】。系统对列出的所有未报满工序补同一数量，不能在这里只挑一道。
3. 填【统一良品数】，不得超过各工序【剩余可报】的最小值。两道剩余 30、20，本次最多统一补 20。
4. 不拆分记当前管理员名下。要记实际工人，勾【按工序拆分到人】，逐道选人和数量，每道合计必须等于统一良品数，可用【+ 加人】增加人员。
5. 核对后点【确认补报】。

做完怎么看：出现“已为…道工序生成…条报工”提示；回列表逐条核对人员、工序、数量。管理员补报直接已通过。

注意：这不是“报末道自动补前面”。未做的工序不能补报；各道漏报量不同要分别核实处理。已结束、已取消不能补报。

## 处理现场异常上报

谁来做：管理员、班组长。入口：**生产管理 → 异常处理**。

工人手机上报设备故障/物料短缺/质量异常后，本页「待处理」对管理员和班组长全员可见（不分班组）。核对描述与照片后点【标记恢复】，可选填处理说明。恢复后车间看板红标与滚动播报消失。

做完怎么看：该条进入「已恢复」；看板「待处理异常」数字下降。

注意：试用期不推企业微信，靠看板和本列表看见。

## 用手机摄像头扫码

入口：底部【扫码】。首次进入默认摄像头待启动。

1. 点【打开摄像头扫码】，浏览器询问时允许摄像头（不要开麦克风）。
2. 把流转卡或工位工序码对准画面，识别成功后进入报工页；先核对工单号和产品。
3. 若扫的是**工序码**（管理员按工序打的标签），进入报工页后该工序会自动选好，直接填数提交即可；若扫的是普通工单码，仍需自己选工序。
4. 不允许摄像头、打不开或提示需要 HTTPS 时：改用【手动输入工单号】，或让管理员检查 HTTPS/证书。
5. 切到别的页或锁屏后摄像头会停；回来再点【打开摄像头扫码】。

做完怎么看：出现正确工单的报工页；工序码会预选工序，工单码则自己选工序。扫码本身不会自动提交报工。

注意：HTTP 地址通常无法开摄像头。系统相机扫「报工页链接」打开网页，与本页「打开摄像头」是两回事。

## 用 PDA 扫码枪，或手动输入

入口：底部【扫码】→【扫码枪模式】；或任意模式下点【手动输入工单号】。

1. PDA：点【扫码枪模式】，看到“等待扫描工单”；扫码头设成“像键盘一样输入、扫完自动回车”。
2. 扫码后进入报工页，先核对工单号、产品。扫工序码时工序会自动选好。本机记住扫码枪模式后，下次打开扫码页可直接扫。
3. 扫不出可点【手动输入工单号】，填纸上编号，点【确定】；返回后继续扫或再开摄像头（手动输入只填工单号，进页后自己选工序）。
4. 要改回手机摄像头：点【摄像头扫码】。

做完怎么看：出现正确工单的报工页；工序码预选工序，工单号则自己选。

注意：手动输入只填工单号，不要把整段网址贴进去。外部扫码工具扫到链接时可直接打开；未登录时登录成功后应回到该工单。

## 把扫码页放到手机桌面（可选）

不想每次输网址、想让工人点一下桌面图标就直接进扫码页的，可以这样加。加完点图标是全屏进扫码页，不用开浏览器找地址。这是浏览器自带的功能，不用下载安装包、不进应用商店。

先确认：手机能正常打开系统地址（就是平时扫码页那个 HTTPS 地址），并先登录一次。

### 安卓手机（华为 / 小米 / OPPO / vivo 等）

用手机**自带浏览器**或 **Chrome**（推荐，效果最好）：

1. 打开扫码页地址，例如 `https://服务器IP:端口/#/h5/scan`。
2. 点浏览器右上角【⋮】（三个点）菜单。
3. 选【添加到主屏幕】或【安装应用】（不同手机叫法略不同，都在这个菜单里）。
4. 桌面出现【小工单】图标（蓝底白框）。点开就是全屏，没有地址栏。

用**百度浏览器**：菜单 →【添加到桌面】，会生成一个快捷方式。点开带地址栏、不算全屏，但扫码能正常用。

### iPhone

必须用系统自带 **Safari** 浏览器（微信、百度里加不了）：

1. 用 Safari 打开扫码页地址，先登录一次。
2. 点底部【分享】按钮（方框里一个朝上的箭头）。
3. 往下滑，选【添加到主屏幕】。
4. 桌面出现【小工单】图标，点开全屏。

### 装完怎么确认装对了

- 桌面图标叫【小工单】，图案是蓝底白框。
- 点开没有地址栏、没有刷新按钮，直接落在扫码页。
- 点【打开摄像头扫码】能正常出画面。

### 加不上怎么办

- 菜单里找不到【添加到主屏幕】：一般是页面没加载全（证书没信任、或访问的是 HTTP）。把地址换成管理员给的 HTTPS 地址再试。
- 想要最稳的全屏、绕开个别浏览器的问题：用手机自带浏览器或 Chrome 添加。

> 各品牌浏览器菜单文字可能略有不同，找到意思相同的那一项即可。

## 选工序、填本次数量

入口：打开工单后的报工页。只填写实际做过的活。

1. 在【工序】选当前这道，例如“裁切”。上方【计划、已完成、剩余可报】随工序变化。
2. 【本次良品】填这一批合格件数。前一批报 20，这一批做 15，就填 15，不是 35。
3. 【不良品】填本批不合格数，没有填 0；大于 0 时选【不良品原因】。
4. 需要记录时长就填小时、分钟，分钟为 0～59，单次总时长不超过 24 小时。
5. 几个人一起干这一道：选完工序就看到【多人共同报工】，勾上后选【平均】或【按工时】，再勾参与的人（必须含自己）。页面会显示每人分到多少，加起来等于你填的总数，分不尽的归当前报工人。
6. 再核对工单、工序、良品、不良后提交。

例子：本批共做 20 件，18 件合格、2 件尺寸不合格，本次良品填 18，不良品填 2，原因选“尺寸不合格”。

做完怎么看：数字与本批实物一致，良品不超过剩余可报。不良数不占良品上限，但仍必须如实填。

注意：【报全部剩余】只把剩余数填入输入框，不判断实际完成量；只有确实全做完才用。已报满时不要换工序凑数。报工页顶部【今日计件】卡片会随提交即时刷新（今日件数与金额估算，含待复核+已通过，以工资单为准）。

## 提交后怎么确认成功

1. 本次结束点【提交并返回】，核对并确认后返回工作台。
2. 同单同工序连续报下一批，点【提交并继续】；核对并确认成功后留在原页，数量和时长清空，进度刷新。
3. 再打开同单选同工序，可核对已完成和剩余可报。多人同时报工时，进度也包含其他人的数量。

做完怎么看：“报工成功”说明已提交。工人提交需班组长或管理员复核，通过后才进入生产报表。

注意：成功后不要把同批再提交。断网、报错或不确定结果时，先让班组长按工单、姓名、时间查记录，确认没有保存后再处理。

## 现场异常怎么上报

入口：底部【异常】。遇到设备故障、缺料或质量问题，主动上报，不要等系统猜。

1. 选类型：【设备故障】【物料短缺】【质量异常】三选一。
2. 写清楚问题描述；需要时可选填工单号、拍一张照片。
3. **可指定处理人（可选）**：上报表单里可点【指定处理人】选本厂在职员工（管理员、班组长、机修/仓库/质检等）。不指定就照常提交。指定后，若该处理人企微账号有效，企微群会**@到这个人本人**，让他第一时间看到；没填、或填了但没企微账号，只发群不@、上报照常不中断。
4. 点【提交上报】，看到“上报成功”。

做完怎么看：班组长或管理员在电脑【异常处理】能看到；车间看板会出现红色滚动提示，处理恢复后消失。

注意：试用期不发企业微信，靠看板和电脑列表通知负责人；指定处理人只在接企微推送时用于@人，不影响上报本身。
