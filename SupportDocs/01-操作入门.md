# 操作入门

各业务页右上角「？」或按键盘 **F1**，可看本页按钮与状态说明（含「待复核要去哪处理」这类跨页指引）；完整操作步骤仍以本手册为准。

## 先看懂每天要做什么

**电脑下工单、打印二维码 → 工人扫码报数量 → 管理员复核、看进度**。

工单就是“这次做什么、做多少”；工序是“一步活”；工艺路线是“这些活按什么顺序做”；报工是“记下这次实际做的数量”。

- 管理员：建人建资料、下单打印、查进度、处理错数和补报。
- 班组长：报工、复核本组、看工单和生产报表，不能改基础资料。
- 生产人员：手机/PDA 找工单、选工序、报本次数量。

先跑通一张单，再逐步启用工资、AI 等功能。

登录后看到的是本厂数据；不同账套（工厂）的数据互相看不到。要看另一家工厂的资料，用该厂获授权的账号登录；账号若同时挂了多家厂，登录后在选厂页选那家厂。

图中的菜品、工序是演示示例，按本厂真实产品、工序操作即可。

## 登录前准备什么

管理员提供本厂系统地址和个人账号。电脑、手机、PDA 连上能访问服务器的工厂网络。

1. 浏览器打开系统地址。
2. 填【账号】【密码】，点【登录】。登录页没有账套/工厂下拉、不显示厂名；账号只挂 1 家厂则直接进入本厂，账号挂了多家厂则登录后先选要进的厂（列表只列该账号有权的厂）。
3. 核对系统名称和角色。生产人员进入手机工单页；管理员、班组长进入电脑工单页。

做完怎么看：能打开对应工单页面。忘记密码找管理员，当前手机没有自助重置入口。

网页打不开先查网络、地址和服务器；提示密码错误再核对账号。不要反复重建用户。

## 登录与选厂（多账套）

谁来做：所有人（登录时）；开通新工厂由管理员在电脑端操作。入口：浏览器打开系统地址后的登录页。

1. 打开登录页，只看到【账号】【密码】两栏，**没有账套/工厂下拉，也不显示任何厂名**。填账号密码，点【登录】。
2. 账号只挂 1 家厂（绝大多数账号）：验密通过直接进入本厂，右上角显示本厂名，全程不出现“账套”二字。
3. 账号挂了 2 家及以上厂（厂家运维、一人管多厂）：验密通过后进入【选择要进入的工厂】页，列表**只列出这个账号自己有权的厂**，选一个才进系统；列表里看不到你没权限的别家厂名。
4. 登录后 PC 左侧栏、手机顶栏、车间看板标题都显示当前工厂名，先看清在哪个厂再操作。
5. 各账套（工厂）的数据互相隔离，一家厂的账号看不到另一家厂的工单和报表，属正常现象。要看另一家厂，用该厂授权的账号登录；账号挂多厂时，登录后在选厂页选那家厂。

做完怎么看：单厂账号输对密码直接进、右上角是本厂名；多厂账号选厂列表里只有自己有权的厂，选完进的厂与所见数据一致。

多厂账号密码说明：同一个账号名在每家厂的密码各自独立，由各厂管理员分别设置；在本厂改密码只影响本厂这一处，不会改动别家同名账号。忘记密码找本厂管理员重置。

授权提示（已开通云激活的客户）：管理员登录后若顶栏出现授权过期/宽限提示，高级功能（工资、扫码报工等）可能暂不可用，现场报工与车间看板仍可继续；联系部署方续费后重新登录即可恢复。未开通云激活时无此提示，不影响使用。

授权档说明：一套代码按工厂分「入门款 / 企业版 / 旗舰版」三档（工厂授权档 `license_tier`）。入门款含下工单、派工、报工、车间看板等基础能力；工资与工价、扫码报工、报工复核、交期预警/企微推送、打印标签、建议报价（接金蝶）等属更高档能力，低档登录后看不到这些菜单或按钮，属正常授权限制。现场报工与看板不受档位影响，可继续使用。

体验账套到期：体验账套（试用）默认有效期 7 天，到期会自动清空该厂全部资料（含上传的附件）并禁用所有账号登录，不可恢复。需要保留数据，请在到期前联系部署方转正式版；正式版/私有版不会触发清空。

注意：要看另一家工厂，须用该厂授权的账号登录（多厂账号登录后在选厂页选）。手机端登录后不能切换账套，需要换厂时退出登录重新登录，或找管理员。新开一家工厂：PC 端管理员可新建账套，开通时灌入一套演示数据和该厂管理员账号，属于开通动作，不是日常操作页面。页面显示异常或更新未生效（白屏 / 旧数据 / 菜单不对）时：登录页有【清缓存并刷新】按钮，点它会请求清理本系统旧缓存、重开登录页，**登录信息和账套保留、不用重新登录**；窄屏也可见。

## 免密登录（个人二维码 / 企业微信）

不用输账号密码也能进系统报工，两条免密通道与账号密码登录并存，老登录原样保留。

### 个人免密二维码（扫自己的码 / 点链接免登录）

谁来做：管理员生成并发给工人；工人自己扫码或点链接登录。入口：电脑端**系统配置 → 用户**，列表每行【二维码】。

1. **管理员准备（一次）**：系统配置 → 用户 → 选员工 → 点【二维码/打印】→ 生成该员工的个人码（一条免密登录地址），二选一发放：
   - 打印印到工牌 / 贴工位；
   - 把链接发到企微 / 微信给工人。
2. **工人·存链接点一下（最省事）**：首次收到链接点开 → 免输密码直接进系统 → 把链接收藏到浏览器书签 /「添加到主屏幕」→ 以后每天点桌面图标直接进工作台 → 扫工单码报工。免密有效期 30 天，到期再点一次链接即可。
3. **工人·扫工牌/工位码**：手机相机或微信「扫一扫」→ 对准工牌 / 工位上的个人码 → 识别出链接 → 选「在浏览器中打开」→ 免密登录进系统 → 之后扫工单码报工。

做完怎么看：扫自己的码 / 点链接能直接进工作台，不用输密码；再扫工单码能正常报工。

说明：个人码就是一条免密登录地址，**扫码和点链接是同一个入口**，会加书签就点一下，不会就贴工位扫码。管理员点【重新生成】后旧码立刻失效；员工停用或码无效时，提示改用账号密码登录。

### 企业微信免密报工（发手机号/账号，机器人秒回专属链接）

谁来做：工人已开通个人免密码（管理员在用户里生成过）；工人在企业微信跟本厂机器人对话，报自己手机号 / 登录账号 / 姓名，机器人秒回专属报工链接。

1. **工人发凭证（每次）**：在企业微信里跟本厂机器人对话，发自己的**手机号**（11 位，最稳）、**登录账号**或**唯一姓名**。
2. **机器人秒回专属链接**：机器人按「手机号 → 登录账号 → 姓名」顺序在系统里找本厂在职用户，命中一人就回一张卡片「**张三师傅，点这里报工**」，附一条专属免密报工链接。
3. **点链接免密报工**：工人点卡片链接 → 企微内置浏览器打开 → 免输密码直接进工作台 → 点任务或扫工单码，填良品数、不良数、选不良原因，提交。
4. **链接 30 天有效**：第一次点开登录后，30 天内再点同一链接直接进工作台，不用再发手机号；过期或清了缓存，再发一次手机号拿新链接。

查无此人 / 停用 / 重名怎么办：机器人会回「未找到该手机号的员工，请联系管理员在用户管理里录入」/「该账号已停用」/「找到多人：张三(账号)、…，请发手机号或登录账号」，**一律不发链接**。

做完怎么看：点机器人回的链接能免输账号密码直接进工作台报工，填数提交成功、看板有数。

说明：前提是管理员先在「系统配置 → 用户」给该员工点过【二维码】生成免密码（没生成过，机器人也会自动补生成，不用管理员先动手）。与账号密码登录并行，老登录原样保留；报工权限仍按「工序报工权限 = 部门」校验，无权限的工序进得去也报不了。

## 第一次配置的顺序

谁来做：管理员。已有正确资料直接使用，不重复建立。

1. 【系统配置 → 用户】：先建工人、班组长账号。
2. 【系统配置 → 部门】：建立部门，在【成员】里选人员。
3. 【基础数据 → 单位】：建“件”“张”等单位。
4. 【基础数据 → 不良品项】：建“划伤”“尺寸不合格”等原因。
5. 【基础数据 → 工序】：建裁切、检验、包装等，选报工部门和不良品项。
6. 【基础数据 → 工艺路线】：按实际顺序逐行选工序并保存。
7. 【基础数据 → 产品定义】：填唯一编号，选单位和路线后保存。

做完怎么看：产品对应正确路线、工序；每道工序允许实际操作者所在部门报工。

先建用户是因为部门页面从已有人员中选成员；用户档案里也能直接勾选【所属部门】，与部门弹窗双向同步（两边写同一张关联表，改任一处另一处跟着变）。也可先建空部门，但之后还要补成员。委外加工的外部供应商，建议先建一个虚拟部门（如“委外供应商”）统一挂，便于月底按人员类型筛出加工费对账。

## 建账号、改密码

谁来做：管理员。入口：**系统配置 → 用户**。

1. 点【+ 创建用户】，填写账号、姓名，需要时填写手机号和微信号（微信号选填，仅作记录；用户列表可按【微信号】搜人）。
2. 选【人员类型】：**内部员工**（默认，能登录扫码报工）/ **临时用工**（能登录扫码，流程同内部员工，报表上多一个“临时”标签）/ **外部供应商**（不开放登录，由管理员在电脑端代报工，用于结算加工费）。选角色：配置和下单选【管理员（电脑全权限）】；现场复核选【班组长（复核 + 报工）】；只报工选【生产人员（仅手机报工）】。
3. 在【所属部门】多选里勾该用户所属的部门（可多选，管多组的人一次勾完；与部门弹窗选人双向同步，改任一处另一处跟着变）。
4. 填初始密码，包含大写字母、小写字母和数字。点【确定】。
5. 回到列表核对姓名、账号、角色，再把系统地址及个人账号交给本人。

做完怎么看：用户出现在列表中，所属部门、人员类型都正确。生产人员登录后进入手机【工作台】，管理员和班组长进入电脑工单页。外部供应商账号登录会被拒（提示“外部供应商账号不开放登录，由管理员代报工”），属正常；报工权限仍按「用户所属部门 ∩ 工序报权部门」判断。

**选填的两个字段（可不填，用到再配）**：

- **工价系数**：默认 1。客户要求“临时工=正式工 8 折”时，把该员工填 **0.8**，只对这一人生效；计件、计时 × 系数，固定（月薪）不乘，不良扣款不乘。详见《工资与预警》「临时工工价打 8 折」。
- **企微 UserId**：企业微信里该员工的成员【账号】。填了它，派工给这人、或异常上报指定他为处理人时，企微群消息能 **@ 到本人**；留空则只发群不 @，不影响报工/派工。

**停用 / 启用账号（人走即停用）**：列表里每条用户有【状态】列（绿=启用、灰=停用）和【停用/启用】按钮。离职工人点【停用】并二次确认，该账号随即不能登录、不能扫码、不能被派工，**历史报工和工资单原样保留、数字不变**（不是删除）；要用回再点【启用】。不能停用自己，也不能把本厂最后一个管理员停用（会锁死系统）。

忘记密码：找到该用户，点【编辑】，填写【新密码】后点【确定】。新密码留空则保持原密码。当前手机端没有自助改密码入口，由管理员处理。登录填写的是【账号】，不一定是资料中的手机号。

## 建部门、把人加入部门

谁来做：管理员。入口：**系统配置 → 部门**。先建好需要加入的用户。

1. 点【+ 创建部门】，填写【部门编码】和【部门名称】，例如 CJ01、裁切组。
2. 在【成员】中选择已有用户，可多选。需要复核本组的班组长也加入本组。
3. 点【确定】，回列表核对部门及成员。
4. 后续增减人员，点部门右侧【编辑】，调整成员后保存。

做完怎么看：列表【成员】中能看到对应人员。工人能否报一道工序，还要在“工序”里允许这个部门报工。

选不到人：先去“用户”确认账号已建立，再重新打开部门页面。

## 使用 AI 助手查问题

谁来做：仅管理员。入口：**系统配置 → AI 助手**。

1. 看状态，【已关闭】或【未配置】时找部署人员，不影响阅读操作手册。
2. 阅读使用说明。问题和必要资料会发送至配置的 AI 服务，不输入密码、工资等敏感内容。
3. 选【查进度】【问工艺】或【智能客服】，例如“工单 XXX 做到哪了”“产品编号 XXX 的包装要求”“报错数量怎么改”。
4. 遇到多个同名结果时，核对编号、工序再点选；回答要结合来源、明细和查询时间看。

做完怎么看：回答应对应所问工单或本厂资料。无资料时联系管理员补充知识文件（即本 SupportDocs 目录）。

注意：AI 只查询解释，不能替你下单、报工、改数或删除。操作步骤也可直接从【帮助 → 操作手册】查。
