车间小工单 · 更新包（增量）

交付方式：直接交付整个 publish-update 文件夹（不打 zip）。

适用：已用整包 publish-win64 装过一次的客户机。
不要用本包做首次安装。
已上线机禁止用整包 publish-win64 覆盖安装目录（会冲掉 HTTPS/连接串）。

本包更新内容：wwwroot、*.dll（及明确需要的web.config）；另附apply-update、说明和scripts供部署使用。
本包不含 SupportDocs 智能客服知识库；知识库变更走独立部署流程，不随程序增量包发布。
本包不含且 apply-update 绝不覆盖：
- appsettings*.json
- start.bat / stop.bat
- WorkshopMes.exe、*.runtimeconfig.json、*.deps.json
- certs\、logs\

（exe / runtimeconfig / deps 若被覆盖，会提示 You must install .NET）

【本包功能 · 2026-11-12 · 版本 1.1.544】
- 开单据不再把列表吃掉（2026-11-12）：
  以前点开工单、价目表，整页被单据盖住，想换一张单得先退出来。现在单据单独开一个页签，列表页签一直留着，点页签就能来回切；页签名直接显示单号。
- 命令按钮位置统一（2026-11-12）：
  列表页、单据页的「保存 / 启用 / 停用 / 删除 / 调整工价」等命令按钮统一收到页面上方左侧，不再有的在右上、有的在右下；只有小确认弹窗的按钮仍放底栏居中，方便回车。
- 工单弹窗少滚一屏（2026-11-12）：
  从「派工」进来的，默认把上面的工序工价折起来，直接看到派工区；从「查看 / 编辑」进来的，默认折起派工区；新建单仍把工价全展开。三种都能手动展开。
- 单价列只写金额（2026-11-12）：
  本单工序工价里，单价列不再塞提示、明细和「去配价」按钮，只显示金额，鼠标停上去能看这笔金额怎么算出来的；缺价只留一句下一步建议（已有表→改旧表；没表或只有别产品的表→优先建通用表），不再弹按钮把人导走。
- 已审核单只看不改（2026-11-12）：
  已审核、报工中的工单不再显示「编辑」，点进去也改不了；顶部与行内重复的「已审核锁价」「已锁价，不可改」去掉，工艺属性和单价照样看得见，只是不能改。要改内容：没报过工的先反审核，报过工的复制一张新单。
- 浏览单据不写「浏览工单」（2026-11-12）：
  右上角不再写「浏览工单 / 编辑工单」，直接显示工单号；是不是只读，靠左上按钮和灰掉的输入框就看得出。
- 价目表启用后不给随便改（2026-11-12）：
  启用中的价目表不能再进「编辑」改结构，要看就浏览；只改金额用「调整工价」；要改结构先停用，或复制一张新的再改。启用、停用在列表上方最显眼的位置。
- 谁建的、谁启用的一目了然（2026-11-12）：
  价目表单据底部显示创建人/创建时间、启用人/启用时间、停用人/停用时间、修改人/修改时间；工单、工资单详情底部同样显示创建人与修改人，出问题知道找谁。
- 防止别人乱改自己建的单（2026-11-12）：
  系统配置新增「单据权限」页，两个开关（默认关闭，与现在一致）：只让创建人改工单、只让创建人改价目表。打开后非管理员改别人建的单会被拦下并提示联系创建人或管理员；管理员不受限。
- 沿用上一版（1.1.543）已上线：建单缺价按原因分开说清差在哪（草稿未启用 / 已停用 / 过期 / 只有别产品的表 / 本产品挂错工序 / 根本没建表），末句统一「可先暂存或保存，配好启用后再审核」；缺价一眼能定位，「已取价 x / y」可点并滚到第一道缺价；价目表工具栏收紧「新增行」直点、「插入行」进下拉；缺价提示由红色改提醒色；产品「单价」注明是参考价、不计件；复制产品 / 工序后提醒补齐计价规则、作业指导书、图纸。
- 沿用更早版本（1.1.539 起）已上线：跨组顶活——没报权、只要派到也能干（docs/448）；PC 列表页只滚表格；右键复制保留编号 / 名称。

【数据库迁移前置】本次不改表结构定义，新增的列和表由服务启动时幂等补建，无需手工跑脚本、无需改服务器 appsettings：

- 工序价目表：补「创建人 created_by、启用人 activated_by、停用人 deactivated_by、停用时间 deactivated_at、修改人 updated_by」；

（上一版 1.1.513 的审核 / 禁用字段同样由服务启动自动补建；已装过 1.1.513 及以后版本的机器无需任何处理。）
建议：仍先备份数据库再更新，便于回滚。
（若服务器停留在 1.1.410 之前的旧工价结构，须先完成 413 迁移并至少升级到 1.1.424 后再装本包；正常在 1.1.424 及以上的机器无需处理。）

【更新步骤】（一键）
1. 把本文件夹拷到服务器任意位置（如 D:\WorkShop\publish-update）
2. 双击 apply-update.bat（自动：停进程 → 更新 wwwroot/dll → 用安装目录原有 start.bat 拉起）
3. 浏览器 Ctrl+F5，看登录页版本号（应显示 v1.1.544）

目标目录写死：D:\WorkShop\backend\publish-win64（不覆盖 appsettings / start.bat）

【若新版本新增了配置项】
不要整文件覆盖 appsettings.json。对比开发机与服务器键差，只把新键合并进服务器那份，旧值不动。
本包新增配置键（1.1.367 起）：
- `Ai` 段（AI 智能客服）：`Enabled`（默认 true，设 false 可关闭）、`BaseUrl`（默认 https://api.deepseek.com）、`ApiKey`（服务器须填自己的 key）、`Model`（deepseek-flash）、`BusinessTimeZone`、`RequestTimeoutSeconds`、`MaxToolRounds`、`MaxInputChars`、`MaxKnowledgeChars`、`SessionIdleMinutes`、`MaxTurnsPerSession`、`MaxSessionsPerUser`、`MaxSessions`；子段 `Ai:SupportDocs`（`Enabled`/`RootPath`/`MaxFiles`/`MaxFileBytes`/`MaxTotalBytes`/`MaxResults`/`MaxEvidenceChars`）。`Ai:SupportDocs:RootPath` 服务器须指向本机知识库目录。
- `KnowledgeBase:RootPath`：知识库检索根路径，服务器改为本机知识库目录。
（较早的服务器若还没有 `WecomReport` 段，补 `ApiToken` / `FactoryId` / `ConfirmExpireMinutes`，旧值不动。）
（本版「单据权限」两个开关存在数据库 sys_doc_perm 表里，不写 appsettings，不用合并配置；装好后到「系统配置 → 单据权限」打开即可，默认关闭。）

【若已误覆盖出现 “You must install .NET”】
用完整包 publish-win64 里的这两个文件盖回去（不要动 appsettings.json / start.bat）：
- WorkshopMes.runtimeconfig.json
- WorkshopMes.deps.json
必要时再盖 WorkshopMes.exe，并确认同目录有 coreclr.dll。
