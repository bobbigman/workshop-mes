# 把「车间MES智能体」发布成网页链接（发给微信里用）

> 状态：**可做**（可选，不影响已打通的 MCP）  
> 用途：让客户/老板不登录控制台，点一个链接就能跟车间智能体对话。  
> 前置：MCP 已打通，方舟调试会话里能查到工单（已 ✅）。  
> 说明：本清单基于火山引擎公开资料整理；**方舟/HiAgent 控制台界面在变，按钮名以你屏幕实际为准**。

---

## 0. 先把三个名字分清（不然会白找）

| 名字 | 是什么 | 和你现在的关系 |
|---|---|---|
| **火山方舟 Ark** | 大模型/智能体工作台，你现在配 MCP 就是在这 | 你在这搭、在这调试 |
| **HiAgent** | 企业 AI 中台，专门干「发布到飞书/钉钉/微信/网页/API」 | 如果方舟里找不到「发布」，多半要来这里 |
| **豆包 App / 扣子 Coze** | 字节的聊天 App + 机器人平台，另一条线 | 和方舟是两套，走这条要重搭 |

**关键一句：** 你现在在「方舟 Ark」。「发布成网页链接」这件事，公开资料显示**主要能力在 HiAgent**；方舟里有没有直接发布按钮，得看你的界面。

---

## 1. 首选：直接在方舟里找「发布」

> 先花 2 分钟找找，找到最省事。

1. 登录方舟控制台：`https://console.volcengine.com/ark`
2. 打开你的「车间MES智能体」编辑页。
3. 页面右上角、或左侧菜单，找这几个词之一：
   - 「**发布**」
   - 「**上线**」
   - 「**分享 / 分享链接**」
   - 「**应用广场**」（`https://ark.volcengine.com/region:cn-beijing/application`）
4. 点进去看有没有「生成体验链接 / 复制链接 / 公开访问」之类。
5. 有 → 复制链接，发到微信群里点开试。
6. 没有 → 走第 2 步或第 3 步。

> ⚠️ 如果只在「调试/预览」里能聊，那不叫发布，别人点链接进不去。要的是「公开链接」。

---

## 2. 让方舟里的豆包助手带路（最省脑）

你之前让豆包教填 MCP 很好用，同样可以让它教发布：

> 在方舟对话里问：  
> 「我这个智能体怎么发布成一个公开网页链接，让不登录控制台的人也能点开聊？一步一步教我，界面按钮名不对就让我念给你听。」

它会一步步带你点。**比这份文档更准**，因为它能看到你账户界面（如果方舟助手有页面引导能力）。

---

## 3. 如果方舟没有「网页发布」→ 转 HiAgent

HiAgent 是火山引擎专门做「发布到飞书/钉钉/微信 + WebSDK + API」的企业中台（见 [HiAgent 产品页](https://www.volcengine.com/product/hiagent)）。

大意步骤（公开资料，非逐屏截图）：

1. 进 HiAgent（火山引擎控制台里搜「HiAgent」，开通服务）。
2. 把智能体重搭一遍（或把方舟的智能体/应用纳管过来），**重新接同一个 MCP**：
   - MCP URL：`https://209c3f5f.r19.vip.cpolar.cn/mcp?token=laohu-demo-2026`（以当时 `Mcp:AuthBaseUrl` 为准）
3. 进「**发布**」模块。
4. 选「**WebSDK / 网页端**」或「飞书 / 企业微信」。
5. 生成网页访问链接或嵌入代码，贴到你的页面/发到微信。

> 代价：等于换个平台再配一遍，MCP 本身不用动，但智能体的提示词/知识库要重搭。**宣传演示阶段不一定要走到这步。**

## 4. 给你的建议顺序（先轻后重）

| 步骤 | 动作 | 成本 |
|---|---|---|
| 1 | 方舟里找「发布/分享」按钮 | 2 分钟，零成本 |
| 2 | 让方舟豆包助手带路 | 5 分钟，零成本 |
| 3 | 转 HiAgent 正式发布 | 半天～1 天，要重搭 |

**别急着上 HiAgent。** 先 1、2 试一轮；真要长期给员工/客户用、且要微信常驻，再考虑 HiAgent + 企业微信。

---

## 5. 提醒

- 「发布」≠「重新配 MCP」。MCP 已经通了，发布只是给智能体开个**公开入口**。
- 你担心的「个人微信机器人」——**官方没有接口**，网上那些会封号；想进微信走「企业微信 / 公众号 / 网页链接」。
- 无论发布到哪，授权闭环（查工单前先 `start_auth` 拿授权码）还在，用户第一次也要点一下授权链接。宣传前先想好怎么跟客户解释这一下。
