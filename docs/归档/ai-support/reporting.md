# 报工与复核

> 与操作手册同源生成；维护 docs/30、31 和 docs/manual 正文后运行 npm run manual:sync。

## 电脑报工

谁来做：管理员、班组长。入口：**生产管理 → 报工**；也可在工单行点【报工】。

1. 点【+ 报工】，输入工单编号，点【加载】或按回车。
2. 核对产品，选工序，查看【计划、良品、不良、剩余】。
3. 填本次【良品数】和【不良品数】，不是从开工至今的累计数。
4. 不良品大于 0 时选【不良原因】。需要记录时长时填小时和分钟，单次合计不超过 24 小时。
5. 点【提交】保存并关闭；同张单继续报下一批，点【继续报工】。

做完怎么看：查询工单号，核对工序、报工人、数量和复核状态。管理员新增直接【已通过】，班组长新增为【待复核】。

注意：普通【+ 报工】记在当前登录人名下，没有“代谁报”字段。需要把漏报记到实际工人名下，管理员使用“一键补报未完工序”的拆分功能，并先核实实际完成情况。

## 复核：通过或退回报工

谁来做：管理员、班组长。入口：**生产管理 → 报工复核**。班组长只能复核与自己有共同部门的人员报工。

1. 输入工单编号或工人姓名，选【待复核】，点【查询】。
2. 核对工序、工人、良品、不良、时长，正确的点【通过】。
3. 多条都已核对，可勾选后点【批量通过】，核对条数再确认。
4. 有问题点【退回】，写具体原因，例如“实际为 18 件，请核对”，点【确定退回】。
5. 纠正已通过记录，先选【已通过】查询，再退回。已结算报工不能退回。

做完怎么看：切到【已通过】或【已退回】查询确认。通过后计入生产报表；退回后不计有效进度，工单状态可能变化。

注意：退回后核对并修改原记录，不要未经确认另报一遍。原记录修改后回到待复核。

## 报错数量怎么改

谁来做：管理员；班组长只能改自己的记录。当前手机端没有历史改数页，工人发现错误联系管理员。

1. 在【生产管理 → 报工】查询工单，按工序、人员和时间找到原记录。
2. 已通过且【修改】不可点时，先到【报工复核】退回这条记录并写原因。
3. 回【报工】重新查询，点原记录【修改】，填正确的良品、不良、原因、时长，点【保存】。
4. 到【报工复核】重新核对通过；管理员改数后同样需要复核。

做完怎么看：原记录数量变更，保存后为【待复核】，通过后再查报表。误报 20、实际 18，就改为 18，不是填 -2。

注意：已结算记录不能改或退回，交结算负责人核查。

## 一键补报未完工序

谁来做：仅管理员、电脑端。入口：**生产管理 → 报工 → 一键补报未完工序**。

1. 先核实哪些工序确实做过、谁做的，确认是漏报。
2. 输入工单号点【加载】，检查【待报工序】。系统对列出的所有未报满工序补同一数量，不能在这里只挑一道。
3. 填【统一良品数】，不得超过各工序【剩余可报】的最小值。两道剩余 30、20，本次最多统一补 20。
4. 不拆分记当前管理员名下。要记实际工人，勾【按工序拆分到人】，逐道选人和数量，每道合计必须等于统一良品数，可用【+ 加人】增加人员。
5. 核对后点【确认补报】。

做完怎么看：出现“已为…道工序生成…条报工”提示；回列表逐条核对人员、工序、数量。管理员补报直接已通过。

注意：这不是“报末道自动补前面”。未做的工序不能补报；各道漏报量不同要分别核实处理。已结束、已取消不能补报。

## 处理现场异常上报

谁来做：管理员、班组长。入口：**生产管理 → 异常处理**。

工人手机上报设备故障/物料短缺/质量异常后，本页「待处理」对管理员和班组长全员可见（不分班组）。核对描述与照片后点【标记恢复】，可选填处理说明。恢复后车间看板红标与滚动播报消失。

做完怎么看：该条进入「已恢复」；看板「待处理异常」数字下降。

注意：试用期不推企业微信，靠看板和本列表看见。

## 用手机摄像头扫码

入口：底部【扫码】。首次进入默认摄像头待启动。

1. 点【打开摄像头扫码】，浏览器询问时允许摄像头（不要开麦克风）。
2. 把流转卡二维码对准画面，识别成功后进入报工页；先核对工单号和产品。
3. 不允许摄像头、打不开或提示需要 HTTPS 时：改用【手动输入工单号】，或让管理员检查 HTTPS/证书。
4. 切到别的页或锁屏后摄像头会停；回来再点【打开摄像头扫码】。

做完怎么看：出现正确工单的报工页，可以选择工序。扫码本身不会自动提交报工。

注意：HTTP 地址通常无法开摄像头。系统相机扫「报工页链接」打开网页，与本页「打开摄像头」是两回事。

## 用 PDA 扫码枪，或手动输入

入口：底部【扫码】→【扫码枪模式】；或任意模式下点【手动输入工单号】。

1. PDA：点【扫码枪模式】，看到“等待扫描工单”；扫码头设成“像键盘一样输入、扫完自动回车”。
2. 扫码后进入报工页，先核对工单号、产品。本机记住扫码枪模式后，下次打开扫码页可直接扫。
3. 扫不出可点【手动输入工单号】，填纸上编号，点【确定】；返回后继续扫或再开摄像头。
4. 要改回手机摄像头：点【摄像头扫码】。

做完怎么看：出现正确工单的报工页，可以选择工序。

注意：手动输入只填工单号，不要把整段网址贴进去。外部扫码工具扫到链接时可直接打开；未登录时登录成功后应回到该工单。

## 选工序、填本次数量

入口：打开工单后的报工页。只填写实际做过的活。

1. 在【工序】选当前这道，例如“裁切”。上方【计划、已完成、剩余可报】随工序变化。
2. 【本次良品】填这一批合格件数。前一批报 20，这一批做 15，就填 15，不是 35。
3. 【不良品】填本批不合格数，没有填 0；大于 0 时选【不良品原因】。
4. 需要记录时长就填小时、分钟，分钟为 0～59，单次总时长不超过 24 小时。
5. 再核对工单、工序、良品、不良后提交。

例子：本批共做 20 件，18 件合格、2 件尺寸不合格，本次良品填 18，不良品填 2，原因选“尺寸不合格”。

做完怎么看：数字与本批实物一致，良品不超过剩余可报。不良数不占良品上限，但仍必须如实填。

注意：【报全部剩余】只把剩余数填入输入框，不判断实际完成量；只有确实全做完才用。已报满时不要换工序凑数。

## 提交后怎么确认成功

1. 本次结束点【提交报工】，显示“报工成功”后回扫码页。
2. 同单同工序连续报下一批，点【继续报工】；成功后留在原页，数量和时长清空，进度刷新。
3. 再打开同单选同工序，可核对已完成和剩余可报。多人同时报工时，进度也包含其他人的数量。

做完怎么看：“报工成功”说明已提交。工人提交需班组长或管理员复核，通过后才进入生产报表。

注意：成功后不要把同批再提交。断网、报错或不确定结果时，先让班组长按工单、姓名、时间查记录，确认没有保存后再处理。

## 现场异常怎么上报

入口：底部【异常】。遇到设备故障、缺料或质量问题，主动上报，不要等系统猜。

1. 选类型：【设备故障】【物料短缺】【质量异常】三选一。
2. 写清楚问题描述；需要时可选填工单号、拍一张照片。
3. 点【提交上报】，看到“上报成功”。

做完怎么看：班组长或管理员在电脑【异常处理】能看到；车间看板会出现红色滚动提示，处理恢复后消失。

注意：试用期不发企业微信，靠看板和电脑列表通知负责人。
