# 黑湖对标速记（扒黑湖结论，出门 / 演示前扫一眼）

> 用途：把几轮扒黑湖的结论收拢一处，避免下次重扒。
> 来源：抖音黑湖陌拜实拍 + 黑湖官网/官方文档 + 简道云官方文档（2026-09 扒）。
> 关联：`docs/77`（界面卖点落地）、`docs/37`（上门演示脚本）、`docs/1D`（对标纠偏）。

---

## 一、黑湖陌拜实际当卖点的（有实拍佐证）

1. **开场先戳 4 痛点**：图纸版本乱做错料 / 插单改单进度看不清 / 报工计件靠手工 / 质量追溯难。
2. **主打卖点**：进度透明（"管 ERP 管不到的执行层"）、扫码出入库账料吻合、计件计时工资自动算、质量追溯、轻量便宜快（小微厂、2 天上线、10 分钟上手）。
3. **打法**：先问诊后解药、按需匹配不泛泛讲（印证王雩式）。

## 二、黑湖是"吹的"（别被唬住）

- **"每个工单料+人工+利润算得清"** —— 销售个别口播，黑湖官方**无工单级成本利润核算**（官方定位"不替代 ERP 财务核算"）。
- **深度"料批次追溯"** —— 黑湖小工单管不了采购/领料，做全就交付重，**做不到**（黑湖智造重型 MES 才有）。

## 三、黑湖有的，咱要跟（不输项）

- **报工拍照 / 现场照片** —— 黑湖基础版、简道云免费版都有，是**标配不是旗舰**。咱改动小（复用异常上报机制），**做了打平，别当卖点吹**。

## 四、咱的差异化（黑湖小工单没有的）

- **本地部署、断外网也能用、数据不出厂**（黑湖云端要联网、数据在对方云）。
- **能接金蝶、数据不重复录**（建议报价 / 排产评分）。
- **工资按厂规矩算、可重算**（黑湖口径偏僵）。
- **按厂收费不按人头**。

## 五、咱不能碰的（黑湖有、咱没有，一问穿帮）

- **扫码出入库 / 库存台账** —— 咱没有库存模块（进销存范围外，`docs/1D`）。黑湖陌拜主打里唯一不能接的，**砍掉、别吹**。

## 六、出处速查

| 结论 | 依据 |
|---|---|
| 陌拜 4 痛点 + 卖点 | 抖音黑湖陌拜实拍（非标机加、汽配） |
| 拍照是标配 | 黑湖官方文档（图片字段/质检拍照）、简道云官方（图片字段免费版可用） |
| 成本利润是吹 | 黑湖官方定位"不替代 ERP 财务核算"，产品页无此功能 |
| 咱能力边界 | `docs/1D`（进销存范围外）、`docs/77`、`docs/37` |
