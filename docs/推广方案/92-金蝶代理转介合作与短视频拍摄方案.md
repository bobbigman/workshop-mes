# 金蝶代理转介合作与短视频拍摄方案

保存日期：2026-09-30

文档分工：本文件用于内部管理合作规则和视频安排；第1条的唯一完整制作稿见[93-第1条视频-AI制作指令](93-第1条视频-AI制作指令.md)。以后调整第1条口播、画面或发布文案，只修改93。

本文保存本次讨论提出的方案，供拍摄和合作洽谈使用；介绍费与服务承诺属于拟议规则，不覆盖现有产品定价文件，正式对外使用前须落实到合作约定。

## 一、推广定位

- 产品：金蝶的轻量配套，不替换客户现有金蝶，只增加车间扫码报工和看板。
- 客户：正在使用金蝶的50—800人钣金、五金厂。
- 视频只给本地金蝶代理商的销售、实施顾问看。
- 目的：让他们遇到车间扫码需求时想到找我，主动加微信或私聊。
- 价格入口：500元配置试用7天，正式年费三千多起。
- 制作方式：可真人手机竖拍或AI制作；第1条按93号制作指令执行。软件画面使用虚拟演示账套或脱敏素材，每条以实际配音或口播计时为准，控制在60秒以内。

## 二、唯一主推合作模式

**代理引荐，我负责需求确认、演示和交付；合作分工与收益在介绍客户前约定，不公开承诺固定介绍费。**

对外名称：金蝶客户车间需求转介合作。

| 事项 | 拟议规则 |
|---|---|
| 代理做什么 | 经客户同意，介绍双方认识，并帮助确认确实存在车间报工需求 |
| 我做什么 | 需求确认、演示、报价、试用配置、培训及产品售后 |
| 谁签合同、收款 | 车间软件由我与客户签约收款，承担约定交付责任；原金蝶业务仍由原服务方负责 |
| 代理收益 | 在介绍客户前，结合正式订单金额、双方工作量及交付成本，书面约定收益金额或比例、结算条件、时间及退款处理；500元为客户支付的配置试用费，不代表正式成交，也不自动触发介绍费 |
| 客户关系 | 事先登记引荐客户；未经合作方同意，不向该客户推销金蝶替换、续费或其他无关业务 |
| 结算对象 | 按代理公司认可的方式向合作方结算，不私下承诺给其员工回扣 |
| 交付边界 | 金蝶接口、现场服务、定制需求先确认并单独列明，不默认包含在三千多的基础年费中 |

统一成交顺序：先确认需求和流程适配 → 客户支付500元配置试用7天 → 跑通后再谈正式购买。基础档必须守住服务范围，不能同时包反复上门和免费接口开发。合作收益先约定，不能先承诺金额、再计算交付成本。

50—800人的跨度很大。试用统一从一个班组、一条真实工单开始，不承诺7天全厂上线。

视频中明确利益没有问题，但不用“零风险”“保证保住续费”等无法保证的说法。具体讲清代理不用进货、不用先付款、不用先学产品，以及我承担哪些工作。公开视频只说合作分工和收益提前约定；具体结算条件在介绍客户前私下说清楚。

## 三、四条视频安排

### 第1条：客户问车间进度，你多一个能接需求的人

- 目的：让本地金蝶销售、实施顾问知道，遇到车间扫码和查进度需求，可以找我确认需求、演示并安排配置试用。
- 核心利益：不用先买软件、不用先学产品；合作分工和收益在介绍客户前约定。
- **完整口播、画面、封面、发布文案及交付要求，统一维护在[93-第1条视频-AI制作指令](93-第1条视频-AI制作指令.md)。** 本文不再重复保存第1条完整稿，制作时只发93。

### 第2条：不用先学我的软件，拿一张客户工单来就行

#### 口播

做金蝶实施已经够忙了，再来一个车间扫码软件，还要你自己学、自己讲，确实麻烦。

跟我合作，第一步不用学产品。经客户同意，拿一张隐去客户信息的工单，告诉我三个事：有几道工序，谁报数量，老板想看什么。

我拿这张单演示。合适，再由客户付500元做七天配置试用；不合适，就把原因讲清楚。

资料配置、操作培训、产品问题，由我直接对接。涉及原金蝶的调整，提前和你确认。

手上有这种需求，私聊我“工单”。

#### 拍摄动作与利益传递

- 桌上放一张自制纸工单，只写产品、数量、三道工序。
- 用笔圈出：**工序、报工人、想看的进度**。
- 指向电脑中对应的演示工单，展示能把纸单变成演示。
- 利益：他不用背功能、组织完整方案，只需要提供具体需求；我承担前期讲解工作。

#### 朋友圈配文

不用先研究我的产品。客户愿意的话，给我一张脱敏工单，我来判断能不能做、怎么演示。合适再开500元七天配置试用。你手上有车间报工需求，私聊“工单”。

#### 视频号标题

金蝶实施顾问：一张工单，就能开始聊车间需求

#### 视频号配文

先看真实流程，再决定是否试用。你提供需求背景，我负责车间软件演示与适配确认。主页联系，备注“工单”；不要在公开评论里发客户资料。

### 第3条：介绍客户之前，先把客户归属和售后说清楚

#### 口播

介绍客户给别人，顾虑往往有两个：以后他会不会绕过我？软件出问题，会不会又来找我？

所以我先把规则写清楚。

你引荐的客户，先登记；原来的金蝶服务关系不变。未经你同意，我不向客户推销金蝶替换、续费或其他无关业务。

车间软件由我签约、交付，客户有产品问题直接找我。涉及金蝶的问题，我先说明边界，再和你协调。

这些写进合作约定，不只在视频里说。

想先看约定，私聊我“规则”。

#### 拍摄动作与利益传递

- 电脑旁摆大字纸：**先登记客户｜原金蝶服务不变｜车间软件找我**。
- 每讲一条，用手指对应一行，不必操作软件。
- 利益：保护原有业务关系，明确产品问题先找谁。
- 不说“你完全没有责任”，接口和跨系统问题仍可能需要双方协调。

#### 朋友圈配文

介绍客户，先把规则说清楚：引荐登记、原金蝶服务关系、车间产品售后、介绍费结算时间。愿意合作的朋友，私聊“规则”，先看清楚再介绍。

#### 视频号标题

介绍客户之前，先说清谁交付、谁售后

#### 视频号配文

金蝶客户车间扫码合作：客户引荐先登记，车间软件由我直接签约和交付，原金蝶业务边界事先约定。主页联系，备注“规则”。

### 第4条：客户怕折腾，先跑一张真实工单

#### 口播

客户听完演示，说“可以，但怕工人不用”，这时别急着谈全厂上线。

我的做法是先确认流程，再由客户付500元做七天配置试用。从一个班组、一张真实工单开始。

我和客户事先约好看三件事：能不能正常扫码报数量，报错能不能处理，老板能不能看懂每道工序还剩多少。

客户需要安排一个负责人，我负责配置和指导。先把这一步跑通，再谈正式购买。

你有卡在“怕用不起来”的客户，私聊我“试跑”，一起看能不能做。

#### 拍摄动作与利益传递

- 电脑打开只有一张工单的演示列表，不展示复杂菜单。
- 桌上放纸：**一个班组｜一张工单｜三个检查点**。
- 指一下扫码入口，再指工序完成数量。无需现场完整扫码，避免一镜到底时出错。
- 利益：给犹豫的客户一个具体下一步，不必先承诺全厂成功；配置和指导由我承担。

#### 朋友圈配文

客户有车间扫码需求，又担心工人用不起来，可以先从一张真实工单试跑。500元七天配置试用，先确认适配和验收范围，不承诺七天全厂上线。私聊“试跑”。

#### 视频号标题

客户怕扫码报工用不起来，先试一张工单

#### 视频号配文

从一个班组验证扫码、数量和工序进度。客户安排负责人，我负责配置与指导。金蝶销售、实施朋友有这类需求，可通过主页联系，备注“试跑”。

## 四、发布与私聊承接

1. 先发第1条，再发第3条。先交代合作机会，再说明客户关系和售后责任；第2、4条用于进一步解释怎么开始。
2. 微信个人简介或视频号介绍写：**常驻××，做金蝶客户车间扫码报工配套。合作请私信。** 填真实城市。
3. 所有视频和朋友圈文案均不承诺固定介绍费，统一为“合作分工和收益提前约定”。后三条分别回答“费不费我时间”“会不会影响客户关系”“客户能不能用起来”。
4. 有人回复后，先发合作规则，再问：**你手头有没有客户正在问这件事？先不报客户名字，讲讲现在怎么报工、哪里查不清就行。**

核心传递：遇到车间扫码需求，我可以接手看，合作边界事先写清。利益不能只说能赚钱，还要说清对方需要干多少活、双方承担哪些工作。
