# 第1条视频-AI制作指令

请帮我用AI制作一条竖屏口播视频。只做这一条，按下面的文案和画面要求制作，先给我预览，不要直接发布。

一、视频给谁看、希望他做什么

观众只有一类：本地金蝶代理商的销售、实施顾问，不是工厂老板。

我做的是车间扫码报工软件，作为客户现有金蝶系统的轻量配套，不替换金蝶。

希望观众看完后记住：遇到客户问车间扫码、查生产进度，可以叫我一起看。我负责需求确认、演示、试用配置和产品支持。

最终引导他私聊我“合作”。

本条不出现800元，也不承诺任何固定介绍费。合作分工和收益，在介绍客户之前私下约定。

二、成片要求

- 9:16竖屏，1080×1920。
- 总时长不超过60秒，目标55秒左右。先生成配音计时，再安排画面，不要用明显加速的声音硬塞文案。
- 风格朴实，像一个做软件的人向同行说明合作。
- 使用自然的中文AI口播人物，普通商务便装，坐在电脑旁。语气平稳，有正常停顿，不用激情推销腔。
- 如果要使用我的脸或克隆我的声音，先找我要授权素材；没有素材就用有商用授权的通用数字人，不冒充我本人。
- 全程中文字幕，每屏最多两行，手机上清楚可读，避开底部和右侧平台按钮区域。
- 不用复杂转场、炫酷特效、金钱动画。背景音乐可以不加，有音乐也不能盖过人声。
- 不用金蝶官方标志，不暗示我是金蝶员工、原厂或官方认证合作方。

三、完整口播文案

做金蝶销售、实施的朋友，客户有没有问过：金蝶在用了，车间订单做到哪儿，怎么还得打电话问？

我做车间扫码报工：电脑开工单，工人扫码报数量，管理人员看进度，不用换现有金蝶。

遇到这类需求，可以叫我一起看。我负责确认需求和演示，你不用先买软件，也不用先学产品。

流程合适，客户付五百元，做七天配置试用。从一个班组、一张真实工单开始，先看能不能用起来。

配置和产品支持我来做，合作分工和收益提前说清楚。

有需求，私聊我“合作”。

四、画面安排

时间是参考，以自然口播为准。

【第一段：约0—11秒】
口播：
“做金蝶销售、实施的朋友，客户有没有问过：金蝶在用了，车间订单做到哪儿，怎么还得打电话问？”

画面：
- 数字人看镜头。
- 顶部显示：“给本地金蝶销售、实施的朋友”
- 旁边出现问题卡：“客户问：订单做到哪道工序了？”

目的：
开头就让观众知道是在跟他说话，同时让他想起客户问过的具体问题。

【第二段：约11—22秒】
口播：
“我做车间扫码报工：电脑开工单，工人扫码报数量，管理人员看进度，不用换现有金蝶。”

画面：
- 展示简单流程卡：
  电脑开工单 → 工人扫码报数量 → 管理人员看进度
- 配重点字：“不替换现有金蝶”
- 有真实软件录屏时，展示一张工单及其工序完成数量；使用虚拟数据或脱敏数据。
- 没有录屏，就用文字流程卡并标注“流程示意”，不要让AI编造产品界面。

目的：
让他迅速理解产品做什么，知道这是车间配套需求。

注意：
“不换金蝶”不等于“已经自动对接金蝶”。不要出现“无缝对接、自动同步、免费接口”等承诺。

【第三段：约22—34秒】
口播：
“遇到这类需求，可以叫我一起看。我负责确认需求和演示，你不用先买软件，也不用先学产品。”

画面：
回到数字人，旁边依次出现：
- 你：介绍需求
- 我：确认需求、演示
- 不用先买软件
- 不用先学产品

目的：
具体传递合作利益：代理不用先投入采购费用，也不用先掌握另一套软件才能开始介绍。

【第四段：约34—47秒】
口播：
“流程合适，客户付五百元，做七天配置试用。从一个班组、一张真实工单开始，先看能不能用起来。”

画面：
展示试用卡：
- 先确认流程适合
- 客户支付500元
- 7天配置试用
- 一个班组、一张真实工单

卡片底部注明：
“试用通过后，再谈正式购买”

目的：
让代理知道如何带客户迈出第一步，不需要先承诺全厂上线。

注意：
必须明确500元由客户支付，不是代理支付。
不能把500元写成软件买断价、正式年费或全厂实施价。
不能写“7天保证上线”“包用起来”。

【第五段：约47—58秒】
口播：
“配置和产品支持我来做，合作分工和收益提前说清楚。有需求，私聊我‘合作’。”

画面：
- 回到数字人。
- 出现：“试用配置、产品支持由我负责”
- 再出现：“合作分工和收益，提前约定”
- 结尾大字：“有车间扫码需求，私聊‘合作’”
- 显示我确认的称呼和真实城市。
- 结尾联系卡至少保留3秒，可在最后一句口播时开始显示。

目的：
让他知道后续有人负责，也有合作收益可谈，最后明确引导私聊。

五、封面

主标题：
客户问车间扫码，可以找我

副标题：
给本地金蝶销售、实施的合作说明

封面不放500元，不放介绍费，不写“零风险”“躺赚”“保证成交”。先突出合作场景。

六、需要我提供的素材

制作前集中找我要以下素材：
1. 对外称呼和常驻城市。
2. 软件工单、报工、进度页面的虚拟演示截图或短录屏。
3. 如要在片尾放联系方式，向我要准确微信号或二维码原图。

没有软件素材，就按文字流程卡制作。
没有联系方式素材，就保留“私聊‘合作’”的引导，不编造微信号，不用AI生成二维码。
最终成片不要留下“××城市”“你的姓名”等占位文字。

我负责需求确认和演示；流程合适，客户再付500元做七天配置试用，从一个班组、一张真实工单开始。你不用先买软件，也不用先学产品。

合作分工和收益提前说清楚。有需求，私聊我“合作”。

【视频号标题】

做金蝶的，客户问车间扫码时可以找我

【视频号配文】

金蝶客户车间扫码报工配套，不替换现有系统。先确认需求，合适再由客户付费试用；我负责演示、试用配置和产品支持。合作分工与收益提前约定，感兴趣请私信“合作”。

八、交付与检查

请交付：
- 一条完整MP4预览视频。
- 一张竖版封面图。
- 如制作工具支持，保留可修改的工程或模板。

交付前检查：
- 时长不超过60秒，口播自然清楚。
- 口播、字幕一致，没有错字。
- 没有800元或其他固定介绍费承诺。
- 明确500元是客户支付的7天配置试用费。
- 没有承诺自动对接、免费接口、全厂实施或保证成功。
- 没有虚构客户、案例、软件界面和联系方式。

先发我确认，再考虑发布。发布时按平台要求声明AI生成或合成内容。
