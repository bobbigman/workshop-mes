## 一、三者本质区别（一句话）

| | 黑湖小工单 | 简道云·车间管理 | 你的小工单 |
|---|---|---|---|
| 模式 | SaaS 云端**成品**，即开即用 | 零代码**平台**，自己搭 | 本地部署**成品** + 上门陪跑 |

## 三、结论：你的四格差异 = 销售话术

1. **本地部署·数据不出厂**——黑湖（云端）、简道云（公有云）都没有，是你唯一的物理级差异，直接回老板最怕的"数据放别人服务器"。
2. **核心生产链功能与旗舰版同档**——派工、报工、复核、交期预警、异常上报、计件工资你全有，但首年只收 8800（黑湖专业版 10800 的 8 折），含上门实施。
3. **简道云的地板价要拆穿**——8000 起是"平台费"，车间功能是积木要自己搭；你是成品+上门，同价卖的是"跑起来"。
4. **金蝶 MCP 是你没有的钩子**——黑湖简道云都不接金蝶主数据，你已做相似件报价（72），这正是金蝶伙伴客户的开口话。
