## 一、一句话总结

**引流 / 陌拜 / 伙伴不是选择题，是时间顺序：先自己陌拜 + 灯塔干出案例（证据 1/2/3），再让伙伴推。视频是副引擎和销售工具，不是获客主引擎，别把 KPI 押在它身上。**

## 二、三个推广视频的点评结论（v1 / v2 / v3）

| 视频 | 定位 | 结论 | 处理 |
|---|---|---|---|
| v3 手机屏内演示（34s） | 主视频 | 三个里最好，手机 + 屏内演示有代入感 | 改开头（前 3 秒戳痛点）+ 结尾 CTA 后主推 |
| v1 无真人版（41s） | 完整演示版 | 信息最全（含本地部署卖点），41 秒太长 | 当长版放视频号主页置顶 |
| v2 AI 人物版（34s） | 降级 | AI 假人假车间 = 信任减分 | 只当抖音素材，不当主力 |
| v4 生活有空版 | 弃 | 文件损坏（缺 moov 索引），无法播放 | 不用管，重新生成 |

**共性五条改法（每条视频都适用）：**

1. 开头前 3 秒戳痛点（"客户又催货，你都不知道这张单做到哪了？"），不做自我介绍开头；
2. 一条视频只讲一件事（这条讲扫码报工、那条讲交期）；
3. 结尾行动指令要具体（"私信我，免费上门帮你把车间跑起来"）；
4. 信任感排序：真车间实拍 > 手机屏内演示 > AI 假人；
5. 时长砍到 15–30 秒。

**额外发现：** 黑湖在 B 站发的是"实操教学视频"（跟着视频跑通你的第一单），不是广告片。后续应做一条"10 分钟带你跑通车间第一单"的录屏教学，发 B 站 + 视频号。

## 三、微信视频怎么发（朋友圈 ≠ 视频号）

- **朋友圈 = 封闭环**：没有算法，只给好友看，不会扩散给陌生人。唯一出路是好友手动转发（人肉扩散），所以朋友圈文案的使命是**求转发，不是求赞**。
- **视频号 = 开放环**：算法推荐 + 社交推荐，内容好会被推给陌生人（包括在刷"车间管理、报工、工厂数字化"的老板）。标题/话题带关键词，好友点赞触发社交推荐。
- **抖音**：算法更强，适合做"车间痛点系列"长线内容（一周 2–3 条，3 个月见效），不占本月 KPI。
- **小红书**：打被忽略的人群——工厂老板娘 / 厂二代（很多小厂的账和采购是她们管）。做"厂二代接手爸爸的工厂"叙事流，做补充不做主攻。

**三平台分工：** 视频号 = 私域信任 + 转发主阵地；抖音 = 算法引流放大器；小红书 = 老板娘/厂二代故事。上门 = 成交动作。

## 四、视频引流 → 上门成交闭环

```
发视频 → 私信/加微信（线索）→ 发一页纸方案+演示 → 上门演示 → 成交
                                                              ↓
                                      拍真车间案例 → 变成下一支素材（信任飞轮）
```

- 视频 KPI = 私信 / 评论 / 加微信人数，**不是播放量**（每条 3–5 条私信即达标）；
- 私信的人 24 小时内发方案并约上门；
- **视频解决"认识你"，上门解决"掏钱"。**

## 五、陌拜（主动扫街）执行要点

- **目标不是当场成交，是"要微信 + 记录线索"**。漏斗：200 家 → 50 个微信 → 15 次上门 → 3–5 单。
- **进门第一句话**：别跟保安说"我是做车间管理系统的"（必被挡）。给保安一个"不用负责"的理由："师傅，我找老板，之前给厂里留过车间管理的资料，今天当面说两句"；或递资料 + 要微信："这是给老板的资料，方便转交吗？我留个微信。"
- **一页纸资料（不是手册）**：痛点大字 → 3 张截图（扫码报工 / 工序进度 / 交期）→ 差异化一句（比黑湖便宜 · 本地部署数据不出厂 · 免费上门装一条产线试用）→ 微信二维码 + "扫码看 30 秒演示" + 电话。
- **三轮跟进**：扫街要微信 → 当天晚上发方案约上门 → 一周后二访（"上次资料看了吗"）——很多单是二访三访出的。
- **筛选**：20–100 人五金 / 注塑 / 电子 / 线束厂；门口看"有货在装、在招工、机器在响"；一天一片工业园（仲恺 / 惠阳 / 大亚湾轮着来）。

## 六、渠道先后顺序（今天最重要的结论）

**不是"伙伴主力 vs 自己单干"的二选一，是先后顺序：**

```
路线A（✗ 现在就先靠伙伴推）：
  找2个原型 → 让伙伴当主力推 → 没案例背书 → 伙伴观望 → 三个月说服，留不住

路线B（✓ 先自己干出案例，再让伙伴推）：
  自己陌拜+灯塔第1家 → 第1家跑通（月底真出计件工资单）
  → 证据1/2/3（能参观的车间、实名案例、可复制SOP）
  → 带证据谈伙伴 → 推荐+分成 → 伙伴成主力
```

理由：

1. 伙伴观望的就是"有没有案例"（`docs/55` §0 原话）；
2. 视频角色随阶段变：现在是敲门砖（模拟演示），第 1 家跑通后拍的真车间视频 + 老板 60 秒口播，才是给伙伴转发的弹药（`docs/55` §5："他转发到同行群的那条 60 秒视频，是你最贵的广告位"）；
3. 没案例就找伙伴 = 被无视；方案先亮给伙伴 = 被扒。顺序对了，两个担心自动消失。

**90 天节奏：**

| 时间段 | 动作 | 视频角色 |
|---|---|---|
| 第 1–30 天 | 自己陌拜 + 灯塔第 1 家；视频照发 | 敲门砖（KPI = 私信数） |
| 第 31–60 天 | 第 1 家跑通 → 拍真车间视频 + 老板口播 → 一页纸案例 | 从"模拟"换"真实" |
| 第 61–90 天 | 带证据约 2–3 个金蝶 / 老伙伴，谈"推荐 + 分成" | 伙伴转发，成放大器 |
| 全年 | 自己出 10 家以内 + 伙伴/转介绍补足 → 20 家 | — |

## 七、20 家/年 目标与交付瓶颈

- 20 万/年 = 20 家存量 × 年费；复购（次年起 6800 远程）是第二年粮仓（`docs/55` 已定）。
- **真实瓶颈不是获客，是交付**：`docs/1E` §9 每客户一个 IIS 站点/池 + 一套库、升级逐实例执行；`docs/55` 因此把灯塔上限卡在 3 家。
- "不靠代理"最多撑第一年；20 家/年必须建立在 ① 批量升级机制解决，或 ② 伙伴承接交付（伙伴能自己交付，才敢报你的价）。
- 口径提醒：3 单/月（36/年）与 20 家/年不一致，**以 20 家/年为年度主线**（solo 舒服目标）。

## 八、金蝶伙伴合作（拆解两个恐惧）

- **"没案例不会被回复"** → 对。解法不是先攒案例，是"第 1 家跑通就带证据谈"（`docs/55` §0）。
- **"方案被扒"** → 拆开看：会扒的是有研发能力的伙伴，那是竞争对手不是渠道，本就不该合作；金蝶伙伴多为销售/实施型，只会卖不会扒。防扒动作：不给源码；交付 = 部署 + 实施 + 年费；迭代权在你（`docs/55` 红线：不为单家改代码）。
- **敲门砖**：金蝶 MCP（`docs/36` 排产评分、`docs/72` 相似件建议报价）——"金蝶主数据不用录第二遍、报价对得上车间真实干了多久"，是进金蝶客户池的钩子，也是谈伙伴的凭据："我不是来抢你客户，是来帮你补车间这块。"

## 九、已定盘口径（记录，不再展开）

- 工资：首版只出**计件工资单**（可查可重算），不含社保 / 考勤 / 底薪 / 个税 / 代发。演示必须说清："计件工资自动算，月底不用拿表对、工人不吵架；底薪社保考勤还是财务那边发，两边对账，不冲突。"（`docs/32` 已留外挂口子，财务工资是以后的外挂加价项。）
