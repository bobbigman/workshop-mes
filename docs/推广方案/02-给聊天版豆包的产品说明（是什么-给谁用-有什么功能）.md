## 一、一句话说清：这是什么

我做了一套**面向中小工厂/车间老板的轻量生产管理系统（MES）**，对标市面上的「黑湖小工单」。核心主链路一句话：

> **电脑下单出二维码 → 工人扫码报工 → 班组长复核 → 老板大屏看进度**

它把车间里"纸上写工单、口头报数、月底对账、靠下车间问进度"的老办法，换成"扫码报工 + 实时看板 + 工资自动算 + 交期自动提醒"。

技术底子：后端 .NET 8 + SQL Server，前端 Vue3（电脑后台 / 手机报工 / 大屏看板）。部署在客户自己的电脑/局域网服务器上，**断外网也能用核心功能**。

## 二、给谁用（目标客户 + 使用角色）

### 目标客户
- **中小制造工厂 / 车间**，规模大约 30～80 人（也有 80～150 人的扩展档）。
- **硬性选客红线：必须是靠计件工资的厂**（因为这正是我们最能帮老板解决的问题）。
- 老板最痛的三件事，排序别搞反：
  1. **交期延期**（得罪客户、赔钱、丢单）——最痛；
  2. **月底算错工资**（工人吵架、跑人）；
  3. **进度要靠下车间问**（心里没底）。

### 三类使用角色
| 角色 | 用什么 | 能做什么 |
|---|---|---|
| 管理员（老板/厂里负责人） | 电脑端 + 手机端 | 建账号、配基础数据、下单、看报表/看板/工资，全部权限 |
| 班组长 | 电脑端（复核）+ 可报工 | 报工、复核本组报工、只读工单/报表/看板 |
| 生产人员（工人） | 手机扫码/列表报工 | 查工单、扫码报工、报异常，不能改基础数据 |

关键权限规则：**工序报工权限按"部门"授权，不是按个人**；报工分"已提交 / 已复核"，复核通过才进报表和工资。

## 三、有什么功能（已做、能演示）

### 主链路能力
1. **下单出二维码**：建工单（工单号可自动生成或自填销售单号、可设计划交期、可加自定义字段）→ 打印带二维码的流转卡 → 贴到现场。
2. **扫码报工**：工人用手机摄像头扫、PDA 扫码枪、手动输工单号、或手机列表点选，四种方式都能报；填良品数 + 不良数（带不良原因）+ 时长。
3. **班组长复核**：提交后进度实时可见；复核通过才算数（进报表和工资）。
4. **老板看板**：全厂工单进度大屏，红黄绿按交期预警（正常 / 临期≤3天 / 超期置顶），超期工单、待处理异常滚动播报。
5. **工资自动算**：按产品/工序/部门/人员配"工价表"（计件/计时/固定三种计价、可设不良扣款），按月/周生成工资单，能确认、能冻结、能撤回重算，可导出。
6. **交期自动提醒**：临期/超期工单可推送到手机（企业微信通道，默认关闭、试用期不推）。
7. **派工到人 + 异常上报**：把每道工序派给具体工人；工人手机一键上报"设备故障/物料短缺/质量异常"。

### 加分 / 差异化能力
- **本地部署、断外网也能用、数据不出厂**（最硬的差异点，见下节）。
- **能接金蝶**：相似件建议报价（用金蝶物料+BOM + 本厂真实报工时长估工）、排产评分。金蝶存量客户的开口话：主数据不用录第二遍。
- **内置 AI 助手**（电脑端管理员用）：查进度、问工艺、智能客服（操作指引+数据解释，回答带来源、只读不改数）。
- **制造知识库**：产品/工序可挂作业指导书、图纸、图片，工人手机报工页直接看。
- **多账套**：一个系统管多个工厂/车间，数据互相隔离。
- 批量导入、自定义字段（少做二次开发）。

### 明确不做的（避免吹过头、一问穿帮）
- 库存 / 扫码出入库、采购、销售、财务、进销存；
- 全流程质检追溯（IQC/IPQC/OQC）、料批次追溯；
- 社保 / 个税 / 银行代发（工资只管"计件绩效算清楚、可对账可重算"，底薪社保仍走财务）；
- 按无报工时长自动猜"工序卡住"的停滞预警（靠人主动上报）。

## 四、和竞品的区别（已核证）

| 维度 | 黑湖小工单 | 简道云 | 我的系统 |
|---|---|---|---|
| 模式 | 云端 SaaS 成品 | 零代码平台自己搭 | **本地部署成品 + 上门陪跑** |
| 数据 | 云端（阿里云） | 公有云 | **不出厂、断外网可用** |
| 计件工资 | 有 | 自搭 | 有 + 按厂规矩 + 可重算 |
| 接金蝶 | ✗ | ✗ | ✅ |
| 单价 | 专业版约 1.08 万/年、旗舰约 1.88 万/年，无免费版 | 免费版 0（30 人内）、标准约 8000 起 | 首年 8800、次年 6800，按厂一口价不按人头 |

一句话差异：**黑湖/简道云是云端、一定要外网、数据在对方云上；我是装客户自己电脑里、断外网也能用、数据不出厂，推送照发不泄露。**

## 五、我现在怎么做生意（商业模式）

- **定价**：首年 8800 元（含上门实施，是黑湖专业版 10800 的约 8 折）/ 次年 6800 元；按厂一口价不按人头。金蝶 MCP、考勤社保外挂、数据大屏等外挂加购。
- **打法**：不打广告不跑量，**本地圈子 + 陌拜 + 灯塔客户 + 30 家深耕**。第 1 家低价换背书、第 3 家全价当成败闸门。
- **获客动作**：上门演示（当场真推一条到自己手机举给老板看）、30 秒录屏反复发、企业微信机器人 5 分钟陌拜话术、灯塔客户方案。没做官网/线上获客页、没上云（目前靠本机+隧道演示）。
