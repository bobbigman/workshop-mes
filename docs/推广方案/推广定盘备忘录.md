## 一、老板真正的痛点（排序，别搞反）

1. **交期/延期**（=得罪客户、赔钱、丢单）——**最痛**，戳痛点先戳这个
2. **算错工资**（工人吵架跑人）
3. **进度靠下车间问**（心里没底）

> **报工是手段，不是目的**——老板不在乎工人怎么点，在乎点完心里有没有底。报工是地基，但让工人愿意扫的钩子是**计件工资**（他扫一下钱就上）。选客户红线：**必须计件工资的厂**。

## 二、竞品事实（已核证）

| 项 | 黑湖小工单 | 简道云 |
|---|---|---|
| 版本 | 专业版(≈1.08万/年) + 旗舰版(≈1.88万/年)，**无免费版** | 免费/试用/标准/企业/旗舰/独享，**有免费版**(30人内) |
| 推送通道 | **微信 + 企业微信**(0217版本,2022-02)，短信有提及 | 微信/企微/钉钉/短信/邮件**全通道**(低代码平台) |
| 交期预警自动化 | 专业版标配 | 智能助手Pro(≈2024)，**免费版都有**(1万次/年) |
| 试用 | **7天免费试用 + 35城免费上门演示，无押金** | 免费版引流 |
| 结论 | **两家都把"交期预警+推送"放最低档全量送 = 签单的钩子** | 同左 |

> 启示：通道多少不是胜负手；黑湖没免费版照样云MES第一。**我们的差异化是：本地部署、断外网也能用；数据在自己服务器、不上公网；推送照发不泄露。黑湖/简道云是云端 SaaS，一定要外网。**

## 三、我们的打法（定盘）

- **陌拜话术**：不说"卖软件"，说"请老板当老师"；先承认被销售轰炸过；给5分钟台阶；戳延期痛点（`docs/37`）
- **演示**：当场真推一条到自己手机举给老板看 + 30秒录屏（一次做反复发）+ 借竞品案例话术「离交期还有2天还卡在第三道工序，手机就收到了」
- **试用**：**低门槛试用优于免费试用**——1000元三个月保证金，转正抵扣、未转正不退（`docs/55`方案B）。免费试用=客户躺平不背书。
- **定价/版本**：**功能全版本有**，不拿推送当版本墙；**开通（企微认证+陪配+维护）收费**——鱼饵免费撒，鱼上钩了再收
- **企业微信**：唯一通道；不承诺钉钉/短信；演示推自己手机，不让老板当场配置
- **自动推送**：**暂缓**，等第一单签了、认证好、数据跑准了再挂 Windows 计划任务（`docs/75`）；判定复用看板口径，禁 BackgroundService

## 三·五、系统的真优势（对内口径，演示主词 —— 完整卖点清单）

> 出门照着说；系统内固化页：帮助 →「产品优势速览」（`docs/76`）。话术原文见出门清单。

### A. 四大真优势（主词，按重要度）

1. **本地部署、断外网也能用，数据不出厂**
   - 装客户自己电脑/服务器，局域网就能跑；**不连外网也能用核心功能**（报工、看板、工资）
   - 推送照发、不泄露（企微推送走开通通道，与「业务数据不上公网」不矛盾）
   - **对黑湖/简道云**：云端 SaaS，**一定要外网**；数据在对方云上——这是最硬的差异句

2. **工资能按厂规矩算**（外挂口子可定制）+ 复核前置 + **可追溯可重算**
   - **边界（必说清）**：管的是「计件绩效算清楚、对得上账」；**不管**底薪档案、社保、个税、银行代发
   - 对外口径：工资报表把**计件部分**算准、能重算；底薪和社保仍走财务发薪，两边对账

3. **轻量、按厂收费不按人头**
   - 不是按人头年费把人卡死；小厂负担得起

4. **能接金蝶 / 开放集成**（加分项，别当主线吹）
   - **已做可演示**：金蝶排产评分（`docs/36`）、相似件建议报价（`docs/72`：金蝶材料 + 本厂报工实绩）、MES MCP（`docs/34`）、AI 客服/知识库（`docs/25/48`）
   - **打单故事（金蝶存量客户）**：金蝶主数据不用录第二遍；报价/估工对得上车间真实干了多久。黑湖封闭 SaaS，材料/BOM/工艺常要两套资料
   - **禁止做成**：纯金蝶数据搬运壳（没本厂实绩就没增量）
   - **旗舰定制（不对外演示）**：WorkBuddy/扣子智能体现场报价、AutoCAD 图纸 AI 报价——只说「旗舰版按需定制交付、按需报价」，不承诺现成、不承诺时间
   - 客户**没金蝶** → 这条卖点放弱，先打 1～3 条

### B. 痛点 → 怎么解（演示前半段）

| 老板痛（排序别搞反） | 我们怎么解 |
|---|---|
| 快到交期才发现要拖（最痛） | 看板黄红预警 + 企业微信推到手机 |
| 月底算工资拿表对、还老吵 | 工价配一次，工资自动算，每笔可查可重算 |
| 想知道单做到哪了，得下车间问 | 扫码报工，看板实时，坐办公室管全厂 |

### C. 六步闭环（一句话串起来）

下单出二维码 → 扫码报工 → 看板实时 → 工资自动算 → 交期自动提醒 → 派工到人 / 异常上报

> 报工是手段不是目的；让工人愿意扫的钩子是**计件工资**。选客红线：**必须计件工资的厂**。

### D. 三句杀招 + 案例（临场兜底）

1. **戳痛**：月底算工资是不是还得拿表对？想知道单做到哪了，是不是得下车间问？快到交期是不是到跟前才发现要拖？
2. **亮底**：大软件管大厂，您这规模花大钱办小事。这套照着您厂子的活法做：扫码报工、看板看进度、工资自动算、交期自动提醒。
3. **差异**：别人数据在云上、按人头年费、**一定要外网**。我这套装您自己电脑里，**断外网也能用，数据不出厂**，推送照发，不泄露。

**案例**：「某张单离交期还有 2 天、还卡在第三道工序，您手机上就收到了——不用等您去问，系统先提醒您。」
