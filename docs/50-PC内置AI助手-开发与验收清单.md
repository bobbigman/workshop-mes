    - 交期：`prod_work_order.due_date` 为 `DATETIME2 NULL`；列表筛选目前**无**交期区间参数。页面三态 `DueStateHelper` 用 `DateTime.Now` 对交期做减法，status≥2 或空交期一律 Normal — **不可**代替 AI「明天到期/逾期」半开日期筛选。
    - 状态：0 未开始 / 1 执行中 / 2 已结束 / 3 已取消（`docs/02`）；`WorkOrderQueryDto` 仅单个 `Status` + `ExcludeCancelled`，默认按工单 ID 倒序。

- [x] 核对知识服务的产品歧义、工序归属、解析及路径限制。
  - 证据（2026-09-20）：
    - 产品：有编号精确；仅名称时 `Name.Contains` + `FirstOrDefault` → 同名默认取第一条（AI 必须另做澄清，不改旧方法）。
    - 工序：指定工序时按工厂+名称模糊取第一条，**未校验**是否属于该产品工艺路线（AI 须另做归属校验）。
    - 解析：`KnowledgeFileParser` 支持 docx/pdf/xlsx；扫描型 pdf 抽不出字会抛错；返回体不含 `relative_path`。
    - 路径：`Path.Combine(RootPath, relativePath)`，**未见**规范化后必须仍在根目录下的校验 → AI 入口不得把模型/用户传入路径交给解析器；只用库表里的 relative_path，并应补路径逃逸防护。
    - 正文：解析器无字符上限；`version` 可空。AI 须按 `MaxKnowledgeChars` 限额，任一文件失败则不作完整工艺结论。
- [x] 核实当前 DeepSeek 工具调用协议和模型可用性，记录日期及官方依据。
  - 证据（2026-09-20）：查阅官方 https://api-docs.deepseek.com/zh-cn/guides/tool_calls/ 与 https://api-docs.deepseek.com/zh-cn/quick_start/pricing 。
    - 协议：OpenAI 兼容 Chat Completions + `tools`/`tool_calls`；模型只提出调用，本机执行后以 `role=tool` 回传。首版用此协议即可，不强制 Beta `strict`。
    - 当前文档样例模型名：`deepseek-flash`（亦有 `deepseek-v4-pro`，二者均支持 Tool Calls）。**仓库配置留空 Model，部署时填写并做连接测试**；不硬编码旧印象中的 `deepseek-chat`。
    - BaseUrl 默认 `https://api.deepseek.com`。思考模式可能返回内部推理字段 → **禁止展示给用户**。
    - 真实连通性：本机未配置密钥，连接测试列入 T02，不得以文档阅读冒充联调通过。

## 3. 验收数据准备

使用独立测试库/测试工厂。准备管理员 A、同工厂管理员 B、另一工厂管理员 C、班组长、工人；至少 25 条符合查询条件的工单；覆盖未开始/执行中/已结束/取消、无交期、当天及跨日边界。状态 2 以数据字典「已结束」为准。

准备两个同名不同编号产品、一份正常工艺文件、一份未标版本文件、空资料产品、重名工序、非该产品路线工序、超长/损坏/扫描型文件。预期结果人工核对，明确“测试数据”标识。
