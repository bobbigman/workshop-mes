# 403-Excel产品属性与价格规则整理指令

> 2026-10-24；待实施。输出是404字段、406产品、408价目表的共同依据，不把客户价格表当产品目录。

## 业务背景与处理

参照金蝶采购价目表：产品放实际规格，价格表放规格条件与金额。读取客户`2026生产部加工单价表.xlsx`所有相关工作表、备注和单位，给每条记录稳定来源ID（文件校验值、页、行及备注子项）。空白和合并单元格需保留上下文，公式值与原文字不互相覆盖。

分类为基础、附加、成套最终价、备注条件、计时/码/倍率等暂不支持项、歧义待定。输出逐行JSON/可核对表，原文、解释、条件、单位、金额、包含项、启用资格分别存放。

## 属性候选

> ⚠️ 本节字段候选为早期梳理，**字段归属定稿以 404/409 为准**（产品 8 固有字段 + 工单-工序工艺字段，工艺差异放工单）。本节仅保留 Excel 来源整理与「禁止猜测」口径价值，候选字段清单不按此落地。

| 稳定编码候选 | 字段/类型 | 说明 |
|---|---|---|
| umbrella_type | 伞型/单选 | 直骨、高尔夫等按原表整理，不按名称猜 |
| size_inch | 尺寸/数字 | 寸，保存实际25而非“25寸以下” |
| rib_count | 骨数/整数 | 实际8而非字符串8K区间 |
| folding | 折叠结构/单选 | 按实际结构，不把直骨当数字0 |
| canopy_structure | 层次结构/单选 | 单层、上下层、内外层及组合分清 |
| canopy_shape | 伞面形状/单选 | 普通、方形、偏心等需区分概念 |
| fabric | 面料/单选 | 高密度、记忆布等 |
| coating | 涂层/单选 | 无、黑胶、彩胶等；未知≠无 |
| print_panels | 丝印片数/整数 | 0明确不丝印，3匹配2—4片 |
| needle_spec | 针数规格/数字 | 10/11.5的业务含义保留说明，不和骨数合并 |

| strap/canopy_stack/mesh/reflective | 夹带/叠片/网纱/反光条/是或否 | 双层不自动等于需要叠片 |

最终字段须逐项给出名称、编码、类型、单位、允许值、适用范围、影响工序、是否关键、来源及确认状态。已有编号/名称/单位不重复造字段；价格、是否已含、生效日期不放产品属性。首版不开发工单覆盖属性；某批不同先复制产品修改差异。

## 禁止猜测的口径

- 同行多名称不自动认定单选或每项累计。如内标/拷克边+0.25、外标/夹带/狗牙边/顶标+0.55、材质涂层等+0.55必须记录歧义。
- 丝印1、2—4、5—8片是互斥档位固定附加价，不逐片累加；含丝印的成套价包含范围不清则待定。
- “25寸以下”“27寸以上（含27寸）”分别记录端点证据；没有证据的边界不猜。实际32寸单独价不得和通用27以上价重复套用。
- 无加号金额、空价、倍率、码与把换算不猜。特殊规格备注高密度+1/+1.5不能和通用+0.55重复加。
