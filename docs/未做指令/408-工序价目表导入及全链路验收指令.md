# 408-工序价目表导入及全链路验收指令

> 2026-10-24；待实施。依403—407和402受影响资料处理。仅HY伞业V2；模拟资料与价格需回查，不能请求成功即完成。

## 准备与导入

1. 从403整理结果生成新价目表材料，不重用旧280组/基础价绑定作为新规则。原始来源ID保持，歧义/码/计时/倍率/未知含价单列待定，不遗漏、不擅自转成每把金额。
2. 首版按工序分别建SIM400-PL编号，草稿默认；表头对应405单位换算和日期，并设**产品（专属表=绑定某产品 / 通用表=通用模板留空）**。每行保留稳定来源ID、性质、属性条件、金额、收费组和包含项；只启用含义与组合口径都明确的范围。
3. 为导入提供可核对母版：表头（含**产品**：专属表填某产品 / 通用表留空=通用模板）、价格明细、属性条件三张表，通过价目表编号+行编号关联；包含行用行编号列表，数字区间有上下界及开闭列；属性按field_key、工序/单位按本厂编码解析；**行全部按属性条件匹配，产品绑定在表头（405 B·跟表走）**。不要求用户手写JSON。
4. 导入先只读预检整表，校验引用本厂、单位换算、日期、金额、来源唯一、条件类型、区间、收费组、包含范围及可发现的重叠；启用与手工编辑走同一服务端验证器。草稿允许待定，状态不得由文件绕过启用校验。
5. 每张表事务保存，失败不留下半张；重复导入同编号默认拒绝覆盖，来源相同内容一致报告跳过，更新须明确选择并带预期版本，禁止自动覆盖已启用表。返回逐表/行错误、实际ID、数量及版本。
6. 明确选择SIM400产品+工序进入属性模式，不能对所有厂或所有产品切换。导入后GET回查表头/行/条件和源数据对账，逐来源记录启用/草稿/待定去向。

## 逐案例取价验收

| 案例 | 预期 |
|---|---|
| 25寸8K，无其他收费条件，丝印1片 | 5+0.25=5.25元/打 |
| 同规格丝印2、3、4片 | 各5+0.50=5.50元/打，不乘片数 |
| 同规格丝印5、8片 | 各5+1.65=6.65元/打 |
| 明确0片 | 命中明确无丝印规则；未知不能代替0 |
| 1/2、4/5、8/9及尺寸上下边界 | 无重叠误命中，9片无规则明确缺价 |
| 含丝印成套价 | 实际丝印片数保留，已含行不加；范围不明为待定 |
| 高密度特殊层次备注价 | 不与通用+0.55重复叠加；口径未知保持草稿 |
| 缺属性、两条基础、组内两条、多有效表、错误单位 | 明确阻断，不能零价或旧价兜底 |
| 调价/停用/改产品属性 | 新单用新依据，原单/报工/工资原金额不变 |

每例记录产品ID/属性、价目表版本、命中/未中原因、计算、报工单位和人工期望；期望不能直接调用被测算法生成。

## 全链路与交付

在HY伞业V2用SIM400-W工单验证建单自动锁价→报工→金额快照→工资预览/允许的草稿重算，使用明确测试身份及系数。1200把×5.25/12=525元（系数1、无扣款）等核算原值换算精度。不得制造已确认真实工资。验收记录若已有下游工资/报工引用，按规则保留测试标识或经合法撤销流程清理，不直接删账本。

本机完成前后端构建、匹配与历史兼容测试后，按已有增量发布渠道更新程序，绝不覆盖服务器配置；共享程序保持其他账套兼容。无可用发布渠道如实标注，不能声称线上已可用。Token只在内存使用，过期/权限不足不绕过授权档。
