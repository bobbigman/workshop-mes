## 为什么比照黑湖恢复产品字段

- 黑湖小工单工价锚在"产品编码×工序"，产品是计价基础。
- 但黑湖**产品规格选填**、不靠规格区分价，编码多则配价爆炸；我们**产品固有字段作取价关键**，比黑湖更靠属性、配价更省。
- 结论：保留产品概念 + 产品固有字段（对标黑湖），同时保留工单-工序工艺字段（应对每单差异，避免每差异建编码）。

## 一、产品自定义字段（8 个固有字段，核心、少填）

产品建固有字段，创建时定死；**不填全部字段、不为每个小差异建产品编码**。丝印、内标、反光条等差异不放产品，放工单（见第四部分）。

| 编码 | 名称 | 类型 | 取价关键 |
|---|---|---|---|
| umbrella_type | 伞型 | 单选 | 是 |
| size_inch | 尺寸(即长度/规格) | 数字 | 是 |
| rib_count | 骨数 | 整数 | 是 |
| folding | 折叠结构 | 单选 | 是 |
| canopy_structure | 层次结构 | 单选 | 是 |
| canopy_shape | 伞面形状 | 单选 | 否 |
| fabric | 材质(面料) | 单选 | 是 |
| coating | 涂层 | 单选 | 是 |

> 材质=fabric（进产品）；长度=size_inch 尺寸（不另建长度字段，拉带长度归工单）；颜色不进产品取价字段（不影响工价、避免重交付，放工单可选记录）。

## 四、工单自定义字段（工序级工艺属性 + 非取价外观）

**关键归属（第 3 点检查结论）**：加工动作本身（缝伞/合片/拉边/小裁/顶带/打珠尾/品检/包装/大裁）是**工序选择**，工单选哪道工序即表达"做不做这个加工"，**不建产品字段、不建工单全局字段**。

工序内的**工艺规格**（丝印片数、内标组、外标组、特殊伞面规格、拉带长度、反光条、网纱、叠片等）**挂工单对应工序**，作该工序价目表属性条件，**不建产品字段、不建工单全局补充字段**。

工单全局补充字段仅保留**非取价**外观（如颜色，可选填，不参与取价匹配）。

工艺属性按工序归属：

| 工单-工序 | 工艺属性 | 类型 | 取价关联 |

| 合片 | 丝印片数 | 整数 | 1片+0.25、2-4片+0.5、5-8片+1.65(按打)；0=不丝印 |
| 合片 | 内标/拷克边组 | 单选互斥 | +0.25 |
| 合片 | 外标/夹带/狗牙边/顶标组 | 单选互斥 | +0.55 |
| 合片 | 特殊伞面规格 | 单选互斥 | +0.55 |
| 合片 | 针数规格 | 数字 | 10/11.5 |
| 合片/打珠尾 | 叠片 | 是/否 | +1.6(合片) |
| 合片/缝伞/小裁/品检 | 网纱 | 是/否 | 按工序价 |
| 伞带.木耳花 | 拉带长度 | 数字 | 9 档区间 |
| 拉边 | 反光条/包边/纳米等 | 单选互斥 | 按工序价 |
| 小裁 | 切口工艺 | 单选互斥 | +0.5 |

## 六、工序价目表（B·跟表走：专属表优先 + 通用表兜底）

- **专属表**：单据头产品=某产品，整表给该产品；行按属性条件匹配。
- **通用表**：单据头产品=通用模板，不绑产品；行按属性条件兜底。
- 为 5 个演示产品各建**合片**专属价目表（表头产品=该演示产品）；附加价行（丝印/内标组/外标组/特殊伞面规格等）作合片价目表收费组，属性条件引用工单-合片工序工艺属性。如需演示缝伞再加缝伞价目表。
