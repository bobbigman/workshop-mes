# 小工单产品差异化打法与竞品分析（内部商用·可转发伙伴）

> 用途：伙伴沟通、售前定位与需求筛选。本文不是产品验收证明，也不作为报价或交付承诺。
> 2026-10-02 修订：样板先展示价值，正式能力按客户需求另定；本文中的调研、报价和生产接入事项，不自动成为配套演示指令的开发或验收任务。市场比例、竞品价格及能力比较仍以可核实证据为准。

## 一、核心判断

小工单的竞争重点应是：客户能否用得起来、多久能看到车间进度、后续要维护多少资料。功能数量只能作为比较的一部分，不能代替实际试用与交付验证。

工序级缺料有价值，但准确判断通常需要工序与物料的对应关系、需求数量、可用库存和占用口径。资料不齐或现场记录滞后时，系统应明确显示未知，而不是给出看似准确的齐套结论。

是否按工序领料、是否扫码开工，取决于管理方案和计算口径，并非所有客户必须采用同一种流程。售前应先看客户现有资料和现场习惯，再决定是否推荐。

## 二、竞品怎么比：带着问题验证

力创、诺飞可以作为重点调研对象。目前材料未附可核实的报价、产品手册或同条件演示记录，因此不判定其“无演示、无 AI、强制捆绑、落地率低”。

| 比较维度 | 需要向竞品或客户核实的内容 | 我方应提供的证据 |
|---|---|---|
| 采购与交付成本 | 软件、实施、接口、培训、维护分别收费多少，哪些可选 | 明确报价范围、客户配合事项和验收清单 |
| 上线门槛 | 最少需要哪些资料、由谁整理、多久可用 | 用客户样本演练基础流程，记录实际耗时 |
| 工序缺料 | 区分演示与生产，核实缺口、在途和补料处理 | 首版只提供固定样板的缺口→补齐→复验；异常数据和生产能力另行核验 |
| 金蝶集成 | 支持哪些产品版本、读写范围、授权及接口限制 | 实际接口清单、字段映射和联调结果 |
| 预警能力 | 规则计算还是 AI 分析，是否提供依据与数据时间 | 可复算的缺口、来源和更新时间 |
| 日常维护 | 资料是否重复录入、失败如何处理、谁维护 | 维护步骤、错误提示和支持范围 |

内部调研每条结论保留“产品版本、日期、来源、验证方式”。未验证项写“待核实”；面向伙伴的材料不转述未经核实的负面评价。

## 三、我方定位与能力边界

**先把下单、二维码、扫码报工、进度查看做好，再按客户需要增加物料管理。** 部署以局域网 H5 + PDA 为基础，不把公网或微信作为现场报工的前提。

| 能力 | 当前沟通口径 | 对外承诺条件 |
|---|---|---|
| 基础小工单流程 | 作为核心产品范围 | 以当前交付版本和验收结果为准 |
| 排产齐套评分 | 现有代码包含手填齐套分及未知兜底 | 不称为自动 BOM 齐套校验 |
| 工序缺料样板 | 2026-10-02 已完成四项验收，独立 PC 固定样板 | 可用于售前展示；不挂正式菜单，不代表生产可用 |
| 金蝶工序级生产校验 | 可选后续接入方向 | 接口、资料和计算口径核验，完成联调验收后才可启用 |
| AI 缺料预判 | 待单独确认实现范围与效果 | 有可追溯数据、确定性计算和验证结果后再宣传 |

不使用“全 ERP 兼容、零负担、无需二次开发、无需投入、独有且无法赶超”等无证据承诺。轻量化意味着控制必要的资料和交付范围，仍需配置、培训和客户配合。

## 四、差异化打法

### 1. 基础流程先成交

面向主要需要掌握进度的客户，先演示下单、出二维码、报工与看板。明确谁下单、谁报工、谁看进度，用一张工单验证日常操作，避免首版附加复杂的工艺和物料维护。

### 2. 样板展示价值，客户样本验证可用性

样板回答“功能有什么用”：哪道工序缺料、缺多少、在途为什么不算现货、一键补齐后如何通过复验。首版固定一张工单、三道工序，用独立 PC 页面展示，始终标注模拟数据；不要求搭建缺料台账、正式权限开关、生产拦截或通用物料计算。

有明确客户需求后，客户样本再回答“在这家工厂能不能用”：核对工序投料、可用库存、占用和数据更新。这属于后续生产接入评估，不是样板开发的前置任务。样板演示通过不能代替客户生产验证，也不能证明竞品缺少同类能力。

### 3. 标准包与可选能力分开报价

基础小工单独立交付；固定样板用于说明价值，正式工序缺料和 ERP 对接根据资料及接口评估另行约定。报价写清包含项、排除项、客户准备事项、实施工作量和验收条件。正式工序能力不强制绑定基础包。

### 4. 后续预警先算清楚，再由 AI 解释

正式预警若立项，物料缺口、预计到货和风险等级应由有依据、可复算的规则计算；这不要求首版样板接 AI、预测日期或生成风险等级。AI 可辅助解释原因、汇总风险和给出催料建议，不凭空补库存、到货日期或齐套结论。效果验证前，不承诺减少停工的具体比例。

## 五、伙伴可用话术

“我们的小工单优先解决下单、扫码报工和进度查看，让车间先用起来。

工序缺料是可选方向。固定样板已完成验收，我们可以用模拟数据展示哪道工序缺什么、补料后怎么变化；这与您工厂的生产接入是两回事。

如果您需要正式使用，我们会先检查金蝶版本、可用接口以及工序投料、库存占用等资料，明确可做范围、费用和验收方式。暂时没有这些资料，也可以先按基础小工单范围上线。”

话术中的功能状态随验收结果更新；未完成的能力只能介绍计划和适用条件。

## 六、行动与商业判断

1. 独立 PC 固定样板已验收，可演示缺口、补齐复验和重置；不附加正式入口、台账或集成任务。
2. 售前沟通沿用当前已验收能力口径；能力清单作为商业资料按需整理，不阻塞样板交付。
3. 需要竞品比较时，再对力创、诺飞按上表收集证据；不把竞品调研设为本次开发前置工作。
4. 有客户明确需要正式工序缺料时，再用其真实样本验证资料和接口，另定生产接入范围及验收；不把这一步打包进样板首版。

我们的可控优势来自容易理解的流程、明确的交付范围和可验证的演示。是否具有价格、速度或预警效果优势，应由实际报价、实施记录和客户使用结果证明。
