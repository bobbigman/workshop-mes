### A 执行补充（Cursor 补全，豆包未写死的技术细节）

- `el-menu` 绑定 `:default-openeds="openedGroups"`，`openedGroups` 初值从 `localStorage.getItem('menu-opened-groups')` 解析（解析失败回退全分组 index 列表：`['production','base-data','sys-config','report','help']`）。
- 监听 `@open`（参数是展开的 index）/`@close`（参数是收起的 index）维护一个 `openedGroups` 数组 ref，每次变更写回 localStorage。注意 `default-openeds` 是初始值不响应式，运行时折叠展开由 el-sub-menu 自身状态驱动，`@open/@close` 只负责持久化，勿试图用 `default-openeds` 动态控制。
- 桌面 aside 与移动端抽屉两个 SideMenu 实例共用同一 localStorage key，状态一致，无需处理冲突。
- `el-sub-menu__title` 样式：保留原 `el-menu-item-group__title` 的字号/颜色/内边距（`padding: 16px 16px 8px 28px`），并给箭头留位（`:deep(.el-sub-menu__title)` 内 `padding-right` 适配箭头），箭头颜色对齐 `--app-aside-text`，monitor-shell 深蓝变量下自动生效。

## 任务 B：登录页改版 + 登录图自配（对应 `69-优化指令-登录页改版与登录图自配.md`）

- 新增表 `login_setting`（`docs/02-数据字典.md` 补 DDL）：`id / factory_id(唯一) / banner_url / updated_at`
- 新增 `LoginSettingController`：

- 默认图放 `frontend/public/`

### 管理端
- `SideMenu.vue` 系统配置组加 `/login-setting`（仅 role=1）+ 新页面：当前图预览 + 上传 + 尺寸建议（2:1 / 4:3 横图）

### 验收

### B 执行补充（Cursor 补全，豆包未写死的遗漏点）

**① 后端完整文件清单（交接单只写了 Controller，漏了实体与上下文）**
- `backend/Models/SysModels.cs`：新增 `LoginSetting` 实体（`Id / FactoryId / BannerUrl(string?) / UpdatedAt`），与 `SysPrintSetting` 同风格。
- `backend/Data/AppDbContext.cs`：新增 `DbSet<LoginSetting> LoginSettings`；`OnModelCreating` 里 `e.ToTable("login_setting")`、`HasIndex(x => x.FactoryId).IsUnique()`、各列 `HasColumnName`（snake_case）映射、`BannerUrl` `HasMaxLength(255)`。
- Controller 直接用 `AppDbContext` 读写（轻量配置，不单开 Service；若嫌 Controller 堆逻辑可下沉，但本项量小，用 DbContext 即可，与 FactoryController 一致）。

**② 缓存坑（必做，否则验收"上传后立即变新图"会失败）**
- banner 文件固定写 `{factoryId}.png`（覆盖同名）。同名 URL 会被浏览器缓存，上传后刷新看不到新图。
- 解决：`GET` 返回 `bannerUrl` 时拼 `?v={updated_at.Ticks}`（从表里取 `updated_at` 的 ticks），前端直接用返回的完整 URL 作 `img.src`。上传接口也返回同样带 `?v=` 的 URL。

**③ 登录页拉图时机（豆包未定义"用哪个 factoryCode"）**
- 挂载顺序：先 `getInstanceInfo()` 拿本实例默认 `factoryCode`，再 `getFactories()`。
- 单账套（`factories.length === 1`）：用该唯一 code 拉图。
- 多账套：默认用 instance 的 `factoryCode` 拉图；`watch(form.factoryCode)`，用户切换账套时重新调 `GET /api/LoginSetting` 换图。
- 拿不到 / bannerUrl 为 null / 请求失败：一律回退默认图（不挡登录）。

**④ 默认图素材（豆包未提供图片文件）**
- 用 SVG 占位图，避免版权风险：`frontend/public/login-banner-default.svg`（深蓝渐变 + 系统名「车间小工单」+ 副标题 + 简单几何图形）。
- 前端引用路径用字符串 `/login-banner-default.svg`（构建后 public 内容进 dist/wwwroot 根，`UseStaticFiles` 直接可访问）。

**⑤ 管理端路由 + 菜单 + 页面**
- `frontend/src/router/index.js`：layout children 加 `{ path: 'login-setting', name: 'LoginSetting', component: () => import('@/views/login-setting/index.vue'), meta: { title: '登录页图片', adminOnly: true } }`。
- `frontend/src/api/auth.js`：加 `getLoginSetting(factoryCode)`、`uploadLoginBanner(formData)`。
- 新建 `frontend/src/views/login-setting/index.vue`：当前图预览（img src 用 GET 返回的 bannerUrl，无则显示"未配置"）+ 上传按钮（`el-upload` 选图即传，成功后刷新预览）+ 尺寸建议文案。

**⑥ 上传接口细节**
- 用 `JwtHelper.GetFactoryId(User)` 定位账套（隔离）；扩展名/ContentType 白名单 png/jpg/jpeg/webp；`≤5MB`（`file.Length` 判断）。
- 写盘前 `Directory.CreateDirectory` 确保 `wwwroot/uploads/login/` 存在；`wwwroot` 用 `builder.Environment.WebRootPath` 或 `ContentRootPath + "wwwroot"` 拼接，勿硬编码绝对路径（保持可移植）。
