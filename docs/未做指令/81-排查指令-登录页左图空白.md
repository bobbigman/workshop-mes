# 81 · 排查指令 —— 登录页左侧默认图不显示（裂图）

> 归属：**未做指令**
> 现象：退出登录回到 `/#/login`，左侧大图区空白，只剩一个裂图小图标（见用户截图）。
> 历史：`69` 要求左图右表单 + 未配置时回退默认图；`70` 任务 B Cursor 自报"验收通过"，默认图声明在 `frontend/public/login-banner-default.svg`。
> 分工：多隆出排查与修复指令，Cursor 执行。**只排查修复，不重写登录页。**

## 0. 总原则

- 每步先观察、后动手；**不许一上来就改代码**。
- 所有异常都要带上下文抛：文件路径、HTTP 状态码、接口返回原文。
- 修复后必须真的浏览器刷新看一眼，不能只靠 curl 200 就勾完。

## 1. 物理文件在不在

- [ ] 1.1 检查 `frontend/public/login-banner-default.svg` 是否存在、非空。
  - 当 **文件存在且 > 1KB** → 跳到 1.3。
  - 当 **文件不存在 / 0 字节 / 是个空壳** → 跳到 1.2。

- [ ] 1.2 补上默认 SVG（如果缺）。
  - 内容：深蓝渐变底 + 系统名「车间小工单」+ 副标题「生产进度 · 工单管理 · 报工统计」+ 简单几何图形，不要引用外部字体/外链图片（避免离线打不开）。
  - 写完后 `file` 大小确认 ≥ 500 字节。

- [ ] 1.3 看构建产物里有没有。
  - 当 **dev 模式（`npm run dev`）** → 直接进第 2 步。
  - 当 **打包后部署（dist/wwwroot）** → 检查 `frontend/dist/login-banner-default.svg`（或后端 wwwroot 对应根路径）是否存在。
    - 当 **缺失** → 重新 `npm run build`，确认 public 目录文件被拷进 dist。

---

## 2. 浏览器真实请求看一眼

- [ ] 2.1 打开登录页，按 F12 → Network，勾 Disable cache，刷新登录页。
- [ ] 2.2 找两个请求：
  - `GET /login-banner-default.svg`（或实际 img.src 拼出来的 URL）
  - `GET /api/LoginSetting?factoryCode=xxx`
- [ ] 2.3 把两个请求的 **URL、状态码、响应正文** 原样抄到本指令下方"实测记录"里。

判断分支：

- 当 **SVG 请求 404** → 路径写错或 public 文件没拷过去。回到 1.3 修构建；同时检查 `login/index.vue` 里默认图字符串是不是写死成 `/login-banner-default.svg`（注意开头的 `/`，不能写成 `login-banner-default.svg` 或 `./public/...`）。
- 当 **SVG 请求 200 但 Content-Type 不是 image/svg+xml** → 后端静态文件 MIME 映射问题，在 `UseStaticFiles` 里补 `.svg → image/svg+xml`。
- 当 **SVG 请求 200 且类型正确，但页面还是裂图** → 打开 SVG 文件本身看 XML 是否合法（有没有未闭合标签、BOM、HTML 注释污染）。
- 当 **`/api/LoginSetting` 500 或 CORS 报错** → 先看后端日志（`ThrowHelper` 原文），修后端；前端兜底分支必须保证**接口报错时也回退默认图**，不能因为接口挂了就把左侧留空。
- 当 **`bannerUrl` 返回了一个字符串（哪怕 null 被前端误判为"有图"）** → 看前端代码：`if (bannerUrl) img.src = bannerUrl else img.src = 默认图`。当 `bannerUrl === ''` 或 `'null'` 字符串时也要走 else。

---

## 3. 前端兜底逻辑复核

- [ ] 3.1 打开 `frontend/src/views/login/index.vue`，找 banner 相关逻辑。
  - 当 **img 标签直接写死 `:src="bannerUrl"` 没有 else 分支** → 改成：`bannerUrl || '/login-banner-default.svg'`。
  - 当 **`@error` 事件没绑** → 补 `@error="onBannerError"`，`onBannerError` 里把 src 强制切到 `/login-banner-default.svg`，防止任何上游失败导致裂图。
- [ ] 3.2 多账套切换时 `watch(form.factoryCode)` 重新拉图；当新 code 接口返回 null → **必须**切回默认图，不能残留旧图或空白。
