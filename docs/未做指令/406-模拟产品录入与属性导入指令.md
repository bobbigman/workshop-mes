# 406-模拟产品录入与属性导入指令

> 2026-10-24；待实施。依赖403/404；实际写入在402清理范围核实且必要程序可用后。仅HY伞业V2。

## 资料与模拟口径

原Excel为价格表，不是一行一个SKU。按403生成少量代表性模拟产品，编号采用SIM400-P001起，名称带“模拟”，来源含页/行和测试假设。不能把客户未提供的属性伪装为事实；可为测试明确设定“本案例无其他收费条件”，标为假设。待确认客户案例单列，不算通过。

至少准备：25寸8K丝印0/1/2/3/4/5/8片、尺寸边界上下、不同骨数、上下层/内外层、特殊材质、含丝印成套价、含黑胶无边夹带特殊价、缺属性负例。并非全部案例可启用正式价：歧义案例作为草稿/负例。

产品输入列：编号、名称、报工单位、路线编号、模拟标记/来源说明，以及`属性:field_key`列。数字保存实际数，0/否明确填写，未知留空。不把区间或价格放产品字段。无真实全流程依据的模拟路线只包含本次已知要验证的工序，名称标明验证专用，不冒充实际完整工艺。

## 导入能力

扩展现有产品模板和导入接口：本厂动态属性列按field_key解析，校验字段类型/选项/单位/路线；旧6列模板仍可导入，属性列出现未知编码明确报错，不能静默丢列。模板导出需本厂上下文。

先只读预检整批，给新增/冲突/错误逐行清单，再执行；不自动覆盖同编号产品。重试已成功行时比对本批来源与内容一致则报告已存在一致，不再插入；不同内容阻断并要求显式编辑。产品及其属性每行同事务，失败不留半行；结果分成功/失败/跳过，能回查ID。导入需管理员，不能利用通用upload绕过产品权限。

至少一个产品手工录入，再复制修改差异；其余批量导入，回查详情和自定义值确认与手输一致，不以请求成功替代回查。原有HY-001等产品保留或替换依402清单，不能擅自覆盖。

## 验收

- [ ] 录入文件含唯一模拟编号、来源/假设、单位、路线及实际属性。
- [ ] 手工/复制/导入结果一致，复制清空编号但保留属性。
- [ ] 重复编号、跨厂引用、未知列、非法选项/数字预检失败且不留残片。
- [ ] 缺事实案例标为待定，不当作取价通过；正例逐个回查有ID映射。
