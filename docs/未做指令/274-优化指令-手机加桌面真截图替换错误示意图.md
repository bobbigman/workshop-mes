## 行为与口径（按浏览器分叉写清）

- **当工人用华为/荣耀自带浏览器**（车间主力）：
  1. 浏览器打开系统地址并登录一次；
  2. 点浏览器**底部工具栏右侧的小包包图标**（菜单按钮，不是右上角三个点）；
  3. 弹出半屏菜单后，拉到最底下【其他】栏，点【添加至桌面】；
  4. 桌面出现"微聚"图标，点开全屏。
  配两张真截图：先 pwa-honor-menu.png（指底部小包包），再 pwa-honor-add.png（指"添加至桌面"）。

- **当工人用 Chrome 或其他安卓浏览器**：仍走右上角【⋮】→【添加到主屏幕】/【安装应用】，文字一句话带过即可，不另配图。

- **当工人用百度手机浏览器**：手册写"暂未确认到稳定的添加桌面入口，建议改用手机自带浏览器或 Chrome"；**不得**再写"菜单→添加到桌面"这种未实测路径。

- 装完确认、加不上怎么办两段不动。
