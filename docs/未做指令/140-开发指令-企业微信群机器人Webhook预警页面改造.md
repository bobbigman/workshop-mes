## 本次范围与落点
- **交付**：一条完整闭环【配置 Webhook → 事件命中（异常上报/交期）→ 企微内部群收到消息，手机弹窗 + @对应人】。
- **已有 / 缺口**：事件规则/投递/账本已有（129）；异常上报已实现（28，`prod_abnormal`）；**缺口**=群消息发送器、Webhook 配置入口、异常上报事件接入群推送（对齐 131）。

## 页面保留控件（Webhook 推荐方案）
1. 启用推送总开关；
2. Webhook 地址输入框（提示：以 `https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=` 开头）；
3. 默认 @成员列表输入框（多个企微账号逗号分隔；支持 `@all` 代表@全体）；
4. 【保存】【发送测试消息】按钮；
5. 消息规则列表、新增/编辑规则弹窗：推送通道下拉仅保留「群机器人 Webhook」；支持单条规则独立 Webhook，为空自动读全局默认；
6. 消息发送记录面板。

## 后端逻辑要点
- 新增群机器人 Webhook 推送，调用 `https://qyapi.weixin.qq.com/cgi-bin/webhook/send`；报文支持 `mentioned_list` 实现 @指定人员。
- 群机器人限流：单机器人 1 分钟最多 20 条，后端加防护。
- 错误提示：区分 key 无效/机器人已删除/网络异常，输出易懂业务提示；原始请求/响应、追踪号写入日志，不对普通用户暴露完整原始报文。
- H5 异常上报事件（`abnormal_reported`）对接推送：按规则异常类型，填对应 `mentioned_list` @对应负责人。

## 页面帮助提示文案（放 Webhook 输入框下方）
> ✅企业微信群机器人推送（推荐）
> 操作：企业微信新建**纯内部群（不可混入普通微信好友）** → 群右上角「…」→ 消息推送 → 新建机器人，复制完整 Webhook 填入。
> 优势：无需 IP 白名单、无需域名备案，消息支持锁屏弹窗、@指定负责人。

## 行为与口径（分叉写成显式条件）
- 当【工人上报异常（设备/物料/质量）】→ 推群并 @对应人（设备@机修、物料@仓库、质量@质检；未配成员仅群通知）。
- 当【交期临期/超期】→ 推群（临期 1 次、超期按间隔；当日去重）。
- 当【规则未配 Webhook】→ 用全局默认；均无 → 不生成待发，业务正常，页面提示补配置。
- 当【Webhook 调用失败 / key 失效】→ 记日志、输出易懂提示，**不阻断异常上报/工单主流程**。
- 当【开关=关 / trial 试用】→ 不调用推送。
