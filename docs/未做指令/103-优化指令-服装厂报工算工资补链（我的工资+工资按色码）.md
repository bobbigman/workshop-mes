# 103-优化指令 · 服装厂报工算工资补链（我的工资 + 工资按色码）

> 接 102 档 1。取舍已拍板（对齐黑湖 + 本系统「结算以固化快照为准」红线）。
> 目标：① 工人手机当天能看钱；② 老板 PC 能按色码看工资。五金零影响。

---

## 一、背景

102 已有色码字段 + 产量色码汇总。还差：工人看不到预估工资（没激情）；工资不能按「黑 M」汇总。

**拍板**：
- ①「我的工资」= 通用能力（五金也要），白送福利；
- ② 工资色码 = 动态 join 工单自定义字段（`field_key=color/spec`），**绝不**往 `salary_statement*` 加正式色码列。

---

## 二、取舍（已拍板，禁止脑补）

| # | 取舍点 | 决定 |
|---|---|---|
| 1 | ① 入口 | **新建** H5「我的工资」，**不塞进**「我的报工」 |
| 2 | 金额口径 | **已结算** → 工资单明细固化金额；**未结算且已复核** → 报工快照 `unit_price`/`wage_amount`；**待复核/退回** → 只展示、标状态、**不计入累计** |
| 3 | 累计周期 | 默认**本月**；可切换 **天 / 周 / 月** |
| 4 | 工人端色码 | 本厂有 `color`/`spec` 时明细多色/码列；五金无列 |
| 5 | ② 落点 | **新建** PC「工资色码汇总」只读页；**不动**现工资列表/抽屉 |
| 6 | ② 导出 | CSV **带色码列**（款+色+规格+数量+金额） |
| 7 | 授权 | ①② **均受 `PieceWage` 控制**；无档则无入口 |
| 8 | 工厂开关 | **不做**；要关就关授权档 |
| 9 | 交付面 | ①只 H5；②只 PC |
| 10 | 表结构 | **不改**工资正式表；色码永远动态 join |

---

## 三、现状（已确认）

1. H5「我的报工」有，无单价/金额 → ①新建页
2. `salary_statement_item.report_id` 可 join 工单色码 → ②可行
3. generate 只取已复核未结算；色码 **查询期** join，不改 generate
4. 工人无工资查询；`Salary` 现仅管理员 + PieceWage

---

## 四、原子步骤

### 步骤 1：H5「我的工资」

- **接口**：`GET /api/Salary/mine?period=day|week|month`（默认 month；可选 `date` 锚定日）
  - 仅本人；RoleGuard 放行工人/班组长 GET `/api/Salary/mine`
  - 返回：明细（工序、数量、单价、金额、复核状态、是否已结算；有色码字段则带 color/spec）+ **累计金额**（仅已复核计入；已结算用固化，未结算用快照）
  - `skuEnabled`：本厂是否配了 color/spec
- **页面**：H5 新页；工单页入口（PieceWage 可见）
- **验收**：当天/本周/本月能查预估；待复核不计入；五金无色码列

### 步骤 2：PC「工资色码汇总」

- **接口**：`GET /api/Salary/sku-summary`（periodType + periodValue，同工资单周期）
  - 口径：工资明细 → 报工 → 工单 → 产品 + color/spec 值 → 按 **productCode + color + spec** 分组（数量、金额）
  - 无 color/spec → `enabled=false`，`items=[]`
- **导出**：`GET /api/Salary/sku-summary/export`，CSV 含款/色/规格/数量/金额
- **页面**：报表菜单「工资色码汇总」；管理员 + PieceWage
- **验收**：服装能按黑 M 汇总并导出；五金 enabled=false；原工资页不动

### 步骤 3：五金回归

未配色码账套：工人能查本人钱（无色码列）；工资色码页空提示；原工资单/导出不变。

---

## 五、开关与回滚

- 色码维：停配 color/spec → 汇总 enabled=false
- 我的工资：关 PieceWage 即无入口
- 回滚：删 mine / sku-summary 接口与页面；工资账本零影响

---

## 六、验收清单

| 链 | 服装 | 五金 |
|---|---|---|
| 工人看钱 | H5 天/周/月累计；待复核不计入；明细可见色码 | 同口径，无色码列 |
| 工资按色码 | PC 汇总 + 导出带色码 | enabled=false |
| 原工资页 | 不动 | 不动 |

---

## 七、红线

1. 不往 `salary_statement*` 加色码列
2. 金额三档口径不得混用
3. 不改现有工资列表/抽屉/按人导出行为
4. 异常不吞；`ThrowHelper`；以 `docs/02` 为准
5. 不按字段显示名匹配色码
