# 68 · 优化指令 —— 侧边导航分组可折叠（对标金蝶树形菜单）

> 归属：**未做指令**
> 目标：把左侧导航的「死分组标题」改成可点击折叠的树形菜单，对齐金蝶左侧导航手感。
> 分工：多隆出指令与验收清单，Cursor 实现。

---

## 1. 现状与问题

文件：`frontend/src/views/layout/SideMenu.vue`

- 菜单分组用 `<el-menu-item-group title="生产管理">` 等**固定分组标题**，标题点不开、收不起（"死"）
- 整个前端仅此一处树状菜单；用户要求像金蝶一样分组可折叠展开

## 2. 改动范围

仅改 **`SideMenu.vue`**（模板 + 脚本 + 样式）。不改路由、不改角色逻辑、不动其他页面。

## 3. 实现要点

### 3.1 分组改为可折叠子菜单
把 5 个 `<el-menu-item-group>` 换成 `<el-sub-menu>`（Element Plus 原生，vertical 模式下内联展开/收起）：

| 分组 | sub-menu index | 可见角色 | 现有子项 |
|---|---|---|---|
| 生产管理 | `production` | 全部 | 工单、执行监控、报工、报工复核(role1/3)、异常处理(role1/3) |
| 基础数据 | `base-data` | role=1 | 产品定义、工艺路线、工序、不良品项、单位、工价表 |
| 系统配置 | `sys-config` | role=1 | 用户、部门、自定义字段、微信预警、AI助手 |
| 报表 | `report` | 全部 | 生产报表、工资报表(role1)、排产评分(role1)、车间看板 |
| 帮助 | `help` | 全部 | 操作手册 |

结构示例：
```html
<el-sub-menu index="production">
  <template #title>生产管理</template>
  <el-menu-item index="/order">工单</el-menu-item>
  ...
</el-sub-menu>
```
子项 `v-if` 角色判断（role1/3、role1）**原样保留**，不动。

### 3.2 默认展开 + 状态记忆
- 挂载时通过 `default-openeds` 默认展开全部分组（保持"一眼看到全部"的现状习惯）
- 用户折叠/展开后，把展开的分组 id 存 `localStorage`（key 建议 `menu-opened-groups`），下次进系统按记忆恢复
- 监听 `@open/@close`（el-sub-menu 事件）或 `@select` 同步 localStorage

### 3.3 样式适配（沿用现有 CSS 变量）
- 分组标题原样式 `el-menu-item-group__title`（`--app-aside-group-text` 等）迁移到 `el-sub-menu__title`
- 保持现有字号/颜色/内边距（`padding: 16px 16px 8px 28px` 一类），仅让标题可点并有展开箭头
- 展开箭头位置与颜色对齐 `--app-aside-text`，不引入新配色
- `monitor-shell`（执行监控深蓝主题）下同样生效，不破深蓝导航

### 3.4 图标（可选，保持简洁）
- 分组标题暂不加图标（现状分组无图标，避免视觉变噪）；如用户后续要金蝶式图标再加

## 4. 验收清单

- [ ] 5 个分组标题可点击：点击展开/收起子菜单，有明确箭头反馈
- [ ] 默认首次进入：全部分组展开，菜单项可见
- [ ] 折叠某分组后刷新页面：保持折叠状态（localStorage 记忆生效）
- [ ] 角色控制不破：role=2 看不到 基础数据/系统配置、报工复核、异常处理、工资报表、排产评分；role=1/3 正常
- [ ] 点击子菜单项正常路由跳转、高亮当前项不变
- [ ] 执行监控页（monitor-shell 深蓝导航）下折叠功能正常、样式不花
- [ ] 移动端抽屉导航（`el-drawer` 内 SideMenu）同样可折叠
- [ ] 无控制台报错

## 5. 不做

- 不做「整栏收起成图标窄栏」的折叠（用户只要分组折叠，不做侧栏收起）
- 不给分组加图标（本次保持简洁）
- 不改菜单项内容、路由、权限
