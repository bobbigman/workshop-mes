## 一、业务背景

本项目是面向小工厂的轻量车间管理系统：电脑建工单，工人手机/PDA扫码报工，按工序统计进度及核算计件工资。

客户是伞厂，现有价格资料为：

`docs/伞业客户加工单价表/2026生产部加工单价表.xlsx`

其中包含合片、包装、品检、拉边、顶带等工序的计价资料，价格受尺寸、骨数、结构、面料、涂层、丝印片数及加工要求等条件影响。

**本次参照金蝶采购价目表的维护和取价方式，变通实现工序价目表。两者在价格管理层面本质一致：金蝶管理外购物料价格，本项目管理产品各工序的工价。**

采用的业务主线为：

**产品属性明确 → 价目表维护条件与价格 → 建工单时根据产品属性自动取价 → 报工沿用计价依据。**

用户维护的是“什么条件对应什么价格”，不是每张工单重新人工选择价格。

此前280实现将加工要求和价格放在工序内部配置，建单时由文员逐项选择基础价和加工项，与本次“产品属性驱动、集中价目表自动取价”的目标存在方向差异。不能以已经开发为由继续沿用该交互，也不能未经核查就删除计价快照、换算及历史计算能力。

## 二、已确定的产品方向

### 1. 价格集中维护

独立设置：

- **工序价目表列表**：集中查询、筛选、新增、复制及打开价目表。
- **工序价目表**：表格式维护价格明细，方便连续录入、比较和核对。

不再把价格配置藏在每道工序内部，要求用户逐个打开查看。

这里是“列表页＋单据详情页”，不是重复维护两套价格数据。

### 2. 属性与价格分开

产品资料描述产品事实，价目表描述取价规则。

| 产品资料 | 工序价目表 |
|---|---|
| 实际尺寸：25寸 | 尺寸匹配条件：25寸以下 |
| 丝印片数：3片 | 2—4片对应附加价0.50元/打 |
| 面料：高密度 | 在指定规格下，高密度对应什么价格 |
| 产品实际需要哪些加工 | 是否另收费、是否已包含、适用范围 |

“不丝印”是明确的属性值，不能把未填写默认为不丝印；“已包含”“附加价”“生效日期”等属于价格规则，不是产品属性。

### 3. 自动判断价格

产品属性可以按具体值或区间匹配固定价格。例如：

- 丝印1片：加0.25元/打。
- 丝印2—4片：加0.50元/打。
- 丝印5—8片：加1.65元/打。

区间是匹配条件，命中后的价格为固定金额，不是按片数递增计算。

同组规则可以互斥，不同类规则能否累计，须根据Excel与客户确认的业务口径确定，不能自行假设。

## 三、本轮目标与边界

**本轮完整实现产品属性驱动的工序价目表（PC列表及表格详情、条件/区间自动匹配、建单锁价、报工快照），并在HY伞业V2重建模拟资料。复用现有金额底座，不建设通用公式引擎。**

顺序为：

1. 核查280实际代码、部署状态及计价资料使用情况，确定撤回与兼容范围。
2. 分析Excel及备注，整理属性字段，核对现有自定义字段能力。
3. 准备可重新导入的属性及产品资料，盘点HY伞业V2待重建的模拟数据；备份已完成，不重复执行。

5. 根据模拟产品建立工序价目表样例，逐产品核对取价结果及剩余差距。

限制：

- 业务数据仅操作指定HY伞业V2。共享服务器程序更新会影响所有账套，必须保持其他账套原有行为；只走已有增量发布渠道，不覆盖服务器配置。

- 仅局部撤回280不符合目标的功能，不重置整个仓库，不删除后续无关改动；存在已使用的锁价或报工快照时保留兼容计算和查询能力。
- 不把客户原始Excel作为产品清单直接导入。
- 未确认规则不得按免费或零价处理。
- 测试环境身份不明确时，先输出待录入资料，不自行写入数据库。
- 遵守本项目技术栈、产品编号唯一、报工部门权限及删除依赖规则。

### 步骤1：完整分析Excel

读取所有相关工作表，包括备注、单位、加号、尺寸范围和“含某加工”等文字。

将内容分为：

1. 基础价格。
2. 附加价格。
3. 特定规格或成套最终价。
4. 备注中的价格条件。
5. 尚不能确定含义的项目。

每条分析保留工作表名称和行号，便于回查。

注意：

- 同一行列举多个名称，不代表这些名称属于同一个单选组。
- 同时存在多个属性，不代表必须逐项累计加价。
- 没有“＋”的金额，不能擅自认定为附加价。
- 特定备注不能未经确认就与通用规则重复累计。

### 步骤2：整理产品属性定义

输出字段清单，至少包含：

| 字段 | 内容 |
|---|---|
| 字段名称 | 用户能够理解的业务名称 |
| 字段类型 | 数字、单选、多选、是／否等 |
| 单位及取值 | 如寸、片、6K/8K等 |
| 业务含义 | 避免不同人员理解不同 |
| 是否必填 | 哪类产品需要填写 |
| 适用产品范围 | 避免所有产品展示全部字段 |
| 影响工序 | 哪些工序使用此属性取价 |
| Excel来源 | 工作表、行号 |
| 确认状态 | 已明确／待确认 |

候选属性包括但不限于：

- 伞型。
- 尺寸。
- 骨数。
- 折叠结构。
- 伞面层次结构。
- 伞面形状。
- 面料。
- 涂层。
- 丝印片数。
- 针数规格。
- 标签要求。
- 边部加工要求。
- 夹带、叠片、网纱、反光条等相关要求。

以上只是候选，必须依据Excel去重、拆分和确认，不得机械地全部创建。

同时区分：

- 产品长期固定的属性。
- 仅某批工单不同、可能需要工单覆盖的要求。
- 可以由其他属性确定、无需重复录入的内容。

### 步骤3：核对自定义字段能力

阅读现有产品、自定义字段代码及权威文档，核实：

- 产品是否可以维护所需字段。
- 是否支持数字、单选、多选及明确的是／否。
- 是否支持单位、必填和适用范围。
- 产品列表、详情、复制、导入是否保留这些属性。
- 字段是否有稳定标识，可供未来价目表引用。

原则：

- 已有编号、名称、单位等字段不重复创建。
- 能复用现有自定义字段时优先复用。
- 能力缺失单独列出，不得通过错误字段类型凑合。
- 不因本轮模拟顺带建设通用规则引擎。

### 步骤4：模拟产品录入

选择一组有代表性的模拟产品，覆盖：

- 普通规格。
- 不同尺寸和骨数。
- 丝印1片、2—4片、5—8片。
- 双层或特殊结构。
- 特殊面料、涂层。
- 已含丝印的成套规格。
- 已含黑胶、无边、夹带的特殊规格。

要求：

- 模拟产品使用独立、唯一且清楚标记为测试的编号。
- 记录实际属性，例如丝印3片，不把“2—4片”填成产品实际片数。
- Excel缺少的产品事实标注待确认，不凭空补全。
- 缺少关键事实的案例只能作为待补资料，不能算作已验证产品。
- 优先复制相近模拟产品、修改差异，验证实际维护工作量。

### 步骤5：模拟工序价目表

根据属性定义与模拟产品，给出“工序价目表列表”和一张或多张“工序价目表”的样例。

明细候选内容：

- 工序。
- 属性条件及区间（产品绑定在表头：专属表绑产品、通用表不绑按属性兜底；行按属性匹配；详见 405/410）。
- 价格性质：基础价、附加价、最终价。
- 计价单位。
- 固定单价或附加金额。
- 已包含项目及适用范围。
- 生效、失效日期。
- 备注及Excel来源。

不要求每行填写所有属性。必须区分：

- **不限**：有意不以该属性限制适用范围。
- **未填写／未确认**：资料尚不完整，不能直接作为有效取价规则。

首版样例参照金蝶价目表的表格维护习惯，不照搬采购组织、供应商、税率等当前工价业务用不到的字段。

### 步骤6：逐产品模拟取价并核对

每个案例展示：

1. 产品属性。
2. 当前工序。
3. 命中的价格行。
4. 未命中或被替代的相关行及原因。
5. 基础价、附加价和最终价的计算过程。
6. 计价单位与报工单位。
7. 与Excel及人工结果是否一致。

至少验证：

- 25寸8K基础价5元/打，丝印1片附加0.25，最终5.25元/打；须明确该案例无其他收费条件。
- 丝印2、3、4片均命中同一档，不按片数重复加价。
- 含丝印的成套价仍保留实际丝印要求；包含范围未确认时，标为待定价。
- 高密度等属性遇到不同规格或层数时，检查通用规则与备注规则是否冲突。
- 缺少关键属性、缺价、重复命中和不适用组合时，明确显示问题，不自动套零价或模糊兜底。
