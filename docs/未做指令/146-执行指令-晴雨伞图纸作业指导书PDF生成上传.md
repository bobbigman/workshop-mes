## 行为与口径（分叉显式）
- **当** 需要远程 refId → 先 `GET /api/Product?pageSize=100`、`GET /api/Operation?pageSize=100`（HY001 admin token），按 code（HY-001 / CB/BB/…）反查**远程当前 id**，不硬编码、不沿用别处 id。
- **当** 生成 PDF → 每份 A4，中文用微软雅黑/宋体（若字体缺失则用系统有中文的字体），作业指导书含：标题、适用产品/工序、作业步骤、设备工具、质量要点/不良项、安全提示；图纸画主打款正视示意图 + 关键尺寸标注 + 标题栏（参考 gen_ddq_drawing_pdf.py）。
- **当** 上传 → `curl -k -F "refType=…" -F "refId=…" -F "version=V1.0" -F "file=@<本地PDF>;filename=<中文原名>"`，控制台代码页 65001（UTF-8）；**filename 传中文原名**（不要 `filename*`，curl 不识别）。
- **当** 上传报「未配置 KnowledgeBase:RootPath」或其它失败 → 停止该份，如实记录错误，不静默跳过、不伪造成功。
- **当** 误传/传错 → `DELETE /api/knowledgefile/{fileId}` 删登记后重传。
