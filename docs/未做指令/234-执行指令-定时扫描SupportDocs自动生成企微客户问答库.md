## 行为与口径（分叉写成显式条件）

- 当源一（15/19/08/10）任一个更新 → 重新抽取合并进问答库，version 递增、updatedAt 刷新到当天。
- 当源二（近期新指令）出现新的"客户可感知能力 / 口径变化" → 提炼成问答并入；当指令只是工程细节（接口、表、部署、脚本）→ 不进问答库。
- 当某问答在多个源重复（如 08 与 15 同题）→ 以客户中立口径去重（15 优先于 08）；与增量指令同题 → 以最新指令口径为准。
- 当白名单文件缺失或解析失败 → 跳过该文件、记日志（"哪个文件 + 哪步失败"），其余照常生成，不中断、不吞错。
- 当源里出现敏感内容（09/13/14/16/17/18、`_retrieval.json`、部署凭据、真实工单号/金额/工资/账套数据）→ 一律不进问答库，白名单硬编码排除，不靠关键词兜底。
- 每条问答保留来源标注（源文件或指令编号），无来源的问答不得进库。
