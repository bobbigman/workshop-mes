## 三、本次范围与落点

- 交付：钉钉群/单聊 @"微聚小工单" → 智能体调车间 MCP → 回显数据
- 已有 / 缺口：MCP 已绑定已测通（截图1）；**缺口**=发布 + 添加到群/单聊 + 意图问答验证
- 数据与契约：只读查询，不改表、不改 MCP 接口契约、不新造工具
- 文档：无 DDL 变更不改 docs/02；钉钉渠道说明进 MCP 对接/渠道文档

## 四、行为与口径（分叉显式）

- 当 @"微聚小工单"消息含「查工单 / 今天有哪些单 / 列表」→ 调 `query_work_order`，回工单列表（最多20条）
- 当消息含「XX单进度 / 做到哪 / 第几道」→ 调 `query_work_order_progress`，回进度+交期+距交期天数
- 当消息含「查报工 / 报工记录」→ 调 `query_report`，回报工记录
- 当消息含「工资 / 工资单」→ **财务敏感，默认拒绝**，回「需管理员授权」，不吐工资
- 当消息无关 / 未识别 → 回支持范围提示（查工单/进度/报工），不报错
- 当 MCP 或网络失败 → 回失败原因，**不假成功**；无工单号查进度 → 回「请给工单号或产品」

## 六、执行步骤（用户可操作，Cursor 可协助看 MCP 侧）
