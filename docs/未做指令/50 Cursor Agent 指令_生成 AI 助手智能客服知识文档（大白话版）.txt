# Cursor Agent 指令：生成 AI 助手智能客服知识文档（大白话版）

## 一、任务背景

当前项目是车间管理系统，技术栈固定为：

- .NET 8 + EF Core + SQL Server
- Vue3 + Element Plus
- 命名空间：`ahu.MicrosoftMes`

现有规划是增加管理员 PC 页面“AI 助手”，首版只读，完成“查进度”“问工艺”两个场景。  
未来要扩展为智能客服，能回答：

- 数量疑问，例如“这个工单怎么只有 80？”
- 延期疑问，例如“为什么工单001显示延期？下次怎么避免？”
- 系统操作说明，例如“怎么报工？”“怎么查工单？”
- 常见错误与处理方式

这些回答不能靠运行时读源码，必须依赖**受控、审核、版本化、可分块检索的说明文档**。  
你的任务：从现有代码和文档中提取事实，整理成结构化、大白话的 Markdown 文档，供 AI 助手后续检索回答。

不要造不存在的页面、接口、字段或业务规则。

## 三、核心目标

在 `docs/ai-support/` 目录下生成一套 Markdown 文档，包含：

1. 模块说明
2. 常见问题 FAQ
3. 操作步骤
4. 业务口径（延期、数量、状态、交期等）
5. 权限与工厂隔离说明
6. 错误提示与处理
7. 来源索引

这些文档要满足：

- **大白话**：车间管理员能看懂，短句，先结论后原因。
- **有依据**：每个结论必须标注来源，如文件、类、方法或文档章节。
- **保留限定**：适用角色、工厂范围、状态限定、时间口径、数据完整度。
- **可审核**：不确定的地方写“需人工确认”，不能编。
- **可追溯**：每个条目带版本、最后更新日期、适用模块。

## 四、禁止事项

- 禁止修改任何现有代码、配置、数据库、文档。
- 禁止调用外部 API，禁止执行 SQL，禁止访问生产数据。
- 禁止建表、写日志、改现有行为。
- 禁止编造业务规则、接口、字段、页面路径。
- 禁止承诺创建/删除/修改数据，首版只读。
- 禁止暴露密钥、连接串、物理路径、SQL、内部类名。
- 禁止把内部推理字段、模型术语、MCP、token 展示给用户。
- 禁止跨工厂假设，所有权限和工厂范围必须来自代码或文档。
- 禁止把“同名工序必须澄清”等新规则写进旧方法说明，旧行为保持不变。

## 五、文档结构建议

每个模块一个文件，例如：

- `docs/ai-support/index.md`
- `docs/ai-support/work-order.md`
- `docs/ai-support/reporting.md`
- `docs/ai-support/due-date.md`
- `docs/ai-support/quantity.md`
- `docs/ai-support/production-guide.md`
- `docs/ai-support/permissions.md`
- `docs/ai-support/faq.md`

每个条目统一格式：

```markdown
### 问题：为什么工单显示延期？

- **大白话答案**：  
  如果工单还没做完，计划交期已经过了，系统就会显示延期。已经结束或取消的工单不算。

- **关键限定**：  
  仅当前工厂；按上海业务时区；已结束和已取消不进入逾期；具体原因要看工序报工、返工、缺料等记录。

- **来源**：  
  `WorkOrderService.cs` → `CheckDueState` 方法；`docs/48`。

- **适用角色**：  
  管理员。

- **版本**：  
  1.0

- **最后更新**：  
  2026-09-20

- **数据完整度**：  
  完整 / 部分 / 需人工确认
```

## 六、工作步骤

1. 阅读所有必读文件，记录关键业务口径。
2. 识别与 AI 助手、智能客服相关的模块和常见问题。
3. 按模块提取事实，形成技术草稿。
4. 将技术草稿改写成大白话，保留所有关键限定条件。
5. 标注来源、版本、适用角色、数据完整度。
6. 生成 `index.md`，列出所有文档和条目。
7. 输出到 `docs/ai-support/`。
8. 最终回复中列出：
   - 生成的文件清单
   - 覆盖的模块
   - 待人工确认项
   - 未覆盖或数据不足的部分

## 七、重点覆盖问题示例

至少覆盖以下方向：

- 工单状态有哪些？分别是什么意思？
- 为什么工单显示延期？系统怎么判断？
- 已结束、已取消的工单算不算延期？
- 工单进度怎么查？完成率怎么算？
- 报工数量、合格数量、不合格数量分别从哪里看？
- 计划数量、已报工数量、库存数量为什么对不上？
- 怎么查某个产品的工艺资料？
- 同名工序怎么处理？
- 管理员能看到哪些数据？工厂隔离怎么生效？
- AI 助手能做什么？不能做什么？
- 为什么 AI 助手有时要求先选择产品/工序？
- 配置缺失、禁用、请求失败时页面怎么提示？

## 八、验收标准

- `docs/ai-support/` 下生成结构化 Markdown。
- 每个条目有来源、版本、适用角色、数据完整度。
- 大白话可读，关键限定不丢。
- 待人工确认项明确列出。
- 不修改任何现有代码和文档。
- 不编造、不承诺写操作、不暴露敏感信息。
