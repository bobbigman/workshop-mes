## 一、最关键的一条：产品到底怎么绑（三版演变，以 410 为准）

**「一张价目表里的产品」在 400～410 反复变过三版，互相打架，已统一为 410：**

| 出处 | 旧说法 | 统一后 |
|---|---|---|
| 405（实施契约） | 行级两级：一张表内既有「产品级行(绑产品)＋模板行(不绑)」 | ✅ 已回写为表级（见下） |
| 408（导入母版） | 「价目表行不绑定产品，按属性匹配」 | ✅ 已回写：支持表头产品（专属/通用） |
| 405-改动记录 | 标题「不绑产品」，实际结论两级 | 存档讨论，以 410 为准 |
| **410（用户拍板）** | **表级（B·跟表走）：单据头产品=专属表 / 通用模板=通用表；同工序多表** | ✅ 最终口径 |

**最终口径（B·跟表走）**：
- 产品绑定在**表头**（`base_operation_price_list.product_id`，null=通用表，非空=专属表），**行不再绑产品、不再分产品级/模板行**，全部按属性条件匹配。
- 取价：工单产品编号 → 先找该工序**专属表**，有则用；无则找该工序**通用表**兜底；再无 → **缺价**。
- 专属表关联上后**缺规格不回通用**，明示「该产品·该工序·缺『具体规格』的价」＋未匹配原因，金额不当 0，补价保存后重算即通。
- **同工序同类表生效期各只能一张**（某产品专属表、通用表各一），撞了报冲突。
