# 407-工序核对补录与路线导入指令

> 2026-10-24；待实施。仅HY伞业V2，依403；先复用正确工序，不把每条价格条件建成一道新工序。

## 整理和导入

1. 按当前服务端数据和历史工序映射核对编号、名称、权限部门、不良品项；Excel页名不必一一等于工序名。缝伞/大裁同页、顶带拆分、伞带木耳花归属等不明确项记录待定，不瞎绑定。
2. 合片是一道工序，1片/2—4片丝印是它的属性价格条件；不得创建数百道同类工序。误建工序先按402查引用，不能只按名字批删。
3. 输出工序复用/补录/待定清单及来源→本厂工序编号/ID映射。正确部门、单位、不良品项保留；缺的先经管理员服务创建，再工序。不能为了导入成功把报工部门填任意默认部门。
4. 复用现有工序模板列：编号、名称、报工部门编码（逗号分隔）、不良品项名称（逗号分隔）。新增导入先预检编号冲突及全部关联本厂，失败不留下半工序；既有同编号不静默覆盖权限。
5. 导入需管理员；路线按工序编号和顺序绑定，不重复同一道工序。优先复用正确路线，差异通过复制建新的SIM400-R编号，不能改共享路线影响老产品。
6. 缺完整工艺依据时只做标明用途的“模拟合片验证路线”，不要编造完整生产流程。正式资料仍保留原路线；406模拟产品引用验证路线。
7. 回查工序关联及路线顺序，操作清单按本厂编号升序展示；记录实际新增/复用/跳过数量。

## 验收

- [ ] 来源到工序映射明确，无按价格条件大量造工序。
- [ ] 工序部门权限按部门正确关联；不良品项及跨厂校验有效。
- [ ] 新增失败整行回滚，重复导入不重复生成，已有权限不被覆盖。
- [ ] 路线顺序、共享引用及模拟产品关联回查一致。
