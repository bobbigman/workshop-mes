## 行为与口径（分叉写成显式条件）

候选按序筛选，全部命中才写入：
1. 当【工序在报工权限部门内】且【候选在岗（未停用，复用 219）】→ 取【当前已派/已报数量最少】的工人，写入 `assignee_user_id`；
2. 当【报工权限部门内无在岗候选 / 无人可派】→ **不写 assignee**，工序标【待人工派工】，班组长手动派；
3. 当【班组长一键确认/改派/取消】→ 以人工为准，不被后续自动重派覆盖（保留 docs/29 的 override）；
4. 当【建单/评分完成】→ 自动跑一次；当【手动点"一键重派"】→ 对仍待派的工序重跑规则；
5. 派工**不强绑报工**：当工人未派工、走自选工序报工时，不拦截（docs/29 已定，避免卡死）。
