## 行为与口径（分叉写成显式条件）
- 当【工人对机器人报手机号且本厂匹配】→ bind_wechat 绑定企微身份（userid 哈希）到 `WxBinds`，返回「绑定成功：{姓名}」
- 当【已绑定企微身份】→ 机器人发的报工卡片/入口 URL 由后端签发**短时签名 token**（绑定该企微身份 + 过期时间）
- 当【工人点带签卡片/URL 进 H5】→ 后端校验签名 token + 查 `WxBinds` 绑定 → 签发正式 JWT → 前端写入 localStorage → 跳转现有 `report?order&op`
- 当【签名 token 过期 / 非法 / 未绑定】→ 拒绝并提示「请先在企微对话中绑定：报您的手机号」，不放行
- 当【工单流转卡二维码为裸 H5 URL】→ 改造成「经机器人发卡」或「先点机器人再扫」；不做"扫裸码免密直达"
- 当【非企微环境（PC 网页/普通浏览器）】→ 维持现有账号密码登录，行为不变
- 当【该工序未派工到当前账号 / 部门无权限】→ 校验不通过，扫码/发卡进也进不去（三条硬规则）
