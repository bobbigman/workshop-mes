# 402-HY伞业V2错误模拟资料清理指令

> 2026-10-24；待实施。备份用户已完成，不重复备份。只处理 https://mes.webok.net:11302/ 的HY伞业V2；HY002/厂ID5为历史线索，必须通过服务端核实。

## 背景

上次把Excel价格条件当作可手选加工项，并把不同规格价格绑在少量通用产品上。需要撤销错误绑定和受影响模拟资料，按真实产品属性重导；不意味着清空账套或删除所有工序。

## 准备及清单

先读历史执行记录、导入结果、修正结果、281和280，再只读查询当前状态。历史记录里的数量/ID不是删除授权清单，执行时必须逐项回查。

输出每条记录的厂、对象、ID/编号、来源、引用数量、处理动作、原因、替代编号。对象覆盖旧pricing_config、普通工价、产品、自定义字段及值、路线、工序和下游业务。

| 对象 | 默认处理 |
|---|---|
| 上次导入的旧280价格配置 | 列出工序ID和版本；新资料就绪后清除指定配置，不删除工序本体；历史任务快照保留 |
| 价格规则误绑通用产品 | 有证据属于本次错误导入的才停用/移除；不动其他原有正确工价 |
| 不完整的模拟产品 | 优先补齐或替换；无业务引用且来源明确的才删除重建；原编号→新编号留映射 |
| 真实/来源不明工单、报工、工资 | 保留，不重算、不直接删账本；不影响独立新模拟资料准备 |
| 正确部门、人员、单位、不良品项、工序 | 保留；不得为了重新导产品重建全部基础资料 |
| 共享路线和字段 | 先查引用，不能随产品一起误删；新增独立模拟路线优于改共享路线 |

## 实际清理

1. 403—408先准备并验证可重导材料及必要程序；不能先删完再研究恢复。
2. 执行前再次核实JWT所属厂、服务端厂编码/名称、目标记录厂ID和版本。Token不写文件、日志或Git。
3. 优先通过有厂隔离和引用校验的业务服务/API清理。现有接口不能清空旧配置时，新增仅管理员可用的明确清除操作：必须带预期版本，事务核对引用，保留任务/报工快照；不得绕过只读诊断接口做写SQL。
4. 删除依赖倒序：先处理清单内可删除的模拟工单等下游，再产品、路线、工序；有报工/工资约束的保留，不禁用外键。旧价目表先停用，引用保留。
5. 每批事务内复核清单和影响行数；数量超出计划或版本变化即回滚该批。重复执行已不存在记录应报告已处理，不扩大删除条件。
6. 处理后回查数量、关联、保留记录及其他厂业务数据未被此次操作改变。无法确认的单条资料记录保留原因，不阻断其他可独立完成事项。
