# 常见问题

## 网页打不开、登录失败

网页打不开：查工厂网络和地址，问同事能否打开；都打不开就找服务器维护人员。

账号密码错误：核对账号和密码大小写，忘记密码由管理员在【系统配置 → 用户 → 编辑】重设。

登录失效：重新登录后回原页面查记录。不能因为重新登录就把刚才那批再报一遍。

## 提示无报工权限

1. 管理员到【系统配置 → 部门】，确认人员在正确部门【成员】中。
2. 再到【基础数据 → 工序 → 编辑】，确认【报工权限】选了这个部门。
3. 保存后由实际操作人员重新打开工单检查。

管理员不受部门限制，班组长受限制。不要为报一道工序把工人改成管理员。

## 超出计划数、剩余可报为零

1. 检查工序是否选对，本次良品是否误填累计数。
2. 管理员查计划和有效报工（待复核、已通过的）：待复核、已通过都占上限，退回不占。
3. 订单计划真有变更，由管理员核实后调整；原记录错了，按改数流程纠正。

不要用不良数、换工序或换工单绕过限制。不良数只记真实不合格件。

## 有不良品却选不到原因

不良品大于 0 必须选原因。管理员先在【基础数据 → 不良品项】建立原因，再到【工序 → 编辑 → 不良品项】选上保存。

现场重新打开工单选工序后查看。没有正确原因时，不要随便选别的凑数。

## PDA / 摄像头没反应、工单不存在

1. 打开底部【扫码】。手机点【打开摄像头扫码】并允许权限；PDA 切【扫码枪模式】，确认扫码头按键盘方式输入并自动回车。
2. 避反光、换角度，确认二维码没污损。
3. 用【手动输入工单号】填纸上编号并【确定】。手动能开而扫码不行，请管理员查标签内容、扫码头或 HTTPS/证书。
4. 扫出整段网址时：网页摄像头可识别本站报工链接；PDA 标签更建议【工单号（PDA）】。也可用系统相机直接打开链接。
5. 编号仍不存在，管理员核对本厂地址及工单是否建立。

摄像头打不开多半是 HTTP 访问或未信任证书；配置 HTTPS 并信任证书后，扫码页可调用手机摄像头。普通手机也可用工单列表或手动输入。

## 扫码一定要扫工单码吗？工序码（工位码）怎么用？

不是。流转卡有两种码：**工单码**（一张单一张，扫完进报工页自己选工序）和**工序码 / 工位码**（管理员打印设置里选「按工序」，每道工序各出一张标签、标着工序名，贴到工位上）。扫**工序码**会**自动预选好那道工序**，工人直接填数量提交，少点一步。

默认打印的仍是工单码 / 报工页链接，只有主动选「按工序」才出工序码；已印的旧卡照样能扫。扫到工序码不会自动提交报工，还是要核对后填数提交；码扫不出或工序找不到，自动退回手动选工序，不报错。

## 报工后生产报表为什么没增加

先到【生产管理 → 报工】按工单查询复核状态。

- 待复核：计进度但未进报表，请班组长或管理员核对通过。
- 已退回：不计有效进度和报表，核对原因修改原记录再复核。
- 已通过：再查报表是今日、本月还是上月。按原报工时间统计，今天复核昨天的记录，不算今天报工。

不要为了让报表增加重复报工。

## 完成数为什么是 80，不是 180

有任务时工单完成数取各道有效良品（待复核和已通过的报工）最少值。例如裁切 100、包装 80，工单为 80；还有一道检验没报，最少值就是 0。

看板与工单详情、列表用同一个最少值口径：这张单显示 80，不会显示 180。「工序达成进度」取各正计划工序（良品/计划）的最小值（0～100%）。生产报表只计已通过。比较数字先确认页面和统计口径。

旧工单如果没有工序任务，打开详情时会尝试按产品路线补出任务；确实没有路线和任务时，列表会按该单有效良品合计显示，不能套用“各道取最少”。先找管理员检查产品路线，不要把没有任务当成已完成。

## 工单找不到、结束后又变执行中

找不到：完整工单号查询，再切状态。【全部】不含已取消，取消单到【已取消】查；手机没有已取消页签，找管理员。

状态变动：有效报工更新进度，各道报满可自动结束；退回、改数减少有效量后可能回执行中或未开始，管理员也能手动结束、撤回。

核对原报工数量、复核状态和工单详情，不把“已结束”当成“全已复核”。

## 报错了、不确定是否提交成功

记下工单、工序、人员、时间、本次数量和提示，管理员在【报工】查原记录。

已成功不再报；记录错了先退回已通过记录，再修改并复核；确认没保存才排错重报。

待复核记录在手机【我的报工】可自己撤回改，改后仍待复核、留痕可查；已通过的先退回再改；已结算记录不能直接退回或改数。不要报负数抵消或删工单纠错。

## 产品或基础资料删不掉

资料之间有关联。产品被工单使用、路线被产品使用时，会阻止直接删除。

1. 按提示确认哪项还在引用，交管理员核查。
2. 只是名字错了优先编辑，先判断是否真需删除。
3. 确需清理，由管理员按依赖处理：工单 → 产品定义 → 工艺路线 → 工序 → 不良品项 → 单位 → 部门。

不是让你为删产品把历史工单全删掉。涉及生产历史，先由负责人确认保留方式。

## 补报与改数有什么区别

已有记录填错用【修改】；实际完成但没记录才新增或补报。

【一键补报未完工序】在电脑【报工】页，仅管理员。对列出的所有未报满工序补同一良品数，上限为剩余量最小值，不自动认定前道已完成。

要记实际工人，勾【按工序拆分到人】，每道合计等于统一数；不拆分记当前管理员名下。

## AI 不能用、页面报服务器错误

AI 关闭、未配置或连接失败时仍可看本手册，正常工单报工不依赖 AI。AI 不能执行修改、补报、删除。

业务页面服务器错误：记录时间、页面、工单号、步骤和追踪编号，交管理员或维护人员查。不要把密码、密钥发给 AI。

提交报错先查是否生成记录，再决定重试。页面错误不代表数据一定没保存。

## 提示授权已过期 / 功能用不了（授权档限制）

系统按工厂授权档开放功能：入门款（trial）含下工单、派工、报工、车间看板；工资与工价、扫码报工、报工复核、交期预警/企微推送、打印标签、建议报价（接金蝶）等属更高档能力。

1. 顶栏出现「授权已过期或无法校验，高级功能暂不可用」：是授权到期/断网超过宽限，有效档临时降为入门款，现场报工与车间看板仍可用；联系部署方续费后重新登录即可恢复。
2. 低档登录后看不到某菜单/按钮（如工资、扫码、复核、微信预警、建议报价）：属该档不开放的高级功能，不是故障。升级档位需联系部署方，改档后重新登录生效。

不要为绕过限制把工人改成管理员。授权判定按工厂档位 + 用户角色两维，互不替代。

## 登录提示体验账套已到期

体验账套默认有效期 7 天，到期自动清空该厂全部资料（含上传的附件）并禁用所有账号登录，不可恢复。历史库、正式版、私有版不会触发。

需要保留数据，请在到期前联系部署方转正式版（企业版/旗舰版/私有版）。到期后没有保留或导出通道，只能重新开通体验或转正后重建。

## 你们要不要先派工才能报工？不派工能直接报工吗？

这题正好戳中很多厂系统用不起来的老毛病——非得先在电脑上把活派好、工人才能报，现场一忙根本来不及。我们偏不这么设计：派工是可选项不是门槛，想派就派、不派也照常报，绝不被卡住。工人报工就两步：扫码（或输工单号）→ 填数量提交。你们现场怎么管、就怎么报，系统不逼你们先做任何动作。

## 现场口头派工、没数、直接干，能用吗？

太能用了。你们现场怎么干，系统就怎么接——口头派工、不派工、甚至没个数就开干，都没问题。工人干完扫码、按实际干成的数量填，多少以现场为准，系统不要求你先弄好派工单和数量。一句话：系统顺着你们的习惯来，不是让你们改习惯。

## 现场忙乱，没时间先在系统派工，怎么办？

现场一忙，谁还有空掏电脑点半天？所以我们压根不让你先派工。工人报工就两步：扫码→填数量提交，几秒钟的事，谁干完谁报。系统是为车间争分夺秒设计的，不是添乱的。

## 工人不会用智能手机，怎么扫码报工？

很多厂最担心的不是系统，是老师傅——怕他们抵触、学不会，最后系统晾在那儿。这一点我们早想在前头：**系统去适应工人，不让工人去学系统。** 老人不用碰手机、不用碰电脑、不用记任何操作。现场三种走法，哪种顺用哪种：

1. **扫码枪"嘀"一下**：像超市收银一样，枪对着标签一按，屏幕自己跳出报工页，填个数点【确认】就完事。扫码枪几十块钱一把，插上即用、不用装软件、不用连蓝牙，固定在工作台上，工人不用领、不用还、不用充电。
2. **干完说一声**：工人干完跟班组长说一句"今天我做了多少"，班组长在电脑上记一笔，账照样记到工人自己头上——工人全程不用碰机器。
3. **漏了也不慌**：就算哪天漏报，管理员后台一键补上，还按人头拆得清清楚楚，不会记错人、不会白干。

老师傅不怕干活，怕的是被机器折腾。我们把"用手机"这一步整个拿掉，他该咋干还咋干，只是干完报个数而已。很多厂就这么顺下来的，工人几天就习惯了，没你想的那么难。

## 车间规定工人不能带手机，怎么办？

厂里不让带手机，反而是最好办的情况——因为我们本来就有不靠手机的报工方式：

1. **扫码枪**：就是给不让碰手机的车间准备的。工人拿枪对着标签"嘀"一下，报工页自己弹出来，填个数点确认，全程不碰手机、不碰电脑。
2. **工人说、班组长记**：工人干完把数量报给班组长，班组长在电脑上记一笔，工人连枪都不用碰。

两种都不让工人碰手机，你们选哪种顺手就用哪种。所以"不让带手机"对我们不是障碍，反而是最干净的用法。

## 工人干了活但漏报了，怎么补？

漏报不可怕，可怕的是记不上账、工人白干。我们有后台一键补报：管理员先核实确实干过、确实漏了，再一次把漏的补上；要记到具体工人，就按人头拆分，谁干多少记谁头上。补的是真干过的活，不是拍脑袋补数——账不丢，人不白干。

## 派给张三100李四100，张三干完帮李四，量和派工对不上？

不用改，也改不过来。派工只是"今天干什么"的提示，不绑报工结果——实际谁干、干多少，就以谁的报工记录为准，工资按实际算。张三帮了李四，照实际报就行，不用为"谁多谁少"回头改派工数据。现场怎么变，系统都接得住。

## 计件工资能自动算吗？

能，全自动——老板最怕的"算错、扯皮"，我们就是冲着这个设计的：

1. **报多少算多少，当场出数**：工价配一次记死，工人每报一笔，系统立刻按报工数量算出这单多少钱，屏幕上就能看到——不是月底翻账本对。
2. **谁干的活按哪个价算，系统自己对上号**：价按"哪个产品、哪道工序"定，报工报的是哪个单、哪道工序，系统自动对上，不用人工翻表、不靠人记。
3. **算完还有一道把关**：报工要过复核、通过了才正式进工资，防止有人瞎报、多报。
4. **定下来就不翻旧账**：确认过的工资就锁死，以后单价改了也不回头动历史——工人拿多少，清清楚楚，不闹糊涂账。真要纠错（比如工价配错），管理员可用【撤回重算】改对工价、把单撤回来重算，全程留痕。

计时工就按干了多少小时算；报了不良的，该扣的自动扣，都不用人工抹。

## 工资单算错了、工价没配对怎么办？

改对工价后，**已确认**的工资单也能纠：管理员在【工资报表】对那张单点【撤回重算】——单子和明细都保留（不是删掉重来），回到草稿重算金额，再确认即可；全程留痕、可查可重算，错误金额不会永远定格。多张一起改：勾选后点【批量重算】，草稿原地重算、已确认先撤回再重算，哪张失败单独提示原因，不影响其它单。

还没确认的草稿单：先核对报工和工价，改对后重算，或删掉重新生成。工人端不用慌——待复核报工本人可在手机【我的报工】改数；已结算的钱动不了，要由负责人核查。

## 工人能看自己工资吗？在哪看、怎么算？

能，**已经上线**。工人（开了计件工资档）在手机【工作台】或【我的报工】点【我的工资】，按**天 / 周 / 月**看累计预估金额（默认本月）。金额三档口径：**已结算** → 工资单明细的固化金额；**未结算但已复核** → 报工时的估算金额；**待复核 / 被退回** → 只展示并标状态、不计入累计。本厂配了颜色 / 规格字段，明细多出颜色、尺码两列；没有就是普通车间。

累计是估算，以确认后的工资单为准；月底对不上先看有没有待复核或退回的报工。没有计件工资档就没有【我的工资】入口，不是坏了。

## 服装厂怎么按颜色尺码（黑 M）查数和算工资？

**已经上线**。做法：工单自定义字段里给「颜色 / 规格尺码」配上编码 `color / spec`，然后一款建一个产品、一个色码拆一张工单（30 个 SKU 就是 30 张工单、同一产品、每张填一个色一个码），正常报工即可。查数走 PC 报表 → **色码汇总**（按款 + 颜色 + 规格汇总良品 / 不良 / 次数，能答「黑色 M 码做了多少件」，口径与生产报表一致）；算工资走报表 → **工资色码汇总**（管理员，按色码汇总工资，可导出带款 / 色 / 规格的 CSV，口径与工资报表一致）。

五金厂不配颜色 / 规格字段，两页都提示去配置、不显示数据，原生产报表、工资报表完全不受影响。别为色码去改产品定义或手工加表，走自定义字段最省事。

## 更新版本后页面白屏、数据旧或菜单不对怎么办？

多为浏览器缓存了旧版页面。到**登录页**点【清缓存并刷新】：它会请求清理本站旧缓存、注销旧 Service Worker、重新打开登录页，**登录信息和账套保留、不用重新登录**（不会清浏览器保存的账号密码之外的登录资料）。点完若页面没自动恢复，手动刷新或换无痕窗口再试一次；不要自己去删浏览器「清除浏览数据」里含登录信息的项目。

## 不良品怎么扣钱？

该扣就扣，而且扣得明白。报工时填不良数和原因，工价表把这道工序的不良单价定好，系统按不良数自动扣款——不用谁去记、去抹，也不会扣错、扣重。扣多少工价表白纸黑字，工人查得着、对得上，不闹纠纷。

## 不良品报表和生产报表数字怎么不一样？

正常，两表用途不同：**不良品报表**看现场质量（不良原因分布、集中在哪道工序、谁报的），口径含**待复核 + 已通过**、不含退回；**生产报表**是算账（入产量、算工资），只算**已通过**。所以同一段时间两表数字可能不一样，不是数据错了。页面都有口径标注，比较数字先看页面口径。

## 报工谁审核、怎么把关？

工资这东西最怕乱报、多报，所以我们留了一道复核关：报完工，管理员/班组长逐条核对，没问题点【通过】、有问题【退回】改数。通过了才正式进报表和工资——进度可以实时看，但"入账"得过这道关。报错了也不慌，退回改对再复核，不会稀里糊涂把钱发了。

## 能看到生产订单实时进度吗？

能，这就是给你当眼睛用的。车间看板 + 执行监控：每道工序做到多少、实时往上走，谁在干、干到哪、有没有卡住、有没有超期，老板一屏看全。不用挨个问班组长，进度自己会说话。

## 你们能不能代报工？主管替工人报工、记实际工人？

可以，而且**已经上线**。管理员、班组长在电脑报工页点「**代报工**」，替工人把数填上——账记到**实际干活的工人名下**、直接进工资，还能查到是谁代的。几点放心：

1. **一次代多人、各人数量可不同**：谁干多少代多少，不搞平均；
2. **权限把着关**：被代报的工人得在该工序报权部门里，班组长再限本组；
3. **漏报照常兜底**：一键补报/拆分到人随时能补，补的是真干过漏记的活。

## 一道工序好几个人一起干，能分别记到人吗（多人分摊）？

可以，**已经上线**。工人用**手机报工**，勾「**多人共同报工**」，把参与的人选上（含自己）、填这道工序的**总数**——分摊方式可选两种：**平均**（默认，分不尽的余数归报工人）或**按报工时长加权**（谁干得久分得多，没填时长的按平均兜底），各人各记各账，合计正好等于总数。

想各报各的、或事后用补报拆分到人，也都行——是补充，不是绕路。

## 买系统不能光看价格，你们怎么证明贴合现场？

这话说在点子上——系统再便宜，不贴合车间就是白花钱。我们的立身点全在现场：不派工也能直接报工、扫码枪不用手机、计件工资自动算、报工有复核把关、数据局域网里本地存不出厂。光说没用，欢迎拿你们一道真实工序现场试——好不好用，工人点两下就见分晓。
