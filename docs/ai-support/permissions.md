# 角色与权限

## 先看懂每天要做什么

**电脑下工单、打印二维码 → 工人扫码报数量 → 管理员复核、看进度**。

工单就是“这次做什么、做多少”；工序是“一步活”；工艺路线是“这些活按什么顺序做”；报工是“记下这次实际做的数量”。

- 管理员：建人建资料、下单打印、查进度、处理错数和补报。
- 班组长：报工、复核本组、看工单和生产报表，不能改基础资料。
- 生产人员：手机/PDA 找工单、选工序、报本次数量。

先跑通一张单，再逐步启用工资、AI 等功能。

登录后看到的是本厂数据；不同账套（工厂）的数据互相看不到。要看另一家工厂的资料，在登录页【账套 / 工厂】下拉选择该厂，并用该厂获授权的账号登录。

图中的菜品、工序是演示示例，按本厂真实产品、工序操作即可。

## 建部门、把人加入部门

谁来做：管理员。入口：**系统配置 → 部门**。先建好需要加入的用户。

1. 点【+ 创建部门】，填写【部门编码】和【部门名称】，例如 CJ01、裁切组。
2. 在【成员】中选择已有用户，可多选。需要复核本组的班组长也加入本组。
3. 点【确定】，回列表核对部门及成员。
4. 后续增减人员，点部门右侧【编辑】，调整成员后保存。

做完怎么看：列表【成员】中能看到对应人员。工人能否报一道工序，还要在“工序”里允许这个部门报工。

选不到人：先去“用户”确认账号已建立，再重新打开部门页面。

## 提示无报工权限

1. 管理员到【系统配置 → 部门】，确认人员在正确部门【成员】中。
2. 再到【基础数据 → 工序 → 编辑】，确认【报工权限】选了这个部门。
3. 保存后由实际操作人员重新打开工单检查。

管理员不受部门限制，班组长受限制。不要为报一道工序把工人改成管理员。

## 产品或基础资料删不掉

资料之间有关联。产品被工单使用、路线被产品使用时，会阻止直接删除。

1. 按提示确认哪项还在引用，交管理员核查。
2. 只是名字错了优先编辑，先判断是否真需删除。
3. 确需清理，由管理员按依赖处理：工单 → 产品定义 → 工艺路线 → 工序 → 不良品项 → 单位 → 部门。

不是让你为删产品把历史工单全删掉。涉及生产历史，先由负责人确认保留方式。

## 使用 AI 助手查问题

谁来做：仅管理员。入口：**系统配置 → AI 助手**。

1. 看状态，【已关闭】或【未配置】时找部署人员，不影响阅读操作手册。
2. 阅读使用说明。问题和必要资料会发送至配置的 AI 服务，不输入密码、工资等敏感内容。
3. 选【查进度】【问工艺】或【智能客服】，例如“工单 XXX 做到哪了”“产品编号 XXX 的包装要求”“报错数量怎么改”。
4. 遇到多个同名结果时，核对编号、工序再点选；回答要结合来源、明细和查询时间看。

做完怎么看：回答应对应所问工单或本厂资料。无资料时联系管理员补充知识文件。

注意：AI 只查询解释，不能替你下单、报工、改数或删除。操作步骤也可直接从【帮助 → 操作手册】查。

## 产品优势速览（演示给老板看）

谁来做：管理员、销售伙伴。入口：**帮助 → 产品优势速览**（也可登录前打开该页）。

解决什么：出门演示不用背 PPT。页上用大白话写清三大麻烦怎么解、六步闭环、以及「本地部署 / 断外网也能用 / 数据不出厂」等差异；下面可展开「销售备忘」（话术、竞品对比），演示时请先收起备忘。

1. 打开【产品优势速览】，先看页顶横幅「本地部署・局域网运行・数据不出厂」。
2. 按页面向下讲：三个麻烦 → 六步闭环 → 三大差异 → 金蝶相关扩展（建议报价、排产评分等，已做才写）。
3. 需要对照话术或竞品表时，再展开销售备忘；讲完可点页内演示路径链到真实功能页。
4. 工单、报工、看板、工资等业务页顶部会有一行浅色价值提示（一句人话），与本页口径一致；**不是弹窗**，可忽略不影响操作。

做完怎么看：能打开页面、能讲清「数据在您自己服务器」；不要向客户承诺未闭环能力（如未接金蝶就吹齐套真取数、未认证就吹企微已推送）。

注意：「断外网也能用」限定局域网内核心功能（工单/报工/看板/工资）；推送依赖企业微信通道，不是断网也能推。工资对外只讲计件算清楚、可查可重算，不把底薪社保银行代发说成系统全包。
