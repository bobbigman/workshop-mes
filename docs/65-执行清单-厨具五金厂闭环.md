### ☑ Step 14：设定工价规则（`POST /api/PriceRule` ×6）✅ 已执行

为打蛋器 6 道工序各设计件工价，不良扣款也配上去。

| 工序 | PriceType | UnitPrice | DeductPrice | 不良品项 |
|---|---|---|---|---|
| 下料 | 1(计件) | 0.50 | — | — |
| 冲压 | 1 | 1.20 | 0.50 | 毛刺 |
| 打磨 | 1 | 0.80 | 0.30 | 划伤 |
| 质检 | 1 | 0.30 | — | — |
| 组装 | 1 | 1.50 | 0.60 | 组装松动 |
| 包装 | 1 | 0.40 | 0.20 | 包装破损 |

参数说明：
- `PriceType`: 1=计件 / 2=计时 / 3=固定
- `ProductId` 需要填打蛋器 ID（已拿到，step 11 产出的）
- `OperationId` 填各工序 ID
- `EffectiveFrom` 填当天（`2026-09-24T00:00:00`）
- `DepartmentId/UserId` 留 null（不限部门/不限人）

验收：`GET /api/PriceRule` 返回 6 条规则。

### ☑ Step 18：生成工资单（`POST /api/Salary/generate`）✅ 已执行

用 admin token（或 banzhang 也可查工资）。

```
POST /api/Salary/generate
{
  "PeriodType": 1,
  "PeriodValue": "2026-09",
  "UserId": gongren的userId
}
```

系统自动：拉取 gongren 所有 `review_status=1` 且 `settled_flag=0` 的报工 → 逐条匹配工价规则 → 计算 amount 和 deduct → 汇总 totalAmount。

验收：
- `GET /api/Salary` 返回一条工资单，生成时 `status=0`（草稿），`totalAmount` = 18.50
- `GET /api/Salary/{id}` 查看明细：6 条 Item，每条含 `amount`、`deductAmount`、`netAmount`
- 确认金额和预期一致：各工序良品 × 单价累加 = 19.30 元（下料 5×0.5 + 冲压 4×1.2 + 打磨 4×0.8 + 质检 4×0.3 + 组装 4×1.5 + 包装 4×0.4）− 扣款（冲压毛刺 0.50 + 打磨划伤 0.30 = 0.80）= 应发 18.50 元（明细逐条核对无误）
