# 操作手册维护与发布

正文来源：docs/30-使用手册-管理员（电脑端）.md、docs/31-使用手册-工人（手机端）.md、docs/manual/第一次使用.md、docs/manual/遇到问题.md。

## 维护

1. 对照实际页面和权威业务规则修改正文。章节用二级标题，标题同时生成章节地址，已发布标题尽量保持稳定。
2. 支持段落、三级标题、数字步骤、无序列表、加粗及本地图片，不使用 HTML、外部图片或复杂 Markdown。
3. 图片放 frontend/public/manual，正文写 ![位置说明](/manual/文件名.png)。页面将其显示为图片和图注，点击原图放大。不要放登录凭据和客户私密资料。
4. 变更版本时同步正文页首、frontend/src/help/manual.js 版本日期，以及 scripts/sync-manual.mjs 的发布元信息。
5. 在 frontend 运行 npm run manual:sync 生成 SupportDocs 和 docs/ai-support 对应操作资料；运行 npm run manual:check 检查一致性、章节、搜索和图片。
6. 运行 npm run build。将完整 frontend/dist 随正常前端发布流程部署，图片已复制到 dist/manual。不需要新接口、数据库表、公网字体或 AI 服务。

## 帮助入口

- 电脑：侧边栏“帮助 → 操作手册”。
- 手机：底部“帮助”，直达手机篇。
- 登录页：“操作手册”，无需登录也可读操作说明，不读取业务数据。
- 单章地址：/#/help?topic=分类/章节标题，复制浏览器地址即可。不存在的章节提示回到入门目录。

## AI 资料

11 篇操作资料由同一正文生成；不要单独修改这些生成文件。due-date、production-guide、ai-assistant 等专题仍按其来源人工维护。SupportDocs 是服务器发布样例，部署目录及重新加载方式按实例配置执行，本任务未改模型服务配置或发送测试聊天。
