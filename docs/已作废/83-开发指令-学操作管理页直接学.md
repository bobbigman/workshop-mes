# 83・开发指令 —— 学操作管理页也能直接学

> 状态：✅ 已落地  

> 前置：82（PC 报工学）  
> 拍板：管理列表加「学」，点开即翻；与报工入口共用 PC 学操作页

## 0. 目标

管理员在「学操作」列表点 **学**，不经过报工/工单，直接按该门内容点翻续学。

## 1. 取舍

| 项 | 决定 |
|---|---|
| 入口 | 列表操作列加「学」（在「卡片」前） |
| 页面 | 复用 `/learn`；`?courseId=` 进单课；`?orderId=` 仍按工单 |
| 返回 | 有 courseId 无 orderId → 回 `/learning`；否则回 `/report` |
| 停用课 | 管理页仍可学（方便预览）；报工按工单仍只取启用课 |
| 进度 | 仍按人+课程记，与报工入口同一套 |

## 2. API（新增 1 个，不改表）

`GET /api/Learning/by-course/{courseId}` → 单课结构同 `LearningByOrderDto`（含 cards / resume / completed）；本厂隔离；role 1/2/3（白名单已有 `/api/Learning/`）。

## 3. 改动点

- 后端：`ILearningService.ByCourseAsync` + `LearningController`
- 前端：`learning.js`、`report/learn.vue` 支持 courseId、`learning/index.vue` 加「学」

## 4. 验收

- [ ] 管理页点「学」能翻页、记进度、续学
- [ ] 报工入口学操作不受影响
- [ ] 停用课从管理页仍可学；A 厂看不到 B 厂课
- [ ] `dotnet build` + `npm run build` 通过
