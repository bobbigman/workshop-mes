## 0. 目标（一句话）

管理员把某产品 / 工序的作业指导书拆成若干**有序文字卡片**（一步一卡），工人手机打开按顺序点翻学习；进度**按人 + 课程**存库，下次进入从上次停的地方接着学。

## 1. 现状（已查实）



* `base_knowledge_file`（`docs/02`，66 落地）：挂产品 / 工序、存相对路径，H5 可整份预览 PDF / 图片。**但不能拆步骤卡片、无顺序学习、无进度**。

* 前端 H5 视图位于 `frontend/src/views/h5/`（`report.vue` 等），路由在 `src/router`（`/h5/*`），有 `TabBar.vue`。

* 前端技术栈 Vue3 + Vant（H5 端）、Element Plus（PC 端）。

## 2. 范围与取舍（已拍板）



1. **学内容**：工序作业指导书拆成的**文字卡片**（标题 + 正文 + 顺序）。`66` 的 "看原文件" 入口保留在旁边当补充。

2. **翻页**：**顺序闪卡**—— 一张卡一步，点一下下一张；**不做 "题目→答案"**（自测考核放二期）。

3. **记进度**：按 **人 + 课程** 存最后一张卡，续学；**自测 / 考核首版不做**。

4. **交付顺序（首版闭环）**：H5 学习端 + **PC 最小录入端**（建课程 / 挂产品工序 / 加卡片 / 排序 / 启停 / 删除）都要做，否则 H5 没有内容可学，闭环是断的。两者都是 "最小能跑"，不做锦上添花。

5. **卡片首版纯文字**（标题 + 正文），不做卡片内图片、不做 OCR 拆卡。

6. **权限**：工人 (2)/ 班组长 (3)/ 管理员 (1) 都能学本厂课程；录入 / 启停 / 删除仅管理员 (1)。严格按 `factory_id` 隔离。

7. **只读红线**：不碰三条业务硬规则、不改既有表与接口契约；仅**新增 3 表**。

8. **内容定位（面向普通用户，硬约束）**：卡片只教**普通车间用户可懂的操作知识**——工序步骤、注意事项、安全规范、设备操作；**严禁出现 SQL、接口、开发/技术黑话**（如"建表、DDL、API、数据库"等一律不得出现在卡片文案里）。这是给**工人**学的，不是技术培训。

## 3. 数据（`docs/02` 新增 DDL，SQL Server 语法）



```
\-- 课程：挂产品或工序（product\_id / operation\_id 可空，二选一）；报工页按 工单→产品→工序 取课程

CREATE TABLE base\_learning\_course (

&#x20; id           BIGINT IDENTITY(1,1) PRIMARY KEY,

&#x20; factory\_id   BIGINT NOT NULL,                 -- 工厂

&#x20; name         NVARCHAR(100) NOT NULL,          -- 课程名，如《下料工序作业指导书》

&#x20; product\_id   BIGINT NULL,                     -- 挂产品（可空）

&#x20; operation\_id BIGINT NULL,                     -- 挂工序（可空）

&#x20; enabled      BIT    NOT NULL DEFAULT 1,       -- 启停

&#x20; sort         INT    NOT NULL DEFAULT 0,       -- 排序

&#x20; created\_at   DATETIME2 DEFAULT SYSDATETIME()

);

\-- 卡片：一步一卡，属于某课程

CREATE TABLE base\_learning\_card (

&#x20; id          BIGINT IDENTITY(1,1) PRIMARY KEY,

&#x20; course\_id   BIGINT NOT NULL,                  -- 所属课程

&#x20; factory\_id  BIGINT NOT NULL,

&#x20; seq         INT    NOT NULL,                  -- 顺序（1,2,3…）

&#x20; title       NVARCHAR(200) NOT NULL,           -- 步骤标题，如"1. 开机前检查"

&#x20; content     NVARCHAR(4000) NOT NULL,          -- 步骤正文

&#x20; created\_at  DATETIME2 DEFAULT SYSDATETIME()

);

CREATE INDEX ix\_learning\_card\_course ON base\_learning\_card(course\_id, seq);

\-- 进度：按人+课程，续学

CREATE TABLE user\_learning\_progress (

&#x20; id           BIGINT IDENTITY(1,1) PRIMARY KEY,

&#x20; user\_id      BIGINT NOT NULL,

&#x20; course\_id    BIGINT NOT NULL,

&#x20; last\_card\_id BIGINT NOT NULL,                 -- 学到哪张

&#x20; updated\_at   DATETIME2 DEFAULT SYSDATETIME()

);

CREATE UNIQUE INDEX ux\_learning\_progress ON user\_learning\_progress(user\_id, course\_id);
```

**删除依赖倒序**（`docs/02` 清单同步追加）：`user_learning_progress` → `base_learning_card` → `base_learning_course`。课程下有卡片 / 有进度记录 → **禁止直接删除**。

## 4. API 设计（实际落地 8\~9 个）



| 方法     | 路径                                      | 用途                                      | 权限         |
| ------ | --------------------------------------- | --------------------------------------- | ---------- |
| GET    | `/api/LearningCourse?keyword=&enabled=` | PC 课程列表                                 | role=1     |
| POST   | `/api/LearningCourse`                   | 新增课程（挂产品 / 工序）                          | role=1     |
| PUT    | `/api/LearningCourse/{id}`              | 改课程（含启停）                                | role=1     |
| DELETE | `/api/LearningCourse/{id}`              | 删课程（有卡 / 进度禁删）                          | role=1     |
| GET    | `/api/LearningCourse/{id}/cards`        | 课程下卡片（按 seq）                            | role 1/2/3 |
| POST   | `/api/LearningCard`                     | 加卡片（courseId+seq+title+content）         | role=1     |
| PUT    | `/api/LearningCard/{id}`                | 改卡片                                     | role=1     |
| DELETE | `/api/LearningCard/{id}`                | 删卡片（重排 seq 由后端处理）                       | role=1     |
| GET    | `/api/Learning/by-order/{orderId}`      | H5：按工单取课程 + 卡列表 + 本人进度                  | role 1/2/3 |
| POST   | `/api/Learning/progress`                | H5：存进度 `{courseId, lastCardId}`（upsert） | role 1/2/3 |

### 安全要点（红线，仿 66）



* 全部按 `factory_id` 隔离：读写都只能命中本厂课程 / 卡片 / 进度，A 厂看不到 B 厂。

* `product_id`/`operation_id` 必须属于本厂；挂关系在新增 / 修改时校验。

* H5 学习接口（`GET /api/Learning/*`、`POST /api/Learning/progress`）在 `RoleGuardMiddleware` 白名单放行 role 2/3；课程 / 卡片写接口仅 role=1。

* 进度 upsert：唯一索引 `(user_id, course_id)` 兜底，避免重复；异常用 `Common/ThrowHelper.cs`，位置 + 做什么失败。
