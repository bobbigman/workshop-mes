# 82・开发指令 ——「学操作」改名 + 电脑报工页也能学

> 状态：✅ 已落地  

> 前置：`docs/已做指令/78` 已落地（H5 点翻 + PC 管课）  
> 拍板：文案用 **「学操作」**（不用「闪卡」）；电脑从 **PC 报工页对着工单学**（方案 A）

***

## 0. 目标（一句话）

对外文案去掉「闪卡」技术味，统一叫 **学操作**；电脑端在报工弹窗加载工单后也能进同一套点翻续学（复用 78 接口，不改表）。

## 1. 取舍（已拍板）

| 项 | 决定 |
|---|---|
| 学习入口文案 | **学操作**（H5 按钮、页标题、空状态提示） |
| 管理菜单文案 | 侧栏「闪卡课程」→ **学操作**；路由 meta 同步 |
| PC 入口 | **仅** PC 报工「新增报工」弹窗：工单加载成功后出现「学操作」按钮；不进管理页预览 |
| 学习页 | 新建 PC 页（Element Plus），逻辑对齐 H5；**不**把 H5 页硬塞进 PC |
| 权限 | 学操作页 role 1/2/3 可进；管课页 `/learning` 仍仅管理员 |
| 表 / API | **不改**；继续 `GET /api/Learning/by-order/{id}`、`POST /api/Learning/progress` |

## 2. 文案对照（用户可见）

代码注释、`docs/02` 表注释、已做指令 78 文件名：**首版可不改**（避免牵文档历史）。

## 3. 改动点

### 前端

1. `SideMenu.vue`：菜单「闪卡课程」→「学操作」
2. `router/index.js`：
   - `/learning` meta.title →「学操作」（仍 `adminOnly`）
   - `/h5/learning` meta.title →「学操作」
   - **新增** 子路由 `learn`（如 `/learn`），组件 PC 学操作页，**非** adminOnly
   - role=2 白名单 `workerQuery` **加上** `/learn`
3. `h5/report.vue`：按钮文案 →「学操作」
4. `h5/learning.vue`：标题默认「学操作」；空状态「本工单暂时没有可学的内容」
5. `report/index.vue`：新增报工弹窗内，`orderDetail` 有值时显示「学操作」→ `router.push({ path:'/learn', query:{ orderId, order }})`
6. **新建** `views/report/learn.vue`（Element Plus）：选课 / 上一步·下一步 / 进度条 / 续学 / 已学完；返回回 PC 报工列表（或关学操作页即可）

### 后端

无。
