# 70-执行清单-H5 移动报工端全功能测试分析

> 依据：`31-使用手册-工人（手机端）.md`、`frontend/src/router/index.js`、`frontend/src/views/h5/*` 源码核对（2026-09-27）。本文给 H5（手机/PDA 报工端）做「全功能测试一遍」的清单，可直接照单执行。
> 分工：多隆（分析/规划）出本清单；现场由测试者照执行，问题报 Cursor 修。

---

## 0. 一句话结论

H5 现有 **6 个功能页 + 登录 + 帮助 + PWA 装桌面**，共约 **9 个模块、50+ 测试用例**。要「全测一遍」，重点盯三条业务红线（报工权限=部门、产品编号唯一、报满锁定）和三处易错交互（扫码三种模式、不良品必选原因、时长≤24h）。

---

## 1. 测试目标与范围

- **范围**：H5 移动报工端（`/h5/*` + 登录），不含电脑端后台、看板、工资、排产等（那些另测）。
- **目标**：验证每个页面功能正常、校验生效、业务红线不破、异常有提示且不吞错。
- **角色**：测试用「生产人员」账号为主，另备「班组长」「管理员」验证权限边界。

## 2. 测试环境与前置条件

| 项 | 要求 |
|---|---|
| 设备 | 1 台安卓手机（含自带浏览器/Chrome）、1 台 iPhone（Safari）、1 把 PDA 扫码枪（可键盘模拟） |
| 地址 | 管理员确认的 HTTPS 地址（手机已信任证书）；HTTP 无法开摄像头 |
| 账套 | 准备「单账套」和「≥2 账套」两种环境各验一遍登录 |
| 数据 | 至少造出下表 3.2 的数据（新工单、进行中、已结束、已取消、派工、异常） |
| 网络 | 局域网正常；另备一次「断网/弱网」场景验证错误提示 |

### 2.1 测试数据准备（先造好）
- 产品 A、B（同名不同编号各 1 条，验证「别只凭名称选」）。
- 工单 ① 未开始（0）、② 执行中（1）部分报工、③ 已结束（2）、④ 已取消（3）。
- 派工：把 ② 的某工序派给测试工人（看【任务】）。
- 工序含「不良品项」配置；给某工序的报工权限部门设成不含该工人的部门（验证无权限被拒）。
- 至少 1 个工单挂作业指导书/图纸（PDF/图片/xlsx 各一样，验证预览/下载）。

## 4. 逐页面测试用例

> 约定：✅=通过　❌=不通过（记录现象+复现步骤+期望，报 Cursor）

### 4.1 登录（6）

| 编号 | 操作步骤 | 预期结果 |
|---|---|---|
| H5-01 | 正确账号+密码登录 | 进【工单】页；顶部显示工厂名；token 已存 |
| H5-02 | 错误密码登录 | 有错误提示，不进入系统 |
| H5-03 | 单账套环境 | 登录页**无**账套下拉，直接进本厂 |
| H5-04 | 多账套环境 | 出现【账套/工厂】下拉；选错厂登录后顶部工厂名=所选厂；数据隔离 |
| H5-05 | 未登录直接开 `/h5/report?order=X` | 跳登录页；登录成功后**回到该工单报工页** |
| H5-06 | 手机登录后不能切账套 | 无切换入口（需换厂找管理员） |

### 4.2 工单页 `/h5/orders`（6）

| 编号 | 操作步骤 | 预期结果 |
|---|---|---|
| H5-10 | 打开工单页 | 列表显示状态标签、工单号、产品、已完成/计划、进度条、剩余、交期 |

### 4.4 扫码页 `/h5/scan`（10）

| 编号 | 操作步骤 | 预期结果 |
|---|---|---|
| H5-30 | 摄像头：点【打开摄像头扫码】 | 浏览器询问→允许后出画面，提示「对准工单二维码」 |
| H5-31 | 摄像头：对准流转卡二维码 | 识别成功进报工页；**扫码本身不自动提交** |
| H5-32 | 摄像头：拒绝权限 | 提示允许摄像头/用系统浏览器重试；可改手动输入 |
| H5-33 | 摄像头：HTTP 地址打开 | 提示「需要 HTTPS」；改用手动/扫码枪 |
| H5-34 | 摄像头：启动超时（15s） | 提示超时原因；可重试 |
| H5-35 | 摄像头：切页/锁屏 | 摄像头停；回来需重新【打开摄像头扫码】 |
| H5-36 | PDA：点【扫码枪模式】 | 显示「等待扫描工单」；扫码头自动回车即进报工；下次打开记住此模式 |
| H5-37 | 手动输入：只输工单号 | 确定后进报工页 |
| H5-38 | 手动输入：空/超长(>64)/整段网址 | 分别提示「未识别到工单号」「工单号过长」；贴整段网址时按链接解析，非本系统链接提示「请扫描本系统工单二维码」 |
| H5-39 | 诊断：网址加 `?scan-check` | 显示扫码检查面板，可复制日志/清空（不记录账号/二维码/画面） |

### 4.5 报工页 `/h5/report`（12）

| 编号 | 操作步骤 | 预期结果 |
|---|---|---|
| H5-40 | 打开报工页 | 顶部显示工厂名+工单号+产品；下方计划/已完成/剩余可报 |
| H5-41 | 未选工序点提交 | 提示「请选择工序」 |
| H5-42 | 选工序 | 上方计划/已完成/剩余随工序变化 |
| H5-43 | 填良品：-10/-1/+1/+10 步进 | 数量按档增减，不超剩余、不为负 |
| H5-44 | 点【报全部剩余】 | 良品填入剩余数（只填数不判实际，仅确已做完才用） |
| H5-45 | 填不良品=0 | 不出现原因下拉，可提交 |
| H5-46 | 填不良品>0 但不选原因 | 提示「有不良品时必须选择不良品原因」 |
| H5-47 | 填时长：分钟 60+ | 提示「时长填写不正确」 |
| H5-48 | 填时长：总 >24h | 提示「单次报工时长不能超过24小时」 |
| H5-49 | 点【提交报工】 | 提示「报工成功」后**回扫码页**；不重复提交同一批 |
| H5-50 | 点【继续报工】 | 提示「报工成功」后**留在原页**，数量/时长清空，进度刷新，输入框聚焦 |
| H5-51 | 已报满该工序 | 提示「该工序已报满，不可继续报工」；提交/继续按钮禁用 |
| H5-52 | 作业指导书：图片 | 点开图片预览；PDF/Word 全屏遮罩预览不跳页；xlsx 触发下载 |
| H5-53 | 工单加载失败 | 显示「无法打开该工单」+【返回扫码】入口，不伪装成功 |

## 5. 业务硬规则专项（5，跨页，必测）

| 编号 | 场景 | 预期 |
|---|---|---|
| H5-90 | 工序报工权限=部门：把工人所在部门从某工序报权剔除后报该工序 | **无权限报工被拒**；管理员检查该用户部门/工序报权 |
| H5-91 | 同名不同编号产品 | 列表/报工按工单号+产品编号核对，**不凭名称选** |
| H5-92 | 已报满再报 | 锁定，禁止凑数换工序 |
| H5-93 | 多人同时报同一工序 | 进度含他人数量；剩余正确减少 |
| H5-94 | 多账套数据 | 各厂数据互相看不到，属正常隔离 |

## 6. 边界与异常用例（每页 1~2 个「坏情况」，验证不吞错）

| 编号 | 场景 | 预期 |
|---|---|---|
| H5-95 | 断网时提交报工 | 有明确网络/业务错误提示，不假报成功 |
| H5-96 | 报工结果不确定（断网/报错） | 提示先让班组长按工单/姓名/时间查记录，确认未保存再处理 |
| H5-97 | 已结束/已取消工单点进报工 | 可查看但不能误报；需撤回/恢复由管理员处理 |
| H5-98 | 无报工权限 | 提示无权限；班组长报工也受部门限制 |
| H5-99 | 被退回的报工 | 退回数量暂不计进度（变小不表示记录丢失）；管理员核对原记录 |
