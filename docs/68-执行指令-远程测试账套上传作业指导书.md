## 1. 背景（功能机制，docs/66 已实现）

- 「图纸/作业指导书」数据模型：表 `base_knowledge_file`（记录元数据）+ 磁盘目录 `KnowledgeBase:RootPath/<factoryId>/<guid>.<ext>`（文件本体）。
- 上传接口：`POST /api/knowledgefile`（multipart：`refType` + `refId` + `version` + `file`），系统自动校验产品/工序存在、自动存盘并登记，**无需手改库**。
- 工人端：`GET /api/knowledgefile/by-order/{orderId}` 按工单（产品级 + 该产品工艺路线各工序级）列出；`GET /api/knowledgefile/{fileId}/raw` 预览/下载。
- 支持文件类型：pdf / docx / xlsx / jpg / png / webp；单文件 ≤ 20MB。

- 重传覆盖：同实体先删旧登记再传；或再传一份（列表会并列显示多份）。
