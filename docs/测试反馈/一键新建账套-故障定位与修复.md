# 一键新建账套（工厂）工具 —— 故障定位与修复说明

日期：2026-10-12

现象：伙伴双击 `C:\Users\Administrator\Desktop\车间管理系统\一键新建账套.bat`，报



```
---- 自检：后端是否可达（https://localhost:8080） ----
[失败] 连不上后端：远程服务器返回错误: (401) 未经授权。
```

## 一、结论（先说结果）

**后端一直是好的，从头到尾没坏。**

是工具自己的两处逻辑过时了，把 "后端活着" 误读成了 "连不上"：



| # | 根因                                | 位置               | 后果                                           |
| - | --------------------------------- | ---------------- | -------------------------------------------- |
| 1 | 自检用一个**需要登录**的接口探活，把任何异常都当成 "连不上" | `.ps1` 第 47-55 行 | 401 直接判定为 "连不上后端"，`exit 1` —— **这就是伙伴看到的报错** |
| 2 | 登录接口已从**一步**改成**两步**，脚本还按一步写      | `.ps1` 第 86-95 行 | 拿到空 token 就去建账套，必然再撞一次 401（根因 1 修好后会立刻暴露）    |

判断依据：`401 未经授权` 这个响应**是后端亲口回的**。只有 "服务在跑、网络能通" 才会得到一个规范的 HTTP 状态码；真断线时 PowerShell 报的是 "无法连接到远程服务器"，跟 401 是两回事。

## 二、实测证据（本机 2026-10-12，后端 [https://localhost:8080](https://localhost:8080)）



| 调用                              | 实测结果                                         | 说明                         |
| ------------------------------- | -------------------------------------------- | -------------------------- |
| `GET /api/factories`（不带 token）  | **HTTP 401 未经授权**                            | 后端活着；**原版脚本把这一步判成了 "连不上"** |
| `POST /api/Auth/login`          | `code=0`，`needSelectFactory=true`，`token=""` | 需要第二步选账套，**token 是空的**     |
| `POST /api/Auth/select-factory` | `code=0`，`token` 319 字符，厂名 "黑湖川菜馆"           | 第二步才拿到真通行证                 |
| `GET /api/factories`（带 token）   | HTTP 200                                     | 鉴权通过                       |
| 修复版 `-DryRun` 全流程               | 自检 OK + 登录 OK                                | 通过                         |
| 修复版指向 `https://localhost:9999`  | `[失败] 连不上后端：无法连接到远程服务器`                      | **真断线仍能准确报出**（回归测试通过）      |

复现原版报错（本机实跑，与伙伴截图逐字一致）：



```
[失败] 连不上后端：远程服务器返回错误: (401) 未经授权。
```

补充：这一版后端把 `GET /api/factories` 从 "匿名可用"（登录页下拉取账套）改成了 "需登录"，

同时把登录改成了两步下发（第一步只发 `selectToken` + 候选账套列表）。

两处改动正好同时踩中原脚本的两个假设，所以脚本一升级就废了。

## 三、已做的修复

改的是 `C:\Users\Administrator\Desktop\车间管理系统\一键新建账套.ps1`

（原文件已备份为 `一键新建账套.ps1.bak-20261012`，6625 字节，可随时还原）。

`.bat` **没有改动**—— 它只负责传参，参数名和值都还对。

### 修复 1：自检判定（核心）



```
# 旧：任何异常都当成连不上
try {
    $probe = Invoke-WebRequest -Method GET -Uri "$Base/api/factories" -UseBasicParsing -TimeoutSec 8 -ErrorAction Stop
    Write-Ok "后端可达（HTTP $($probe.StatusCode)）"
} catch {
    Write-Fail "连不上后端：$($_.Exception.Message)"   # ← 401 走到这里，误报
    exit 1
}
```



```
# 新：拿到 HTTP 状态码就算可达，只有"没有任何响应"才算连不上
$probeStatus = $null
try {
    $probe = Invoke-WebRequest -Method GET -Uri "$Base/api/factories" -UseBasicParsing -TimeoutSec 8 -ErrorAction Stop
    $probeStatus = [int]$probe.StatusCode
} catch {
    $probeErr = $_.Exception.Message
    if ($_.Exception.Response) { $probeStatus = [int]$_.Exception.Response.StatusCode }
}
if ($null -ne $probeStatus) {
    if ($probeStatus -eq 200) { Write-Ok "后端可达（HTTP 200）" }
    else { Write-Ok "后端可达（HTTP $probeStatus）—— 该接口需要登录，401/403 属正常" }
} else {
    Write-Fail "连不上后端：$probeErr"
    exit 1
}
```

### 修复 2：兼容两步登录（同时兼容老的一步登录）



```
$token = $login.Data.token
if ([string]::IsNullOrEmpty($token) -and $login.Data.needSelectFactory) {
    $cands = @($login.Data.candidates)
    $codes = ($cands | ForEach-Object { $_.factoryCode }) -join '、'
    if (-not ($cands | Where-Object { $_.factoryCode -eq $CurFactory })) {
        Write-Fail "账号 $CurAccount 不属于账套 $CurFactory，无法用它登录。可选的账套：$codes"
        exit 1
    }
    $sel = Invoke-ApiJson -Method 'POST' -Path '/api/Auth/select-factory' `
        -Body @{ selectToken = $login.Data.selectToken; factoryCode = $CurFactory }
    if ($sel.Code -ne 0 -or [string]::IsNullOrEmpty($sel.Data.token)) {
        Write-Fail "选择账套未成功：$($sel.Msg)"; exit 1
    }
    $login = $sel; $token = $sel.Data.token
}
if ([string]::IsNullOrEmpty($token)) { Write-Fail "登录未拿到通行证（token 为空）。"; exit 1 }
```

顺带补了个原来漏掉的坑：原判断写的是 `$null -eq $login.Data.token`，

而后端返回的是**空字符串** `""`，`$null` 判断拦不住，于是脚本会打印 "登录成功" 再往下走然后失败。现已改为 `[string]::IsNullOrEmpty()`。

### 新增：`-DryRun` 开关（只自检 + 登录，不建账套）



```
powershell -NoProfile -ExecutionPolicy Bypass -File "一键新建账套.ps1" -DryRun
```

建议以后在伙伴机器上先用它确认连通性，再真建账套。
