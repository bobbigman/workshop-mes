# 电脑日常操作

适用：管理员；班组长可阅读报工、复核和查数章节。手册版本 1.8，更新于 2026-10-03，按当前系统界面核对。

各业务页右上角「？」或按键盘 **F1**，可看本页按钮与状态说明（含「待复核要去哪处理」这类跨页指引）；完整操作步骤仍以本手册为准。

## 登录与选厂（多账套）

谁来做：所有人（登录时）；开通新工厂由管理员在电脑端操作。入口：浏览器打开系统地址后的登录页。

1. 填【账号】和【密码】。工厂同时开有多家（2 个及以上账套）时，登录页出现【账套 / 工厂】下拉，先选自己所在的厂再点【登录】；只有 1 个账套时没有下拉，直接进入本厂。
2. 登录后 PC 左侧栏、手机顶栏、车间看板标题都显示当前工厂名，先看清在哪个厂再操作。
3. 各账套（工厂）的数据互相隔离，一家厂的账号看不到另一家厂的工单和报表，属正常现象。

做完怎么看：登录页下拉能选到本厂；登录后各处显示的工厂名与本人所在厂一致。

授权提示（已开通云激活的客户）：管理员登录后若顶栏出现授权过期/宽限提示，高级功能（工资、扫码报工等）可能暂不可用，现场报工与车间看板仍可继续；联系部署方续费后重新登录即可恢复。未开通云激活时无此提示，不影响使用。

授权档说明：一套代码按工厂分「入门款 / 企业版 / 旗舰版」三档（工厂授权档 `license_tier`）。入门款含下工单、派工、报工、车间看板等基础能力；工资与工价、扫码报工、报工复核、交期预警/企微推送、打印标签、建议报价（接金蝶）等属更高档能力，低档登录后看不到这些菜单或按钮，属正常授权限制。现场报工与看板不受档位影响，可继续使用。

体验账套到期：体验账套（试用）默认有效期 7 天，到期会自动清空该厂全部资料（含上传的附件）并禁用所有账号登录，不可恢复。需要保留数据，请在到期前联系部署方转正式版；正式版/私有版不会触发清空。

注意：提示「账套不存在」时重新选择账套再登录。手机端登录后不能切换账套，需要换厂时退出登录重新选择，或找管理员。新开一家工厂：PC 端管理员可新建账套，开通时灌入一套演示数据和该厂管理员账号，属于开通动作，不是日常操作页面。页面显示异常或更新未生效（白屏 / 旧数据 / 菜单不对）时：登录页有【清缓存并刷新】按钮，点它会请求清理本系统旧缓存、重开登录页，**登录信息和账套保留、不用重新登录**；窄屏也可见。

## 建账号、改密码

谁来做：管理员。入口：**系统配置 → 用户**。

1. 点【+ 创建用户】，填写账号、姓名，需要时填写手机号和微信号（微信号选填，仅作记录；用户列表可按【微信号】搜人）。
2. 选角色：配置和下单选【管理员（电脑全权限）】；现场复核选【班组长（复核 + 报工）】；只报工选【生产人员（仅手机报工）】。
3. 填初始密码，包含大写字母、小写字母和数字。点【确定】。
4. 回到列表核对姓名、账号和角色，再把系统地址及个人账号交给本人。

做完怎么看：用户出现在列表中。生产人员登录后进入手机【工作台】，管理员和班组长进入电脑工单页。

忘记密码：找到该用户，点【编辑】，填写【新密码】后点【确定】。新密码留空则保持原密码。当前手机端没有自助改密码入口，由管理员处理。登录填写的是【账号】，不一定是资料中的手机号。

## 建部门、把人加入部门

谁来做：管理员。入口：**系统配置 → 部门**。先建好需要加入的用户。

1. 点【+ 创建部门】，填写【部门编码】和【部门名称】，例如 CJ01、裁切组。
2. 在【成员】中选择已有用户，可多选。需要复核本组的班组长也加入本组。
3. 点【确定】，回列表核对部门及成员。
4. 后续增减人员，点部门右侧【编辑】，调整成员后保存。

做完怎么看：列表【成员】中能看到对应人员。工人能否报一道工序，还要在“工序”里允许这个部门报工。

选不到人：先去“用户”确认账号已建立，再重新打开部门页面。

## 配单位、不良品项和工序

谁来做：管理员。入口：**基础数据 → 单位 / 不良品项 / 工序**。

1. 在【单位】点【+ 创建单位】，填“件”“张”等实际计数单位，点【确定】。
2. 在【不良品项】点【+ 创建不良品项】，填“尺寸不合格”“划伤”等原因，点【确定】。
3. 在【工序】点【+ 创建工序】，填【工序编号】和【工序名称】，例如 CJ、裁切。
4. 在【报工权限】选允许报这道工序的部门；在【不良品项】选这道工序可能用到的原因。
5. 点【保存】，核对列表里的【报工权限(部门)】和【不良品项】。

做完怎么看：工序列表出现新工序，并列出允许报工的部门和不良原因。

注意：权限按部门判断。工人和班组长必须属于允许的部门；管理员不受此限制。管理员能报成功，不能证明工人的权限已经配好。

## 批量导入

谁来做：管理员。入口：**系统配置 → 用户**、**基础数据 → 工序**、**基础数据 → 产品定义** 工具栏的【导入】。

1. 点【导入】，再点【下载母版】，得到 `.xlsx`（不支持老式 `.xls`）。
2. 按表头填数据。第 2 行是格式示例，可改可删；关联列（报工部门编码、不良品项名称、单位名称、工艺路线编号、工序编码）须与本厂**已有**资料一致，留空表示不挂关联。
3. 点【上传文件】选填好的表格。结束后看「成功 N / 失败 M」；失败行会列出 Excel 行号和原因，可复制后改表再传。
4. 成功条会进列表；失败行不会留下半截数据。同一文件里好行会入库、坏行报错，不必整份重导。

做完怎么看：对应列表出现新数据；若有失败，按行号改 Excel 后只重传或再传一次即可。

注意：产品编号、用户账号不能重复。工序/产品的关联填错会整行失败并提示，不会静默跳过。空文件或全是空行会提示「没有可导入的数据行」。

## 配工艺路线和产品

工艺路线就是"这个产品按什么顺序把活做完"的工序流程（比如裁切 → 检验 → 包装）。谁来做：管理员。入口：**基础数据 → 工艺路线 / 产品定义**。先配好单位、工序。

1. 在【工艺路线】点【+ 创建工艺路线】，填路线编号、名称。
2. 第一行选第一道工序，点【+ 添加一行】继续选后面的工序，例如“裁切 → 检验 → 包装”。按行从上到下排列（当前不能拖动排序）。
3. 核对顺序后点【保存】。排错了可重新选择各行工序，或用【×】删除多余行再添加。
4. 在【产品定义】点【+ 创建产品】，填产品编号、名称，选单位和工艺路线。供应商、单价按实际情况填写。
5. 点【保存】，在列表核对产品编号、单位和工艺路线。

做完怎么看：下工单时能选到产品，创建后的工单详情能看到对应工序。

注意：**产品编号不能重复，名称可以重复。** 同名产品要核对编号。需要扫码报工的产品应配好工艺路线，避免打开工单后没有工序可选。

## 上传作业指导书、图纸和图片

谁来做：管理员。入口：**基础数据 → 产品定义** 或 **基础数据 → 工序**，打开某条记录的【编辑】。

1. 在【产品定义】或【工序】点某条记录【编辑】（新建的保存后即可）。
2. 表单下方「作业指导书 / 图纸」区，点【上传作业指导书 / 图纸】选文件。
3. 支持 pdf / docx / xlsx / jpg / png / webp，单个不超过 20MB；版本（如 V1.2）可填可不填。
4. 上传后列表显示文件名、类型、版本；可点【删除】移除（只删登记记录，磁盘文件保留）。

做完怎么看：产品页、工序页能看到已挂文件；工人手机报工界面（H5）打开对应工单，可查看这些作业指导书、图纸和图片；管理员在 PC 工单详情页【图纸 / 作业指导书】区也能按单查看并预览（pdf / docx 页面内预览，xlsx 下载查看）。

注意：jpg / png / webp 也能传，可作为产品图片或工序示意图。文件一旦挂在产品或工序上，删除该产品/工序前须先移除这些文件（删除依赖倒序：先删知识库文件，才能删产品/工序）。

说明：这是“制造知识库”——文件存服务器知识库目录，系统只记路径。PC 工单详情页已按工单聚合查看图纸/作业指导书并支持内嵌预览（预览依赖点击文档时按需加载；Word/PDF 排版以实际文件为准）。

## 下工单

谁来做：管理员。入口：**生产管理 → 工单**。先建好产品和工艺路线。

1. 点【+ 创建工单】。
2. 【工单号】可留空自动生成（自动单号是 A0001 → A9999 → B0001 → … → Z9999，短、好记）；也可自己填一个不重复的号（比如填销售单号，方便查询）；选产品时核对编号和名称。
3. 填【数量】，即这张单要做多少。需要跟踪交期时，填写【计划交期】的日期和时间。
4. 如有额外字段，按现场要求填写，点【保存】。
5. 在列表找到新单，点【详情】，核对产品、数量、工序及各道计划数。

做完怎么看：列表出现新工单，初始状态为【未开始】。记下工单号，打印、报工和查询都用它。

注意：新建表单选产品后不会立即列出工序计划。保存后先看详情；确需调整，再打开【编辑】。不要为了找工单重复创建，先用工单号搜索。

## 派工：把工序派给工人

谁来做：管理员或班组长。入口：**生产管理 → 工单**，找到工单点【详情】；班组长也可在**手机端**打开工单详情点【派工】（限本组人员）。

1. 详情里每道工序右侧有【执行人】下拉，点开选本厂工人（也可选班组长）；**一道工序可以派多个工人**（电脑端和手机端都支持）。
2. 选完自动保存；把下拉清空，等于取消派工。
3. 被派的工人，手机打开【任务】就能看到要干的活。

做完怎么看：详情里工序的执行人显示对应姓名；工人手机【任务】页出现该工单的工序。

注意：派工只是让工人知道今天干什么，不拦报工——没派工也能照常报工，不会被卡住。一道工序派多人时，多人共同报工有两种分摊：**平均**（默认，分不尽的余数归报工人）或**按报工时长加权**（谁干得久分得多，没填时长的按平均兜底），合计正好等于总数。

## 打印二维码流转卡

流转卡就是"贴在工件或流转单上、扫码就能打开这张工单"的二维码标签。谁来做：管理员。入口：**生产管理 → 工单**。

1. 首次先点【打印设置】，选与标签纸匹配的【80×60 mm】或【30×40 mm】。
2. 选二维码内容：【工单号（PDA）】适合扫码枪；【报工页链接（手机）】适合手机打开报工页；【报工页链接·按工序（工位码）】会按工单**每道工序各打一张标签**，扫码后直达该工序报工（贴到工位用）。后两种需确认【前端基址】是手机能访问的 **HTTPS** 局域网地址。默认仍是工单号/报工链接，只有主动选「按工序」才出工序码；已印旧卡照样能扫。
3. 勾选要显示的字段，点【保存】。
4. 找到工单，点这一行【打印】，在【工单流转卡】预览里核对工单号、产品和二维码（按工序时预览多张，每张带工序名）。
5. 再点弹窗【打印】，在浏览器打印窗口核对打印机、纸张和缩放。先试打一张，确认内容完整且能扫，再正式使用。

做完怎么看：纸上工单号与页面一致；扫工单码进报工页再选工序，扫工序码则工序已预选好。

注意：手机链接的地址必须是手机能访问的局域网地址，不能用只有本机能打开的地址；网页内「打开摄像头」需要 HTTPS 且证书被手机信任。

## 改工单、结束、撤回和取消

谁来做：管理员。入口：**生产管理 → 工单**，找到工单右侧操作。

1. 改数量或交期，点【编辑】后【保存】。工序计划不可低于已报的有效良品数（待复核和已通过的报工）；已有报工的工单不能更换产品。
2. 【开始】把未开始改为执行中。有有效报工后系统也会更新状态。
3. 【结束】把执行中工单手动结束。各道工序全部报满后也会自动结束。已结束不等于所有报工已经复核通过。
4. 结束过早需要继续处理，点【撤回】：已结束变为执行中；执行中再撤回变为未开始。撤回状态不会删除原报工记录。
5. 不再生产时点【取消】。需要恢复时，在【已取消】页签找到工单，点【恢复】，回到未开始。
6. 想参考旧单再开一张，点【复制】，找到新工单后核对并按需编辑，再打印。

做完怎么看：查询后检查状态和详情。已结束、已取消不能新增报工或补报，应先确认业务上是否要撤回、恢复。

注意：取消不是删除。不要为了隐藏列表或纠正报工而删除工单；涉及历史数据先由负责人核对。

## 电脑报工

谁来做：管理员、班组长。入口：**生产管理 → 报工**；也可在工单行点【报工】。

1. 点【+ 报工】，工单号可下拉选择（显示工单号+产品名，也可手敲），选中后自动带出产品与工序。
2. 核对产品，选工序，查看【计划、良品、不良、剩余】。
3. 填本次【良品数】和【不良品数】，不是从开工至今的累计数。
4. 不良品大于 0 时选【不良原因】。需要记录时长时填小时和分钟，单次合计不超过 24 小时。
5. 点【提交】保存并关闭；同张单继续报下一批，点【继续报工】。

### 代报工（替工人记数）

谁来做：管理员、班组长。入口：**生产管理 → 报工 → 代报工**。

1. 点【代报工】，选工单、工序。
2. 选实际干活的工人（可一次代多人，各人数量按实际填，不搞平均）。
3. 填各人数量，核对后点【提交】。

做完怎么看：报工记录记到**被代的工人名下**、直接进他的工资；记录里能查到是谁代的。

注意：被代报的工人必须在该工序报权部门里，班组长再限本组；代报工是”替人记实际账”，不是绕过权限。

做完怎么看：查询工单号，核对工序、报工人、数量和复核状态。管理员新增直接【已通过】，班组长新增为【待复核】。

注意：普通【+ 报工】记在当前登录人名下，没有”代谁报”字段。需要把漏报记到实际工人名下，管理员使用”一键补报未完工序”的拆分功能，或【代报工】，并先核实实际完成情况。顶部筛选工单编号也可下拉点选（只列未结束工单）；查已结束单可手敲编号。

## 复核：通过或退回报工

谁来做：管理员、班组长。入口：**生产管理 → 报工复核**。班组长只能复核与自己有共同部门的人员报工。

1. 工单编号可下拉选择（只列当前有待复核报工的工单，含已结束但仍挂着待复核的；也可手敲），或按工人姓名筛选，选【待复核】，点【查询】。
2. 核对工序、工人、良品、不良、时长，正确的点【通过】。
3. 多条都已核对，可勾选后点【批量通过】，核对条数再确认。
4. 有问题点【退回】，写具体原因，例如“实际为 18 件，请核对”，点【确定退回】。
5. 纠正已通过记录，先选【已通过】查询，再退回。已结算报工不能退回。

做完怎么看：切到【已通过】或【已退回】查询确认。通过后计入生产报表；退回后不计有效进度，工单状态可能变化。

注意：退回后核对并修改原记录，不要未经确认另报一遍。原记录修改后回到待复核。

## 报错数量怎么改

谁来做：管理员、班组长；**报工本人（待复核记录）也可在手机端自己撤回改**，改动留痕可查。

1. 待复核（还没审核）的报工：报工本人在手机【我的报工】可撤回/修改自己这条记录的良品、不良、原因、时长，改后仍为【待复核】；每次修改都会记一条修改记录（原值 → 新值、谁改的、什么时间），可追溯。
2. 管理员/班组长在【生产管理 → 报工】查询工单，按工序、人员和时间找到原记录。
3. 已通过且【修改】不可点时，先到【报工复核】退回这条记录并写原因。
4. 回【报工】重新查询，点原记录【修改】，填正确的良品、不良、原因、时长，点【保存】。
5. 到【报工复核】重新核对通过；管理员改数后同样需要复核。

做完怎么看：原记录数量变更，保存后为【待复核】，通过后再查报表。误报 20、实际 18，就改为 18，不是填 -2。

注意：**已通过**的记录要走退回再改；**已结算**的记录不能改或退回，交结算负责人核查。生产人员只能改自己的待复核报工，不能改别人的。

## 一键补报未完工序

这个功能就是：工人干过的活漏报了，管理员一次把漏掉的工序补报上，要的话还能按人头拆开记到具体工人名下。谁来做：仅管理员、电脑端。入口：**生产管理 → 报工 → 一键补报未完工序**。

3. 填【统一良品数】，不得超过各工序【剩余可报】的最小值。两道剩余 30、20，本次最多统一补 20。

## 查进度、查报表、看看板与执行监控

谁来做：管理员、班组长；生产人员可只读查看工单与执行监控。入口：**生产管理 → 工单 / 执行监控**，**报表 → 生产报表 / 不良品报表 / 色码汇总 / 工资色码汇总 / 车间看板**。

1. 工单页输入工单号或产品点【查询】，按状态页签查找。【全部】不包含已取消。
2. 点【详情】逐道看计划、已报良品和进度，确认卡在哪道；需要派工时在详情里选执行人。
3. 【执行监控】一眼看未开始/执行中/已结束、临期、超期和待处理异常；中间是当前页工单的工序进度链，右侧是异常与超期摘要，底部是明细和待办（待复核、未派工工序数按角色显示）。
4. 监控页可按工单号/产品、状态、交期筛选；点状态卡可切换状态（统计卡本身不受当前状态筛选影响）。约每 10 秒自动刷新，右上角显示最后成功更新时间；失败会提示并保留上次数据。
5. 从监控可跳到工单详情（含派工）、报工、异常处理、报工复核；处理完后回到监控会随刷新更新。
6. 【生产报表】选【今日、本月、上月】，按报工人看良品、不良和次数。时间按原报工时间，不是复核时间。
7. 【不良品报表】看不良原因分布、工序×原因×人汇总、逐条明细；口径是待复核+已通过（不含退回）。不良品报表看现场、生产报表算钱，两表数不同正常。
8. 【色码汇总】按「款（产品）+ 颜色 + 规格尺码」分组汇总良品、不良、次数，能直接答「黑色 M 码做了多少件」；口径与生产报表一致（只算已复核通过的报工）。本厂没配颜色 / 规格字段（五金厂通常不配）时，页面提示去「自定义字段」配置，不显示数据。
8. 【车间看板】看状态、临期和超期。交期已过且未结束/取消为超期；未来 3 天内到期为临期；没填交期不做临期判断。

做完怎么看：整单现场进度看工单详情或执行监控；查原记录看报工列表；查已复核数量看生产报表。

注意：**完成数和「工序达成进度」用的是一套算法（口径），前后一致。** 现场进度只算"待复核 + 已通过"的报工（被打回的不算）。一张单有多道工序时，**完成数取各道合格数里最小的那个**；「工序达成进度」取各道 `已报/计划` 的最小值（0～100%），它不是成品产出率，也不是机器利用率。没有计划的工序显示「无需报工」，不参与百分比。生产报表和工资仍然只算已通过的。举个例：裁切报了 100、包装报了 80，那完成数和进度都按 80 这一道算（因为卡在包装这道）。

## 工价和工资报表

谁来做：负责算工资的管理员。入口：**基础数据 → 工价表**（先定"每道活给多少钱"）、**报表 → 工资报表**（按周/月算工资）。

### 先把"每道活给多少钱"定好（工价表）

工价表就是"哪个产品、哪道工序，按件 / 按小时 / 干一次给多少钱"的清单，可一次管一大片：

1. 可按【产品 / 工序 / 部门 / 人员】筛选（多条件组合），列表按【产品 + 工序】排好序，方便核对；到期的价（过了失效时间）用不同颜色标出来，不影响改价。
2. 批量定 / 加价可用【导入】上传 Excel（列：产品编号、工序编号、部门、人员、计价方式、单价、不良扣款、生效时间、失效时间、优先级），哪一行哪个字段填错，会逐行提示原因。
3. 计价方式三选一：**【计件（元/件）】**按件算、**【计时（元/小时）】**按小时算、**【固定（单笔）】**干这道给一次。填单价、不良扣款（出一件不良扣多少）、生效时间，需要可设失效时间、优先级，点【保存】。

### 到周底 / 月底，一键算工资

4. 报工都复核通过后，进【工资报表】点【生成工资单】：选按月还是按周，填周期（如 2026-09 表示 9 月、2026-W37 表示第 37 周），按需选算哪些人，点【生成】。
5. 生成后先看【明细】。系统按**已通过的报工**自动算出**计件合计 / 计时金额**；若有报工没对上任何一条工价，会标红色【未匹配】——先回去把工价补齐，别把缺价的当零工资发了。
6. 工资单**没有手工发薪列**（底薪、餐补、社保个税这类已移除）——工资单只放报工算出来的活钱，干净对账；到手工资里的底薪、补贴、社保扣款等由工厂按自己规则另行核算发放，**系统不代算社保费率、也不负责银行代发**。
7. **应发合计 = 计件合计 + 计时金额 − 不良扣款**（不良扣款按工价里的【不良扣款】× 不良数扣）。
8. 核对无误再点【确认】：只要有红色【未匹配】，系统会拦住不让确认，先把工价补齐。确认后这批复核过的报工就**锁死**了，数量不能再改。想带走数据核对，点【导出 CSV】（用 Excel 能打开）。

**算错了、工价没配对怎么办**：改对工价后，已确认的工资单也能纠——管理员点【撤回重算】把单**软撤回**（单子和明细都保留、不删除）回草稿，重算金额后再确认，全程留痕、可查可重算，错误金额不会永远定格。多张一起改，列表勾选后点【批量重算】：草稿原地重算、已确认先撤回再重算，任一张失败单独提示原因，不影响其它单。

**看明细、查账**：工资报表页可按【工序 / 时间】筛选，报表层直接列出明细（人员、工序、良品、不良、单价、不良扣款、小计，并带工单的**颜色 / 规格尺码**两列），可【导出明细 CSV】；原【明细】按钮进单子照旧。

**手机看工资**：用手机浏览器打开工资报表，汇总自动变成**卡片式**（人名 + 应发合计 + 状态 + 操作按钮，不用左右拖），明细大块默认收起；批量重算在手机上不可用（提示电脑端操作）。工人端【我的工资】不受影响。

**工人手机看工资【我的工资】**：工人（开了计件工资档）在手机点工作台 / 我的报工里的【我的工资】，按**天 / 周 / 月**看累计预估金额（默认本月）。金额三档口径：**已结算** → 工资单明细的固化金额；**未结算但已复核** → 报工快照的单价 × 金额；**待复核 / 被退回** → 只展示并标状态、**不计入累计**。本厂配了颜色 / 规格字段，明细还多出颜色、尺码两列；五金厂没有。累计是估算，以确认后的工资单为准。

**按色码看工资【工资色码汇总】**：报表 → 工资色码汇总（管理员，需开计件工资档），按「款 + 颜色 + 规格」汇总工资（数量、金额），可【导出 CSV】（带款 / 色 / 规格 / 数量 / 金额）；口径与工资报表一致（只算已确认工资单对应的已通过报工）。没配色码字段的账套页面提示去「自定义字段」配置、不显示数据。

做完怎么看：工资单从【草稿】变成【已确认】。确认就是定稿结算，相关报工就不能随便改，别当成普通保存。

注意：工资只按**已通过的报工**算（还在核对、或被打回的都不算）。计件=良品数×单价，计时=时长（小时）×单价，固定=单价一次；出了不良按【不良扣款】扣。**系统不自动算社保费率、也不负责银行代发**，具体薪酬规则由工厂自己定。草稿算错了先核对报工和工价，可删掉重生成；已确认单要改，用【撤回重算】（仅管理员），别口头答应"随便改已确认的数"。

## 建议报价（相似件 · 金蝶材料 + 车间实绩）

解决什么：**报价不用再拍脑袋，也不用在金蝶和小工单里各录一遍资料。** 金蝶里已有的物料、BOM（物料清单）、标准工艺直接读过来当材料成本；人工成本按你们车间**真实报工干了多久**来估，不靠经验毛估。现场比价能当场算、能导出带走；日常用不用、按老习惯拍板都行——功能不逼你们改流程。

谁来做：管理员（报价 / 业务员）。入口：**报表 → 建议报价**。

1. 选相似产品：搜编号或名称，勾 1 个或多个**本厂做过的老产品**作参考（报价按它们的实做来估）。
2. （可选）填金蝶物料号：读金蝶该物料的成本单价 + BOM 材料费合计；没 BOM 就只算物料价。没填金蝶号或连不上也不崩，材料区会标红提示。
3. 调【毛利%】和【不良预留%】：页面可改，默认来自配置。毛利是你想留的赚头，不良预留是替预计会出不良的部分提前留的钱。
4. 点【计算】：材料（金蝶）+ 人工（参考老产品已复核报工的真实时长估）+ 不良预留 → 建议总价；需要时【导出 Excel】留给客户。

做完怎么看：材料区显示金蝶物料成本 / BOM 明细；人工区显示「平均单件工时 = 总时长 ÷ 良品数」的来源说明。金蝶连不上时材料区标红，但人工建议照常能出。

注意：人工只取**已通过复核且填了时长**的报工；没填时长的计件报工不计入平均工时分母，页面会提示「部分报工缺时长」。本厂没有相似产品的历史报工 → 人工建议为 0 并明确提示，不编造。首版只算不存（不生成报价单），也不写回金蝶销售报价；金蝶标准工艺只读展示、不自动拆单。

## 按需使用的辅助功能

谁来做：管理员。这些功能不影响先跑通建单报工。

自定义字段：进【系统配置 → 自定义字段】，选对象（要加字段的资料，如工单、产品、报工），点【+ 添加字段】，填名称、类型及单选选项后【保存】。已建字段类型不能改。对象选【报工】时，工人手机报工页会出现这些字段（如设备、模具），随报工一起保存、可查回；对象选【工单】时，当前工单表单展示工单字段。其他对象的配置入口不代表所有页面都已有填写入口。

工单列表显示与筛选（可选）：对象选「工单」时，可打开「在工单列表显示」。打开后【工单】页表格会出现该列。需要按自定义内容查单时，在工单页选字段、匹配方式（文本可选精确/包含；单选和数字固定精确）和值后点【查询】。关显示只藏列，不影响按该字段筛选，也不影响打印勾选。不支持查「没填过的空值」。

排产评分（帮您给生产任务排个先后顺序）：进【报表 → 排产评分】，看现有任务和交期，按实际情况给客户等级、金额、换型、齐套性（材料配不配得齐）打分，调好权重后【重新计算】，需要时【导出 Excel】。算出的建议顺序得计划员确认，不表示系统已自动派工、也不代表真有外部库存。

工人手机视角（可选）：管理员在【系统配置 → 工人手机视角】切换。默认「全车间可见可报」：工人手机能看到全车间工单、扫码可报有权限的活；切到「只看我的任务」后，工人手机默认进【任务】、隐藏【工单】入口，但扫码报工不受影响（仍能扫全车间有权限的单）。切换只影响工人看到什么，不改变报工权限。

微信预警：默认关闭的可选功能，开启方法见下一章《微信预警（企业微信群机器人，默认关闭）》。

做完怎么看：重新打开核对保存的配置，查看计算结果或实际消息接收结果；错误交维护人员处理。

## 微信预警（企业微信群机器人，默认关闭）

谁来做：管理员。入口：**系统配置 → 微信预警**。

这是默认关闭的可选功能，不开也能正常用系统：临期、超期在看板上已有黄/红提示。

1. 前置条件：在**企业微信**里建一个纯内部群，群设置中添加「群机器人」（名称随客户端版本可能不同），复制机器人的 **Webhook** 地址。**不需要**域名备案，也**不需要**企业微信自建应用的可信 IP；服务器需要能出站访问 `qyapi.weixin.qq.com`。
2. 打开【启用推送】开关，填 **Webhook**（完整链接或纯 key 都行，保存后显示为 `********`），填默认 @成员（企微 UserId，多人用竖线分隔，也可填 `@all`），需要时调整【每日上限】，点【保存】。
3. 交期预警规则（页上也有说明）：**一天一批一条消息**（临期+超期写在一起）；**当日批次不重推**。
4. 群规则（可选）：可分别配置【报工成功 / 工单开始 / 工单结束 / 异常上报】触发推送；异常上报按设备 / 物料 / 质量匹配对应规则（机修 / 仓库 / 质检），规则里填的成员才会被 @，留空只发群不 @人。
5. 点【发送测试消息】验证链路；需要时点【推送临期/超期工单】手动推送。
6. 若要自动推：计划任务调 `backend/scripts/wechat-alert-cron.ps1`（每日交期）和 `wechat-events-cron.ps1`（事件投递，约每分钟）；每机器人每分钟最多 20 条，超了会延后/提示。

做完怎么看：群里能收到测试消息。收不到先看【启用推送】是否打开、Webhook 是否填对，再点【发送测试消息】排查；手机是否弹锁屏通知取决于手机通知权限、免打扰和系统设置，不能保证一定弹窗。

注意：Webhook key 属敏感信息，不要发给 AI 或发到群里。不使用预警也可以正常报工和阅读手册。

## 使用 AI 助手查问题

谁来做：仅管理员。入口：**系统配置 → AI 助手**。

1. 看状态，【已关闭】或【未配置】时找部署人员，不影响阅读操作手册。
2. 阅读使用说明。问题和必要资料会发送至配置的 AI 服务，不输入密码、工资等敏感内容。
3. 选【查进度】【问工艺】或【智能客服】，例如“工单 XXX 做到哪了”“产品编号 XXX 的包装要求”“报错数量怎么改”。
4. 遇到多个同名结果时，核对编号、工序再点选；回答要结合来源、明细和查询时间看。

做完怎么看：回答应对应所问工单或本厂资料。无资料时联系管理员补充知识文件。

注意：AI 只查询解释，不能替你下单、报工、改数或删除。操作步骤也可直接从【帮助 → 操作手册】查。

## 产品优势速览（演示给老板看）

谁来做：管理员、销售伙伴。入口：**帮助 → 产品优势速览**（也可登录前打开该页）。

解决什么：出门演示不用背 PPT。页上用大白话写清三大麻烦怎么解、六步闭环、以及「本地部署 / 断外网也能用 / 数据不出厂」等差异；下面可展开「销售备忘」（话术、竞品对比），演示时请先收起备忘。

1. 打开【产品优势速览】，先看页顶横幅「本地部署・局域网运行・数据不出厂」。
2. 按页面向下讲：三个麻烦 → 六步闭环 → 三大差异 → 金蝶相关扩展（建议报价、排产评分等，已做才写）。
3. 需要对照话术或竞品表时，再展开销售备忘；讲完可点页内演示路径链到真实功能页。
4. 工单、报工、看板、工资等业务页顶部会有一行浅色价值提示（一句人话），与本页口径一致；**不是弹窗**，可忽略不影响操作。

做完怎么看：能打开页面、能讲清「数据在您自己服务器」；不要向客户承诺未闭环能力（如未接金蝶就吹齐套真取数、未认证就吹企微已推送）。

注意：「断外网也能用」限定局域网内核心功能（工单/报工/看板/工资）；推送依赖企业微信通道，不是断网也能推。工资对外只讲计件算清楚、可查可重算，不把底薪社保银行代发说成系统全包。
