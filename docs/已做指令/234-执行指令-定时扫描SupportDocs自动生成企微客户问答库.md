## 行为与口径

- 当 15、19、08 任一文件内容变化 → 重跑后问答库对应条目更新，version 加 1，updatedAt 改为当天。
- 当三份都没变化 → 重跑仍成功，version 与 updatedAt 保持上次的值，日志记「内容未变」。
- 当问句按上面的规则判为同题 → 留优先级高的那条答案，日志记保留谁、丢弃谁。
- 当白名单文件缺失或解析失败 → 跳过该文件，日志写「哪个文件 + 哪一步 + 失败原因」，其余照常生成。三份都失败则退出码 1，并写日志。
- 当 08 的答案夹着点名 16 号或「不要念 / 原样念」的 `>` 引用块 → 引用块不进库。
- 当生成结果正文出现禁用文件名（09/13/14/16/17/18、10 号、`_retrieval.json`）→ 不落盘，任务失败并写日志。
