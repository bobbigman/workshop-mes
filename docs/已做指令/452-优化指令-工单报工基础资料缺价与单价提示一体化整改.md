## 2. 范围与完整流程

### 2.1 工单缺价提示分色（对应原 449）

入口：工单弹窗 → 本单工序工价表（`frontend/src/components/WorkOrderProcessing.vue`）。

- **非审核态**（新建/草稿/待审，`approveMode=true`，可暂存/保存/审核）：缺价、缺属性按"待办警示"显示（黄/中性，不套红 error 样式）；保留「去配价」按钮与字段级感叹号；顶部说明保留"暂存/保存可不取齐价"口径。
- **审核被拦**（点审核或严格校验 `getQuoteTokens(strict=true)` 抛错）：仍用红色，保留分型文案与分工序原因清单。
- **已生效锁价行**（`approveMode=false`、`keep`）：维持绿色"本单单价已定"，不动。
- **工序整块加载失败**（顶部 `error` 横幅，网络/数据异常）：保持红色 + 重试，不降级成黄。

### 2.2 报工缺价口径对齐与跳转预填（对应原 450）

入口一：PC 报工列表，某行 `unitPrice == null`。
- 管理员：「去设置单价」跳转带 `create=1&operationId=<本行工序>&productId=<本行产品>`，复用现有 `applyCreateQuery` 预填；产品 ID 缺失时只带工序 ID，产品留空由价目表页选。
- 非管理员：仅缺价文案，不出按钮。

入口二：PC 单条/单人报工成功，返回含 `unitPrice == null` 记录。
- 黄色警告口径与代报对齐："该工序暂未设置单价，本次金额暂按 0 元计；补齐单价后需重算工资单"，并附入口说明。

### 2.3 产品/工序档案单价口径与复制提醒（对应原 451）

- 产品表单「单价」字段旁加中性备注："参考单价，不计入计件工资；工人计件工价在「工序价目表」维护。"
- 复制产品/工序：保留顶部 info 不复制说明；保存成功且本次为复制新建（`copyFromId` 有值）时，成功提示补一句"计价规则、作业指导书、图纸未随复制带来，请到新资料中补齐"；普通新建不加该后缀。
