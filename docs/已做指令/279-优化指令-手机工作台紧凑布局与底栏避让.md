# 279-优化指令：手机工作台紧凑布局与底栏避让

> 状态：已实施（实际组件短视口隔离验证通过，真机动态地址栏/字号放大待验）。2026-10-23 用户授权先列指令、再按指令落地；不部署。

## 依据与范围

用户真机截图显示普通手机浏览器工具栏占用高度，工作台第二排入口在首屏被固定底栏遮住。此前375×812的独立页面验证不能代表手机浏览器实际可用高度；尚未证实“滚到底仍遮挡”，不得把它当作已定位事实。

只调整 `frontend/src/views/h5/home.vue` 的布局样式。不改后端、数据表、接口、统计口径、权限、四列入口、管理菜单、字号及PWA引导，不调整其他手机页面的公共底栏。

## 实施指令

1. 页面采用自身可纵向滚动的可视区：100vh兼容回退，支持时使用100dvh跟随浏览器动态高度。保留盒模型计算，不使用固定内容高度、缩放整页或禁止滚动。
2. 内容底部预留原底栏高度 + 安全区 + 16px间隙，使最后一排可以完整滚到固定底栏上方；为滚动定位保留相同底部余量。
3. 扫码主卡最小高度104→88px，减少内边距；保留标题23px和说明12px。扫码图标底块52→48px。
4. 顶栏最小高度52→48px，下方间距16→10px；长厂名/姓名沿用省略，退出保持至少44px高可点。
5. 两张统计卡上下内边距14→8px，数字字号27px不变；统计说明完整保留，区块间距16→12px。
6. 任务摘要最小高度52→44px，任务区块后间距18→12px；继续允许窄屏换行，不裁掉任务文案。
7. 功能卡片最小高度102→88px，图标底块48→44px，图标26px及文字13px保持；内部间距8→6px、上下内边距8px；四列间距10→8px，标题下间距10→8px。
8. 字体放大、加载失败、长文字等导致内容超高时允许滚动，不承诺所有手机都一屏装下，不为凑首屏隐藏功能。320px宽的原扫码内边距覆盖需同步，避免抵消紧凑调整。
