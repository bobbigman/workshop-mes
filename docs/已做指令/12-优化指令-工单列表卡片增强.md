## 2. 自主拍板（最优建议 = 本期范围）

| 项 | 决定 | 理由 |
|----|------|------|
| 本期范围 | **P0 卡片进度+工序链** + **P1 搜索** | 后端已有工序任务与报工数，主要是列表拼装 + H5 UI；收益最大 |
| 明确不做 | 交期/逾期、排序、漏斗筛选、快速操作、五 Tab、手机建单 | 需新字段或大改信息架构 |
| 进度口径 | `planQty = 工单 qty`；`doneQty = 各工序已报良品的最小值`（瓶颈）；`remainQty = max(0, planQty - doneQty)` | 与「所有工序都完成才结束」一致；单数展示对齐黑湖「一格进度」 |
| 无任务行兜底 | `doneQty = 该工单全部报工良品合计`（按工单汇总，不按工序），`planQty = qty` | 兼容旧数据 |
| 列表接口 | **扩展** 现有 `WorkOrderListDto`，不新增 URL | 少接口 |
| 工序链字段 | `ops: [{ operationName, planQty, doneQty }]` 按 seq | 前端画圆点；完成条件 `doneQty >= planQty` |
| 产品编号 | 列表增加 `productCode` | 卡片可显示「编号 名称」 |
| H5 搜索 | 顶栏输入框，走已有 `keyword` | 回车/防抖 300ms 后刷新列表；切 Tab 保留关键字 |
| 点卡片 | 仍进 `/h5/report?order=` | 不变 |
| PC 工单表 | 增加列「进度」（`done/plan`）与「剩余」可选 | 同一接口，顺手对齐；不做圆点链（表格不适合） |
| 性能 | 列表页批量查任务+报工汇总，禁止 N+1 逐单 `LoadTasksAsync` | 一次拉当前页 orderIds |

## 3. 后端

### 3.1 扩展 DTO

```csharp
public class WorkOrderListOpDto
{
    public string OperationName { get; set; }
    public int PlanQty { get; set; }
    public int DoneQty { get; set; }
}

public class WorkOrderListDto
{
    // 原有...
    public string ProductCode { get; set; }
    public int PlanQty { get; set; }     // = 工单 qty
    public int DoneQty { get; set; }     // 瓶颈最小值（见拍板）
    public int RemainQty { get; set; }
    public List<WorkOrderListOpDto> Ops { get; set; }
}
```

### 3.2 QueryAsync 拼装步骤

1. 现有筛选/分页查出当前页工单（含 `ProductCode`）。  
2. 取 `orderIds`。  
3. 查 `prod_work_order_operation` + 工序名，按 `work_order_id, seq`。  
4. 查报工：`GROUP BY order_id, operation_id SUM(good_qty)`。  
5. 填每道工序 `DoneQty`；算工单级 `DoneQty = Min(各工序 DoneQty)`（有任务行时）；`RemainQty`。  
6. 无任务行：用工单级 `SUM(good_qty)` 作 `DoneQty`，`Ops = []`。

### 3.3 不改表

本期 **零 DDL**。

## 4. 前端 H5（`orders.vue`）

### 4.1 顶栏

- 标题「工单」右侧或下方：搜索框（placeholder「工单号/产品」）。  
- `keyword` → `getOrderList({ ..., keyword })`；清空则全量当前 Tab。

### 4.2 卡片结构（对标截图信息，布局可简化）

```
[状态] 工单号
产品：code name
进度 doneQty/planQty          [ remainQty 剩余数 ]
○工序1  ○工序2  ●工序3 ...     （完成实心，未完成空心；可横滑）
数量 / 创建时间（次要信息可缩小）
```

- 整卡点击仍进报工。  
- 无 `ops` 时不画圆点行。

### 4.3 样式

- 剩余数：右侧强调块（数字大、文案「剩余数」）。  
- 圆点：约 28px 圆 + 工序名；完成色主色/绿，未完成灰边。  
- Tab 样式保持胶囊。
