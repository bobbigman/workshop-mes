# 447-优化指令：仅在「全部」页签操作后保持勾选

> 状态：已做（2026-11-09 集中做，「全部」不跳签+勾回；前端 build 过；现场点选未勾）  
> 类型：优化  
> 执行节奏：已集中做（2026-11-09；清单 #6）  
> 日期：2026-11-09  
> 性质：正式 UX；不改审核业务规则  
> 本次交付：代码 + 前端 build；不部署  
> 目标：让【管理员】在【PC 工单 → 全部】勾选后点审核/反审核等，刷新后**仍勾着同一张单**，可接着点顶栏；在草稿/已保存等分状态页签则不强留勾选（行常会离开当前列表）。  
> 依据：用户 2026-11-09「只有在全部的时候，勾选框才保留，这样操作后才保留」；规范 419。

## 1. 已核实现状与取舍

| 项 | 现状/方案 | 证据 | 标记 |
|---|---|---|---|
| 根因 | 审核成功强制 `statusTab='0'` + `load()` 且 load 末尾 `clearSelection()` | `order/index.vue` | 已核实 |
| 「全部」 | `statusTab===''`；列表不含已作废、已挂起，但含草稿/已保存/已审核等，**改状态后行仍在** | 同文件 load / statusTabs | 已核实 |
| 用户方案 | **仅当前在「全部」时**，操作成功后保留勾选；分状态页签不按此做 | 本会话 | 待确认→回过即已定 |

### 已定建议（请回「过」）

| 场景 | 行为 |
|---|---|
| 当前在 **全部**，审核/反审核（及同类改状态顶栏动作，本批至少含审核、反审核）成功 | **不跳页签**；刷新列表；按原 `id` 勾回 |
| 当前在 **草稿 / 已保存 / 已审核…** 等分签 | **保持现网**：可跳到目标状态页签 + load 清空勾选（行本来就会从当前签消失，留勾无意义） |
| 查询 / 手动换页签 / 重置 / 翻页 | 仍清空勾选 |

### 范围

| 项 | 决定 |
|---|---|
| 本批 | **只做工单列表**（有「全部」状态签的就是这里） |
| 通用 | 规则写清即可；其它页没有同类「全部状态签」不硬套；需要时再接 |
| 不做 | 不做「所有 load 都留勾」；不改审核锁价规则 |

## 2. 决策表

| ID | 条件 | 用户看到 | 验证 |
|---|---|---|---|
| B01 | 在「全部」勾选已保存 → 审核成功 | 仍在「全部」；该行仍勾选；状态已变为已审核 | V01 |
| B02 | 在「全部」勾选已审核 → 反审核成功 | 仍在「全部」；该行仍勾选；状态变为已保存 | V02 |
| B03 | 在「已保存」勾选 → 审核成功 | 现网：进「已审核」、勾选清空（或等价不保留） | V03 |
| B04 | 在「全部」点查询/换到其它签 | 勾选清空 | V04 |

## 3. 实现要点（执行时）

```text
const stayAll = statusTab.value === ''
const id = row.id
// …业务成功…
if (!stayAll) { statusTab.value = 目标签 }  // 现网跳签
page = 1
await load()
if (stayAll) await reselectById(id)  // nextTick + 新 list 行引用
```

可抽 `reselectRowsById(tableRef, list, [id])` 备其它页，本批非必须大而全。
