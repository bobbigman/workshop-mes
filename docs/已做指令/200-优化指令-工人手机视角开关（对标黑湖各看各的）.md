# 200-执行指令：工人手机视角开关（对标黑湖「各看各的」）

> 状态：已做（2026-10-02）
> 一句话目标：给工人手机端加一个**工厂级开关**，让管理员可配「工人只看我的任务」还是「全车间可见可报」，既不丢「派工不拦报工」卖点，又能对标黑湖「各看各的」。
> 依据/拍板：2026-10-02 多隆老同学与黑帽大人评估对标黑湖后拍板——做成开关而非做死；放在 `docs/未做指令/200`。三处取舍已拍板：**1C（工单入口收窄、扫码不收窄）、2A（PC 系统配置下新菜单页，对齐微信预警）、存储新建 `sys_worker_view_setting`**。

## 取舍（定死）
| 项 | 定案 |
|---|---|
| 做/不做 | 做开关，**不做死**。保留「全车间可报」默认能力，黑湖式「只看我的任务」作为可选视角 |
| 复用还是另写 | 复用现有【任务】页（h5，已按 `assignee_user_id` 过滤）+ 现有工单列表；**不重写页面**，只加视角入口和过滤开关 |
| 默认值 | 默认 `worker_view_mode=1`（全车间可见可报），行为零变化；开关让管理员自行切换 |
| PC / H5 | 配置入口在 **PC（管理员）**，生效逻辑在 **H5（工人）** |
| 存储 | **新建** 工厂级单条配置表 `sys_worker_view_setting`（对齐 `sys_print_setting`/`sys_wechat_alert_setting` 模式）；不塞旧表 |
| 工单页（mode=2） | **C 方案**：隐藏 H5【工单】入口（工作台快捷入口；直链 `/h5/orders` 也跳回任务）；扫码仍可扫全车间有权限的单（入口收窄、扫码不收窄），派工不拦报工 |
| PC 入口 | **A 方案**：系统配置下新建菜单页，对齐「微信预警」配置页 |

## 已核实现状（勿重复做）
- 已有：手机【任务】页（底部 Tab），只显示派给自己（`assignee_user_id`）的工序，含工单号/产品/工序/剩余/交期（`SupportDocs/03-工单·我的任务`）。
- 已有：手机【工单】页全车间单可见、可报；派工是提示、不拦报工（`SupportDocs/03-工单` 第 49 行明示「没被派工不代表不能干活」）。
- 已有：工厂级单条配置的既有模式：`sys_print_setting`、`sys_wechat_alert_setting`、`login_setting`（`docs/02`，均 `UNIQUE(factory_id)`）；**已核实无通用工厂配置表**，故新建。
- 缺口：无「工人手机默认只看我的任务」视角开关；工人进 app 首屏目前非「我的任务」。

## 改动点
- 数据字典（**改 docs/02**，改表必须改）：新增表 `sys_worker_view_setting`，字段 `id`、`factory_id`、`worker_view_mode TINYINT DEFAULT 1`（`1=全车间可见(默认)`/`2=只看我的任务`）、`updated_at`，约束 `UNIQUE(factory_id)`（同 `sys_print_setting` 写法）。
- 后端（.NET 8，路径以 `backend/` 现状为准，勿绑死行号）：
  - 新增管理员读写接口：`GET /api/WorkerView`（返回该厂 `workerViewMode`）、`PUT`（仅管理员可改，当非管理员 → 403）。
  - 登录返回 `workerViewMode`；工人 H5 当 `=2` → 默认落地【任务】、隐藏【工单】入口；当 `=1`（默认）→ 维持现状全车间可见。
  - 权限校验沿用「工序报工权限=部门」，不受该开关影响报工合法性。
- 前端：
  - PC（**Element Plus**）：系统配置下新建「工人手机视角」菜单页（对齐微信预警配置页），下拉/单选 `1/2`，保存调 PUT，仅管理员可见。
  - H5（**Vant**）：当 `worker_view_mode=2` → 默认落地【任务】、隐藏【工单】入口、扫码仍扫全车间有权限的单（扫码页不因开关收窄）；当 `=1` → 现状。切换只影响入口与可见范围，不刷新数据。
- 文档：`docs/02` 新增表说明；`docs/33` 补接口一行。

## 验收（3～5 条勾选）
- [x] 默认 `worker_view_mode=1`：工人手机行为与现在完全一致（全车间可见可报）。
- [x] 管理员在 PC 切到 `2` 后：工人手机默认进【任务】，【工单】入口隐藏；扫码仍可扫全车间有权限的单，已派工本人照常可报。
- [x] 切回 `1`：工人手机恢复全车间可见，无需清缓存（进页会 GET 刷新）。
- [x] 工人（role=2）不能自己改视角（无入口/接口 403）；班组长/管理员视角行为不受该开关影响（仍全可见）。
- [x] `docs/02` 已同步新增表说明。

## 不做 / 边界
- **不删除**「全车间可报」能力，只默认隐藏入口；不改变「派工不拦报工」规则。
- 不做手机端派工（黑湖班组长手机派工属另一需求，不在本条）。
- 不改报工权限逻辑、不改工资口径。
- 切换为纯视角/入口开关：不因 mode=2 而改写任何报工或派工数据。
