# 143-优化指令：登录页参照金蝶云星空精简

> 状态：已完成（2026-10-04）
> 性质：内部试用（内网 H5/PC 登录页，不涉及公网找回）
> 目标：让登录页主视觉只剩「Logo+账套+账号+密码+登录按钮」，参照金蝶云星空登录页的克制感，把排障/版权/说明书类信息从主区挪走
> 依据/拍板：黑帽大人 2026-10-04 对照金蝶云星空截图提的 5 条；本指令是对 112 号清缓存按钮的 UI 降级，**不动 112 已实现的后端接口和工具逻辑**

## 本次范围与落点

- 交付：登录页 `/#/login` 打开 → 主区干净（见验收 1）→ 四个辅助入口（清缓存 / 忘记密码 / 操作手册? / 账套刷新）各自按行为分叉工作
- 已有能力（直接复用，别重写）：
  - 112 号：`POST /api/Auth/clear-browser-cache`、`src/utils/clearBrowserCache.js`、独立 Axios 封装、localStorage 保留、一次性 sessionStorage 表单恢复
  - 现有操作手册站内路由 `/help`（原 `router-link`，改到 Logo 旁 `?` → `router.push('/help')`）
  - 现有账套列表加载/报错逻辑（改成内联红字 + 刷新图标；实例信息失败主区不展示）
- 无新增配置项：管理员联系方式不配，弹窗文案写死即可
- 数据与契约：**不改表、不改后端接口、不改鉴权**；只改登录页 Vue 组件和可能加一个前端配置常量
- 文档：本指令不涉及 `docs/02`；不动 `docs/33` 接口说明（112 已记）

## 行为与口径（分叉写成显式条件）

- 当账套/工厂列表加载失败 → 账套下拉框下方显示红字「账套列表加载失败」+旁边一个小刷新图标（Element Plus 图标 `Refresh`）；点图标重新调现有账套列表接口；**不出现整行大报错横幅**
- 当实例信息（`getInstanceInfo`）加载失败 → **主区不展示任何报错**，仅 `console.warn`；不提供实例信息「重试」按钮（工人靠账套区刷新即可）
- 当有实例信息成功 → **不在 Logo 下显示** `factoryLabel`（已砍）
- 当用户点右下角「清除本地缓存」小灰字链接 → 先弹 Element Plus MessageBox 确认：「将清除本站缓存并刷新页面，未提交的账号密码需重新输入，已登录状态保留。是否继续？」；确认后**直接调用 112 已实现的清缓存流程**（loading、失败上下文提示、能力限制提示、刷新后表单恢复全走 112 既有逻辑）；取消则什么都不做
- 当用户点「忘记密码」小灰字链接 → 弹 MessageBox：标题「重置密码」，正文就一句固定文案「局域网系统暂不支持自助找回密码，请联系系统管理员重置。」；一个「知道了」按钮关闭；**不发任何请求、不查配置、不显示联系方式**
- 当用户点 Logo 旁「?」图标 → **同页** `router.push('/help')`；不 `window.open`、不新标签
- 当登录成功正常跳转 → 与本次改动无关，走原逻辑

## 补充变更（2026-10-04 第二轮，黑帽大人对照金蝶截图提）

> 背景：第一版落地后截图（小蜜蜂登录页）黑帽大人对照金蝶云星空登录页底部灰字行，发现少了几样东西，补回。**只动 `frontend/src/views/login/index.vue` 底部区域和表单校验，不动后端、不动 112 接口。**

### 新底部灰字行（参照金蝶，页面最底端、卡片外、居右或居中，11~12px 浅灰）

布局分两行（参照金蝶截图右下角）：

**第一行（链接行）：**
`用户协议 | 隐私政策 | 帮助`

**第二行（信息行）：**
`小蜜蜂报工 v{版本号} | 建议浏览器 Chrome | 清除本地缓存`

> **版本号必须真显示出来，不许留空、不许写死成 `v1.0.0`。** 取数方式：从 `frontend/package.json` 的 `version` 字段读，在 `vite.config.js` 里通过 `define` 注入（例如 `__APP_VERSION__: JSON.stringify(require('./package.json').version)`），登录页底部直接渲染 `v{__APP_VERSION__}`。改完 `package.json` 发版，底部版本号自动跟着变。现场报障截图一眼能看到版本号。

### 行为与口径（新增分叉）

- 当点击「用户协议」或「隐私政策」→ 弹 Element Plus MessageBox（标题"说明"，一个"知道了"按钮），正文就一句固定话：**"本系统为内网使用，业务数据由本厂管理员管理，具体请联系管理员。"** 两个链接弹同一句话即可，**不做正经法律文本页、不新增路由、不发请求**。
- 当点击「帮助」→ 同页 `router.push('/help')`（前序拍板 1B）。
- 当点击「清除本地缓存」→ 走 112 已实现的清缓存流程（含二次确认 MessageBox），跟原来降级方案一致；**位置从"右下角主按钮区"挪到这第二行灰字里**，仍是文字链接不是按钮。
- 当账套/工厂未选择就点「登录」→ 表单校验拦截，账套下拉下方红字提示"请先选择账套/工厂"，**不发登录请求、不打后端**；Element Plus `el-form` rules 加一条 `required` 即可。账号/密码为空沿用现有校验。
