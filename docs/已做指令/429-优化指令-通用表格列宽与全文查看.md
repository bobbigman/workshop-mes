# 429-优化指令：通用表格列宽与全文查看

> 状态：已实现待现场验证；2026-10-30。交付为前端代码及本地验证，不部署。
> 依据：用户要求把本次工单表格改善通用到项目所有表格；按419规范编写。

## 1. 现状与范围

已核实：工单页有独立列宽存储与重置；其它业务表格统一使用 Element Plus，存在弹窗、嵌套明细、复选框、固定列、输入控件和固定高度。没有后端或数据库变化。

所有现有 Element Plus 业务表格改用公共 MesTable；静态宣传对比表、AI Markdown 表格及手机卡片不引入管理表格操作。新业务表格也使用 MesTable。保留原始默认列宽，不统一套用工单的编号/时间格式。

## 2. 操作流程与分支

| 分支 | 条件 → 行为 | 不变量与验证 |
|---|---|---|
| B01 | 普通列截断 → 悬停全文；表头竖线清晰，鼠标可拖动 | 保留原有槽内容、排序/筛选/行事件；V01 |
| B02 | 拖动结束 → 自动保存；重新打开 → 恢复 | 本浏览器按工厂、账号、表格唯一标识隔离；V02 |
| B03 | 新增、隐藏、重排列 → 按稳定列标识匹配 | 不用数组位置；新列用默认宽度，操作列不拖动；V03 |
| B04 | 选择、展开、序号列及明确关闭拖动/提示的列 → 保留原行为 | 不干扰选择、展开、编辑与按钮；V04 |
| B05 | 每张表底部“恢复默认列宽” → 清除本表记录，恢复初始布局 | 不重新挂载整表，不清勾选、表单内容或排序；V05 |
| B06 | 本地存储不可读/损坏 → 提示并用默认；写失败 → 提示，当前拖动仍有效 | 不吞错，不写业务数据；V06 |
| B07 | 工单旧记录 → 公共组件兼容读取 | 保留之前调整；恢复默认同时清除本表旧记录；V07 |

## 3. 实现边界

- 公共组件透传 Element Plus 属性、事件、插槽及表格实例方法，使用原生拖动事件与列宽绑定。
- 表标识由源码显式给定，区分同页多个表、弹窗与嵌套表；列优先使用 column-key，自定义字段以字段ID标识，其余使用属性/标签等稳定信息。显式列标识不随标签重命名变化。
- 存储无网络请求，不含业务行数据；仅保存列宽，校验数值范围；不保存行选择、过滤条件或报工/工资数据。
- 公共样式仅作用于 MesTable；保留手机卡片与打印排版。表格底部重置入口随表一起显示/隐藏，固定高度仍由原始属性控制。
- 不新增模板管理、列显隐配置、跨设备同步；不改权限、业务规则、金额计算、接口与DDL。
