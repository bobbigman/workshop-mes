# 279 工单加工选项计价交互小样

状态：已做（2026-10-23）。仅交互演示，正式计价另行确认；未部署、未客户现场验收。

## 目标和边界

在项目内使用 Vue3 + Element Plus 制作可点击小样，供客户确认“基础工价 + 加工选项”的建单流程。PC 管理员工单页进入独立演示页；保留现有登录和管理员权限。不接业务 API、不读写工单、不写本地存储、不参与报工和工资；不改数据库和接口契约，不部署。

## 演示内容

- 分为“工序设置”和“工单试选”，设置修改仅在本页内存有效，可重置。
- 固定演示工序“合片”，丝印为单选：不丝印 0、1片 +0.25、2—4片（保留剪线头/对线/折叠标原文）+0.50、5—8片 +1.65，单位元/打。
- 两个基础价案例取自客户 `2026生产部加工单价表.xlsx` 的“合片”：25寸8K 5元/打；27寸以下大小片方形（含丝印）7.7元/打。
- 普通案例必须明确选一个丝印值（初始不选），未选不能确认演示。含丝印案例仍可记录丝印档位，但其加价为0，展示已包含原因；切换案例清空选择和确认结果。
- 另外提供“双层伞面叠片 +1.60元/打”复选演示跨组叠加；明确“是否适用当前规格、能否叠加待客户确认”，不能把演示组合当正式规则。
- 设置中可调整三档丝印加价和叠片加价（非负，2位小数），可设置叠片是否已包含于当前基础价；切换案例恢复各案例初始包含项，防止残留。
- 数量明确使用“打”（默认10打，正整数），仅演示本工序估算加工费，不称工资。使用整数分计算，显示基础、逐项附加、已含项目、最终单价和数量金额。
- “确认演示选择”只显示本页确认结果；任何输入变化使确认失效。刷新/离开恢复，不提供真实保存按钮。

## 待客户确认

1. 2—4片丝印整行是打包要求还是列举独立加工。
2. 表中以顿号列出的加工如何计费；无加号的0.7属于基础还是附加。
3. 含丝印价格是否适用全部丝印档位；叠片等附加项的适用条件及组合限制。
4. 正式报工单位和换算、计价精度、历史改价及重算规则。
