# 440-开发指令：产品禁用与反禁用

> 状态：**已做**（代码已落地；现场验收勾选留空）  
> 目标：【管理员】在【PC 产品定义】对产品做【禁用 / 反禁用】；禁用后不可新建工单选用，历史工单保留。  
> 后续：审核/反审核与人时痕迹见 **docs/441**。  
> 不做：工序/工艺路线禁用（另议）。

## 取舍

| 项 | 决定 |
|---|---|
| 范围 | 仅 `base_product` |
| 字段 | `status` TINYINT：1启用 0禁用（对标用户停用口径） |
| 列表默认 | 启用；过滤可选禁用/全部 |
| 建单下拉 | 默认只返回启用（`IncludeDisabled` 默认 false） |
| 删除 | 仍走引用校验硬删；禁用是软下架 |

## 契约

- `docs/02`：`base_product.status`；DbCompat `ProductForbidSchema` 幂等加列。  
- `POST /api/Product/{id}/forbid`、`/unforbid`（管理员）。  
- `GET /api/Product`：`FilterField=status`；或 `Status` / `IncludeDisabled`。

## 验收（现场）

- [ ] V01 启用列表默认不含禁用；过滤「禁用」可见  
- [ ] V02 禁用后建单下拉无该产品；接口选禁用产品被拒  
- [ ] V03 反禁用后可再建单  
- [ ] V04 已有工单引用的产品可禁用，不可无故删
