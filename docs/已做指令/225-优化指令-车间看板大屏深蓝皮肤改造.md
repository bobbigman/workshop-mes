## 行为与口径（分叉写成显式条件）

- 当用户从 `/board` 点"📺 大屏模式"→ 路由跳 `/board/screen`，页面自动开始拉数据并 10 秒轮询。
- 当 `/board/screen` 首次加载且未全屏 → 显示半透明遮罩"点击任意处进入全屏挂墙模式"，点击后调 `requestFullscreen()`；Esc 退出全屏不刷新页面。
- 当 `data.openAbnormalCount > 0` → 顶部异常 ticker 红底红字滚动（保留现有逻辑，只是改成深色适配：红底 `#FF4D4F`、字白、背景 `#2A0E14`）。
- 当无异常 → 顶部显示一条青绿色"✓ 现场运行正常"，不滚。
- 当 `dueState==='overdue'` → 数字/工单名红 `#FF4D4F`；`dueState==='warning'` → 黄 `#FFB020`；正常 → 青 `#36E0FF`。
- 当某条工单完成率 ≥100% → 进度条变绿 `#52E08A`，不再是蓝。
- 当窗口 resize → ECharts 图表 `chart.resize()`（已有逻辑保留）。

## 布局要求（给 Cursor 的硬指标）

按 1920×1080 画布铺：

```
┌─────────────────────────────────────────────────────────┐
│  ← 顶部条：左【工厂名+今日日期】 中【车间生产监控大屏】 右【时间大号】│
├─────────────────────────────────────────────────────────┤
│  异常 ticker（通栏，红/绿）                                │
├──────────┬────────────────────────────┬───────────────┤
│  左列     │        中间核心区           │   右列         │
│ 6个状态数 │  大圆环仪表盘：今日达成率%   │  交期预警 Top6 │
│ (未开始/  │  + 大号数字在制/已完成      │  (超期红/临期黄)│
│  执行中/  │                            │               │
│  已完成/  ├────────────────────────────┤               │
│  临期/超期/│  工单达成率进度条 Top8     │               │
│  异常)    │  (字号要大，进度条要粗)     │               │
│           ├────────────────────────────┤               │
│ 良品/不良  │  不良品项分布（横向条形）   │               │
│ 两个大数  │                            │               │
└──────────┴────────────────────────────┴───────────────┘
```

**字号硬指标**（1080p 下）：
- 中间达成率数字：≥120px
- 6 个状态数：≥56px
- 良品/不良大数：≥64px
- 工单进度条文字：≥20px
- 交期预警工单号：≥22px
- 其余标签：≥16px

**配色硬指标**：
- 页面背景：`#0B1E3F`（深蓝），可叠一层 `radial-gradient` 微亮中心
- 卡片背景：`rgba(20,50,100,0.4)` + 1px 边框 `rgba(54,224,255,0.3)`
- 数字主色：`#36E0FF`（青）
- 字体：`DIN Alternate, Roboto Mono, system-ui`，数字用 `tabular-nums`
- 不要阴影过重，不要花哨渐变，不要紫色/粉色
