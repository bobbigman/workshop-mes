## 行为与口径（分叉写成显式条件）

- 当仅说“帮我报工”或记不住单号 → 先查候选，不一次索要三项；已有单号工序数量则直接预览。只有一项也需用户明确选择/报数，不自动提交。
- 当本人/班组派工中有符合关键词且可报工的未完成工序 → 只列该来源；当无此类候选 → 回退全厂本人有权限的未完成工序（含未派工任务）。派工查询报错不能当空结果处理。
- 当工单已结束/取消、该工序计划已完成、部门无权限或现行预览校验不通过 → 不列入“可报工”候选；工单整体未完成不代表每道工序均可报。按最小1件只读校验筛选，实际可报数量仍以预览为准；业务拒绝计入过滤提示，技术异常继续抛出并保留上下文。
- 当用户说“第一项，50件” → 用该本人最新列表凭证及序号预览，回显完整工单和工序；当序号越界、列表过期/被替换、他人列表或对象变化 → 拒绝并重新查询，不能套用另一项。切换候选列表使旧待确认预览失效。
- 当无候选 → 提示暂无符合条件任务，可换关键词或扫码；“换一批”只在hasMore时请求下一页，页尾不绕回/假装无派工；页码和关键词改变均重新确定候选范围。
