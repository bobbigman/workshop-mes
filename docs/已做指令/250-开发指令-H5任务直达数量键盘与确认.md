# 250-开发指令：H5任务直达数量键盘与确认

> 状态：已做（前端构建、本机静态更新及只读HTTP核验通过；手机触控与真实提交待现场验收）
> 依据：用户要求按建议简化；按豆包精简指令规则先写验收，覆盖247默认语音入口。

## 方案

- 工作台、我的任务和报工页移除默认语音输入区域，不新增录音接入；保留未挂载的解析/组件便于以后评估，不再通过旧voiceQty参数自动带数。
- 保留既有个人码免密、H5登录与扫码。点真实任务时带任务ID，报工页按当前授权工单详情匹配工序；任务失效不自动换另一项。
- 良品数使用Vant大号数字键盘，点数量框打开，支持删除与完成，不要求系统输入法。不开页面自动录音、不默认填剩余数、不夹带语音确认步骤。
- 原报工表单及不良、多人/时长等复杂能力继续可用；提交/继续报工均先验证再回显工单、工序、良品及不良数量，确认后沿用原接口和幂等/上游校验。防重复点击。
- 同步PRD、当前使用说明及企微人设，不再指导工人去找键盘麦克风；不改变249首次关联规则，不改后端/表结构。
