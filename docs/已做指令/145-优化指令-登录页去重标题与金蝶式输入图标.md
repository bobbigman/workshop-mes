## 本次范围与落点

### A. `frontend/src/views/login/index.vue`

- 交付后右侧卡片从上到下应为：logo 图 →（直接接）账套下拉/账号/密码 → 登录按钮 → 忘记密码。中间不再有任何大标题或副标题。
- 删完品牌区后，`.brand-row` 的下边距适当放宽（建议 `margin: 0 0 28px` 量级），让 logo 与表单之间有呼吸感，别贴脸。

### B. `frontend/public/brand/xiaomifeng-logo.svg`

- 这是纯 `<text>` 节点（非转曲路径），可直接改字串。
- 改动点：
  1. 主标题 `<text ... letter-spacing="4">小蜜蜂</text>` → 文案改为 `小蜜蜂报工`（font-size 58、font-weight 700 保持）。
  2. viewBox 由 `0 0 620 168` 加宽到 `0 0 760 168` 量级（5 字比 3 字多约 120px，避免贴边）；`letter-spacing` 由 4 收到 2。
  3. `aria-label="小蜜蜂 轻MES"` 与 `<title>小蜜蜂 · 轻MES</title>` 同步改为 `小蜜蜂报工 · 轻MES`，别让无障碍标签跟画面脱节。
  4. 蜜蜂六边形图形（x≈16–144 那组 path/polyline）位置不动；下方"轻MES"小字（font-size 22）内容、位置不动。
  5. 登录页 `.brand-logo` 的 CSS（width:260px / max-width:100%）**不动**，svg 等比缩放即可。
- 影响面：`xiaomifeng-logo.svg` 全工程仅 `login/index.vue` 一处 `<img>` 引用；`xiaomifeng-mark.svg` 是纯蜜蜂图标、about 页在用，**别动**。

- 不改表、不改后端、不改 `docs/02`、不改任何业务规则文档。

## 行为与口径

- 当桌面宽屏打开登录页 → 右侧卡片顶部只有 logo 图一张（蜜蜂+小蜜蜂报工+轻MES），居中；下方依次是账套（若≥2个账套才出现）、账号、密码、登录按钮。
- 当窄屏（≤480px）打开 → 同样只有 logo 图，不出现"扫码报工，查看生产任务"旧窄屏副标题；卡片不破版。

- 账号框前缀图标放在输入框内部左侧，不改变现有 `size="large"`、`min-height:48px`、聚焦态、密码可见切换按钮。
