# 133-开发指令：登录后首次弹「添加到主屏幕」引导（原子步骤版）

> 依据：系统已内置完整 PWA（`frontend/public/manifest.json`、`sw.js`、`icons/icon-192/512/maskable`、`index.html` 声明齐全）。本指令只做一件事：**工人手机 H5 端进入工作台时，弹一次「如何把系统加到桌面图标」的引导**。纯前端，无后端改动。
>
> **取舍（已拍板）：挂载在 H5 工作台 `home.vue`，不挂登录页。** 原因：登录成功会立刻 `router.push('/h5/home')`，挂登录页会随路由卸载，工人看不到。
>
> 编写规约：每一步都是「当<条件>则<动作A>，否则<动作B/跳过>」，条件可判定、判断在动作之前、不满足前置判断就停下不硬改。Cursor 逐条执行，每条完成后打勾。

---

## 阶段 0｜准备引导组件 `PwaGuide.vue`

**步骤 0.1**
- 当 `frontend/src/components/PwaGuide.vue` 不存在 → 新建该文件。
- 否则 → 跳过新建，直接编辑现有内容。

**步骤 0.2｜组件内部按手机系统分支显示文案**
- 当 `navigator.userAgent` 含 `Android` → 显示安卓段文案：「右上角菜单「⋮」→ 添加到主屏幕 / 安装应用 → 桌面出现图标」，配图 `/manual/pwa-android-add.png`。
- 当 `navigator.userAgent` 含 `iPhone`/`iPad`/`iPod` → 显示苹果段文案：「点底部「分享」按钮 → 添加到主屏幕 → 桌面出现图标」，配图 `/manual/pwa-ios-add.png`。
- 当两者都不含 → 同时展示安卓段 + 苹果段（未知环境兜底）。
- 当 `navigator.userAgent` 含 `MicroMessenger`（微信内置浏览器，无论安卓/苹果）→ **额外**显示兜底句：「请先用右上角「…」→ 在浏览器打开，再按上面的步骤添加」。
- 卡片底部统一可展示 `/manual/pwa-homescreen.png`（装好后桌面图标示意）。

**步骤 0.3｜组件渲染要求**
- 当父级以 `v-if` 挂载本组件 → 显示半透明遮罩 + 居中卡片。
- 当父级不挂载 → 完全不渲染，不留占位。
- 样式用纯 CSS（H5 端，不依赖 Element Plus Dialog）。

**步骤 0.4｜按钮发射事件**
- 当点击「知道了」→ `emit('dismiss-this-time')`（本次关闭，不写永久标记）。
- 当点击「不再提示」→ `emit('dismiss-forever')`（写永久标记并关闭）。

## 阶段 1｜H5 工作台挂载与前置判断（改 `frontend/src/views/h5/home.vue`）

**步骤 1.1｜引入组件**
- 当文件 script 区尚未 `import PwaGuide` → 添加 `import PwaGuide from '@/components/PwaGuide.vue'`。
- 否则 → 跳过，不重复引入。

**步骤 1.2｜定义开关**
- 当 script 区无 `showPwaGuide` 响应式变量 → 新增 `const showPwaGuide = ref(false)`。
- 否则 → 直接复用已有变量。

**步骤 1.3｜新增判断函数 `maybeShowPwaGuide()`（前置判断，按序执行）**

以下判断按顺序逐条执行，**任一条不满足立即 `return`，不做后续动作**：

- 步骤 1.3.1：当 `Number(localStorage.getItem('role') || 0) === 2`（工人）→ 继续执行 1.3.2；否则 → `return`（非工人不弹；电脑端不会进本页，此条双保险）。
- 步骤 1.3.2：当 `window.matchMedia('(display-mode: standalone)').matches === false`（还没在桌面图标模式）→ 继续执行 1.3.3；否则 → `return`（已在桌面图标里，说明装好了，不教）。
- 步骤 1.3.3：当 `localStorage.getItem('pwaGuideDismissed') !== '1'`（没点过「不再提示」）→ 继续执行 1.3.4；否则 → `return`（永久关闭过，不再弹）。
- 步骤 1.3.4：当以上全部通过 → `showPwaGuide.value = true`（触发渲染）；否则 → 保持 `false`。

**步骤 1.4｜在 `onMounted` 调用**
- 当工作台 `onMounted` → 在现有 `load()` 之外调用 `maybeShowPwaGuide()`（可与 `load` 并行，互不影响）。
- 当 `maybeShowPwaGuide` 抛错 → 见阶段 4，不得影响任务列表加载。

**步骤 1.5｜登录页**
- 当本取舍为挂 `home.vue` → **不改** `frontend/src/views/login/index.vue`。

## 阶段 2｜模板挂载（`home.vue` 的 `<template>`）

**步骤 2.1**
- 当 `<template>` 末尾没有 `<PwaGuide>` → 在根节点 `.h5-page` 末尾加：
  `<PwaGuide v-if="showPwaGuide" @dismiss-this-time="onPwaDismissThisTime" @dismiss-forever="onPwaDismissForever" />`
- 否则 → 跳过，只改事件处理。

**步骤 2.2**
- 当 `showPwaGuide` 为 true → 组件渲染弹窗。
- 当 `showPwaGuide` 为 false → 组件不渲染，工作台外观不变。

---

## 阶段 3｜按钮收尾（`home.vue` 回调）

**步骤 3.1｜「不再提示」**
- 当收到 `dismiss-forever` 事件 → `localStorage.setItem('pwaGuideDismissed', '1')`，并把 `showPwaGuide` 置 `false`。
- 否则 → 不写标记。

**步骤 3.2｜「知道了」**
- 当收到 `dismiss-this-time` 事件 → 仅把 `showPwaGuide` 置 `false` 关闭本次，**不写** `pwaGuideDismissed`。
- 否则 → 组件保持打开。

> 意图：默认「知道了」下次进入工作台仍弹；只有明确「不再提示」才永久关闭。

## 阶段 4｜兜底与验证

**步骤 4.1｜异常兜底**
- 当 `maybeShowPwaGuide()` 执行过程中抛错（如 `matchMedia` 不可用）→ `try/catch` 捕获，`console.error('[PwaGuide] 引导渲染失败', error)`，工作台任务列表加载不受影响。
- 当无异常 → 正常渲染。

**步骤 4.2｜构建验证**
- 当 `npm run build` 失败 → 按报错定位修复，不得绕过。
- 当构建成功 → 进入验收。

## 六、风险与边界

- 纯前端；无后端、无数据库表、无接口变更；**不改登录页**。
- `localStorage` 按浏览器/设备区分；换手机或清缓存会重新弹，属正常。
- 微信内置浏览器无法可靠「添加到主屏幕」，用 MicroMessenger 检测 +「在浏览器打开」兜底。
- 本期不做「只某工厂弹」；若以后需要，在此函数加一条工厂条件即可，保持最简。
