# 141-优化指令：工资报表手机窄屏——汇总卡片化 + 明细大块默认收起

> 状态：已完成（2026-10-02）
> 一句话目标：老板拿手机浏览器开 PC 工资报表页，首屏一眼看到「谁 + 这个周期应发多少钱 + 状态」，不要像现在这样只看到一堆"明细/重算/确认/删除"按钮、人名和金额被横向滚动藏掉；139 新加的"工资明细（报表层）"大块在手机上默认收起，别抢首屏。
> 依据/拍板：2026-10-02 黑帽大人手机实测反馈（截图）：改完后工资手机端只剩明细块，原来的汇总看不到了。

## 取舍（定死）
| 项 | 定案 |
| 做 | salary/index.vue 加窄屏判断（<768px）：汇总表改卡片式；明细大块默认收起 |
| 复用 | 复用现有 list 数据和 openDetail/onRecalc/onConfirm/onDelete/onRevoke 方法，不新写逻辑 |
| 不做 | 不改后端、不改 H5 my-wage.vue（工人"我的工资"页本身好的，别动）、不改表 |
| PC | 宽屏（≥768px）完全保持现状，一行不改 |

## 已核实现状（勿重复做）
- 截图页面 = PC 路由 `/salary`（标题"工资报表"、右上角"报工端"切换），不是 H5 `my-wage.vue`。
- 现汇总表 el-table 列宽合计约 850px（人员90+周期100+应发100+状态80+时间160+操作320），手机窄屏 ~400px 横向滚动，fixed 列只剩"操作"露在外面，人名/应发合计被滚没。
- 139 在页面下方加了 `.items-section`（工资明细报表层：工序下拉+日期范围+查明细+导出明细CSV+明细表格），`load()` 里自动调 `loadItems()`，手机上也整块渲染、占首屏。
- H5 `views/h5/my-wage.vue` 有大卡片"预估合计 ¥XXX"，本身完好，本指令不碰。

## 改动点（frontend/src/views/salary/index.vue）
1. 加窄屏标志：`const isNarrow = ref(window.innerWidth < 768)`，`window.addEventListener('resize', ...)` 里更新（节流可不做，值小）。
2. **当 isNarrow=true（手机）**：
   - 隐藏原 el-table（v-if="!isNarrow" 或包一层）。
   - 新做卡片列表：v-for list，每张卡片显示：
     - 第一行：`{{ row.userName }}`（大字加粗）+ 右边状态 tag（草稿/已确认，沿用 row.status）。
     - 第二行：周期 `{{ row.periodValue }}` + 生成时间小字。
     - 第三行：应发合计大字 `¥{{ fmtMoney(row.totalAmount) }}`（用主色）。
     - 操作按钮行（沿用现有方法，按 row.status 显隐）：明细 / 重算（草稿）/ 确认（草稿）/ 删除（草稿）/ 撤回重算（已确认）。
   - `.items-section`（工资明细报表层整块）**默认 v-show="!isNarrow" 或加折叠开关**：当 isNarrow=true 时整块隐藏；若老板非要在手机上看明细，加一个小按钮"展开报表层明细"临时展开（可选，不做也合格）。
3. **当 isNarrow=false（PC 宽屏）**：上面所有窄屏卡片和折叠都不渲染，el-table 和 items-section 完全保持现状。
4. toolbar 手机上可让按钮换行（已有 flex-wrap，不用动）；批量重算按钮手机上可保留（选中逻辑在卡片里不做勾选，批量重算按钮手机上 disabled 即可，避免在卡片里塞 checkbox）——**当 isNarrow=true 时批量重算按钮 disabled 并提示"电脑端操作"**。
5. **PC layout（views/layout/index.vue）加角色分流跳转**：路由守卫或 layout onMounted 里加判断——
   - **当 isMobile=true（窄屏）且当前登录人 role=2（工人）且路径不以 /h5 开头** → 自动 `router.replace('/h5/home')`（工人拿手机误开PC后台，直接送进报工端，别让他看管理界面）。
   - **当 isMobile=true 且 role≠2（管理员/老板）** → **不强制跳**，但把右上角已有"报工端"按钮从 text 小按钮改成实心大按钮（primary 色、带手机图标），显眼指向 H5 工作台；管理员要手机看全厂汇总就留在 PC 页走第2条卡片化。
   - **当 isMobile=false（电脑宽屏）** → 上面两条都不触发，现状不动。
   - 同时 H5 `/h5/home` 工作台首页加一个不起眼的小入口"管理后台"（仅 role≠2 可见），跳回 `/order`，双向不迷路。
