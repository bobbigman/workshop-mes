# 264-手机助手聊天与问题抽屉

2026-10-20，用户确认按微信式聊天布局执行。仅调整管理员 AI 页在手机浏览器的布局，不新增 H5 路由或权限，不改接口、模型提示词与回答业务口径。电脑端保留角色入口与聊天布局。

## 实现

- 768px 及以下隐藏常驻介绍、角色工具栏和正常就绪标签；异常配置与错误提示仍显示。
- 顶栏使用“车间小助手”，将新对话、返回报工端、退出登录放入“⋯”；保留系统导航菜单。回答期间禁用新对话。
- 输入栏贴底，默认一行，最多增高四行；保留发送和停止，隐藏手机无用的快捷键提示。按可视视口高度适配键盘缩小后的空间。
- 左下角“常见问题”打开底部抽屉，复用原有五类角色和全部问题。切换角色沿用原有会话模式规则；点题关闭抽屉并发送；直接关闭不改变聊天滚动位置。
- 消息采用左右气泡，减少姓名、卡片边框和段落空白，正文保持16px。表格、证据、分页及来源继续使用原有功能。
