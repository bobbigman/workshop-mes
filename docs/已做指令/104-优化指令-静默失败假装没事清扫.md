# 104-优化指令 · 静默失败「假装没事」清扫

> 接登录页账套偶发空白排查。目标：失败要让人看见，禁止空 catch 把缺能力伪装成「本来就没有」。
> **改一条勾一条**，勾完再做下一条。

---

## 一、范围（全部改）

| ID | 位置 | 取舍（拍板） |
|---|---|---|
| A1 | 登录页 `getInstanceInfo` | 失败不挡登录；**可见提示 + 可重试**（同账套列表口径） |
| A2 | PC 布局 `getInstanceInfo` / `getLicenseStatus` | 失败 **ElMessage 提示**；不空 `.catch(()=>{})`；授权状态失败不清空已有本地缓存 |
| A3 | 关于页实例信息 | 失败 **提示**；版本仍可用构建号 |
| A4 | 登录页图片配置 `getLoginSetting` | 失败 **提示**；不把失败伪装成「无图」 |
| A5 | H5 报工候选人 | 失败 **Toast**；列表空时文案区分「加载失败」vs「无人可选」 |
| A6 | H5 作业指导书列表 | 失败 **Toast**；不静默当「无指导书」 |
| A7 | 工单列表 `?openId=` 打开详情 | 失败 **ElMessage**；列表仍保留 |
| B8 | H5 报工自定义字段 | 已有 Toast；补 **重试入口**（按钮/再次进入可再拉） |
| B9 | H5 报工成功后刷进度 | 已有 Toast；保持（不改业务） |
| B10 | AI 助手删会话等忽略 | 失败 **ElMessage**（http 已提示的可不重复，但禁止裸 `/* 忽略 */` 无反馈） |
| B11 | 建议报价·金蝶材料支路 | **保留**材料失败不挡人工；确认前端能展示 `materialWarning`（缺则补展示） |
| B12 | 授权云校验断网保留缓存 | **保留**业务；前端布局拉授权状态失败走 A2 提示即可，后端不改抛错语义 |

不做：SideMenu localStorage、DocPreview cancel、用户取消确认框、事务二次 Rollback、C 类无害项。

## 三、验收

1. 后端未启动时打开登录页：账套有加载中/重试；实例信息失败有提示，不空白装没事。
2. PC 进主界面：实例/授权接口失败有 Message，菜单仍可用。
3. H5 报工：候选人/指导书/自定义字段失败有 Toast，且能区分空数据与失败。
4. 建议报价：材料失败时页面上能看到警告文案。
5. `npm run build` 通过。

## 四、红线

- 不吞异常装成功；降级必须可见。
- 不挡登录主路径（A1）；不改 B11/B12 业务语义。
- 命名与现有 Element Plus / Vant Toast 风格一致。
