## 1. 做（范围）

### A. 前端入口（P0，本期核心）

- **PC 三个页面各加「导入」按钮**：产品定义 `product/index.vue`、工序 `operation/index.vue`、用户 `user/index.vue`。
- 交互：点「下载母版」→ 下载 xlsx → 客户填数据 → 点「上传」选文件 → 结果对话框展示「成功 N / 失败 M」+ 逐行错误列表（可复制）。错误文案中的行号必须与 Excel 行号一致（表头第 1 行，数据从第 2 行起；依赖后端 §C 真实行号）。
- 复用 `prod.js` 现有 `downloadTemplate` / `uploadImport`，**不要另写 API 方法**；blob 下载对齐 `salary` / `schedule` 写法，走 `frontend/src/api/http.js`。
- 不良品项 / 工艺路线两类**本期不做入口**（手录足够），验收后再看要不要补。

### B. 母版示例（P0）

- 每类模板第 2 行放**格式正确的占位示例**（列齐全、类型对），并在单元格批注或手册写清：关联列须填**本厂已有**部门编码 / 不良品名称 / 单位名称 / 路线编号 / 工序编码；**不承诺照抄必入库成功**（多工厂、空库无法绑死真实数据）。
- 建议占位（可按表头微调，关联列用明显占位或留空并在批注说明「可选；填了必须存在」）：
  - user：`demo001 / 13800000000 / 示例用户 / 2 / Admin123`
  - defect：`示例不良品`
  - operation：`OP-DEMO-001 / 示例工序 / （空或批注：填本厂部门编码，逗号分隔） / （空或批注：填本厂不良品名称）`
  - routing：`R-DEMO-001 / 示例路线 / （空或批注：填本厂工序编码，按顺序逗号分隔）`
  - product：`P-DEMO-001 / 示例产品 / （空或批注：本厂单位名） / （空或批注：本厂路线编号） / （空） / 1.5`
- 母版第 3 行起留空。单测用种子数据构造「可成功导入」的行，不依赖母版占位行在空库可成功。

### C. 后端：关联校验 + 写入顺序 + 行号 + 空文件（P0）

#### C1. 关联匹配不到 → 行级失败（空单元格仍可选）

- **仅当单元格非空**且拆出的 token 在本厂匹配不到时，`ThrowHelper.Biz` 行级失败；**空 = 不挂关联 / 外键 null，不报错**。
- 逗号分隔中**任一 token 无效 → 整行失败**（不允许半挂半跳过）。
- 覆盖：
  - operation：报工部门编码、不良品项名称
  - routing：工序编码
  - product：单位名称、工艺路线编号
- 不改：产品编号唯一、账号唯一、密码复杂度等既有规则。

#### C2. 禁止「失败行半截入库」（必须改写入顺序）

- 现状：`ImportOperationAsync` / `ImportRoutingAsync` 先 `SaveChanges` 父表，再解析关联。若仅在关联处 throw，外层记 Fail，**父记录已提交**。
- 要求：先解析并校验全部关联（得到部门/不良品/工序实体列表），**全部通过后再写入父表 + 关联，同一次（或同一事务）提交**。失败行不得留下孤立工序/路线。
- product：在 insert 前完成单位/路线解析；非空匹配失败则勿 `Add`/`SaveChanges`。

#### C3. Errors 行号 = Excel 真实行号

- 解析时跳过空行，但保留每行在工作表中的行号；Errors 写成 `第{excelRow}行：{原因}`，禁止再用过滤列表 `IndexOf + 2`。

#### C4. 空文件 / 全空数据行

- 无任何非空数据行时：抛业务异常或返回 Fail 语义明确的结果（不得 Success=0/Fail=0 假装成功）。文案如「没有可导入的数据行」。

#### C5. 部分成功语义（保持）

- 好行入库、坏行记 Errors，**不整批回滚**；坏行须满足 C2（无半截数据）。

### D. 自动化测试（P0）

- `backend.Tests` 新增 `ImportServiceTests`，至少覆盖：
  - 5 类各一条成功导入（测试内种子部门/单位/路线/工序后再导入）
  - 重复编号 / 重复账号 → 该行报错、其余行成功
  - operation 部门编码不存在 → 行级错误，且库中**无**该工序半截记录
  - routing 工序编码不存在 → 行级错误，且库中**无**该路线半截记录
  - product 路线编号不存在 → 行级错误，无产品入库
  - 空文件 / 全空行 → 明确失败，不静默成功
  - 数据行之间夹空行时，Errors 行号仍等于 Excel 行号
