# 报工页帮助弹窗・蓝框内文字层次补丁

> 现象：钩子副标已就位，但蓝框最底下那句 "提醒" 跟正文一样深、一样色，没层次；里面的 "待复核" 状态、"生产管理→报工复核" 路径也没染色，班组长找不到去哪操作。
> 范围：只改报工页 (/report) 弹窗蓝框里的文字样式，不动复核页、不动列表。

## 修复步骤（前置判断 → 条件执行）

### 步骤 1：提醒段整体压灰



* 前置判断：找到蓝框里 "提醒：状态「待复核」的在这只看得见…… 要处理得去左侧……" 这一句。

* 当它现在跟主句同一个 class：单独包成 `<p class="help-note">`。

* CSS：



```
.help-note { color: #909399; font-size: 13px; margin: 8px 0 0 0; line-height: 1.6; }
```

### 步骤 2：提醒段里两个关键词染蓝



* 在 `.help-note` 内部：


  * 「待复核」包成 `<span class="help-tag">待复核</span>`

  * 「生产管理 → 报工复核」包成 `<span class="help-tag">生产管理 → 报工复核</span>`

* CSS：



```
.help-tag { color: #409eff; font-weight: 600; }
```

### 步骤 3：主句里的 "补报、代报" 保持蓝



* 前置判断：看 "报工 = 记数 + 看进度：还能补报、代报。" 里这俩字。

* 当已经是蓝色加粗：保持不动。

* 当还是黑字：包 `<span class="help-tag">` 染蓝。

### 收尾自检



* 蓝框四层从上到下颜色分明：钩子深黑粗 → 副标斜灰 → 主句深字 → 提醒小灰字。

* 提醒小灰字里，"待复核" 和 "生产管理 → 报工复核" 两个词是蓝色加粗，一眼跳出来。
