## 本次范围与落点

### 已有能力（已读代码核实）
- H5 `views/h5/my-wage.vue`：已有今日/本周/本月工资预估，首页已有入口
- 后端已有 `/api/salary/mine`（预估接口）
- `salary_statement`（工资单主表：user_id/factory_id/period_type/period_value/total_amount/status）
- `salary_statement_item`（工资明细快照：unitPrice/wageCoeff/deductAmount/amount/price_type/duration_minutes/report_id；orderNo/operationName/goodQty/defectQty 通过 report_id 关联报工表取出）
- JWT鉴权中间件（从token取userId + factory_id）

### 缺口（本次要做）

#### 1. 后端新增接口（仅两个GET；仅为这两个新接口增加 role=2生产人员、role=3班组长 白名单；role=1管理员沿用现有权限，不放开整个 /api/salary）
- `GET /api/salary/my-statements`
  - 从JWT取 userId + factory_id
  - **查询条件同时限定**：user_id=本人 AND factory_id=本厂 AND status∈{1,2}
  - 不传周期参数 → 按结算周期结束日期倒序取最近一张，返回其 periodType + periodValue
  - 传 periodType + periodValue → 查指定周期；缺一或不合法 → 400"周期参数不合法"，不自动回退
  - 返回字段：`id、periodType、periodValue、grossAmount(Σ amount)、deductAmount(Σ deduct_amount)、totalAmount(读 total_amount)、status`
  - 无工资单返回空数组
- `GET /api/salary/my-statements/{id}/items`
  - **三重校验**：①JWT的userId=工资单.user_id ②JWT的factory_id=工资单.factory_id ③工资单.status∈{1,2}
  - 任一不满足 → 403"无权查看该工资单"
  - 返回明细列表（逐条，不聚合）：
    - **金额、单价、系数、计价方式、时长读 salary_statement_item 快照**（不按现价重算）
    - **orderNo、operationName、goodQty、defectQty 通过 report_id 关联 prod_report + 产品/工序表取出**（参照现有PC明细查询逻辑）
    - price_type（1计件/2计时/3固定/0未知）、duration_minutes

#### 2. H5前端改造（my-wage.vue）
- **保留**现有今日/本周/本月预估区块（不动）
- **下方新增"已确认工资单"区块**：
  - 月份/周次选择器（默认最近一个已确认周期）
  - 工资卡片三段：**计价金额**（Σ amount）、**扣款**（Σ deduct_amount）、**应发工资**（读 total_amount，大字）；不写"实发/已到账"
  - 明细列表：
    - 每条报工一行：工序名 + 工单号
    - 计件岗（price_type=1）：`良品数 件 × 单价`；wageCoeff≠1 时追加 `×系数0.8`；= 小计
    - 计时岗（price_type=2）：`X小时Y分 × 时薪`；wageCoeff≠1 时追加 `×系数0.8`；= 小计
    - 固定岗（price_type=3）：`固定X元`
    - 未知（price_type=0）：`历史记录／计价方式未记录`，金额直接显示 amount
    - 不良扣款单独一行显示
- **空状态**："暂无已确认工资记录"（不写"快去找班组长报工"，无工资单可能只是尚未结算）

## 行为与口径

- **当**工人打开"我的工资"页 → 上方保留现有预估区块，下方显示最近一个已确认工资单
- **当**工人切周期（月/周）→ 调接口查指定周期；无则空状态
- **当**工资单 status=0（草稿）→ 不返回给H5；即使工人直接拼URL查ID → 403
- **当**工人A请求工人B的工资单明细 → 403
- **当**工人A请求其他厂的工资单 → 403（factory_id不匹配）
- **当**工资单被撤回（status回0）→ 不再出现在H5列表
- **当** price_type=0 且 amount有值 → 金额照显示，但单价列显示"历史记录"
- **当** wageCoeff≠1 → 明细行显示系数，避免工人对账时"10件×2元=16元"对不上
- **当** duration_minutes < 60 → 显示"X分钟"；≥60 → 显示"X小时Y分"
