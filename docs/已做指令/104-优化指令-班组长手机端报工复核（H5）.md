## 0. 为什么做（人话）

黑湖的班组长是用**手机**复核报工的，咱们 22 号首版只做了电脑端。现在补上手机端：班组长在车间里，不用跑回电脑也能「通过 / 退回」报工。现场审、现场了，更贴近黑湖卖点。

## 1. 已有底子（别重复造轮子）

- **后端复核接口已上线、不用动**：`GET /api/Review/pending`、`POST /api/Review/{id}/approve`、`POST /api/Review/{id}/reject`、`POST /api/Review/batch-approve`。权限已管好：班组长只审本组、管理员审全厂、工人调接口会被后端 403 拦。
- **前端接口已封装好**：`frontend/src/api/review.js` 里四个函数直接用（`getPendingReviews` / `approveReview` / `rejectReview` / `batchApproveReview`）。
- **H5 页面范式现成**：`frontend/src/views/h5/my-reports.vue` 就是模板（顶部返回+标题+退出、筛选栏、卡片列表、底部 TabBar）。
- **权限/档位机制现成**：`FEATURE.ReportReview` 已在 `licenseTier.js`（企业档）；路由 `meta.feature` 会自动做档位校验。

## 2. 交付物

新增 1 个 H5 页面 `h5/review.vue` + 底部 TabBar 加「复核」入口 + 路由注册 + 文档收尾。**无后端改动。**

## 3. 原子步骤（每步都带条件判断）

### 步骤1：新增 H5 复核页 `frontend/src/views/h5/review.vue`

照抄 `my-reports.vue` 骨架：顶部返回+标题+退出、筛选栏、卡片列表、底部 TabBar。

- **列表数据**：调 `getPendingReviews({ page, pageSize, orderNo, userName, reviewStatus: 0 })`（默认只看待复核）。
- **卡片显示**：工单号、产品、工序、工人、良品/不良、报工时间、状态标签（待复核/已通过/已退回）。
- **操作按钮显隐**：
  - 当 `reviewStatus === 0` 时 → 显示【通过】和【退回】；
  - 当 `reviewStatus !== 2` 时 → 显示【退回】；
  - 否则 → 只显示状态，不显示操作按钮。
- **【通过】**：调 `approveReview(id)`，成功后弹「已通过」提示并刷新列表。
- **【退回】**：弹出填原因框（必填，1～256 字）：
  - 当原因为空 → 拦截，提示「请填写退回原因」，不发请求；
  - 当原因非空 → 调 `rejectReview(id, { reason })`，成功弹提示并刷新。
- **【批量通过】**：多选待复核卡片 → 调 `batchApproveReview({ ids })`，按返回的 `approved` 条数提示。
- **页面启动（onMounted）做角色兜底**：
  - 当当前 `role` 是 1（管理员）或 3（班组长）→ 正常加载待复核列表；
  - 当 `role` 是 2（普通工人）→ 不加载、提示无权限并 `$router.replace('/h5/tasks')`（防工人拿链接直达；后端本就 403，前端先拦体验更好）。

### 步骤2：底部导航加「复核」入口 `frontend/src/views/h5/TabBar.vue`

- 在「异常」与「帮助」之间加一个「复核」tab，图标用对勾/勾选样式。
- **显隐条件**：
  - 当 `role` ∈ {1,3} 且 `canUse(currentTier(), FEATURE.ReportReview)` 为真 → 显示；
  - 否则 → 不显示（普通工人、或非企业档，都不出现）。
- 点击 `$router.replace('/h5/review')`；`active` 高亮逻辑加 `'review'`。
- 参考现成写法：扫码 tab 用的是 `v-if="canScan"` + `computed`，照这个套路加。

### 步骤3：注册路由 `frontend/src/router/index.js`

- 加一行顶层 H5 路由：
  `{ path: '/h5/review', name: 'H5Review', component: () => import('@/views/h5/review.vue'), meta: { title: '报工复核', feature: FEATURE.ReportReview } }`
- 说明：`meta.feature = ReportReview` 让「低于企业档」自动跳回 `/h5/tasks`；role=2 的直达拦截由步骤1页面内校验兜底。

### 步骤4：文档收尾（当功能实现并通过验收后再做）
