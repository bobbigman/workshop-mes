## 2. 完整流程

入口 PC 工单 → 勾选【报工中】→【挂起】→ 进【已挂起】→ 需要时【恢复生产】回【报工中】可继续报工。  
作废仍可用：挂起单可【作废】；【恢复】（作废专用）与【恢复生产】（挂起专用）分开。

## 4. 数据与接口契约

- `prod_work_order.status`：补充 **6=已挂起**（无 DDL 变更）。同步 `docs/开发手册和方案/02-数据字典.md`。
- `POST` 既有工单流转接口 `action`：新增 `hang` / `unhang`（与 `start|finish|withdraw|cancel|restore` 同路径）。
- `GET` 状态计数：增加 `suspended`；`all` 仍 = 已审核+报工中+已结束（不含 3/4/5/6）。
- 列表：`excludeCancelled` 同时排除 3 与 6（及既有 4/5）；按 `status=6` 查已挂起页签。
