# 258-开发指令：PC助手提问面板与简短回答

> 状态：已做（2026-10-20）；自动检查及前端构建通过，浏览器外观和真实模型问答未验收
> 依据：用户确认按四点分析执行；不部署、不改数据库、权限或工具写入范围。

## 实现范围

1. 四个角色改为带展开箭头的按钮；点击当前角色切换面板显隐，点击其他角色切换角色并展开；两列问题面板、小屏一列，点题直接发送并收起。mode映射和清空对话规则沿用257。
2. 输入区内右下角只保留一个主按钮：空闲“发送”、生成时“停止生成”；停止按钮不使用loading导致不可点击。Ctrl+Enter兼容。收窄内容宽度，移除“为你整理”。
3. 隐藏操作文档来源卡片及正文技术引用编号，后台保留原始回答、引用校验和来源证据；工单数据、查询时间、分页、报工证据及失败提示保留。工艺资料来源不在隐藏范围。
4. 简单操作默认一句结论、最多三步和一句必要提醒，目标150字内；用户要求详细/复杂核对时按需展开。不强行重点标题、不附无关管理流程/推送条件，不截断重要失败或风险提示。资料检索排除与当前问题无关的销售应答资料，排除规则不应在兜底时失效。
5. 隐藏来源后，模型失败的客服兜底不得再要求用户看来源卡片，明确回答生成失败，不冒充已生成答案。

- [ ] 操作检索不夹销售五步法；销售问题仍可命中销售资料，排除文档不兜底混入。
- [ ] 前端专项检查、后端相关检查及构建记录据实填写，真实模型回答与浏览器外观未测不标通过。
