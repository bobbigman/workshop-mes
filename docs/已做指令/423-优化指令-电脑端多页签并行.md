# 423-优化指令：电脑端多页签并行

> 状态：已做（代码已落地；未现场浏览器点验收，勾选保持空白）  
> 一句话目标：电脑端点菜单开新页时，旧页留在页签栏，可来回切换；工单与工序价目表可同时挂着。

## 做 / 不做

| 项 | 决定 |
|---|---|
| 范围 | 仅 PC 后台外壳（`layout`，`!isMobile`） |
| 手机 / H5 / 看板大屏 | 不做多页签，保持现有单页 |
| 开页 | 点侧栏或站内 `router.push` 到带 `meta.title` 的子路由 → 加入页签；已存在则激活 |
| 关页 | 页签 × 关闭；关当前则切到相邻（优先右侧，否则左侧）；只剩 1 个时不可关 |
| 状态 | `keep-alive`（max 16）；关掉的页下次再开重新进（epoch 换 key） |
| 持久化 | 不做 localStorage；刷新 / 退出登录清空 |
| 后端 / 表 / 权限 | 不改 |

## 落点

- `frontend/src/composables/usePcTabs.js`
- `frontend/src/components/PcTabs.vue`
- `frontend/src/views/layout/index.vue`（页签条 + `keep-alive`）
- 退出登录时 `clearPcTabs()`

## 验收

- [ ] PC：工单 → 工序价目表 → 顶栏两个页签，点工单页签仍在原列表态（未整页重载）
- [ ] 关闭价目表页签后只剩工单；只剩一个时关不掉
- [ ] 窄屏 / 手机布局无页签条
- [ ] 退出登录后再进，页签为空（随当前路由重新开）

不改 H5、不改接口、不做「固定首页不可关」、不做右键菜单（关闭其他等）。
