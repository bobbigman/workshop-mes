## 行为与口径（分叉写成显式条件）

- 当管理员在用户档案勾选多个部门并保存 → 部门列表对应部门的"成员"列同步出现该用户；反向在部门弹窗取消某人 → 用户档案里该部门也同步取消。两边写同一张关联表，不出现两边数据不一致。
- 当该用户尝试扫码报工 → 后端判断：当前用户所属部门集合 ∩ 当前工序的报工权限部门集合 ≠ 空 → 放行；= 空 → 拒绝并提示"您所在部门无此工序报工权限"。
- 当用户一个部门都没勾 → 该用户**不能做任何工序报工**；但管理员/角色型账号（纯后台管理不扫码的）不受此限制，需 Cursor 在代码里确认角色判定不受影响。
- 当Excel导入某行"部门"列填了不存在的部门编码 → 整行报错并在导入结果里列出"第X行：部门编码XXX不存在"，**不静默跳过、不创建新部门**。
- 当Excel导入同一账号出现多行 → 以后出现的行为准，部门集合取所有行的并集；账号冲突时提示。
- 当导入手机号/账号已存在 → 更新该用户部门集合为Excel里的值（覆盖式），不要重复建行。
