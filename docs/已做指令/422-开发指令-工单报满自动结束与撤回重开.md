## 2. 流程

1. 报工/改数/退回 → Recalc：无有效报工→未开始并清 reopened；有报工→执行中；全道报满且 **未** reopened→已结束；全道报满且 reopened→保持执行中；未报满→清 reopened。  
2. 【撤回】已结束→执行中：`reopened=1`。执行中→未开始：`reopened=0`。  
3. 【结束】→已结束，`reopened=0`。取消/恢复：清 `reopened`。  
4. 列表/详情：`status=1` 且 `reopened=0` 且进度已满 → 静默写成已结束（纠脏数据）。`reopened=1` 时展示「已重新打开」。
