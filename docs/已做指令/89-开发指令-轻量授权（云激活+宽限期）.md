## 一、目标与原则

- **防"白用 + 复用"**，不是防黑客破解。本地部署下彻底防破解不可能，不做。
- 授权校验**只发非业务标识**（`factory_code`、档位、时间戳），**不泄露**工单/报工/工资等业务数据。
- **不得误伤断网现场**：宽限期兜住短期断网；超期**降为 trial**，不锁报工/看板。
- 技术栈不可变更：.NET 8 + EF Core + SQL Server；命名空间 `ahu.MicrosoftMes`（授权小 API 可用独立命名空间 `ahu.MicrosoftMes.LicenseServer`）。

---

## 二、架构与机制

**授权服务端（`license-server/`）**：轻量 API，JSON 文件登记 `factory_code` + `license_tier` + `expires_at_utc`。客户机联网校验，返回状态与服务端 UTC。

**客户端（WorkshopMes）**：登录时联网校验一次 → 写回 `sys_factory` 缓存列 → 断网用宽限期 → 超期有效档按 `trial`。

**配置** `LicenseCloud`（`appsettings`，增量包勿覆盖）：
- `Enabled`：默认 `false`（开发/未开通客户不受影响，行为=仅本地 `license_tier`）
- `BaseUrl` / `GraceDays`（默认 7）/ `TimeoutSeconds` / `SharedSecret`（可选，请求头 `X-License-Key`）

**宽限期**：断网且 `effectiveNow - last_license_ok_utc <= GraceDays`，且未过 `license_expires_at_utc` → 仍用库内 `license_tier`。

**超期 / 宽限用尽**：`GetTier` 返回的**有效档**=`trial`（**不改**库内 `license_tier`，续费校验成功后自动恢复）。报工/看板等 88 三档共享能力仍可用。

**防改本地时（轻量）**：
- 信任云端返回的 `serverUtc` / `expiresAtUtc` 写入库；
- 每次校验更新 `last_license_seen_utc`；判定时用 `max(UtcNow, last_seen)` 抑制拨回时钟；
- 拨回超过容差（5 分钟）→ 视为异常，有效档 `trial`。

**外部键**：云端用 `factory_code`（稳定、跨库可读）；不传内部 `factory_id`、不传业务数据。

---

## 三、硬约束（红线）

- 只发非业务标识；失败也不得把业务数据带到授权服务。
- 有效档由后端 `ILicenseTierService.GetTierAsync` 统一算，前端只展示。
- 超期不得锁死报工/看板；降 `trial` 而非停摆。
- `LicenseCloud:Enabled=false` 时不做云校验（兼容现网/开发）。
- 异常统一 `ThrowHelper`；改表先更新 `docs/02`；三条硬规则不回归。

## 四、数据（`docs/02`）

`sys_factory` 增量列：

| 列 | 类型 | 说明 |
|---|---|---|
| `license_expires_at_utc` | `DATETIME2 NULL` | 云端有效期（UTC） |
| `last_license_ok_utc` | `DATETIME2 NULL` | 最近一次**成功**云校验时的服务端 UTC |
| `last_license_seen_utc` | `DATETIME2 NULL` | 最近一次发起校验时的本地 UTC（防拨回） |

`license_tier` 仍表示合同档；有效档运行时计算。

## 五、原子步骤

### 步骤 1 · 授权服务端（`license-server/`）
- `POST /api/license/check`：入参 `{ factoryCode, requestedAtUtc? }`；出参 `{ factoryCode, licenseTier, expiresAtUtc, serverUtc, status }`（`valid`/`expired`/`unknown`）。
- 登记数据：同目录 `licenses.json`（可热读）。
- **当** `SharedSecret` 非空 → 校验头 `X-License-Key`；
- **当** 未登记该 `factoryCode` → `status=unknown`。
- 验收：按 factoryCode 返回档位 + 有效期状态。

### 步骤 2 · 客户端联网校验 + 缓存宽限期
- `ILicenseCloudService`：登录成功后调用；成功写三列 + 可选回写 `license_tier`（与云一致）；失败只更新 `last_license_seen_utc`，不抛死登录。
- **当** `Enabled=false` → 跳过云，有效档=`license_tier`；
- **当** 联网成功 → 刷新缓存；
- **当** 断网/不可达 → 宽限期判定；
- **当** 宽限用尽或已过 `expires` → 有效档 `trial`。
- 验收：断网 7 天内照用；超 7 天变 trial。

### 步骤 3 · 超期策略
- `LicenseTierService.GetTierAsync` 走有效档；88 的 `EnsureFeature`/前端显隐自动生效。
- **当** 需提示续费 → 文案「授权已过期或无法校验，高级功能暂不可用，请联系部署方续费」；
- **当** 客户续费 → 只改云端 `licenses.json`，客户端下次校验恢复。
- 验收：超期后报工/看板可用，工资等企业档入口按 trial 隐藏；续费恢复。

### 步骤 4 · 防本地改时
- 见第二节；验收：拨回本地时间不延长宽限/有效期。

### 步骤 5 · 回归 + 文档
- `GET /api/license/status`（需登录）：返回合同档、有效档、到期、状态（`disabled`/`valid`/`grace`/`expired`）、提示语；管理员顶栏提示一行。
- 同步 `docs/02`、`docs/01`/`03` 各补一句；`docs/30` **当**有合适小节再补一句，无则跳过。
- 验收：`dotnet build` 主站 + license-server 通过。
