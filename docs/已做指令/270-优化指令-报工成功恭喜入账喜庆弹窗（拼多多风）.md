## 行为与口径

- 当 `w != null && w > 0` → 弹出奶白底弹窗：金币图（coins-stack.png，90×90px）上下浮动 + "恭喜入账" + 金色粗字"+¥{w.toFixed(2)}" + "开心收下"按钮；1.8 秒自动关。
- 当 `w == null`（未配工价）→ 走原 `showSuccessToast`，文案同 268 的"未配工价"分支，**不弹喜庆窗**。
- 当 `w === 0`（计时未出额/固定工资分摊为 0）→ 走原 Toast，不弹。
- 当用户在弹窗自动消失前点"开心收下"或弹窗任意处 → 立即关窗，继续走原 `clearQty → loadTodaySummary → focus goodInput` 流程。
- 弹窗期间不阻塞后续 `reloadDetail`（进度刷新），动画与数据刷新并行。
- 金额永远两位小数，前缀 `+¥`；不写"元"字，不写"计件"。

## 止步线

- 不做金币雨/粒子特效（过度动画 PDA 会卡）。
- 不做音效（车间嘈杂+多设备同步播放扰民；要做另立指令）。

- 不改 269 的提交前预览弹窗。
- 不引外部 CDN 字体/图片/Lottie。
