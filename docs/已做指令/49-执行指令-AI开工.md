## 5. 实现红线（违反即返工）

- 命名空间 `ahu.MicrosoftMes`；SQL Server 语法（`IDENTITY`/`NVARCHAR`/`DATETIME2 DEFAULT SYSDATETIME()`）；返回 `{ code, msg, data }`。
- 异常用 `ThrowHelper`，带「位置 + 在做什么」；**禁止空 catch / 静默吞异常 / 用默认值假装成功**。文件读不到、解析失败，必须抛出带文件名的错误，不得返回空串装成功。
- 表结构先改 `docs/02`，再改实体/DbCompat。
- **`relative_path` 只活在后端内部，绝不进出参**——出参只给 `file_name` + `content`（文字），这是「扣子读不到路径」的落地保证。
- `query_production_guide` 只读不写；`DemoSkipAuth=true` 时免授权（与 `query_work_order` 同写法）。
- 产品编号唯一、报工权限=部门、删除倒序——本功能不破坏；删除产品/工序前必须能查出并阻断「已被知识库文件引用」。
- 不做向量库、不做 OCR、不做内嵌大模型、不做上传页面。
