# 249-开发指令：统一H5免密入口与首次身份关联

> 状态：已做（代码、136项检查、本机更新及只读工具核验完成；管理员实际关联与企微发布待用户现场执行）
> 依据：用户同意“已有个人码/登录直接使用，首次由管理员关联；不凭姓名加一句确认新发登录权限”；按豆包精简指令规则先改契约再编码。覆盖215/248中仅凭姓名或手机号发个人免密链接的旧口径。

## 方案与分支（已定）

- 已有本人个人码或免密链接：照旧使用，不新增密码/验证码。已有H5登录可直接打开普通报工首页；普通入口不自带他人登录凭证。
- 机器人新获取本人专属免密链接：复用当前MCP入口工厂、可信平台X-Mcp-Session-Id、管理员VerifiedUsers核验映射、有效WxBind员工三者一致；仅手机号自绑、聊天姓名/手机号/账号或“是本人”均不授予权限。身份参数保留兼容但仅可核对本人，不用于选人。
- 缺少稳定平台身份或首次未关联：返回明确状态和不含凭证的H5首页，告知已有登录可直接用，或扫描管理员提供的本人个人码。需要首次关联请管理员核验，不能转成新一轮网页登录+8位码，也不让用户发密码。
- 管理员沿用现有用户管理发个人码；企微平台能提供真实稳定身份时，按已有WxBind加VerifiedUsers流程确认一次，后续自动认人。本次不造新的关联UI、不将协议session当用户身份、不伪称临时域名已能传userid。
- 仅原MCP入口厂范围，不新增跨厂免密。原245/246聊天直接写入授权仍独立，不能拿H5免密链路跳过其核验。
- 不改表、原个人码登录/有效期/可撤销方式和报工规则不变。HTTPS链接仅取配置，不接受模型填域名，不回显他人资料。
