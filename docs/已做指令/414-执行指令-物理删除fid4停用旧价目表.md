3. 工资 `salary_statement_item.price_list_id` 并非唯一引用。工单 `prod_work_order_operation.processing_price` 的 `attributeEvidence.priceListId`、报工 `prod_report.price_snapshot` 的 `PriceListId` 及嵌套计价依据也须检查。脚本递归扫描 JSON 的 `priceListId` 键，兼容大小写；任意引用均阻断，不修改快照。

5. 所有检查与删除在同一 Serializable 事务内执行，共用现有同厂价目表应用锁；删除条件包含厂别、已核实ID及停用状态。任何异常或行数不为8自动回滚，不再依赖人工看完行数后决定是否提交。
