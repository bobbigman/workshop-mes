## 5. 实现红线（违反即返工）

- 命名空间 `ahu.MicrosoftMes`；SQL Server；返回 `{ code, msg, data }`。
- 异常用 `ThrowHelper.Biz`，带「位置 + 在做什么」；SQL 错带 SQL；**禁止空 catch / 静默吞 / 默认值假装成功**。
- 产品编号唯一、工序报工权限=部门、删除倒序——本功能不破坏；工价/工资仅管理员。
- **禁止**用 `base_product.price` 当工价。
- **禁止**已结算报工仍可 `UpdateAsync`。
- **禁止**确认时仍存在未匹配规则却放行。
- 改表必须先改 `docs/02`，再改实体/DbCompat（本项目不走 EF Migration，走 DbCompat 幂等）。
- 金额一律 `DECIMAL` + `HasPrecision`，禁止 float。
