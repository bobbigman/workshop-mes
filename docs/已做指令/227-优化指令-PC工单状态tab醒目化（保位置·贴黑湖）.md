# 227-优化指令：PC 工单状态 tab 醒目化（保位置·贴黑湖）

> 状态：已做（2026-10-12）
> 性质：内部试用（现场真实数据、真实权限在用）
> 目标：让【PC 端管理员】进工单页一眼认出顶部的【全部/未开始/执行中/已结束/已取消】是可点击的切换条，不再被当成统计数字；能随手切出已完工/全部工单。
> 依据/拍板：黑帽大人 2026-10-12 拍板 **A 方案——保位置 + 做醒目（贴黑湖）**；黑湖官方 0217 改版（xiaogongdan.net/72.html）实锤：状态 tab 位于搜索/筛选条**下方**，四个 tab 带数量角标、当前项高亮。

## 行为与口径

- 当用户进 PC 工单页 → 过滤条下方显示一排胶囊 tab：全部 / 未开始 / 执行中 / 已结束 / 已取消，各带数量角标；当前选中项主色填充白字，其余白底描边灰字。
- 当用户点任一 tab → 列表切到对应状态，沿用现状 load 逻辑；默认仍落"执行中"（statusTab 初值 `'1'` 不变）。
- 当某状态数量为 0 → 该 tab 仍显示"0"且可点（对齐黑湖四 tab 常驻，不隐藏）。
- 当用户点"全部" → 维持现状（不含已取消，与 counts.all 口径一致）；点"已取消"→ 现状逻辑照旧。
- 手机端 /h5/orders → 本期零改动，仅核对样式一致性。

## 止步线
