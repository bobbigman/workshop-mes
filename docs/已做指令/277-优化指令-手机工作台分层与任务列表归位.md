## 页面结构（已定）

1. 顶栏保留厂名、工作台、当前用户和退出；本次不新增个人中心。
2. 扫码报工仍为蓝底白字主按钮，沿用授权档控制。
3. 用一个可点击的“我的任务”摘要入口替代全部任务卡片，跳 `/h5/tasks`。展示“已派任务 N 项 · 查看全部”，不展示工单、产品、剩余量等详情。
4. 常用功能统一两列：工单（原视角允许时）、我的工资（有授权时）、上报异常、帮助、更多功能、管理操作（仅管理员/班组长）。不保留首页重复的“我的报工”和“报工复核”按钮，使用固定底栏。
5. 管理操作采用Vant底部操作菜单：管理员可选代报工、一键补报未完工序、补报开工记录、管理后台；班组长只有代报工、管理后台。保留原有目的路由与后端校验。菜单可取消，点击只导航、不提交业务数据。
6. 今日良品和预计计件收入摘要放在常用功能之后，保留原有金额口径、权限、加载/失败重试，不改变工资计算。
7. 底栏沿用工作台、任务、我的报工；管理员/班组长且有复核授权才显示复核，不修改底栏。

## 任务数量与失败分支

- 复用 `GET /Assign/my-tasks`，数量为当前接口返回列表长度（个人与本班组派工的既有去重集合）。接口包含已报满/结束的历史项，因此明确叫“已派任务”，不能叫“待办”或“待报工”。本次不擅自按剩余量过滤，也不改任务页口径。
- 加载中显示加载提示，不显示0；失败显示失败及重试，仍可点击“查看任务”进入任务页；成功空集合显示“暂无派给我或本班组的任务”。
- 视角配置加载完成前/失败时隐藏工单入口，保留失败重试；仅任务视角不能因整理界面而新增全车间入口。
- 生产人员没有管理操作入口；班组长不获得两种管理员补报入口。工序报工权限依旧按部门执行。
