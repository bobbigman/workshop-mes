# 248-开发指令：企微优先免密链接与扫码进入H5报工

> 状态：已做（本机更新与工具说明核验完成，企微人设发布/刷新由用户完成）
> 依据：用户要求继续完善，补充扫码登录报工；按豆包精简指令规则先明确分支再落地。

## 行为约定

- 默认“帮我报工/语音报工”引导H5：可点击本人专属免密链接，也可扫描管理员发给本人的个人登录码。扫码登录后再选任务或扫工单码，不能把工单码说成本人登录码。
- 用户已有本人个人码/免密入口时直接说明用法，不强制索要手机号，不先走report-authorize网页登录和8位码。
- 需要生成链接时才用既有get_report_link_by_identity，在其原钥匙工厂范围准确查找；未命中或重复按实际原因提示，不借聊天授权接口跨厂取他人免密码。不宣称新增跨厂免密能力。
- 链接仅使用工具当次真实结果，失败不编造、不复用历史链接，不宣称已提交。没有个人码时请管理员提供；机器人没有生成二维码图片能力，不假称已发送图片。
- 进入H5后可用键盘语音填入任务/数量，网页按钮依浏览器实际支持；用户核对确认才提交，不说企微聊天语音已经打通。免密会话/个人码失效按原登录规则处理。
- 只有用户明确坚持在聊天中直接完成（或已有正在确认的聊天预览），才使用原身份核验、候选、预览与确认；不把免密H5凭证当聊天写入授权，不打断待确认记录重新开一笔。
