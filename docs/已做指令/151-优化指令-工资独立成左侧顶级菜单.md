# 151-优化指令：工资从"报表"组拆出，独立成左侧顶级菜单

> 状态：已做（2026-10-09）
> 性质：内部试用
> 目标：让会计/厂长打开系统，工资能从左侧一级菜单直接点到，不用先展开"报表"再找。
> 依据/拍板：2026-10-09 黑帽大人指示"把工资弄成单独的一个模块"；现状工资两项（`/salary`、`/salary-sku`）埋在"报表"折叠组里（`SideMenu.vue` 43-44 行），会计天天用却藏得深。

## 本次范围与落点

- 只改一个文件：`frontend/src/views/layout/SideMenu.vue`。
- 具体动作：
  1. 在 `report` 那个 `<el-sub-menu>` **前面**，新增一个 `<el-sub-menu index="salary" v-if="role === 1 && canWage">`，标题"工资"，里面放原来那两项：
     - `<el-menu-item index="/salary">工资报表</el-menu-item>`
     - `<el-menu-item index="/salary-sku">工资色码汇总</el-menu-item>`
  2. 从原 `report` 组里删掉这两行（避免重复出现）。
  3. 把 `ALL_GROUPS` 数组加上 `'salary'`，否则老用户 localStorage 里缓存的 openedGroups 会把新组过滤掉，导致工资组默认不展开。
  4. `report` 组剩下的项（生产报表/不良品报表/色码汇总/建议报价/排产评分/车间看板）顺序不动。
- 不改：`router/index.js`、`salary/index.vue`、`salary-sku/index.vue`、后端、权限逻辑。
- 文档：不动 docs/02、不动 PRD。
- 轻重：单文件、十几行改动，纯前端导航重组。

## 行为与口径

- 当管理员（role=1）+ 计件工资档（canWage=true）登录 → 左侧菜单看到独立"工资"组，展开即见两项；"报表"组里不再出现这两项。
- 当非管理员（role=2/3）或未买计件工资档 → 整个"工资"组不渲染，和现状一致（原来就看不见这两项）。
- 当用户原本把"报表"组折叠了 → 新的"工资"组按 ALL_GROUPS 默认展开（老用户刷新后看到工资组展开，可手动折叠，localStorage 正常记忆）。
- 当用户直接访问老地址 `https://.../#/salary` → 正常进入工资报表页，左侧"工资"组高亮展开，不报错。
