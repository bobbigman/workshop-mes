# 优化指令：工单打印模板（轻量对标黑湖 frame_0327s～0342s）

> 状态：已实现  
> 依据：截图 `截图/frame_0327s.jpg`～`frame_0342s.jpg`；PRD §4.10；`docs/03`/`04`/`05`  
> 目标：电脑端能打出**带真实二维码**的流转标签；可切换母版尺寸与二维码内容类型  
> 原则：**能实现，但砍掉黑湖可视化拖拽设计器与 Excel 模板**；用固定 HTML 母版 + 配置项落地

---

## 0. 可行性结论

| 问题 | 结论 |
|------|------|
| 当前能否实现？ | **能**。技术栈已具备：Vue3 + 浏览器打印 + 前端二维码库；工单详情/产品/数量/工序已有接口 |
| PRD 是否要求？ | **是**。§4.10「母版选择（如 80×60）、组件配置（二维码）」；M2 清单未勾完 |
| 与黑湖 1:1？ | **不做 1:1**。黑湖有「打印模板」可视化编辑、字段拖拽、Excel 模板打印——工作量大且非车间刚需 |
| 推荐落地形态 | **固定 2 套标签母版（30×40 / 80×60）+ 配置项（二维码内容、显示字段开关）+ 工单行「打印」预览打印** |

### 0.1 截图能力拆解 → 本期取舍

| # | 黑湖（截图） | 本期 | 理由 |
|---|-------------|------|------|
| 1 | 顶栏「打印模板」入口 | **做**（简化：工单页工具栏「打印设置」） | 对应用户演示路径 |
| 2 | 编辑打印模板弹窗 | **做简化版**（选母版 + 二维码类型 + 勾选字段） | 不做画布拖拽 |
| 3 | 内置 30×40 / 80×60 工单二维码 | **做** 两套固定 HTML/CSS | 对齐标注「选 80×60」 |
| 4 | 二维码取值：工单号 / 工单外链 | **做** 两种 | 对齐 docs/05 方案 A/B |
| 5 | 预览区标签效果 | **做**（打印弹窗即预览） | 必须看得见码 |
| 6 | Excel 模板打印 | **不做** | 超范围 |
| 7 | 任意字段拖拽排版、多自定义模板 CRUD | **不做** | 维护成本高；二期再议 |
| 8 | 改完模板后「重新打印」 | **做**（配置存工厂级，下次打印即生效） | 对齐 frame_0342 |

### 0.2 技术可行性（无阻塞）

| 依赖 | 方案 | 风险 |
|------|------|------|
| 二维码图形 | 前端 `qrcode`（或 `qrcode.vue`）根据字符串生成 canvas/img | 低 |
| 标签尺寸 | `@media print` + mm 单位 CSS；用户选系统打印机/标签纸 | 中（打印机驱动各异，验收用 PDF/浏览器打印预览） |
| 外链 URL | `window.location.origin + '/#/h5/report?order=' + orderNo`；可配置 `VITE_PUBLIC_BASE` 或设置项「外网/内网基址」 | 中（部署 IP 变更需改配置） |
| 工单数据 | 已有 `GET /api/WorkOrder/{id}`（含 tasks） | 无 |
| 持久化配置 | 新增表 `sys_print_template`（工厂 1 条当前选用配置）或 JSON 存在 `appsettings`/前端 localStorage | 推荐 **DB 工厂级**，多电脑一致 |

**结论：无硬阻塞；可开工。**

## 1. 自主拍板

| 项 | 决定 |
|----|------|
| 配置粒度 | **每工厂一条「当前打印配置」**（非黑湖多模板自由创建列表） |
| 母版 | 枚举：`Label30x40` / `Label80x60`（默认 80×60） |
| 二维码内容类型 | `OrderNo`（默认，PDA） / `ReportUrl`（手机扫码跳 H5 报工） |
| ReportUrl 基址 | 配置项 `baseUrl`（如 `http://192.168.1.100:5173`）；空则用当前浏览器 `origin` |
| 标签字段（可勾选） | 工单号（必显）、产品编号、产品名称、计划数量、工序路线（名称用「→」拼接）、备注（本期无备注字段则隐藏开关） |
| 打印入口 | 工单列表「打印」→ 预览弹窗 →「打印」调用 `window.print()`（只打标签区域） |
| 设置入口 | 工单页工具栏「打印设置」→ 改母版/二维码类型/字段 → 保存 |
| 批量打印 | **本期不做**（可二期：勾选多行连打） |
| 后端生成图片 | **不做**；二维码纯前端生成 |
| Role | 仅管理员/可进 PC 的角色用打印设置；role=2 无 PC 打印需求 |

## 2. 数据（DDL，SQL Server）

> 改前同步 `docs/02-数据字典.md`。

```sql
CREATE TABLE sys_print_setting (
    id              BIGINT IDENTITY(1,1) NOT NULL CONSTRAINT PK_sys_print_setting PRIMARY KEY,
    factory_id      BIGINT NOT NULL,
    label_size      NVARCHAR(32) NOT NULL CONSTRAINT DF_sys_print_setting_size DEFAULT N'Label80x60', -- Label30x40 | Label80x60
    qr_mode         NVARCHAR(32) NOT NULL CONSTRAINT DF_sys_print_setting_qr DEFAULT N'OrderNo',     -- OrderNo | ReportUrl
    base_url        NVARCHAR(256) NULL,   -- ReportUrl 时的前端基址
    show_product_code BIT NOT NULL CONSTRAINT DF_sys_print_setting_pc DEFAULT 1,
    show_product_name BIT NOT NULL CONSTRAINT DF_sys_print_setting_pn DEFAULT 1,
    show_qty          BIT NOT NULL CONSTRAINT DF_sys_print_setting_qty DEFAULT 1,
    show_ops          BIT NOT NULL CONSTRAINT DF_sys_print_setting_ops DEFAULT 1,
    updated_at      DATETIME2 NOT NULL CONSTRAINT DF_sys_print_setting_ua DEFAULT SYSDATETIME(),
    CONSTRAINT UQ_sys_print_setting_factory UNIQUE (factory_id)
);
```

`DbCompat`：若不存在则 CREATE（与现有兼容策略一致）。

## 3. 后端 API

```
GET  /api/PrintSetting          → 当前工厂配置（无则返回默认）
PUT  /api/PrintSetting          → 保存（管理员）
GET  /api/WorkOrder/{id}/print  → 打印所需快照（可选；也可用现有 GetById + 前端拼）
```

### 3.1 PrintSetting DTO

```json
{
  "labelSize": "Label80x60",
  "qrMode": "OrderNo",
  "baseUrl": "http://192.168.1.100:5173",
  "showProductCode": true,
  "showProductName": true,
  "showQty": true,
  "showOps": true
}
```

### 3.2 打印快照（若单独接口）

返回：`orderNo, productCode, productName, qty, ops: string[]`（按 seq）。

也可前端 `getOrder(id)` 自拼，**拍板：不新增 print 专用接口，复用详情**，减少接口。

### 3.3 现有 `/qr`

继续返回工单号字符串；打印页按 `qrMode` 决定最终编码内容（OrderNo 直接用；ReportUrl = baseUrl + `/#/h5/report?order=` + orderNo）。

## 4. 前端

### 4.1 依赖

```bash
cd frontend && npm i qrcode
```

（或项目已有同类库则复用。）

### 4.2 打印设置弹窗（工单页）

- 母版：单选 30×40 / 80×60  
- 二维码：单选 工单号 / 报工页链接（外链）  
- 基址：输入框（仅 ReportUrl 时显示）  
- 字段勾选：产品编号/名称/数量/工序  
- 保存 → `PUT /api/PrintSetting`

### 4.3 打印预览弹窗（替换现「仅文字工单号」）

布局示例（80×60）：

```
┌─────────────────────────────────────┐
│ 工单号  DEMO001                      │
│ 产品编号 xxx   产品名称 回锅肉        │  ┌────┐
│ 计划数量 10                          │  │ QR │
│ 工序 切菜 → 炒制                     │  └────┘
└─────────────────────────────────────┘
```

- 打开时：拉详情 + 拉打印设置 → 生成 QR DataURL  
- 「打印」：`@media print` 隐藏壳子，只输出 `.print-sheet`  
- 尺寸 class：`.label-80x60 { width:80mm; height:60mm }` / `.label-30x40 { width:30mm; height:40mm }`
