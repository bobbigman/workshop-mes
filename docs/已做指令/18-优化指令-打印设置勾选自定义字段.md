# 优化指令：打印设置勾选工单自定义字段

> 状态：已实现  
> 依据：工单可录桌号/辣度等自定义字段，打印设置原先仅硬编码四项，标签打不出扩展信息  
> 原则：动态勾选 fieldId，不做拖拽设计器

---

## 1. 目标

打印设置「显示字段」中，列出当前工厂 `work_order` 自定义字段（如桌号、辣度），可勾选；打印流转卡时按勾选输出「字段名：值」；无值显示「—」（仍占行，避免勾了像没生效）。

## 2. 取舍

| 项 | 决定 |
|----|------|
| 存储 | `sys_print_setting.show_custom_field_ids`（NVARCHAR，JSON 数组如 `[1,2]`） |
| 默认 | 空数组（不挤小标签；用户按需勾） |
| 设计器 / 拖拽排版 | **不做** |
| 产品/工序自定义字段 | **本期不做**（仅工单） |

## 3. DDL（SQL Server）

```sql
IF NOT EXISTS (
  SELECT 1 FROM sys.columns
  WHERE object_id = OBJECT_ID(N'sys_print_setting') AND name = N'show_custom_field_ids'
)
ALTER TABLE sys_print_setting ADD show_custom_field_ids NVARCHAR(512) NULL;
```

同步 `docs/02-数据字典.md`；`DbCompat` 幂等补列。

## 4. API

`GET/PUT /api/PrintSetting` 增加：

```json
{ "showCustomFieldIds": [1, 2] }
```

保存时校验：ID 须属于本工厂且 `target=work_order`；非法 ID 拒绝。

## 5. 前端

| 文件 | 改动 |
|------|------|
| `PrintSettingDialog.vue` | 拉 `getCustomFields('work_order')`，勾选写入 `showCustomFieldIds` |
| `PrintLabelDialog.vue` | 按勾选 + 工单 `ext` 渲染；空值跳过 |

## 6. 验收

- [x] 打印设置可见桌号、辣度等自定义字段并可勾选
- [x] 勾选后打印出现「桌号：一号桌」类行；未勾选不出现
- [x] 字段无值时仍占行，显示「—」
- [x] 删掉某自定义字段后，配置里残留 ID 不导致崩溃（打印时忽略）
