## 二、目标与范围

管理员在“自定义字段”中为工单建立文本字段“销售订单号”，打开“在工单列表显示”。下单时填写后，PC 工单列表出现该列，并能按此字段查出所有相关工单。

- 实现通用能力，使用字段 ID 关联，禁止按“销售订单号”这个名字写特殊逻辑。
- 不增加工单表专用列，不自动为所有工厂创建销售订单号字段。
- 一个销售订单允许对应多个工单，字段值不加唯一约束。
- 首版只改 PC 管理界面；不增加 H5/PDA 的动态列和筛选界面，保持旧接口调用兼容。
- 只支持同时筛选一个自定义字段，不做组合条件编辑器、排序配置、个人列配置或销售订单实体关联。
- 列表显示开关为工厂共享配置，由现有管理员权限控制；与打印设置相互独立。

### 2.1 首版取舍（明确不做）

| 项 | 决定 |
|----|------|
| 动态列顺序 | 按字段 ID 升序；无独立 `seq`，不做拖拽排序 |
| 空值筛选 | 筛选值为空白时不应用该筛选；**不支持**查「未填该字段」的工单 |
| 数字匹配 | 按字符串精确比较；`"1"` 与 `"1.0"` 不等价，不做数值归一 |
| 多字段同时筛 | 不做；一次只筛一个自定义字段 |

## 三、数据与接口契约

### 3.1 字段配置

在 `sys_custom_field` 增加 `show_in_order_list BIT NOT NULL`，默认 `0`；实体/API 对应 `ShowInOrderList` / `showInOrderList`。

- 更新 `docs/02-数据字典.md` 的权威 DDL，再同步实体、映射和数据库升级路径。
- 检查当前项目迁移、`DbCompat` 和初始化方式，遵循实际机制，确保新库和旧库都可用，重复启动/升级不报重复列错误。不得因本需求另建一套升级体系或直接手改生产表。
- 原有字段默认关闭，不改变既有工单列表；开关只影响列表显示，不删除字段值。
- `GET /api/CustomField?target=work_order` 返回开关；现有新增、编辑接口支持保存开关。
- 创建时省略开关默认关闭；更新时省略开关应保留原值，避免旧客户端编辑字段名称时意外关闭显示。
- 仅 `target=work_order` 可开启；产品/工序界面不显示此开关，后端拒绝其开启请求。
- 字段类型与归属仍不可更改；保持已有值禁止删除、仅本工厂可操作等既有规则。

### 3.2 工单列表

`GET /api/WorkOrder` 在现有参数之外增加：

| 参数 | 规则 |
|---|---|
| `customFieldId` | 可选，必须属于当前工厂且归属工单 |
| `customFieldValue` | 筛选值，长度不超过现有字段值上限 256；去除输入首尾空白 |
| `customFieldMatch` | `exact` 或 `contains`，默认 `exact` |

- 无自定义筛选参数时行为与旧版一致；只有字段 ID、筛选值为空白时不应用该筛选，但仍校验字段 ID 的合法性。
- 有非空值但无字段 ID、非法匹配模式、非法字段 ID、跨工厂或非工单字段请求，均通过统一异常机制明确拒绝。
- 文本支持精确和包含；单选只支持精确，使用现有选项；数字首版只支持精确，按现有字符串存储值比较，不引入数值范围或 `1` 与 `1.0` 等价转换。
- 所有本工厂工单自定义字段均可筛选，不受列表显示开关限制。
- 精确匹配采用数据库现有排序规则，不自行增加大小写规则；包含匹配将 `%`、`_`、`[` 等作为普通输入字符，禁止未转义地拼接 LIKE 或 SQL。
- 新筛选与已有关键字、状态条件按 AND 组合。保留现有状态 Tab 数量的全厂统计口径；表格总条数必须为当前筛选结果，避免把两者混为一谈。
- 筛选在数据库中、分页之前执行；不能只过滤当前页，不能产生重复工单。
- 列表每行增加 `ext` 字典，键为字段 ID，值为字符串，只返回当前工厂开启列表显示的工单字段；无值可不返回该键，前端显示“—”。
- 先取得筛选后本页工单，再批量读取本页所需扩展值，禁止每行独立查库，也禁止全表加载后在内存中筛选。
- 扩展值关联必须同时约束字段所属工厂、`target=work_order` 和本页工单 ID，不能只用 `target_id`，避免产品/工序同 ID 串值。
- 如果现有索引不足，依据实际查询验证后再增加必要索引，并同步数据字典；不为猜测的性能问题堆索引。

## 四、PC 界面规则

### 自定义字段配置页

- 在工单字段的新建、编辑表单增加“在工单列表显示”开关，默认关闭。
- 配置列表展示当前开关状态，管理员可通过编辑修改。
- 改名后工单列表标题随之更新，数据仍按字段 ID 读取。关闭后列消失，原值保留。

### 工单列表页

- 保留原有固定列，在固定信息列之后、操作列之前插入动态列，按字段 ID 升序展示。
- 每列使用字段 ID 作为稳定 key，标题使用字段名称；空值显示“—”，长文本省略并可悬停查看全文，允许横向滚动，保证操作按钮可访问。
- 新增一组筛选控件：“自定义字段”选择、“精确匹配/包含”选择、值输入；复用现有查询/重置动作。
- 文本显示两种匹配方式，默认精确；单选使用选项下拉框，数字用能保留现有字符串内容的输入框，两者固定精确。
- 切换字段时清空旧值并恢复默认匹配方式；提交筛选或重置时回到第 1 页；翻页保留条件；状态切换保留自定义筛选并回到第 1 页。
- 无自定义字段时不显示空的筛选控件。无匹配工单时展示现有空状态，不弹“系统错误”。
- 返回/重新进入工单页时重新加载字段定义，核查路由是否使用缓存，确保配置变化可见；已删除的筛选字段清理条件，避免反复提交失效 ID。
- 不将所有自定义字段强行并入原关键字搜索框。
