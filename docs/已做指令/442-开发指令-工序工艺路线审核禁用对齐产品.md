# 442-开发指令：工序 / 工艺路线审核·禁用（对齐产品）

> 状态：**已做**（代码已落地；现场验收勾选留空）  
> 承接：docs/441 产品审核/禁用；本指令把同等模式落到工序 + 工艺路线。  
> 不做：单位 / 不良品项 / 部门 / 用户 / 自定义字段；多级审核流。

## 规则

| 项 | 决定 |
|---|---|
| 新建 | `audit_status=0`；须【审核】且启用后，才可被下游引用 |
| 历史 | DbCompat 加列默认 `audit_status=1`、`status=1`，不打断现网 |
| 引用链 | 工艺路线步骤只能选「已审+启用」工序；产品只能挂「已审+启用」路线；审核路线时步骤工序也须可用 |
| 已审改删 | 须先【反审核】 |
| 痕迹 | 审核人/时；禁用人/时；反禁用人/时（与产品同口径） |
| 列表 UX | 字段+比较符+值；勾选+顶栏；业务操作：审核/反审/禁用/反禁用；无行内操作列 |

## 契约

见 `docs/开发手册和方案/02-数据字典.md`：`base_operation` / `base_routing` 生命周期列。  
API：`POST /api/Operation|Routing/{id}/audit|unaudit|forbid|unforbid`；列表 `FilterField/FilterOp/FilterValue` + `includeDisabled/includeUnaudited`。

## 验收

- [ ] V01 新建工序未审；编进路线时下拉不可见；审核且启用后可见  
- [ ] V02 新建路线未审；产品选用时不可见；审核且启用后可见  
- [ ] V03 已审锁定编辑/删除；反审可改再审  
- [ ] V04 禁用后下游不可再选；反禁用恢复  
- [ ] V05 历史工序/路线仍可被引用（迁移默认已审）  
- [ ] V06 列表快捷过滤 + 顶栏业务操作可用；详情可见人时
