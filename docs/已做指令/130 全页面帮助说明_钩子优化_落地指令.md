## 一、5 个页面最终定稿文案（逐字照抄）

### 1. /order 工单页
- **hook（大钩子，加粗）**：每张单做到哪道工序，张口说得清
- **slogan（斜体副标）**：不下车间问、不打电话追，下单/改状态/打流转卡都在这。
- **items 列表**：原样保留，不动。

### 2. /abnormal 异常处理页
- **hook**：小问题，不拖成大损失
- **slogan**：设备坏了 / 缺料 / 出质量，工人手机拍照一键上报，班组长手机秒收，不用满车间找人，有人跟进。
- **items 列表**：原样保留。

### 3. /price-rule 工价表页
- **hook**：工价算明白，工人干活卖力
- **slogan**：每道活给多少钱定死，工资自动算；错了能撤回重算，员工不少拿、主任不背锅。
- **items 列表**：原样保留。

### 4. /stat 生产报表页
- **hook**：每人做多少，实时看得见
- **slogan**：不是月底才算的死数，跟着报工实时更新，对账不用拿计算器加。
- **items 列表**：原样保留。

### 5. /execution-monitor 执行监控页
- **hook**：工厂里最累的，不是干活的人，是到处问进度的人
- **slogan（两行，第二行稍深）**：
  - 第一行（斜体灰）：没这页时，老板问主管、主管问班长、班长跑车间问工人，一圈问下来半天没了；
  - 第二行（正文色）：有了执行监控，该你办的事——待复核、待派工、异常、临期超期工单，主动堆在这，一屏看全，不用翻工单找。
- **items 列表**：原样保留。

## 二、数据结构怎么改（pageHelp.js）

现在每个页面是 `{ title, value: '一整段字符串', items: [...] }`。
**改为可选支持新字段**（向后兼容，其他 20 个页面不动）：

```js
'/order': {
  title: '工单页',
  hook: '每张单做到哪道工序，张口说得清',
  slogan: '不下车间问、不打电话追，下单/改状态/打流转卡都在这。',
  // 旧 value 字段删掉，或留空都行；items 原样保留
  items: [ ...原样... ]
},
```

- /execution-monitor 的 slogan 是两行，写成数组 `slogan: ['没这页时……半天没了；', '有了执行监控……不用翻工单找。']`。
- 其他页面（/product /routing /operation /defect /unit /user /dept 等）**一律不动**，它们没有 hook/slogan 字段，走旧渲染。

## 三、PageHelp.vue 怎么改（前置判断 / 条件执行）

### 前置判断
- 当 `help.hook` 存在时：按新样式渲染"钩子 + 副标"，不渲染旧的 `.page-help-value` 整段框。
- 当 `help.hook` 不存在时：维持现在的 `<div class="page-help-value">{{ help.value }}</div>` 不动（其他 20 个页面照原样）。

### 新模板结构（有 hook 时）
```html
<div v-if="help.hook" class="page-help-hero">
  <div class="page-help-hook">▸ {{ help.hook }}</div>
  <template v-if="help.slogan">
    <p v-for="(s, i) in sloganLines" :key="i" class="page-help-slogan" :class="{ 'is-solution': i === sloganLines.length - 1 && Array.isArray(help.slogan) }">{{ s }}</p>
  </template>
</div>
<div v-else class="page-help-value">{{ help.value }}</div>
```

### 样式新增
```css
.page-help-hero {
  margin: 0 0 16px;
  padding: 12px 14px;
  border-radius: 6px;
  border: 1px solid #d9ecff;
  background: #ecf5ff;
}
.page-help-hook {
  font-size: 16px;
  font-weight: 700;
  color: #303133;
  line-height: 1.5;
  margin-bottom: 6px;
}
.page-help-slogan {
  margin: 0;
  font-size: 13px;
  line-height: 1.6;
  color: #606266;
  font-style: italic;
}
.page-help-slogan.is-solution {
  color: #303133;
  font-style: normal;
  margin-top: 4px;
}
```

### script 加一个 computed
> 注意：本组件里 `help` 已是 `computed`，取 slogan 用 `help.value?.slogan`（不是 `help.slogan`）。

```js
const sloganLines = computed(() => {
  const s = help.value?.slogan
  if (!s) return []
  return Array.isArray(s) ? s : [s]
})
```

### items 列表按钮名染色 + 权限压灰（重要，别漏）
- 现状：`formatHelpLine` 把 what/how/who 拼成纯文本，按钮名是黑字、权限说明跟正文一样深。
- 改法：`mustLines` / `tipLines` **都**改为直接返回 item 对象（不再 `.map(formatHelpLine)`）；模板里拆 what/how/who。`formatHelpLine` 函数可保留不删（别处若引用不崩），本组件不再调用。
- 列表渲染（must / tip 两处同样结构）：
  ```html
  <li v-for="(line, i) in mustLines" :key="'m'+i">
    <template v-if="line.what">
      <span class="help-op">{{ line.what }}</span><template v-if="line.how">：{{ line.how }}</template>
    </template>
    <template v-else>{{ line.how }}</template>
    <span v-if="line.who" class="help-perm">（{{ line.who }}）</span>
  </li>
  ```
- 对应 CSS：
  ```css
  .help-op { color: #409eff; font-weight: 600; }
  .help-perm { color: #909399; font-size: 12px; }
  ```
- 当某个 item 的 what 是空字符串：不包 `.help-op`，直接显示 `how`（再跟 who）。
