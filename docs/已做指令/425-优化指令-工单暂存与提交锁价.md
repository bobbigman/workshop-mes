# 425-优化指令：工单暂存与提交锁价

> 状态：已做（代码已落地；未现场点验收，勾选保持空白）  
> 依据：用户 2026-10-29——正式保存须属性齐并能取价；允许金蝶式暂存；填对属性才能提交生效。

## 目标

电脑端建/改工单：**暂存**可缺工艺属性、不锁价、不可报工；**提交**（新建）或正式**保存**（已生效单）必须全部工序取价成功并锁价，失败整单不生效。

## 状态

| 值 | 含义 |
|---|---|
| **4** | 草稿（暂存） |
| 0/1/2/3 | 未开始/执行中/已结束/已取消（不变） |

改 `docs/02` 注释；无新表。

## 决策表

| 条件 | 行为 |
|---|---|
| 新建+暂存 | status=4；存属性；**不** BindAsync |
| 新建+提交 | BindAsync 全工序成功 → status=0；失败整单回滚 |
| 改草稿+暂存 | 保持 4；不 BindAsync |
| 改草稿+提交 | BindAsync 成功 → status=0；失败保持草稿、提示缺什么 |
| 改未开始/执行中+保存 | 必须 BindAsync（与现网一致）；禁止改回草稿 |
| 报工/计时/补报 | status=4 → 阻断：「工单为草稿，请先在电脑端提交后再报工」 |
| RecalcStatus | status=4 不改状态 |
| 列表「全部」/H5 excludeCancelled | 不含 3 与 **4**；PC 增「草稿」页签与计数 |

## 界面（PC）

- 新建/复制/编辑草稿：【暂存】【提交】  
- 编辑未开始/执行中：【保存】（正式，须取价成功）  
- 状态文案含「草稿」；草稿可取消/删除，不可「开始」

## 不做

- 不把历史缺锁价单批量改成草稿（仍靠 424 懒绑定/补属性）  
- 不上审批流、不反审核回草稿  
- H5 不提供暂存入口（后端拦报工即可）

## 验收

- [ ] 缺丝印片数等 → 提交失败有明确属性提示；暂存成功且 status=4  
- [ ] 草稿不可报工；提交后未开始可报工且任务有锁价  
- [ ] 草稿页签可见；全部/H5 列表不见草稿  
- [ ] 执行中工单保存仍须取价成功
