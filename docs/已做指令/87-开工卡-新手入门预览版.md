## 2A. 页面内容（照抄进页面，全是大白话）

> 页面分两个区：先「老板/管理员，从零把厂子配起来（6步）」，后「工人，一学就会（3步）」。底部放一句：**"有问题？右上角『帮助』有完整操作手册；或找管理员。"**

### 管理员/老板线（6步）

1. **环境准备**
   大白话：用电脑浏览器打开系统地址（就是内网 IP）。管理员管配置用电脑；工人报工用手机或 PDA。建议用 Chrome / Edge 浏览器。
   去操作：（这里不用跳转，说明文字即可）
   完成标志：浏览器能打开登录页。

2. **建账号和部门**
   大白话：先给每个工人开个账号、分到部门。报工能不能做，看的是**部门**，不是看人。
   去操作：系统配置 → 用户、部门（跳 `/user`、`/dept`）
   完成标志：账号建好、人都进了部门。

3. **填基础资料**
   大白话：把"单位 → 工序 → 不良品项 → 工艺路线 → 产品 → 工价表"按顺序填一遍。先有单位才有产品，先有工序才能排路线。
   去操作：基础数据 → 单位、工序、不良品项、工艺路线、产品、工价表（跳 `/unit` `/operation` `/defect` `/routing` `/product` `/price-rule`）
   完成标志：产品定义里有产品、工艺路线能选。

4. **建工单出码**
   大白话：进工单，选产品、填数量、定交期，保存后能打印出带二维码的工单。
   去操作：生产管理 → 工单（跳 `/order`）
   完成标志：工单出来、二维码能打印。

5. **扫码报工**
   大白话：工人用手机/PDA 扫工单二维码 → 选自己干的工序 → 填良品数、不良品数（有不良要选原因）→ 提交。班组长在报工复核把关。
   去操作：生产管理 → 报工、报工复核（跳 `/report`、`/review`）
   完成标志：工人在手机上把工序报上去了。

6. **看进度**
   大白话：车间看板、生产报表、执行监控，一眼看到每张单到哪道工序、不良率多少、工人今天挣多少。
   去操作：报表 → 车间看板、生产报表；生产管理 → 执行监控；报表 → 工资报表（跳 `/board` `/stat` `/execution-monitor` `/salary`）
   完成标志：看板上能看到工单进度、报表有数。

### 工人线（3步）

1. **扫码打开工单**
   大白话：手机或 PDA 扫工单上的二维码，工单就打开了。
   去操作：（无 PC 跳转；可给「扫码报工」链到 `/h5/scan`，方便演示）
   完成标志：手机上能看到这张工单和要干的工序。

2. **报工**
   大白话：选自己干的工序，填良品数和不良品数（有不良要选原因），点提交。
   去操作：可跳 PC「报工」`/report`（演示用）
   完成标志：显示"报工成功"。

3. **看产出/工资**
   大白话：下班看看今天报了多少、挣了多少（计件/计时工资自动算）。
   去操作：可跳「生产报表」`/stat`（演示用；工资报表管理员可见）
   完成标志：能查到自己的产量和工资。
