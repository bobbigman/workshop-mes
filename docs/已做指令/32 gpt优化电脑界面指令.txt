# 车间管理系统 PC 端 UI 完善

## 总要求

本轮只做 PC 端视觉完善。

严格禁止：

* 不改任何业务逻辑。
* 不改 API、请求参数、返回数据处理。
* 不改路由。
* 不改权限判断。

* 不引入新的 UI 框架。

设计目标：

**飞书 / 钉钉后台式浅色企业 SaaS。**

关键词：

> 大气、干净、克制、宽松、层级清楚、信息密度适中。

* 深色大屏风

# 一、全局基础

## 文件

`src/styles/theme.css`

## 当前问题

当前主题方向已经正确，但仍存在几个问题：

1. 14px 全局大圆角略偏“卡片化”，企业生产后台应更克制。
2. 表格自身直接带阴影和大圆角，容易产生“一张表就是一张悬浮卡片”的感觉。
3. 页面没有形成统一的 PC 内容留白标准。
4. Element Plus 默认组件高度、页面工具栏、表格行高之间还缺少统一尺度。
5. 部分全局表格颜色仍然硬编码。
6. 页面背景、容器、分割线已经有变量，但页面没有充分利用。

## 修改指令

### 1. 建立统一 PC 空间尺度

在 `theme.css` 增加纯尺寸变量，不涉及业务：

* `--app-page-padding-x: 24px`
* `--app-page-padding-y: 20px`
* `--app-section-gap: 16px`
* `--app-card-padding: 20px`
* `--app-control-height: 36px`

PC 主内容区域统一按照：

**24px 左右 / 20px 上下**

处理。

1920 宽屏不要无限拉开内容间距，也不要做居中窄版网页；生产管理后台应保持高信息利用率。

### 2. 圆角克制

建议：

* 普通内容容器：10~12px
* 输入框/按钮：6~8px
* Tag：保持 Element Plus 小圆角
* Dialog：12px

不要所有东西都 14~16px。

### 3. 阴影降低存在感

普通业务卡片尽量：

* 白底
* 浅边界/极轻阴影二选一

不要同时使用明显 border + shadow。

`--app-shadow` 只保留非常轻的层次感。

### 4. 表格

全局 `.el-table`：

* 白底
* 不做明显悬浮阴影
* 表头 14px / 600
* 正文 14px
* 表头高度约 44px
* 数据行约 48~52px
* 只保留横向浅分割线
* hover 极浅
* 数字继续保持 tabular-nums

表格是后台核心工作区域，应当“平、稳、宽”，不要像一叠卡片。

# 最终视觉判断

完成后不要以“有没有改颜色”为验收标准。

最终应该达到：

**左侧导航安静，顶部框架稳定，正文空间宽松，表格是主角，主按钮明确，状态色克制，看板与后台属于同一套浅色 SaaS 系统。**

如果某个元素需要靠：

* 更深的颜色
* 更大的字号
* 更重的阴影
* 更多的描边

才能显得重要，优先重新检查它的：

**留白、位置、字号层级、间距。**

不要继续叠视觉效果。

这份指令是针对你实际源码写的：例如目前工单页确实是 `toolbar → tabs → table` 的扁平结构，搜索框固定 200px、创建工单用了 success 色、操作列固定 400px；这些正是最值得先收拾的地方。

另外，看板现在确实整页采用深蓝背景、深色指标卡和 56px KPI，并且 ECharts 颜色也直接硬编码，所以我会把**看板浅色化列为这一轮优先级最高的视觉改动之一**。
