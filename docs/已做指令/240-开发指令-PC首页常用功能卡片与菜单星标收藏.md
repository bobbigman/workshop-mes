## 本次范围与落点

- 一条完整流程：登录 PC → 侧边菜单 hover/展开某菜单项旁出现空心☆ → 点击变实心★并写入 → 回到首页"我的工作→常用功能"卡片看到该入口 → 再点★变空心 → 首页卡片移除。
- 已有 / 缺口：电脑端没有「我的工作」页，`/` 原跳 `/order`。本次新建 `frontend/src/views/home/index.vue`，并把登录落点改到 `/home`。菜单星标加在 `SideMenu.vue`。
- 数据与契约：
  - 新表 `sys_user_favorite`：`id BIGINT IDENTITY`、`user_id BIGINT`、`menu_key NVARCHAR(128)`（路由，如 `/order`）、`menu_title NVARCHAR(128)`、`icon NVARCHAR(64) NULL`、`sort_at DATETIME2 DEFAULT SYSDATETIME()`、`created_at DATETIME2 DEFAULT SYSDATETIME()`；唯一约束 `(user_id, menu_key)`。
  - `GET /api/userfavorite`：当前用户收藏，按 `sort_at` 倒序，最多 12 条。
  - `POST /api/userfavorite/toggle`：入参 `{ menuKey }`。清单里有且当前角色看得见 → 已有则删、没有则增；返回 `{ favorited, item }`。未知菜单或当前角色看不见 → 业务提示，不写库。
- 文档：建表后同步 `docs/开发手册和方案/02-数据字典.md`；不改 PRD。
- 轻重：1 张表 + 2 个接口 + 2 处前端改动（菜单项星标、首页卡片），属轻量；不接金蝶、不接 MES 外部系统。

## 行为与口径

- 当用户在菜单旁看到空心☆ → 可点击；点击后该☆立刻变实心★，POST 成功才视为收藏（失败恢复空心并提示）。
- 当☆已是实心★ → 再点则变空心，删除该条收藏；首页对应卡片同时移除。
- 当 POST 接口失败（含 SQL 异常）→ 星标恢复点击前状态。提示走现有请求拦截器（技术故障带 SQL 原文，业务失败带业务句），不另弹一句盖住详情。后端用 `ThrowHelper.Sql`，异常信息带 SQL 说明和 `menu_key`，不吞错。
- 当未收藏任何菜单且列表加载成功 → 首页 `/home` 渲染 4 个默认入口：工单、报工、报工复核、执行监控。看不到复核（角色或授权档）时，第三格改为生产报表。底部灰字「点左侧菜单旁的☆可加入常用」。这 4 个不写入收藏表。列表加载失败时不拿默认入口冒充「还没收藏」。
- 当已收藏 N 个（N≤12）→ 首页按收藏时间倒序显示 N 个卡片；超过 12 个只显示最近 12 个，"更多"入口本版不做。
- 当切换登录账号 → 收藏列表按当前 JWT 用户重拉，互不可见。
- 重复点击：toggle 接口以 `(UserId, MenuKey)` 唯一约束兜底，并发双击只保留一条。

| 数据 | 处理方式 |
|---|---|
| sys_user_favorite 记录 | toggle 即增/即删，不做软删除；历史收藏随用户存在，不做批量迁移 |
