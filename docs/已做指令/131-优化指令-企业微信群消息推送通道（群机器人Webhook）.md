- **文档**：改表同步 `docs/02`；业务口径同步 `docs/01`。

## 行为与口径（分叉写成显式条件）

- 当【规则目标 = group 且已配 webhook_key】→ 命中后 **POST webhook 发群**，无需 access_token。
- 当【工人上报异常（设备/物料/质量）】→ 推群并 **@对应人**（设备故障@机修、物料短缺@仓库、质量异常@质检；未配置成员则仅群通知）。
- 当【规则目标 = session】→ 现有会话到人逻辑，**不变**。
- 当【规则目标 = group 但未配 webhook_key】→ 不生成待发，业务正常，页面提示补配置。
- 群消息**去重/每日额度复用现有**：`alert_key` + `daily_limit`，同一事件当日不重推。
- 群消息无"部分失败"（群整体成败）；失败记账本、可手动重试；**结果未知不自动重发**。
- webhook key 属敏感信息，不进日志、不出现在页面明文（脱敏）。
