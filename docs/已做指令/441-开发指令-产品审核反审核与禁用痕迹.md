# 441-开发指令：产品审核/反审核与禁用痕迹

> 状态：**已做**（代码已落地；现场验收勾选留空）  
> 承接：docs/440 禁用；本指令补审核 + 人时字段。  
> 不做：工序/工艺路线同等能力；提交/审核中多级流。

## 规则

| 项 | 决定 |
|---|---|
| 新建 | `audit_status=0` 未审核；须【审核】后且启用才能建单 |
| 历史 | DbCompat 加列默认 `audit_status=1`，不打断现网 |
| 已审改删 | 须先【反审核】 |
| 痕迹 | 审核人/时；禁用人/时；反禁用人/时（反审保留末次审核人时，再审覆盖） |

## 契约

见 `docs/02` `base_product`：`audit_status/audited_*`、`forbid_*`、`unforbid_*`。  
`POST .../audit`、`/unaudit`；forbid/unforbid 写入人时。

## 验收

- [ ] V01 新建未审，建单下拉不可见；审核且启用后可见  
- [ ] V02 已审锁定编辑；反审可改再审  
- [ ] V03 禁用/反禁用写入人时；详情可见  
- [ ] V04 历史产品仍可建单（已审默认）
