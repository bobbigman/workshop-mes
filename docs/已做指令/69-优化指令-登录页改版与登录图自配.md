## 3. 接口设计

### 3.1 读取（登录页展示，免鉴权）
`GET /api/LoginSetting?factoryCode={code}`
- 返回当前工厂登录页 banner URL：`{ "code":0, "data": { "bannerUrl": "/uploads/login/{factoryId}.png" } }`
- 未配置 → `bannerUrl: null`，前端用内置默认图
- 参照 `InstanceController`/`AuthController` 的公开访问写法（登录前可调）

### 3.2 上传（仅管理员 role=1）
`POST /api/LoginSetting/banner`
- `multipart/form-data`，字段 `file`（图片）
- 校验：仅图片（png/jpg/jpeg/webp）、大小上限（建议 ≤ 5MB）
- 保存：写 `wwwroot/uploads/login/{factoryId}.png`（覆盖旧图，文件名用工厂隔离）
- 更新 `login_setting.banner_url`，返回新 URL
- 权限：管理员（RoleGuard role=1）

### 3.3 数据字典（`docs/02` 补充）
```sql
CREATE TABLE login_setting (
  id          BIGINT IDENTITY(1,1) PRIMARY KEY,
  factory_id  BIGINT NOT NULL,                 -- 工厂(账套)，隔离
  banner_url  NVARCHAR(255) NULL,              -- 登录页左侧图相对路径
  updated_at  DATETIME2 DEFAULT SYSDATETIME(),
  CONSTRAINT uk_login_setting_factory UNIQUE (factory_id)
);
```
> `UseStaticFiles()` 已开启，`/uploads/...` 直接可访问；无需改静态文件配置。

## 4. 前端登录页改版（对标金蝶分栏）

### 版式
- 整屏左右两栏：**左侧图区**（约占 58% 宽、全高）+ **右侧登录区**（居中，保留现有标题/表单/账套选择/登录按钮/操作手册/版本号）
- 左侧图 `object-fit: cover` 铺满，无图时用内置默认图（放 `frontend/public/` 或后端 wwwroot 默认图）
- 背景沿用现有 `--app-login-bg` 体系，主题变量生效

### 数据获取
- 登录页挂载时调 `GET /api/LoginSetting` 拿 bannerUrl（拿不到/为 null 则用默认图）
- 登录成功逻辑、路由跳转、账套下拉、`narrow` 窄屏判断**全部保留不动**

### 响应式
- 窄屏（`max-width: 768px`）：左右分栏改为上下，左侧图缩小为顶部横幅（或隐藏，保留登录表单为主），不挤爆

## 5. 管理端「登录页图片」页（role=1）

- 入口：侧边 `SideMenu.vue` 系统配置组加菜单项 `/login-setting`（仅 role=1）
- 页面能力：当前图预览 + 上传按钮（选图→上传→成功后刷新预览）+ 提示尺寸建议（建议 2:1 或 4:3 横图，视左侧图区比例）
- 上传走 `POST /api/LoginSetting/banner`
