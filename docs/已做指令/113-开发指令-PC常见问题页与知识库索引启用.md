# 113-开发指令：PC 常见问题页（系统能力50问）+ 启用知识库索引

> 状态：已做（2026-10-02）
> 一句话目标：给 PC 端加一页「常见问题 / 系统能力50问」静态页，供客户自己翻看；同时确认 SupportDocs 索引已启用，让 AI 助手（PC 客服 + 扣子）能检索到这份口径、随时答疑。
> 依据/拍板：2026-10-02 黑帽大人确认——50 问已整理成中立口径版（`SupportDocs\10-系统能力50问.md`），要"专门放一页常见问题列表"，并让 AI 能引用它回答。解析规则已拍板：**`##`=分组、`###`=问题+正文**（与现 md 结构一致，不改 md）。豆包起草，Cursor 落地。

## 取舍（定死）
| 项 | 定案 |
|---|---|
| 做/不做 | 做 PC 一页常见问题列表；**不做**复杂搜索/折叠/打分 |
| 数据来源 | **单一来源**：页面数据取自 `SupportDocs\10-系统能力50问.md`，**不另存硬编码副本**（避免与知识库漂移） |

| 读法 | 优先复用现有 `SupportDocumentService` 读取该 md；当无可复用只读接口 → 新建 `GET /api/SupportDocs/faq`，返回该 md 的 `##` 分组 + 各组下 `###` 问题 + 正文 |
| PC / H5 | 先 **PC（Element Plus）**；H5 不做 |
| 索引启用 | 属部署配置动作：本机 `Ai:SupportDocs:Enabled` 已是 true、RootPath 已指向 SupportDocs → **只验证/重启，不改配置** |

### 一、PC 常见问题页
- 后端：新建只读 `GET /api/SupportDocs/faq`（鉴权任意登录用户），读取 `10-系统能力50问.md`，按 **`##`=分组、`###`=问题+正文** 解析返回 `[{group, questions:[{title, content}]}]`；当该 md 不存在/解析失败 → 返回"常见问题暂未收录"占位，不报错不编造。不改表（无 DDL，docs/02 不改）。
- 前端（Element Plus）：帮助菜单新增「常见问题（系统能力50问）」页。
  - 当已有可复用只读接口能读到 SupportDocs md → 复用；当没有 → 调 `GET /api/SupportDocs/faq`。
  - 页面按分组（工单/报工/工资/进度/异常）渲染，组内逐条显示问题（`###` 标题）+ 口径正文（含 ✅/❌/⚠️ 结论）。
  - 当返回占位/为空 → 页面显示"常见问题暂未收录"，不报错。
- 文档：`docs/33` 补 `GET /api/SupportDocs/faq` 接口一行。
