# 自定义字段删除

目标：PC 自定义字段列表在编辑旁提供删除，覆盖工单、产品、工序。

契约：新增 `DELETE /api/CustomField/{id}`，仅管理员，工厂身份来自 JWT。字段不存在或不属于本厂时提示“字段不存在”；存在字段值记录时禁止删除，保留历史数据。未使用字段连同选项在事务中删除，不改表。打印设置中的旧 ID 已由现有界面按有效字段过滤。

验收清单：
- 删除前展示字段名称并确认；取消不提交。
- 未使用字段删除后刷新列表，重复点击受限。
- 已使用字段明确提示阻断，不清除历史值。
- 跨工厂删除失败；生产人员不能调用删除接口。
- 前后端构建通过；实际部署后验证“辣度”删除流程。
