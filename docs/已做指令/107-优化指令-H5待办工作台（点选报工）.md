# 107-优化指令：H5 待办工作台（点选报工）

> 状态：**已实现（2026-10-01）**
> 依据：`frontend/src/views/h5/`（tasks/orders/scan/report）、`api/assign.js`（myTasks）、`api/prod.js`（getOrderList）
> 对标：黑湖——工人一登录看到「今日待报工 / 待领任务 / 进度概览」的**工作台**，点一下就选中报工，不用敲字。
> 痛点：咱家 H5 以「扫码」为主，工单/任务两个列表分开，缺一个聚合的「待办」首页，工人进来要先想点哪。
> 目标：把 H5 默认首页做成**待办工作台**：顶部「去扫码报工」大入口 + 「我的任务」点选列表 + 快捷入口（我的报工/我的工资）。**纯前端聚合，复用现有接口，不改后端。**

---

## 0. 为什么做（人话）

黑湖工人一打开手机就是"今天要我干哪些活"的工作台，点一下就报工。咱家现在默认首页是工单列表、扫码在单独 tab，工人要想"该点哪"。做一个工作台，把「扫码入口 + 今天要我干的任务 + 快捷入口」聚到一屏，点选即报，对齐黑湖。

## 1. 已有底子（别重复造轮子）

- `h5/tasks.vue`（我的任务）：已能点卡片 → 去报工，显示 工单号/产品/工序/剩余/交期。可直接搬进工作台当"我的任务"块。
- `api/assign.js` 的 `myTasks()`：已返回当前工人的任务列表。
- `h5/scan.vue`：扫码报工入口已很成熟，工作台顶部放一个大按钮跳过去即可。
- H5 底部 TabBar 已固定（原：工单/任务/扫码/异常/帮助）。

## 2. 交付物

新增 1 个 H5 首页组件 `h5/home.vue` + 路由 `/h5/home` 设为默认首页 + 文档收尾。**无后端改动、不动现有 tasks/scan/orders 页逻辑。**

---

## 3. 原子步骤（落地纪要）

### 步骤1：新增工作台首页 `frontend/src/views/h5/home.vue`

1. 顶部大按钮「去扫码报工」→ `/h5/scan`；无扫码档时不显示。
2. 「我的任务」调 `myTasks()`，点卡片 → `/h5/report?order=`；空列表文案「暂无派给我的任务，可扫码报工」。
3. 快捷入口：工单 / 我的报工 / 我的工资（工资按档显隐）。`TabBar active="home"`。

### 步骤2：路由与默认首页

- 路由加 `/h5/home`。
- **TabBar 取舍**：首项「工单」改为「工作台」→ `/h5/home`；工单列表改由工作台快捷入口进入；任务/扫码/异常/复核/帮助保留。
- 生产人员（role=2）登录无 redirect 时落 `/h5/home`；报工页返回 `/h5/home`。

### 步骤3：不改动原则

不删 tasks/orders/scan；报工逻辑仍在 report。工作台只聚合跳转。

### 步骤4：文档

docs/31、docs/30、docs/04 已同步；本文件移入已做指令。
