## 一、完整卖点清单（自定盘并入，演示主词）

> 出门照着说；系统内固化页：帮助 →「产品优势速览」。话术原文亦见出门清单。

### 1.0 战略定位（2026-09-27 并入，演示第一句）

> 口径源：《定价对标备忘录》§五；改口径先改它，再同步本文与 76、优势速览页、演示话术。

**一句话定位（演示第一句）：** 「我卖的不是黑湖旗舰版的减配版，是『车间执行层 + 金蝶集成』：老板已在用的金蝶我不重复做，只把车间最后这一公里管起来——比黑湖专业版便宜 2000 还含上门实施，比旗舰版便宜 1 万。」

**三层定位：** 经营层（销售/采购/库存/财务）= 金蝶已有，咱不做、对接省用户工作量；车间执行层（工单/派工/报工/复核/交期/计件工资）= 咱的主战场，与黑湖专业版同档；部署/集成层（本地部署·数据不出厂·接金蝶 MCP）= 咱独家，黑湖/简道云都没有。

**不拼旗舰版四格（采购/销售/质检/PDA——2026-09-27 拍板）：** 供应链不是卖点，上了很难用起来、给用户加工作量；金蝶客户已有，重复建设。质检：基础不良记录有（PRD），全流程 IQC/IPQC/OQC 不做、留给金蝶/以后外挂；对外**不说"比专业版少质检"**。

**没上金蝶的客户（可能三四成，别当边缘情况）：** ① 只卖核心（报工+计件+看板，本就不依赖金蝶）；② Excel 导入/导出 = **个案集成加分项**，对老板说"能做"，**不承诺工期、不进协议**。可对外承诺的集成只有已闭环：金蝶排产评分（`docs/36`）、相似件报价（`docs/72`）、MES MCP（`docs/34`）、AI 客服（`docs/25/48`）。

### 1.1 四大真优势（主词，按重要度）

1. **本地部署、断外网也能用，数据不出厂**
   - 装客户自己电脑/服务器，局域网就能跑；**不连外网也能用核心功能**（报工、看板、工资）
   - 推送照发、不泄露（企微推送走开通通道，与「业务数据不上公网」不矛盾）
   - **对黑湖/简道云**：云端 SaaS，**一定要外网**；数据在对方云上——最硬差异句
   - **A 区对外写法**（不点名竞品）：「数据在您自己服务器，局域网就能跑；没外网、断网也照用。那些必须联网的云端系统，一断网就动不了。」竞品对比只留 B 区。

2. **工资能按厂规矩算** + 复核前置 + **可追溯可重算**
   - **边界**：管「计件绩效算清楚」；**不管**底薪、社保、个税、银行代发
   - 对外：工资报表把**计件部分**算准、能重算；底薪社保仍走财务

3. **轻量、按厂收费不按人头** —— 不是按人头年费把人卡死

4. **能接金蝶 / 开放集成**（加分，别当主线吹）
   - **已做可演示**：金蝶排产评分（`docs/36`）、相似件建议报价（`docs/72`）、MES MCP（`docs/34`）、AI 客服/知识库（`docs/25/48`）
   - **打单故事（金蝶客户）**：主数据不录第二遍；报价对得上车间实做。黑湖封闭常要两套资料
   - **主标语（A区大白话）**：「能和金蝶打通，数据不重复录」
   - **竞品对比话术（对外打单）**：「有的系统接不进您的金蝶、没地方取数；有的要您在小工单里再录一遍，双维护、易错。我们直接取数、不重复录。」
   - **禁止**：纯金蝶搬运壳；**没金蝶** → 本条放弱，先打 1～3
   - **旗舰定制（不对外演示）**：智能体/CAD 报价——只说「按需定制、按需报价」，不承诺现成与时间

### 1.2 痛点 → 怎么解

| 老板痛（排序别搞反） | 我们怎么解 |
|---|---|
| 快到交期才发现要拖（**最痛**） | 看板黄红预警 + 企业微信推到手机 |
| 月底算工资拿表对、还老吵 | 工价配一次，工资自动算，每笔可查可重算 |
| 想知道单做到哪了，得下车间问 | 扫码报工，看板实时，坐办公室管全厂 |

> 报工是手段不是目的；工人愿意扫的钩子是**计件工资**。选客红线：**必须计件工资的厂**。

### 1.2.1 演示开场痛点（扒自黑湖陌拜，可用）

> 黑湖销售陌拜开场先戳这 4 条（**客户的病，不是黑湖专利**），咱可直接用作演示开场（先痛点、后解药）。每条按咱能力核实，别照抄。

| 痛点（扒黑湖） | 咱怎么解 | 边界 |
|---|---|---|
| 图纸版本乱，易做错料 | 工单挂图纸 / 作业指导书，工人扫码看、手机/PC 可预览 | **已有**（docs/68/69/30：上传 + 版本号 V1.x + 按工单聚合）；别吹「版本对比 / 历史版本」 |
| 插单改单频繁，进度看不清 | 扫码报工 + 看板实时，坐办公室管进度 | §1.2 进度 |
| 报工计件靠手工，月底核算累 | 扫码报工 + 计件工资自动算 | §1.1②；只算计件，不吹发薪社保 |
| 质量追溯难，不良原因查不清 | 报工记录（谁 / 哪天 / 工序 / 不良原因）+ 异常 | 不吹「料批次」；可对接金蝶 |

**扒用红线**：黑湖陌拜主打里的「**扫码出入库、账料吻合**」咱**没有库存模块**（进销存范围外，`docs/1D`），**不扒、不吹**——客户一问「出入库在哪」就穿帮。

### 1.2.2 开场话术（一问一答，先问诊、后解药）

> 照黑湖「先问诊再开口，像医生看病」——先让客户自己点头认了痛点，再给解药。**先问，别急着讲。**

| 痛点 | 问（戳痛） | 答（买点 + 根据） |
|---|---|---|
| 图纸乱 | 「老板，现在是不是还靠纸质图纸？换版了，车间拿的还是旧图，做错型号、报废返工，没少赔吧？」 | 「咱这套，图纸/作业指导书直接挂工单上，工人扫码看**当期带版本号**的，手机/电脑都能预览——**不做错型号，少报废少返工**。」 |
| 插单 / 进度 | 「插单、改单是不是常来？想查单做到哪了，是不是得下车间问、打电话追？」 | 「扫码报工，看板实时——**坐办公室就能看每张单到哪道工序**，不用来回跑，进度看得见。」 |
| 报工计件 | 「月底算工资是不是还拿表对？数对不上，工资老吵？」 | 「工人扫一下就报工，**计件工资自动算，每笔可查可重算**——月底少熬夜、少吵工资架。」 |
| 质量追溯 | 「出问题想查是哪天、谁做的、哪道工序，是不是得翻半天纸质单？」 | 「**报工记录谁/哪天/哪道工序/不良原因**都在系统里，几秒调出来，现场照片也能留；追溯原材料批次**可对接金蝶**。证据**存您自己厂里**，不泄露。」 |

> 话术守边界：图纸不吹「版本对比/历史版本」；追溯不吹「料批次现成」；全程**不碰「出入库」**。

下单出二维码 → 扫码报工 → 看板实时 → 工资自动算 → 交期自动提醒 → 派工到人 / 异常上报

### 1.4 三句杀招 + 案例

1. **戳痛**：月底算工资是不是还得拿表对？想知道单做到哪了，是不是得下车间问？快到交期是不是到跟前才发现要拖？
2. **亮底**：大软件管大厂，您这规模花大钱办小事。这套照着您厂子的活法做：扫码报工、看板看进度、工资自动算、交期自动提醒。
3. **差异**：别人数据在云上、按人头年费、**一定要外网**。我这套装您自己电脑里，**断外网也能用，数据不出厂**，推送照发，不泄露。

**案例**：「某张单离交期还有 2 天、还卡在第三道工序，您手机上就收到了——不用等您去问，系统先提醒您。」

### 1.5 竞品启示（对内）

通道多少不是胜负手。两家都把「交期预警+推送」放最低档全量送 = 签单钩子。我们差异化 = **本地部署、断外网也能用、数据不出厂、推送照发不泄露**。

### 1.6 打法摘要（对内，非界面文案）

- 陌拜：请老板当老师；5 分钟台阶；先戳延期（`docs/37`）
- 演示：真推一条到自己手机 + 30 秒录屏 + 案例话术
- 试用：低门槛保证金优于纯免费（`docs/55`）
- 定价：功能全版本有；开通（企微认证+陪配+维护）收费
- 企微：唯一通道；不承诺钉钉/短信；自动推送暂缓（`docs/75`）

## 二、界面级卖点（每个界面顶部一行）

> 文案必须能从 §一 找到出处；禁止另起一套说法。
> **王雩式方法（先立，再写）**：
> - **讲买点，不讲卖点**：别写「我们有什么（自动记 / 大屏见）」，写「您得到什么（月底不熬夜 / 不接烂单 / 不吵工资架）」。
> - **每条必须带「根据」**：客户会问「凭什么你能做到」——根据就是**数据从哪来**，且必须真实：**金蝶打通只用在建议报价、排产评分**（真靠金蝶取数）；工资 / 报工 / 看板 / 预警的根据是**扫码报工 / 工单真实数据**，**别硬贴金蝶**，否则演示一问就穿帮。

> **句式统一**：`[您少受什么罪] —— [凭什么：真实数据从哪来]`  
> **头号卖点不进本表**：本地部署 / 断外网 / 数据不出厂 → 只进优势速览页底座（及可选登录/首页横幅），**不塞进业务页提示条**，避免和功能页抢戏。

| 界面 | 顶部价值提示（买点 + 根据） | 数据根据 | 对应 §一 | 备注 |
|---|---|---|---|---|
| 工单（管理） | 「单做到哪了，打开就能看——不用下车间问、不用打电话追」 | 扫码报工实时进度 | 1.2 进度 / 1.3 闭环 | 给管理人员看；不跟工资页抢「对单据」 |
| 报工（现场） | 「扫一下产量就记上，计件有据——月底少扯皮」 | 扫码报工记录 | 1.2 工资钩子 / 1.3 闭环 | 钩子是计件，不吹「对单据早点回家」 |
| 车间看板 | 「订单到哪一步，大屏一眼见——不用下车间、不用打电话，坐办公室就能管进度」 | 报工实时汇总 | 1.2 进度 | 交期黄红另见企微预警；不写「全厂尽在掌握」那种空话 |
| 工资 | 「报工一结，计件部分算准、能查能重算——不用从表里抄一遍，少吵工资架」 | 报工 + 工价 | 1.1② / 1.2 工资 | 只承诺计件绩效；**不吹**底薪/发薪/社保/个税 |

## 五、红线（违反即演示翻车）

- 未闭环能力（金蝶真取数、企微推送、AI 在线、旗舰版）**不吹「已上线」**，只讲「可对接、认证即用、按需定制」。
- **不承诺上线时间**（钉钉 / 短信 / 自动定时推送等）。
- 「断网也能用」限定：核心工单 / 报工 / 看板 / 工资，**局域网内**断外网照跑；不吹「完全不用网 / 推送也断网可用」。
- **不为单家改代码**；灯塔期一次穿帮本地圈子全知道。
- 界面、优势页、演示话术、定盘备忘录 **口径一致**；改一句四套一起改。
- **不把 SaaS 与私有部署并列成「您随便选」主故事**——定盘主词是私有部署差异化；若日后真有 SaaS 交付，另开定盘，不在本期界面文案里抢戏。
- **不吹「扫码出入库 / 库存台账」**——咱没有库存模块（进销存范围外，`docs/1D`）；客户问「出入库在哪」就穿帮。
