### 文件修改清单
1. `Program.cs`
    - 读取appsettings配置 `McpEnable` 开关；
    - 如果`McpEnable=true`：注册MCP鉴权中间件、MCP请求处理器；
    - 路由规则：**POST请求访问`/mcp`交给MCP处理器处理；GET请求访问`/mcp`仍然走原有前端静态页面逻辑**；
    - 如果`McpEnable=false`，POST `/mcp`直接返回404。

2. 新建文件夹 `McpServer`，内部新建3个类文件
    - `McpRequestMiddleware.cs`：MCP鉴权中间件，校验请求头`Authorization: Bearer xxx`，比对token为`laohu‑demo‑2026`，校验失败返回401；
    - `McpHandler.cs`：MCP核心处理器，实现Streamable‑HTTP协议；只处理标准MCP方法：`list_tools`、`call_tool`，其他方法做兼容空返回；
    - `McpTools.cs`：定义5个MCP工具元数据，调用项目内部已经存在的业务服务：
      - `start_auth`：生成授权码，用于工资敏感操作；
      - `query_work_order`：查询工单；
      - `query_report`：查询生产报表；
      - `query_salary`：查询工资，必须校验已经拿到有效授权码；
      - `calc_schedule_priority`：排产优先级计算。

3. 修改 `appsettings.json`
    增加配置节点：
    ```json
    "McpEnable": true
    ```

4. 日志要求
    MCP所有入参、工具调用、返回值、异常堆栈全部写入系统日志；方便排查方舟调用问题。
