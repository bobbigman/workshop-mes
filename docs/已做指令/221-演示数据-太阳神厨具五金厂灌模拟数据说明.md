> ⚠️
> **只报首尾工序会翻车**
> ：系统完成量 = 各工序良品最小值、达成率 = 各工序 (完成 / 计划) 最小值。上面 2.5 只报到中间工序，质检 / 组装 / 包装是 0，导致执行监控「工单进度 / 工序达成 / 完成・剩余」全 0%（看着像没干活）。

> ，末道最少即可形成梯度。

### 2.6 建异常（multipart/form-data，中文用手工 UTF8 multipart）

```
foreach($it in $items){
  $b = "----MesBound" + [Guid]::NewGuid().ToString("N")
  $s = "--$b`r`nContent-Disposition: form-data; name=`"Type`"`r`n`r`n$($it.type)`r`n" +
       "--$b`r`nContent-Disposition: form-data; name=`"Description`"`r`n`r`n$($it.desc)`r`n" +
       "--$b`r`nContent-Disposition: form-data; name=`"WorkOrderId`"`r`n`r`n$($it.wid)`r`n" + "--$b--`r`n"
  $bytes = [Text.Encoding]::UTF8.GetBytes($s)
  Invoke-RestMethod -Uri "http://127.0.0.1:8080/api/Abnormal" -Method Post -Headers $h -ContentType "multipart/form-data; boundary=$b" -Body $bytes

```

## 4. 注意事项



1. **中文编码**：API body 一律 `[Text.Encoding]::UTF8.GetBytes(...)`，否则中文存成 `?`。

2. **多工序数量不可相加当完成量**：看板 doneQty 按末道工序良品计；演示文案别把在制量相加当完成量。

3. **AI 对话演示**：三场景对话依赖 DeepSeek 账户余额。余额不足时接口回 `HTTP 402 Insufficient Balance`，AI 助手答不了；演示前先充值或换 key。数据演示不受影响。

4. **演示材料**：配套看板见 `artifacts\太阳神厨具五金厂_演示看板.html`（含三场景剧本）。
