# 253 · PC 助手回答排版优化

日期：2026-10-20。状态：已实现；本地测试、生产构建及组件浏览器预览通过，未部署。用户明确要求出指令并落地。

## 目标和范围

以 `docs/测试反馈/bee.png`、`weixing.png` 为视觉对照，让 PC 内置 AI 助手的回答呈现清晰的标题、重点、列表和表格。复用当前工作区已有的 AiAnswer、AiInline 和 aiMarkdown 草稿，先审核再完善，保留其它已有修改。

只调整 PC 回答展示；不改模型、提示词、工具调用、查询口径、权限、接口和数据库，不增加模型调用或等待步骤。不承诺固定 8 秒响应；本次不处理截图中查询数量不同的问题。原有业务卡片、候选、证据、翻页和错误提示继续使用。

## 实现约定

- 助手回答通过 Vue 模板渲染 Markdown 子集：标题、段落、加粗、列表、引用、代码、HTTP/HTTPS 链接和表格；用户输入继续按纯文本显示。
- 结论用浅蓝提示块、警告用浅黄提示块；正文保持舒适行距，表头底色、行分隔清楚。宽表只在表格容器内横向滚动；长来源编号可换行。
- 当输入是普通文字、空文本或尚未闭合的语法时，保留可读文字；不执行模型输出的 HTML、脚本或危险链接，不使用 v-html。
- 当表格分隔行每列至少一个短横线时兼容显示（容忍模型的简写）；当表头与分隔列数不符时保留原文，不误当表格。当数据列超出表头时不得静默丢失。
- 仅支持本指令列出的 Markdown 子集，不新增富文本编辑器或后端服务。
