# 优化指令：PC 壳子大气化（仅简约主题）

> 状态：已实现  
> 依据：现界面是「飞书/钉钉同款」克制工具风，干净但太素、太窄、太低调，老板/客户演示时显简陋  
> 原则：只动样式与壳布局；**不改业务逻辑、不改接口、不动数据库、不引入新组件库**  
> 承接点评：大气要可验收；内容页本期不做；砍毛玻璃/发光；双主题用变量隔离；路径写准  
> 落地文件：`theme.css`、`views/layout/index.vue`、`views/layout/SideMenu.vue`、`views/login/index.vue`、`views/board/index.vue`

---

## 1. 目标（「大气」操作定义）

本期只让 **PC 管理端壳子**（登录页、侧栏+顶栏框架、车间看板）更有品牌感和层次，满足下面可核对的信号：

| # | 信号 | 达标标准 |
|---|------|----------|
| A | 品牌区醒目 | 侧栏顶部有品牌色底 + 主标题 + 一行副标题；主色只出现在 logo 区、主按钮、看板重点数字 |
| B | 尺度加大一档 | 侧栏更宽、顶栏更高、登录卡更大、看板统计数字明显变大（见 §3 数值） |
| C | 层次更分明 | 卡片圆角/阴影比现网略加重；页面留白更足，仍是浅色工具风，**不做成深色营销站** |
| D | 经典版可回退 | 右上「切经典版」后，侧栏宽度、顶栏高度、logo 样式与改版前一致 |

**明确不做（避免预期落空）**

- 工单列表、基础数据、表单弹窗等**内容页**本期不动（壳变了、馅仍素——接受，二期再说）
- 手机 H5 / Vant **不动**
- 全站暗色主题、新组件库、改路由/菜单结构 **不做**
- **不做**顶栏毛玻璃（`backdrop-filter`）、**不做**看板发光描边（易显花、像 AI 套模板）

---

## 2. 取舍

| 项 | 决定 | 理由 |
|----|------|------|
| 技术栈 | Vue3 + Element Plus；样式优先扩 `src/styles/theme.css` 变量 | 与现网一致，易回退 |
| 业务 / 接口 / 库 | **一律不动** | 纯视觉 |
| 双主题 | **只改简约（`:root`）**；`body.theme-legacy` 保持改版前尺度与皮肤 | 验收硬要求 |
| 尺寸写在哪 | 侧栏宽、顶栏高、logo 高等用 **CSS 变量**；vue 里禁止写死会污染经典版的 px | 避免 layout 写死 `232px` 两主题一起变 |
| 渐变 | **仅** logo 品牌条 + 登录页极浅底可用；别处禁止铺渐变 | 克制、易交付 |
| 内容页 | 本期不做 | 先交付演示壳，真要「整站不简陋」另开指令 |
| H5 | 不动 | 交付节奏：管理动作先 PC |

**允许改动的文件（仅此 5 个）**

1. `frontend/src/styles/theme.css`
2. `frontend/src/views/layout/index.vue`
3. `frontend/src/views/layout/SideMenu.vue`
4. `frontend/src/views/login/index.vue`
5. `frontend/src/views/board/index.vue`

## 3. 具体改动

### 3.1 `theme.css`（主战场）

在 `:root` 增加/调整令牌（名称可微调，语义须有）：

| 变量意图 | 建议值（简约） | 经典版（`body.theme-legacy`） |
|----------|----------------|-------------------------------|
| 侧栏宽 | `232px` | 保持现网 `200px`（或等价回退） |
| 顶栏高 | `60px` | 保持现网 `52px` |
| logo 区高 | `64px`～`72px` | 与现网一致、无品牌渐变条 |
| `--app-radius` / `sm` | `14px` / `8px` | 可回退 `10px` / `6px`，或经典不强制大圆角 |
| 阴影 | 略加重，如 `0 2px 8px …`、`0 8px 24px …` | 保持现网轻阴影 |
| 品牌渐变 | 如 `--app-brand-gradient`（蓝→深蓝） | 不使用 / 置空 |
| 登录页背景 | 白→极浅蓝浅渐变 | 经典可维持现有渐变逻辑 |

同步：Element 圆角随 `--app-radius*` 走；**不要**在全局乱加主色渐变到按钮/表格。

### 3.2 框架 `views/layout/index.vue` + `SideMenu.vue`

- `el-aside` 宽度改为绑定 CSS 变量（如 `width: var(--app-aside-width)`），**禁止**模板写死 `232px`。
- logo 区（简约）：品牌渐变底 + 白字「车间管理系统」+ 浅白副标题（如「生产数字化管理平台」）。
- logo 区（经典）：无渐变条，观感与改版前一致（靠 `theme-legacy` 覆盖变量/样式）。
- 顶栏：高度走变量；底部一条细阴影即可；**不加**毛玻璃。
- 菜单项：高度约 `46px`、字号 `14px`；分组小标题可略加字间距（仅简约）。

抽屉导航（窄屏）与侧栏共用同一套 logo 样式规则。

### 3.3 登录页 `views/login/index.vue`

- 背景：品牌浅渐变（白→极浅蓝），不要深色大图。
- 卡片：宽约 `400px`，圆角约 `16px`，阴影用 `--app-shadow-lg`；标题约 `24px`。
- 控件/主按钮高度加大一档（仍用 Element，可调 size 或 CSS）。

### 3.4 车间看板 `views/board/index.vue`（深色大屏，独立于双主题）

- 背景：保留深蓝；允许一层**极淡**径向微光（可选，不明显即可）。
- 统计数字：`32px` → **`56px`**，加粗 + `font-variant-numeric: tabular-nums`；标签 `12px` → `14px`。
- 统计卡片：圆角 `12px`，padding 加大；边框用普通半透明描边即可，**禁止** box-shadow 发光晕。
- 大标题：`24px` → `32px`；进度条高 `8px` → `10px`。
- ECharts：配色沿用现有蓝/红，只调标题字号。
