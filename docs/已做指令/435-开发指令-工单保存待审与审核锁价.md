# 435-开发指令：工单保存待审与审核锁价

> 状态：已做（2026-11-03；代码已落地，现场点选验收未勾）  
> 性质：正式；改状态语义与 PC 按钮，不改价目金额算法  
> 目标：让【管理员】在【PC 工单】用【暂存 / 保存 / 审核】三档；**审核后才锁价**；未审核不可报工、不出现在报工选单；状态能区分草稿与待审核。  
> 依据：用户拍板三档 +「无审核不能报工/下拉不出/状态体现」；承接 docs/425；规范 419。  
> **覆盖说明（2026-11-12 清单 #21）**：A07「已生效仍可保存改数/交期」作废；已审核/报工中不可 Update，改内容走反审核或复制新单。

## 1. 取舍（已定）

| 项 | 决定 |
|---|---|
| 状态 | **4=草稿**（暂存）；**5=待审核**（保存，未锁价）；**0=未开始**=已审核已锁价（可报工） |
| 按钮 | 新建/草稿/待审：【暂存】【保存】【审核】；已生效(0/1)：只浏览，无保存改数（#21 覆盖原 A07） |
| 锁价时机 | 仅【审核】调用 BindAsync；暂存/保存待审不 BindAsync |
| 审核人 | 与建单同权（管理员 PC）；不做多人审批流、不做驳回专用状态（待审上可改后再审；可作废） |
| 列表/下拉 | 「全部」与报工候选：**排除 3、4、5**；PC 增加「待审核」页签与计数 |
| 历史 | 已有 0/1/2 单视为已审核；不批量改历史 |
| 反审核 | 顶栏【审核∨】→反审核：仅 status∈{0,1} 且无报工；清锁价与审核人时，退回 status=5；未审或已报工拦截（2026-11-04） |
| 不做 | H5 建单；班组长审单 |
