## 1. 为什么做

卖点、对比、话术散在文档里，出门演示要靠背。把定盘的三大优势 + 六步闭环 + 竞品对比**固化进系统**，打开即见：销售自看、演示给老板看，两用。

### 1.1 战略定位（2026-09-27 定盘；改口径先改《定价对标备忘录》§五，勿在此另起说法）

**一句话定位（演示第一句）：** 「我卖的不是黑湖旗舰版的减配版，是『车间执行层 + 金蝶集成』：老板已在用的金蝶我不重复做，只把车间最后这一公里管起来——比黑湖专业版便宜 2000 还含上门实施，比旗舰版便宜 1 万。」

| 层 | 功能 | 谁来做 | 结论 |
|---|---|---|---|
| 经营层 | 销售/采购/库存/财务 | 金蝶已有 | 你不做，对接省用户工作量 |
| 车间执行层 | 工单/派工/报工/复核/交期/计件工资 | **你** | 你的主战场，与黑湖专业版同档 |
| 部署/集成层 | 本地部署·数据不出厂·接金蝶 MCP | **你独家** | 黑湖/简道云都没有 |

**不做采购/销售/库存（2026-09-27 拍板）：** 供应链不是卖点，上了很难用起来、给用户加工作量；金蝶客户已有，重复建设。黑湖旗舰 = 专业版 + 采购/销售/质检（+PDA），咱不拼这四格。质检表述：基础不良记录有（PRD），全流程 IQC/IPQC/OQC 不做、留给金蝶/以后外挂——对外**不说"比专业版少质检"**。

## 3. 页面结构（上客户版 / 下销售版）

### A 区・客户版（默认显示，演示给老板看）

> 大字、大白话，一屏讲完。

**① 先戳三大痛点 → 我们怎么解决**



| 痛点             | 解决                 |
| -------------- | ------------------ |
| 快到交期才发现要拖      | 看板黄红预警 + 企业微信推送到手机 |
| 月底算工资拿表对、还老吵   | 工价表配一次，工资自动算、每笔可查  |
| 想知道单做到哪了，得下车间问 | 扫码报工，看板实时，坐办公室管全厂  |

**② 六步闭环（横向小图 / 流程条）**

下单出二维码 → 扫码报工 → 看板实时 → 工资自动算 → 交期自动提醒 → 派工到人 / 异常上报

**③ 三大差异点（每点一句卖点）**



1. **数据在你自己的服务器，不上公网，推送照发，不泄露**

2. **工资能按你厂规矩算**（可定制 + 可重算）—— 口播友好，A 区用这句

3. **轻量、按厂收费不按人头**，局域网就能跑

**④ 深度集成（加分项，客户版一句话）**

「我们不是封闭软件：**能对接金蝶**（排产评分、建议报价），还能接 AI 智能体**现场给你算价**—— 接口是开放的，要啥加啥。」

### A 区配图 / 图标规范（演示一屏有图有字，老板一眼看懂）



* **三痛点**：各配一个**线性图标**（如：交期→沙漏 / 闹钟；工资→计算器 / 纸币；进度→放大镜 / 车间）—— 用 Element Plus 自带图标或内联 SVG，**不依赖外部图片**（防加载慢、防断链）

* **六步闭环**：横向**流程条 + 箭头**（①…⑥ 编号小圆标），一屏横排或两行排开

* **三大差异点**：各配图标（如：锁 / 盾 = 数据不出厂；齿轮 + 勾 = 工资可定制可重算；厂牌 = 按厂收费）

* **统一风格**：全部**线性、同粗细、同圆角**；主色 2～3 个（蓝 / 绿 + 警示黄红），**不搞复杂插画、不堆渐变**

* **尺寸**：图标约 24px，痛点 / 差异点标题图标约 40px，能配一屏看清为准

* **目的**：演示时老板扫一眼图 + 字就懂，您照着图讲不卡壳
