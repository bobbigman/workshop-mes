## 行为与口径（分叉显式，禁止脑补）

* 当班组长把工序派给【班组】或【个人】（含改派）→ 派工落库成功后，同事务生成 `operation_assigned` 待发（EnqueueAssignAsync）。
* 当微信预警总开关开启 且 存在启用、事件类型 =「派工」、目标通道 = group 的规则 且 规则或全局配置了有效 Webhook 且 授权可用 → 计划任务投递，企微群收到派工通知。
* 当没有派工规则 或 总开关关闭 或 trial 试用 → 静默跳过，不生成待发，派工本身照常。
* 当取消派工（清空执行人且不选班组）→ 不触发派工通知。
* 当规则事件类型下拉无「派工」→ 记为前端开发缺口（本次已核实有「派工」）。
