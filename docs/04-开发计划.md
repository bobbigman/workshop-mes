## 三、验收要点（对应 PRD 三条硬规则）

1. 产品编号重复 → 创建被拦截并提示。
2. 非本部门人员对工序报工 → 拒绝并提示"无报工权限"。
3. 删除有关联下级的对象 → 按倒序删除，否则阻止。

## 四、风险与建议

| 风险 | 建议 |
|---|---|
| 多租户复杂度 | MVP 先固定单工厂，`factory_id` 预留 |
| 手机摄像头扫码需 HTTPS | 已实现网页摄像头扫码；生产环境须配内网 HTTPS 并真机验收（见 docs/05、docs/2E） |
| 打印兼容性 | 优先浏览器打印 + HTML 模板，稳定后再接打印插件 |
| 绩效/工资口径不清 | **已决策（docs/21）：** 砍掉绩效；只做计件/计时/固定 + 不良扣款；工价对照表 + 结算快照 |
