# 手机/PDA 报工

适用：生产人员，也供班组长指导现场操作。手册版本 1.7，更新于 2026-10-03，按当前系统界面核对。

## 登录和找到自己的工单

准备：连上工厂指定网络，拿到管理员给的系统地址、账号和密码。手机要用摄像头扫码时，地址须是管理员确认过的 **HTTPS** 地址，且手机已信任证书。

1. 浏览器打开地址，填【账号】和【密码】，点【登录】。系统不是短信验证码登录。工厂同时开有多家（2 个及以上账套）时，登录页会出现【账套 / 工厂】下拉，先选自己所在的厂再登录；只有 1 个账套时没有下拉，直接进入本厂。
2. 生产人员登录后先进入手机【工作台】：顶部【去扫码报工】、中间【我的任务】点选列表、下方快捷入口（【工单】【我的报工】，开了工资档还有【我的工资】）。有派工的任务点卡片就能报；没有任务也能点【去扫码报工】或快捷入口【工单】干活。工作台和报工页顶部还有【今日计件】卡片，实时显示你今天的件数和估算金额（含待复核+已通过，不含退回；是估算，以工资单为准）。
3. 要从工单列表找单：点快捷入口【工单】，或底部【任务】看派给你的活。按工单号或产品搜索，必要时切到【未开始】或【执行中】。核对工单号和产品，点卡片进入报工页。不要只凭名称选择，同名可能是不同产品。

做完怎么看：页面顶部显示当前工厂名，先看清在哪个厂再干活；页顶是正确的工单号和产品，确认后再选工序。不同账套（工厂）的数据互相看不到，属正常隔离。

进不去：核对地址、网络和账号。提示「账套不存在」时，重新在下拉里选自己所在的厂；手机上登录后不能切换账套，需要换厂找管理员处理。忘记密码找管理员，不要把密码发进 AI 对话或公共群。

## 我的任务（被派工了看这里）

班组长把某道工序派给你后，手机底部会出现【任务】。

1. 点底部【任务】，看到派给你的活：工单号、产品、工序、还剩多少、交期。
2. 点任意一条任务，直接进该工单的报工页，正常选工序填数量提交。
3. 报工后剩余量会减少；报完的工序仍保留在列表里，方便查看。

做完怎么看：任务卡片上的「剩余」随报工减少；工单被结束或取消后不再需要理会。

注意：没被派工不代表不能干活——工单照样能在【工单】页找到并报工，派工只是帮你把「今天要干的」挑出来。

## 用手机摄像头扫码

入口：底部【扫码】。首次进入默认摄像头待启动。

1. 点【打开摄像头扫码】，浏览器询问时允许摄像头（不要开麦克风）。
2. 把流转卡或工位工序码对准画面，识别成功后进入报工页；先核对工单号和产品。
3. 若扫的是**工序码**（管理员按工序打的标签），进入报工页后该工序会自动选好，直接填数提交即可；若扫的是普通工单码，仍需自己选工序。
4. 不允许摄像头、打不开或提示需要 HTTPS 时：改用【手动输入工单号】，或让管理员检查 HTTPS/证书。
5. 切到别的页或锁屏后摄像头会停；回来再点【打开摄像头扫码】。

做完怎么看：出现正确工单的报工页；工序码会预选工序，工单码则自己选工序。扫码本身不会自动提交报工。

注意：HTTP 地址通常无法开摄像头。系统相机扫「报工页链接」打开网页，与本页「打开摄像头」是两回事。

## 用 PDA 扫码枪，或手动输入

入口：底部【扫码】→【扫码枪模式】；或任意模式下点【手动输入工单号】。

1. PDA：点【扫码枪模式】，看到“等待扫描工单”；扫码头设成“像键盘一样输入、扫完自动回车”。
2. 扫码后进入报工页，先核对工单号、产品。扫工序码时工序会自动选好。本机记住扫码枪模式后，下次打开扫码页可直接扫。
3. 扫不出可点【手动输入工单号】，填纸上编号，点【确定】；返回后继续扫或再开摄像头（手动输入只填工单号，进页后自己选工序）。
4. 要改回手机摄像头：点【摄像头扫码】。

做完怎么看：出现正确工单的报工页；工序码预选工序，工单号则自己选。

注意：手动输入只填工单号，不要把整段网址贴进去。外部扫码工具扫到链接时可直接打开；未登录时登录成功后应回到该工单。

## 把扫码页放到手机桌面（可选）

不想每次输网址、想让工人点一下桌面图标就直接进扫码页的，可以这样加。加完点图标是全屏进扫码页，不用开浏览器找地址。这是浏览器自带的功能，不用下载安装包、不进应用商店。

先确认：手机能正常打开系统地址（就是平时扫码页那个 HTTPS 地址），并先登录一次。

### 安卓手机（华为 / 小米 / OPPO / vivo 等）

用手机**自带浏览器**或 **Chrome**（推荐，效果最好）：

1. 打开扫码页地址，例如 `https://服务器IP:端口/#/h5/scan`。
2. 点浏览器右上角【⋮】（三个点）菜单。
3. 选【添加到主屏幕】或【安装应用】（不同手机叫法略不同，都在这个菜单里）。
4. 桌面出现【小工单】图标（蓝底白框）。点开就是全屏，没有地址栏。

![图：安卓浏览器菜单示意。点右上角三个点，选「添加到主屏幕」或「安装应用」。](/manual/pwa-android-add.png)

用**百度浏览器**：菜单 →【添加到桌面】，会生成一个快捷方式。点开带地址栏、不算全屏，但扫码能正常用。

### iPhone

必须用系统自带 **Safari** 浏览器（微信、百度里加不了）：

1. 用 Safari 打开扫码页地址，先登录一次。
2. 点底部【分享】按钮（方框里一个朝上的箭头）。
3. 往下滑，选【添加到主屏幕】。
4. 桌面出现【小工单】图标，点开全屏。

![图：iPhone Safari 分享面板示意。点分享，再选「添加到主屏幕」。](/manual/pwa-ios-add.png)

### 装完怎么确认装对了

- 桌面图标叫【小工单】，图案是蓝底白框。
- 点开没有地址栏、没有刷新按钮，直接落在扫码页。
- 点【打开摄像头扫码】能正常出画面。

![图：装好后桌面应出现「小工单」图标（示意）。](/manual/pwa-homescreen.png)

### 加不上怎么办

- 菜单里找不到【添加到主屏幕】：一般是页面没加载全（证书没信任、或访问的是 HTTP）。把地址换成管理员给的 HTTPS 地址再试。
- 想要最稳的全屏、绕开个别浏览器的问题：用手机自带浏览器或 Chrome 添加。

> 上面三张菜单 / 桌面图是**示意**，各品牌浏览器菜单文字可能略有不同，找到意思相同的那一项即可。

## 选工序、填本次数量

入口：打开工单后的报工页。只填写实际做过的活。

1. 在【工序】选当前这道，例如“裁切”。上方【计划、已完成、剩余可报】随工序变化。
2. 【本次良品】填这一批合格件数。前一批报 20，这一批做 15，就填 15，不是 35。
3. 【不良品】填本批不合格数，没有填 0；大于 0 时选【不良品原因】。
4. 需要记录时长就填小时、分钟，分钟为 0～59，单次总时长不超过 24 小时。
5. 再核对工单、工序、良品、不良后提交。

例子：本批共做 20 件，18 件合格、2 件尺寸不合格，本次良品填 18，不良品填 2，原因选“尺寸不合格”。

做完怎么看：数字与本批实物一致，良品不超过剩余可报。不良数不占良品上限，但仍必须如实填。

注意：【报全部剩余】只把剩余数填入输入框，不判断实际完成量；只有确实全做完才用。已报满时不要换工序凑数。报工页顶部【今日计件】卡片会随提交即时刷新（今日件数与金额估算，含待复核+已通过，以工资单为准）。

## 提交后怎么确认成功

1. 本次结束点【提交报工】，显示“报工成功”后回扫码页。
2. 同单同工序连续报下一批，点【继续报工】；成功后留在原页，数量和时长清空，进度刷新。
3. 再打开同单选同工序，可核对已完成和剩余可报。多人同时报工时，进度也包含其他人的数量。

做完怎么看：“报工成功”说明已提交。工人提交需班组长或管理员复核，通过后才进入生产报表。

注意：成功后不要把同批再提交。断网、报错或不确定结果时，先让班组长按工单、姓名、时间查记录，确认没有保存后再处理。

## 我的工资（看这个月挣了多少）

谁来做：工人自己（开了计件工资档才有入口）。入口：手机【工作台】或【我的报工】里的【我的工资】。

1. 打开默认看**本月**累计，右上可切【天 / 周 / 月】。
2. 列表按报工记录列出：工序、数量、单价、金额、复核状态、是否已结算。
3. 金额口径：**已结算**的显示工资单定下的固化金额；**未结算但已复核**的显示报工时的估算金额；**待复核 / 被退回**的只显示并标状态，不并入上面的累计数。
4. 本厂配了颜色 / 规格尺码字段，明细还会多出颜色、尺码两列；没有就是普通车间。

做完怎么看：累计金额就是「这段时间大概能拿多少」——**是估算，以确认后的工资单为准**。月底对不上先看有没有待复核或退回的报工。

注意：没有计件工资档就没有【我的工资】入口；这不是坏了，是老板还没开这个功能。

## 现场异常怎么上报

入口：底部【异常】。遇到设备故障、缺料或质量问题，主动上报，不要等系统猜。

1. 选类型：【设备故障】【物料短缺】【质量异常】三选一。
2. 写清楚问题描述；需要时可选填工单号、拍一张照片。
3. 点【提交上报】，看到“上报成功”。

做完怎么看：班组长或管理员在电脑【异常处理】能看到；车间看板会出现红色滚动提示，处理恢复后消失。

注意：试用期不发企业微信，靠看板和电脑列表通知负责人。

## 班组长/管理员：手机端报工复核

入口：底部【复核】（仅班组长、管理员可见；普通工人没有此 tab）。企业档以下账套不显示。

1. 点【复核】，默认只看待复核列表：工单号、产品、工序、工人、良品/不良、报工时间。
2. 单条：点【通过】直接通过；点【退回】必须填写原因（1～256 字）。
3. 多条：勾选待复核卡片，点【批量通过】，按实际通过条数提示。
4. 可用顶部筛选切换「已通过 / 已退回」，或按工单号、工人姓名查询。

做完怎么看：通过后该条进生产报表入账；退回后进度回落、报表仍不含。班组长只审本组，管理员审全厂。

注意：工人拿链接直达复核页会跳回任务页。电脑端【报工复核】仍可用，口径与手机一致。

## 报错了、无权限或被退回怎么办

报错数量（还没复核的）：在【我的报工】找到那条**待复核**记录，点【撤回 / 修改】，改成正确的数量、不良、原因、时长，提交后仍为待复核；每次修改都有记录可查（原值 → 新值、谁改的、什么时间）。**已通过**的要管理员先退回再改，**已结算**的不能改。不要报负数或再报一条抵消。

无报工权限：管理员检查你是否在正确部门、工序是否允许该部门报工。班组长报工也受部门限制。

已结束或已取消：管理员核对后，确实要继续生产才撤回或恢复；工人不要改报到别单。

被退回：先问清原因，由管理员核对修改原记录，再复核。退回数量暂不计进度，变小不表示记录丢失。

做完怎么看：管理员查到并处理原记录，数量和复核状态正确。需要步骤可点底部【帮助】。
