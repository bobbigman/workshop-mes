# 78 · 使用手册 — 给老沈的「建账套」傻瓜步骤

> 适用：老沈（伙伴）在系统里新建一家工厂/账套，用来给新客户开试用环境。
> 依据：后端 `POST /api/factories`（管理员建厂，自动灌演示数据 + admin 账号）；`GET /api/factories`（登录页下拉）。
> 现状核对日期：2026-09-27

## 先说清一件要紧事（免得找不着按钮干着急）

**目前系统里没有「新建账套」的页面按钮**，管理端也没有工厂/账套管理页。
所以"后台建账套"的真实操作 = 给接口发一条"创建"命令。老沈您照着下面做，一样能建，效果和"点按钮"完全相同。

---

## 老沈版 · 三步建账套（人话版）

**前提**：能打开系统的网址（内网地址，如 `http://localhost:8080`），能看到登录页。

### 第 1 步 先拿一张"管理员通行证"（token）
1. 用**现有任一账套**的管理员账号登录（账号 admin，密码问老胡要）。
2. 按 `F12` 打开浏览器"开发者工具"，切到 **控制台 / Console** 标签。
3. 在里面粘这一行、回车，会自动取出登录后存好的通行证：
   ```
   copy((localStorage.getItem('token')||'').replace(/"/g,''))
   ```
   出现 `copied to clipboard` 就行——通行证已经复制到你剪贴板。

### 第 2 步 发一条"建账套"命令
在**同一个控制台**里粘下面这行，把两个占位改掉后回车：
- `CJ001` → 换成一个**没被用过的新厂代码**（字母+数字，别跟现有厂重复）
- `厨具五金厂` → 换成你要建的厂名

```
const t=localStorage.getItem('token');fetch('/api/factories',{method:'POST',headers:{'Content-Type':'application/json','Authorization':'Bearer '+JSON.parse(t).token},body:JSON.stringify({FactoryCode:'CJ001',FactoryName:'厨具五金厂'})}).then(r=>r.json()).then(console.log)
```

> 上面这行已经替你自动拿 token，你只改 `CJ001` 和厂名两处即可，**不用手动粘贴通行证**。

### 第 3 步 看结果
- **成功**：控制台打印 `code:1`，账套建好了，自动带 admin 账号 + 一套演示数据。
- **失败**：最常见是 `code≠1` 且提示"账套代码已存在，请换一个"——换一个新厂代码再跑一次第 2 步。
- 建完**刷新登录页**，"账套 / 工厂"下拉里就多出这家厂；用 `admin` / `Admin123` 登录进去，就是这家新厂的完整后台。

## 一键工具（已就绪，老沈首选这个）

**项目根目录下有 `一键新建账套.bat`**，老沈以后双击它就行，全程照着提示敲，不用碰任何代码：
双击 → 填后端地址（回车用默认）→ 填现有账套厂代码/管理员账号/密码 → 填新厂代码+厂名 → 确认 → 打印成功或失败原因。

> 工具已在本机后端实测验证过"成功/失败"两条返回路径（成功 code=0、失败 code=1 带原因），不污染数据。

---

## 附 · 给老沈记住的三条底线
1. 厂代码全局唯一，重复就建不上——换一个就行，不是系统坏了。
2. 建出来的账套自带 admin，但**演示数据要按客户情况再改**（部门、工序、产品、工单都可在新厂后台配）。
3. 建账套是"开通"动作，不常做；日常用厂是**登录选下拉**，跟建厂是两回事。
