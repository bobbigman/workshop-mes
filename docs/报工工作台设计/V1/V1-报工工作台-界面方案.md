# 报工工作台 · 界面方案 V1（对标黑湖小工单）

> 性质：移动端（H5/手机）界面设计方案 + 高保真效果模拟
> 日期：2026-10-23
> 状态：仅出模拟效果，未出实施指令；V2 对比时在同目录 `V2\` 下存放

## 一、背景与目标

现有「报工工作台」首页信息空、任务藏、看板深。本次对标黑湖小工单重新规划手机端工作台，
核心目标：**任务驱动 + 扫码C位 + 今日概要有获得感 + 看板/报表提上首页**。

## 二、对标结论（黑湖手机端 vs 电脑端）

- 黑湖手机端＝**干活的工具**：扫码报工、接收/查看派工任务、上报异常、当日计件工资预估、进度看板、移动审批、领料确认。
- 黑湖电脑端＝**管活的工具**：创建工单、派工排产、配置工艺路线、批量导入、基础数据、复杂报表（工资报表明细/产量统计/不良品/在制品/打卡）、车间大屏看板、系统配置。
- 黑湖**没有「工作台首页」聚合**：工人打开手机看到的是「工单/任务列表 + 扫码报工」，不是把扫码+任务+常用功能+今日良品+计件收入聚合的首页。

→ 结论：微聚的「报工工作台」聚合形态是黑湖没有的差异化，保留；短板在「信息空、任务不具体、看板报表藏太深」。

## 三、新版设计结构（V1）

### 自上而下

| 区块 | 内容 | 对标依据 |
|---|---|---|
| 顶部 | 企业名 / 用户名 / 日期星期问候 | 保留 |
| Hero | **大按钮「扫码报工」** + 副文案 | 黑湖最高频动作，保持差异化入口 |
| 今日概况 | 今日良品 / 今日不良 / 预计计件收入 三格 | 黑湖只给计件预估，微聚多了良品/不良汇总 |
| 我的任务 | 待报工 N 项 / 待加工 N 项；工单卡片（工单号/产品/工序/计划数/进度条/去报工按钮） | 学黑湖任务驱动，第一屏看今天干什么 |
| 常用功能 | 九宫格：工单 / 我的工资 / 上报异常 / **生产报表 / 执行监控 / 车间看板** / 帮助 / 更多功能 | 把看板/报表提上首页，不再藏"更多功能" |
| 底部导航 | 工作台 / 任务 / 我的报工 | 保留 |

### 改了什么（相对现状）

1. 扫码报工放大成首屏大按钮（原已是大按钮，保留并强化 C 位）。
2. 今日概况升级：从「全 0 空数」改为「良品+不良+计件收入」三格，工人有获得感。
3. 我的任务从「一行文字」升级为「待办汇总 + 工单卡片」，任务驱动。
4. 生产报表 / 执行监控 / 车间看板从"更多功能"里提上首页九宫格。
5. 底部导航不变：工作台 / 任务 / 我的报工。

## 五、待定/占位说明

- 今日良品/不良/计件收入的数据口径与刷新时机待定（报工提交后实时刷新 vs 定时刷新）。
- 工单卡片显示规则（几条、排序）待定。
- 看板/报表入口是否按角色显示（工人 vs 班组长）待定。

## 六、对比基准（给 V2 用）

V2 迭代时在同目录新建 `V2\`，对比维度建议固定为：
1. 扫码入口是否首屏 C 位
2. 今日概要有无获得感（是否空数）
3. 任务是否具体（卡片 vs 一行文字）
4. 看板/报表是否提上首页
5. 底部导航与信息层级
