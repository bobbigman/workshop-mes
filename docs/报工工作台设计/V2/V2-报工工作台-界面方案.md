## 二、278 方案要点（V2 依据）

- 布局顺序：紧凑顶栏 → 扫码主卡 → 两张成果卡及口径 → 任务摘要 → 两排四列常用功能 → 原底栏。
- 常用功能 8 入口及配色：
  1. 工单·淡蓝　2. 我的工资·淡绿　3. 上报异常·淡橙　4. 生产报表·淡紫
  5. 执行监控·淡青　6. 车间看板·淡黄　7. 帮助·淡粉　8. 更多功能·淡灰蓝
- 权限显式条件：`canWage` 控制我的工资/今日成果；`canScan` 控制扫码卡；视角"仅看我的任务"隐藏工单/生产报表/执行监控/车间看板；管理角色在更多功能内见【管理操作】（管理员4项/班组长2项/工人无）。
- 不改表、不改后端、不改接口契约；今日成果数字来源 `getTodayPieceSummary()` 口径不变。
