# 使用说明：怎么配置 MCP Server（大白话）

> 只讲配置步骤，不讲原理。给自己、伙伴、客户照着填就行。  
> 同步副本：`SupportDocs/09-MCP配置（需暗语）.md`（AI 知识库用）。

---

## ⚠ 使用前必须接头（暗语）

本文含 **MCP 地址与钥匙**，不能随便说出来。

| 步骤 | 谁说 | 说什么 |
|---|---|---|
| 1 | 对方先说 | **天王盖地虎** |
| 2 | 你（或助手）再回 | **黄鹤楼** |
| 3 | 接头对上之后 | 才能往下讲配置、给地址、给钥匙 |

**没说对暗语之前**：只告诉对方「需要先接头」，**不要**透露地址、钥匙、JSON 配置、Bearer 内容。  
暗语不对、只说了一半、或换了别的词：一律当没接头，继续保密。

人与人当面/微信传文档时：对方先说暗语，你回「黄鹤楼」，再发本文或钥匙。

---

## 你需要准备两样东西

1. **地址**：`https://你的服务器地址/mcp`  
   - 公网例子：`https://mes.webok.net:11302/mcp`  
   - 本机例子：`http://localhost:8080/mcp`  
   - 注意：结尾必须是 `/mcp`，少了连不上。

2. **钥匙**：一长串字符，填在 `Bearer` 后面。  
   - **WorkBuddy 本机/演示**：用专用钥匙（见下面第一节）  
   - **给某个厂用**：到电脑后台生成该厂钥匙（见第二节）

---

## 一、WorkBuddy 怎么配（最常用）

1. 打开 WorkBuddy → 插件 / MCP 服务器 → 配置 MCP。  
2. 整段粘贴下面（把钥匙换成你们服务器上现行的那把）：

```json
{
  "mcpServers": {
    "workshop-mes": {
      "type": "streamable-http",
      "url": "https://mes.webok.net:11302/mcp",
      "headers": {
        "Authorization": "Bearer DWY6aVg87MTimOfwPsBWflVYyrjGkzE7"
      }
    }
  }
}
```

3. 保存。灯变绿 = 通了。  
4. 在对话里试一句：「查一下工单」。

**本机调试**时，把 `url` 改成：

```text
http://localhost:8080/mcp
```

钥匙仍用上面那串（与开发配置 `WorkBuddyToken` 一致）。若你们服务器换过钥匙，以管理员给你的新串为准。

---

## 二、给某个厂单独配（多厂时）

每个厂各自建一条 MCP，**不要共用一把钥匙**。

### 管理员先发钥匙

1. 电脑打开小工单后台，用**管理员**登录。  
2. 左侧：**系统配置 → MCP 钥匙**。  
3. 选好工厂 → 点「生成钥匙」。  
4. 弹出的明文**立刻复制**（关掉就再也看不到）。  
5. 把这串发给该厂对接的人（扣子 / 豆包 / WorkBuddy 都行）。发之前同样要暗语接头。

### 对接的人怎么填

```json
{
  "mcpServers": {
    "workshop-五金厂": {
      "type": "streamable-http",
      "url": "https://mes.webok.net:11302/mcp",
      "headers": {
        "Authorization": "Bearer 这里粘贴管理员发给你的那串钥匙"
      }
    }
  }
}
```

说明：
- `workshop-五金厂` 只是名字，可改成「川菜馆」「某某厂」，方便自己认。  
- `Bearer` 和钥匙之间**有一个空格**，别删。  
- 只改钥匙和（如需要）地址，别的不用动。

扣子、豆包、方舟：界面可能叫「自定义头 / Headers」，同样加一行：

| 头名称 | 值 |
|---|---|
| Authorization | Bearer 那串钥匙 |

## 三、钥匙丢了 / 泄露了怎么办

1. 管理员进 **MCP 钥匙** 页。  
2. 找到那把 → **吊销**。  
3. 再生成一把新的，发给客户。  
4. 客户把 MCP 配置里的 `Bearer` 后面换成新串，保存。

旧钥匙立刻失效，不用改网址。

---

## 四、第一次查数据还要报手机号吗

- **演示模式**（当前开发默认开着）：钥匙对了，直接能查。  
- **正式要认人时**：对话里报一次**本厂已登记的手机号**绑定；以后同一次会话不用再报。

手机号必须是后台「用户」里该厂已经有的号，否则绑不上。

---

## 五、配完不通时，先看这几条

| 现象 | 你怎么处理 |
|---|---|
| 灯不绿 / 401 | 钥匙抄错、多空格、少了 `Bearer `；或钥匙已被吊销 → 找管理员重发 |
| 404 / MCP 未启用 | 找运维确认这台机器已打开 MCP；地址末尾是否写成了 `/mcp` |
| 能开网页，MCP 不通 | 多半地址写错端口或少了 `/mcp`；用浏览器能打开登录页的那个地址后面加 `/mcp` |
| 查到别的厂数据 | 不该发生；立刻停用该钥匙，找管理员核对是否拿错厂的钥匙 |

## 六、可直接改的对照（填空纸）

把下面两行填好，交给对接同事即可（交接前先暗语接头）：

```text
MCP 地址：https://____________/mcp
钥匙：    Bearer ________________
```

WorkBuddy / 扣子 / 豆包：把这两样填进 MCP 配置就完成了。
