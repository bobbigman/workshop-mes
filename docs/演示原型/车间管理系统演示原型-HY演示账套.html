行号品名/规格取价条件(字段+规则)数量范围(从~到)单价(元)单位收费组
说明：产品级行＝该产品直接一价（优先）；模板行＝按属性条件+数量区间兜底。收费组单选互斥、命中任一取价一次、不同组可叠加。关键属性匹配不到 → 缺价提示，不当 0。

取价机制说明

  1. 报工时，若此价目表针对某产品，直接按该产品行取价（优先）。
  2. 若为通用模板（或该产品无产品级行），按"产品固有属性＋工单-工序工艺属性"合并匹配模板行的条件+数量区间（兜底）。
  3. 丝印、内标、外标、特殊伞面等收费组：单选互斥、命中任一取价一次、不累计，不同组可叠加。
  4. 关键属性匹配不到 → 提示缺价，不当 0。
