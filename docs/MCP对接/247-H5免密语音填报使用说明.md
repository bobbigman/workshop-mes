# H5免密语音填报（历史试用说明）

> 2026-10-18：默认语音入口已按250收起，当前请按250-H5简化报工使用说明操作。以下为历史试用记录，不代表当前页面。

1. 打开原个人免密报工链接，或扫描管理员发给本人的个人码。登录尚有效时直接进入，不必重复报姓名或手机号。
2. 有派工任务时，工作台或“我的任务”显示真实序号。点语音填报输入框，使用手机键盘的麦克风说“第一项五十件”，点击“识别并填入”。
3. 扫工单码进入报工页时，可以说“包装五十件”；已选工序时可以只说“五十件”。同名工序按页面序号选择；语音序号与当前工序下拉列表前的序号一致。
4. 检查带入的工序和良品数，点击“提交报工”，核对确认框的工单、工序、良品、不良数后“确认提交”。只有服务器返回成功才算报工完成。原“继续报工”也有同样确认。
5. 可以一段话说“包装五十件，改成六十件”。不良、多人、时长或其他复杂报工仍使用原表单；语音不会清除已有不良数量。

微信内置浏览器首版使用手机键盘语音，不是接收微信聊天语音消息。支持网页语音识别的HTTPS浏览器会额外显示“点击说话”，识别失败可改用键盘语音或手输。浏览器识别可能经其联网服务处理；本系统不新增录音上传服务，不保存识别文本。

没有派工任务时仍可扫码报工，或按工厂现有权限使用工单入口；加载失败会明确提示，不能当作没有任务。个人码仅由本人保管；首次登录/会话过期遵循原有登录规则。

## 首版范围与现场验收

已完成页面与解析检查、生产构建；手机键盘麦克风、浏览器录音权限与车间实际噪音须真机验证。没有替用户提交真实报工。本次不改变企微聊天MCP的身份验证方式。

## 企业微信机器人如何引导（248）

默认提供两种入口：点击本人专属免密链接，或扫描管理员提供的本人个人登录码。已有个人码即可直接扫码；没有个人码请管理员提供。进入H5后再选择任务或扫工单码；个人码与工单码不是同一个用途。只有明确要求在聊天里直接报工才走聊天身份授权，不让普通H5用户回传8位验证码。

企微发布用：248-企微免密扫码优先角色设定可粘贴.txt。须刷新插件工具并发布角色设定，本地修改不会自动更新企微。

## 本人入口与首次关联（249）

已有个人码/原免密链接无需重新验证；已登录H5可直接用报工首页。机器人首次没有可靠身份时，不按姓名或“确认是我”新发个人链接，改为普通首页/本人码指引。需要新领个人码请管理员核对后在用户管理发放；企微可信身份关联经管理员一次核验后，才可由机器人自动取本人的入口。临时域名不传平台身份时仍可用已有H5会话或本人码，无须回传8位验证码。新版人设发布用249-企微本人入口与首次关联角色设定可粘贴.txt。
