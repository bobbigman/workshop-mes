# H5简化报工

1. 用本人原免密链接、个人登录码或已有H5登录进入工作台。
2. 在“我的任务”直接点要报的任务，自动带入对应工单和工序；也可扫描工单/工序码进入。
3. 点“良品数量”，弹出页面大号数字键盘。输入本次实际完成数，按删除键修正，点“完成”收起键盘。不自动填剩余量。
4. 点“提交报工”，核对工单、工序、良品与不良数量，再点“确认提交”。点取消不会报工。需要连续报同一道工序时用“继续报工”，成功后清空本次数量。
5. 多人、不良、时长等仍在原表单填写，原权限和上游/数量校验保留。任务已变或无权报工时重新选择，不默认替换其他工序。

工作台、我的任务、报工页已收起默认语音输入区域，不需要寻找键盘麦克风。语音组件和解析源码仅保留作后续评估，不承诺微信内网页录音功能。

机器人发布人设：250-企微简化报工角色设定可粘贴.txt。已有免密与首次管理员关联规则仍按249；本地改动不会自动发布企微角色设定。
