## 0. 先定三件事（扒之前必须明确，避免扒错方向）

1. **产品线范围**：晴雨伞具体做哪几款？（建议先做一款主打 + 1~2 款衍生，别贪多）
   - 结构：三折伞 / 直柄伞 / 全自动伞 / 太阳伞（沙滩伞）
   - 伞径规格：常见 55cm / 58cm / 60cm / 65cm / 70cm（八骨/十骨）
   - 伞骨材料：铁骨 / 玻纤骨 / 碳纤维骨 / 铝合金骨
   - 伞面材料：210T 涤纶 / 碰击布 / 黑胶涂层（晴雨两用遮阳）
2. **产品编号规则**：沿用系统「产品编号唯一」硬规则，如 `HY-001`「晴雨伞·三折·55cm 黑胶」。
3. **工艺路线形态**：走一条完整工序链（每款一条路线），还是多工序多分支。
