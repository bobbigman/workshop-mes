## 一、服装能力配置（102 字段底座）

> 演示库现在是「桌号/辣度」，没有 `color`/`spec`。要验服装链路，先加这两个字段。

1. 左侧 **系统配置 → 自定义字段**
2. 归属选 **工单**
3. **+ 添加字段**
   - 字段名称：`颜色`
   - 字段编码：`color`（必填这个，不能只起中文名）
   - 类型：单选或文本均可；单选则加选项如黑/白/红
   - **在工单列表显示**：建议打开
   - 点 **保存**
4. 再 **+ 添加字段**
   - 名称：`规格/尺码`，编码：`spec`，类型文本（或单选 M/L/XL）
   - 列表显示建议打开 → **保存**
5. （可选）**工单 → 打印设置**：勾选这两个自定义字段，确认标签能打出色码

## 二、开单拆色码（业务用法）

1. **基础数据 → 产品定义**：确认「一个款」只有一条产品（编号唯一），例如一个 `HG-001`
2. **生产管理 → 工单 → 新建**（或复制）
   - 同一产品开多张工单（例如黑 M、黑 L 各一张）
   - 每张填：**颜色**、**规格/尺码**（一张工单只对应一个色码）
   - **保存**
3. 工单列表：应能看到颜色/规格列；可用自定义字段筛一次（当前仍是单字段筛，双条件靠报表）

## 三、报工 + 色码产量（102）

## 四、工资链路（103）

### PC 老板侧

1. **报表 → 工资报表**
   - 填周期（月 `yyyy-MM`）→ **生成工资单** → 需要的话 **确认**
2. **报表 → 工资色码汇总**
   - 同一周期 → **查询**
   - 应能按「款 + 色 + 规格」看到数量、金额
   - 点 **导出 CSV**，用 Excel 打开，列应有：产品编号、产品名称、颜色、规格、数量、金额、报工次数
3. 再回 **工资报表**：列表/明细抽屉应与以前一样（确认没被这份新页带歪）

### 工人手机 H5

1. 手机或浏览器打开 H5 工单页（`#/h5/orders`），用 **zhangchu** 登录  
   （需企业档及以上，有计件工资 PieceWage；无档则看不到「我的工资」按钮）
2. 点顶栏 **我的工资**（在「我的报工」旁边）
3. 切换 **今天 / 本周 / 本月**，可改日期 → 看合计
4. **要点**：
   - 已复核：计入合计（已结算用固化金额，未结算用快照）
   - 待复核/退回：有记录、标状态、**不进合计**
   - 有 color/spec 时明细能看到色/码
