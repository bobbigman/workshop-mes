## 三、销售话术（对客户不提竞品名）

### 工人

- 派工后，手机只看自己的活；一道活多人干，可以分摊报工。
- 报错了手机能撤回改，改完留痕，账不乱。
- 今天干多少、挣多少，实时看得见。

### 班长

- 手机就能派工，人到单到，不用回电脑；限本组。
- 多人工序两种拆：平均，或按工时。
- 不良集中在哪道工序、什么原因，一眼看清，好去查设备/查人。

### 老板

- 计件工资自动算、白纸黑字有据；调工价批量重算，多人一次改，不用逐个点。
- 工厂可开「只看我的任务」：默认全车间可见可报，按厂选。
- 工资单只算计件；保底、加班、考勤归人事。

### 边界

- 工资单不算手工发薪项（保底/加班/考勤归人事）。
- 不良品三表口径：含待复核+已通过、不含退回。
- 班组长手机派工限本组。
- 未审核报工才允许手机撤回改；改完留痕。
